## Before getting started
During frontend development, you sometimes need temporary images before the server is ready.
An API that returns random images is convenient in these situations.
In this post, I will introduce the random-image APIs I often use.

## via.placeHolder
via.placeholder is an API that provides blank gray placeholder images.
It is very simple to use: Specify the image dimensions.
Unfortunately, its official website appears to have disappeared, so an exact specification no longer seems to be available.
<Img src="https://via.placeholder.com/450x120" width="450" alt="https://via.placeholder.com/450x120" />

## loremflickr
loremflickr is an API that provides random cat images.
See the official site for detailed usage.
[loremflickr](https://loremflickr.com)
1. Append the width, height, and a keyword to search for an image.
	`https://loremflickr.com/320/240/paris`
2. Supply a random seed number to retrieve a random image.
	`https://loremflickr.com/320/240?random=1`
