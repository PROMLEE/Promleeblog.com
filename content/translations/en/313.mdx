## Before We Begin
Let's set up a Vue.js 3 development environment. Vue is a progressive framework for building user interfaces. Vue 3 improved performance and made development more convenient compared with earlier versions. We'll use *Vite* to create a project and then look at Vue's *single-file components (SFCs)*.

## Create a Vue 3 Project with Vite
Vue projects were often created with *Vue CLI*. *Vite* is now a common choice for setting up and running a project quickly with less overhead.

### What Is Vite?
Vite is a frontend development tool. Unlike traditional bundler-based setups such as Webpack, it uses native ES modules to serve source code during development, so the dev server starts quickly. It often takes less than a second to start, and you can get to work without a complex Webpack configuration.

### Create the Project
Install *Node.js* and a package manager such as *npm* or *Yarn*. npm normally comes with Node.js. Open a terminal, Command Prompt, or PowerShell, and run the command below.
```bash
npm create vite@latest
```
Vite will prompt you for a few choices.
1. At `project name:`, enter a name such as `my-vue-app`.
2. At `Select a framework:`, use the arrow keys to select `Vue` and press Enter.
3. At `Select a variant:`, choose `JavaScript` or `TypeScript`. For this guide, choose `JavaScript`.

Vite creates the project folder and starter files. Open the new folder and install the dependencies.
```bash
cd my-vue-app
npm install
```
The `npm install` command downloads and installs the packages the project needs. When it finishes, start the development server.
```bash
npm run dev
```
The terminal will show an address such as `http://localhost:5173`. Open it in your browser to see the Vue starter page, with the Vue logo and a “You did it!” message in the template shown here.

## Understand Single-File Components (.vue Files)
One of Vue's distinctive features is the `.vue` file, called a *single-file component* or *SFC*. Each `.vue` file acts as a self-contained component, like a LEGO brick. It can hold HTML, JavaScript, and CSS together, making related code easier to manage.

### Basic SFC Structure
Open `src/components/HelloWorld.vue` in the generated project. You'll see a structure like this.

```html
<script setup>
// JavaScript 로직이 들어가는 부분
// 컴포넌트의 데이터, 함수 등을 정의합니다.
import { ref } from 'vue'

defineProps({
  msg: String,
})

const count = ref(0)
</script>

<template>
  <h1>{{ msg }}</h1>

  <div class="card">
    <button type="button" @click="count++">count is {{ count }}</button>
  </div>

  <p>
    Edit
    <code>components/HelloWorld.vue</code> to test HMR
  </p>
</template>

<style scoped>
/* CSS 스타일이 들어가는 부분 */
/* `scoped` 속성을 사용하면 이 스타일은 현재 컴포넌트에만 적용됩니다. */
.read-the-docs {
  color: #888;
}
</style>
```

<br />
#### `<template>`
This section contains the component's *HTML structure*. Put the text, buttons, images, and other content you want to show here. Vue uses syntax such as `{{ }}` in the `template` to display data on the screen.

#### `<script setup>`
This section contains the component's *JavaScript logic*. Declare state, write functions that update data, and import other components here. Vue 3's `setup` attribute makes component logic more concise. With `setup`, the code runs when each component instance is created, so you can declare reactive data and define functions there.

#### `<style scoped>`
This section contains the component's *CSS*. The `scoped` attribute matters here. With `scoped` on the `<style>` tag, Vue limits those rules to the *current component*. This helps you keep its styles separate and avoid conflicts with other components or global styles.

### Benefits of SFCs
- **Readability** — Keeping HTML, JavaScript, and CSS together makes it easier to understand and edit a component.
- **Maintainability** — A separate file for each component lets you organize and maintain code by feature.
- **Reusability** — Import a component wherever you need it and reuse the work you've already done.
