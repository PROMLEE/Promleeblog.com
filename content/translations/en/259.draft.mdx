## Algorithm categories
Graph theory, graph traversal, BFS, DFS.

## Problem description
Cabbages are planted in a field with width M and height N.
Each cabbage occupies a 1 × 1 cell, and cells without a cabbage are marked 0.
Cells containing a cabbage are marked 1.
You want to place cabbage worms in the field to protect the cabbages from pests.
A single worm can care for all adjacent cabbages in its group.
Write a program to find the minimum number of worms required.
<Img src="/250506-145917.webp" width={300} alt="#1012 Organic Cabbage"/>
### Input
The first line gives the number of test cases T.
For each case, the first line gives the field's width M, height N, and number of planted cabbage positions K, in that order.
The next K lines give the cabbage positions.
Each position is (x, y), where x is the horizontal coordinate and y is the vertical coordinate.
(0 ≤ x < M, 0 ≤ y < N)

### Output
For each test case, print the minimum number of cabbage worms.

## Solution
1. Create a two-dimensional array from the input field information.
2. Mark each cabbage position with ground[y][x] = 1.
3. Traverse the entire field. Whenever an unvisited cabbage is found, use BFS to explore all connected cabbages.
4. Each new BFS starts an independent group, so increment the worm count by 1.
5. After exploring all groups, print the worm count, count.

## Code — Python
```python
import sys
from collections import deque

sys.setrecursionlimit(10000)  # DFS 사용 시 재귀 제한 증가 (예방 차원)

T = int(sys.stdin.readline())  # 테스트 케이스 수
dx = [0, 0, 1, -1]  # 좌우
dy = [1, -1, 0, 0]  # 상하

for _ in range(T):
    M, N, K = map(int, sys.stdin.readline().split())  # 가로(M), 세로(N), 배추 위치 수(K)
    ground = [[0] * M for _ in range(N)]  # 배추밭 초기화 (세로 x 가로)
    visited = [[False] * M for _ in range(N)]  # 방문 체크 배열

    for _ in range(K):  # 배추 위치 표시
        x, y = map(int, sys.stdin.readline().split())
        ground[y][x] = 1

    # BFS로 연결된 배추 그룹 탐색
    def bfs(y, x):
        queue = deque()
        queue.append((y, x))
        visited[y][x] = True
        while queue:
            cy, cx = queue.popleft()
            for d in range(4):
                ny, nx = cy + dy[d], cx + dx[d]
                if 0 <= ny < N and 0 <= nx < M:
                    if not visited[ny][nx] and ground[ny][nx] == 1:
                        visited[ny][nx] = True
                        queue.append((ny, nx))

    count = 0  # 지렁이 수
    for i in range(N):
        for j in range(M):
            if not visited[i][j] and ground[i][j] == 1:
                bfs(i, j)
                count += 1  # 새로운 연결 그룹 발견 시 증가

    print(count)
```

## Key points
### Graph traversal
- Use breadth-first search (BFS) or depth-first search (DFS) to explore connected cabbages.
- BFS uses a queue; DFS can use recursion or a stack.
### Time complexity
Input size: $M x N <= 50 x 50 = 2500, K <= 2500$
Worst case: All 2,500 cabbages are isolated → BFS is started O(K) times.
Work inside BFS: Each cell checks at most four neighbors → O(K × 4) = O(K).
Total time complexity: O(K).
