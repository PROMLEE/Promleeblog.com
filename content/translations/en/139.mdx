## Before We Begin

> This guide was written for Flutter 3.24.

It assumes your Flutter app is already connected to a Firebase project. If you need to create one, see [Register a Flutter app with Firebase](/blog/post/134-flutter-firebase-apps).

### What Is FCM?

<Img src="https://firebase.google.com/static/docs/cloud-messaging/images/diagram-FCM.png?hl=ko" width={500} alt="FCM architecture overview — source: https://firebase.google.com/docs/cloud-messaging/fcm-architecture"/>

Firebase Cloud Messaging (FCM) is a cross-platform messaging service that reliably delivers messages at no cost. An FCM implementation has two main parts.

1. A trusted environment, such as Cloud Functions for Firebase or an app server, that creates, targets, and sends messages.
2. An Apple, Android, or web (JavaScript) client that receives messages through its platform's transport service.

The first part is typically your backend. The second is your Flutter app. This guide focuses on the Flutter side: obtaining an FCM token and receiving push notifications.

## 1. Set Up iOS

> You need an Apple Developer account. If you don't have one, [join Apple Developer](https://developer.apple.com/) or skip this section and continue with Android.

## 3. Write the Flutter Code to Receive Push Notifications

### 3.1. Install firebase_messaging

```bash
flutter pub add firebase_messaging
```

### 3.2. Request Notification Permission

Add this code where you want to ask the user for permission to receive notifications.

```dart
import 'package:firebase_messaging/firebase_messaging.dart';

// 적절한 위치에 선언
FirebaseMessaging messaging = FirebaseMessaging.instance;
NotificationSettings settings = await messaging.requestPermission(
  alert: true,
  announcement: false,
  badge: true,
  carPlay: false,
  criticalAlert: false,
  provisional: false,
  sound: true,
);
print('User granted permission: ${settings.authorizationStatus}');
```

### 3.3. Handle Notifications in the Background

Add the following to the top-level main.dart file.

> Keep these requirements in mind when writing a background message handler.

1. It must be a named function.
2. It must be a top-level function, such as a standalone function instead of a method on a class that requires initialization.
3. With Flutter 3.3.0 and later, annotate it with @pragma('vm:entry-point') immediately above the declaration. Otherwise, tree shaking may remove it in release mode.

```dart title="/lib/main.dart"
import 'package:firebase_messaging/firebase_messaging.dart';

@pragma('vm:entry-point')
Future<void> _firebaseMessagingBackgroundHandler(RemoteMessage message) async {
  await Firebase.initializeApp();
}

void main() {
  FirebaseMessaging.onBackgroundMessage(_firebaseMessagingBackgroundHandler);
  runApp(MyApp());
}
```

### 3.4. Handle Notifications in the Foreground

Add the following listener to the top-level file.

```dart title="/lib/main.dart"
import 'package:firebase_messaging/firebase_messaging.dart';

void main(){
	// ...
	FirebaseMessaging.onMessage.listen((RemoteMessage message) {
		print('Got a message whilst in the foreground!');
		print('Message data: ${message.data}');

		if (message.notification != null) {
			print('Message also contained a notification: ${message.notification}');
		}
	});
  runApp(MyApp());
}
```

## 4. Get an FCM Token
### 4.1. What Is an FCM Token?
An FCM token is a unique identifier a Flutter app uses to communicate with FCM. With a token, the app can receive push notifications.

### 4.2. Retrieve the Token

```dart
import 'package:firebase_messaging/firebase_messaging.dart';

// 적절한 위치에 선언
final req = await FirebaseMessaging.instance.requestPermission(
	alert: true,
	badge: true,
	sound: true,
);
final fcmToken = await FirebaseMessaging.instance.getToken();
if (req.authorizationStatus == AuthorizationStatus.authorized && fcmToken != null) {
	print('FCM Token: $fcmToken');
} else {
	print('FCM Token: null');
}
```

## Troubleshooting

### Failed to Get an FCM Token on iOS

> apns token has not been set yet. please ensure the apns token is available by calling getapnstoken()

Even with the basic configuration in place, this error can appear when Flutter does not obtain the APNs token automatically. In that case, retrieve the APNs token explicitly.

```dart title="/lib/main.dart" {16}
import 'package:firebase_messaging/firebase_messaging.dart';
import 'package:flutter/material.dart';

void main() async {
	WidgetsFlutterBinding.ensureInitialized();
	FirebaseMessaging messaging = FirebaseMessaging.instance;
	await messaging.requestPermission(
		alert: true,
		announcement: false,
		badge: true,
		carPlay: false,
		criticalAlert: false,
		provisional: false,
		sound: true,
	);
	messaging.getAPNSToken(); // 이 코드 추가
	await messaging.getToken();
	runApp(MyApp());
}
```

You may see this error after installing and running the app on a physical iOS device. On iOS, the APNs token must be available before you request an FCM token. Update your code as shown above to retrieve the APNs token first, then request the FCM token.
