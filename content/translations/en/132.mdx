## Before You Begin

This guide assumes that you already have a basic Flutter project.

### What Is MetaMask?

> https://metamask.io/
> Start enjoying the convenience of tracking and managing all your Web3 activity in one place.

<Img src="https://upload.wikimedia.org/wikipedia/commons/thumb/3/36/MetaMask_Fox.svg/1024px-MetaMask_Fox.svg.png?20220831120339" alt="MetaMask" width="100" />

MetaMask is a software *cryptocurrency wallet* used to interact with the Ethereum blockchain. Available as a [browser extension and mobile app](https://metamask.io/ko/download/), it provides the features needed to manage digital assets, including a key vault, secure sign-in, token wallet, and token swaps.
Users can access their Ethereum wallet through the browser extension or mobile app and use it to interact with *decentralized applications*.

### What Is Reown?

> https://reown.com/
> Reown gives developers the tools to build user experiences that make digital ownership effortless, intuitive, and secure.

<Img src="https://avatars.githubusercontent.com/u/179229932?s=200&v=4" alt="Reown" width="100" />

Reown (formerly WalletConnect) provides tools that make it easier to connect decentralized apps (DApps) with wallets such as MetaMask.
In this guide, we will use it to connect MetaMask to a Flutter app.

## 1. Install the Library and Configure the Project

### 1.1. Install the Library

Install the library by following the [official Reown documentation](https://docs.reown.com/appkit/flutter/core/installation).
```bash
flutter pub add reown_appkit
```

### 1.2. Configure iOS

At the top of `/ios/Podfile`, uncomment the `platform :ios, 'xx.0'` line and set the version to 13.0 or later.
If the commented line is not there, add it near the top.
```xml title="/ios/Podfile"
platform :ios, '13.0'
```

Run the following commands from the ios directory to finish setup.
```bash
cd ios
pod install
```

### 1.3. Configure Wallet Linking on iOS and Android

Add the wallet scheme to the native code for each platform.
This guide adds MetaMask, but to add other wallets, refer to the [iOS example](https://github.com/reown-com/reown_flutter/blob/master/packages/reown_appkit/example/modal/ios/Runner/Info.plist) and the [Android example](https://github.com/reown-com/reown_flutter/blob/develop/packages/reown_appkit/example/base/android/app/src/main/AndroidManifest.xml).

#### iOS

Open `/ios/Runner/Info.plist` and add the wallet you want to support.
You also need to define a URL scheme using a lowercase string of your choice.
This example uses `exampleapp`; remember it because we will use it later.
Enter your app's Bundle ID as well; this example uses `com.example.yourBundleId`.
```xml title="/ios/Runner/Info.plist"
<dict>
	<key>LSApplicationQueriesSchemes</key>
	<array>
		<string>metamask</string> <!-- 지갑 이름 -->
		<!-- 다른 지갑 이름을 추가할 수 있습니다 -->
	</array>
	<array>
		<dict>
    <key>CFBundleTypeRole</key>
    <string>Editor</string>
    <key>CFBundleURLName</key>
    <string>com.example.yourBundleId</string> <!-- 앱의 Bundle ID -->
    <key>CFBundleURLSchemes</key>
    <array>
      <string>exampleapp</string> <!-- 임의의 소문자로 이루어진 문자열 -->
			</array>
		</dict>
	</array>
</dict>
```

#### Android

Open `/android/app/src/main/AndroidManifest.xml` and add the wallet you want to support.
Android also needs a URL scheme, so enter a lowercase string of your choice.
This example uses `exampleapp`; you will need it later.
```xml title="/android/app/src/main/AndroidManifest.xml"
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <application>
			<activity > <!-- 태그 속성 생략 -->
				<intent-filter>
					<action android:name="android.intent.action.VIEW" />
					<category android:name="android.intent.category.DEFAULT" />
					<category android:name="android.intent.category.BROWSABLE" />
					<data android:scheme="exampleapp" /> <!-- 임의의 소문자로 이루어진 문자열 -->
				</intent-filter>
			</activity>
    </application>
		<!-- ... -->
    <queries>
        <package android:name="io.metamask"/> <!-- 지갑 이름 -->
        <!-- 다른 지갑 이름을 추가할 수 있습니다 -->
    </queries>	
</manifest>
```

## 2. Connect MetaMask

<Rbox>Installing MetaMask in the iOS simulator is difficult because it requires a developer account. This walkthrough uses an Android simulator.</Rbox>

### 2.1. Install MetaMask

Search for MetaMask in the Android simulator's Play Store, install it, and sign in.
If you already have a wallet, restore it with your recovery phrase.

### 2.2. Create page_wallet.dart

```
📦 lib
┣ 📜 page_wallet.dart
┗ 📜 main.dart
```

First, import the package.
```dart
import 'package:reown_appkit/reown_appkit.dart';
```

Create a StatefulWidget.
```dart title="/lib/page_wallet.dart"
class PageWallet extends StatefulWidget {
  const PageWallet({super.key});
  @override
  State<PageWallet> createState() => _PageWalletState();
}

class _PageWalletState extends State<PageWallet> {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text('Wallet'),
      ),
    );
  }
}
```

Override the `@override` method in `_PageWalletState`.
Use the URL scheme defined earlier, which is `exampleapp` in this example, and enter the values that match each key.
```dart title="/lib/page_wallet.dart"
// _PageWalletState 클래스 내부
	late ReownAppKitModal appKitModal;

	@override
	void initState() {
		super.initState();

		appKitModal = ReownAppKitModal(
			context: context,
			projectId: '{YOUR_PROJECT_ID}', // 프로젝트 ID 입력
			metadata: const PairingMetadata(
				name: 'Example App',
				description: 'Example app description',
				url: 'https://example.com/',
				icons: ['https://example.com/logo.png'],
				redirect: Redirect(  // OPTIONAL 이지만 (준)필수인 항목입니다
					native: 'exampleapp://', // 위에서 정의한 url scheme
					universal: 'https://reown.com/exampleapp',
					linkMode: true|false,
				),
			),
		);

		appKitModal.init().then((value) => setState(() {}));
	}
// ...
```

### 2.3. Get the Wallet Address

You can use the wallet address to implement sign-in or create links for viewing transaction results.
Register appKitModal as a listener so that the address is updated when the connection changes.
```dart title="/lib/page_wallet.dart"
// _PageWalletState 클래스 내부
	String address = "none";
	late ReownAppKitModal appKitModal;

	@override
	void initState() {
		super.initState();

		appKitModal = ReownAppKitModal(
			context: context,
			projectId: '{YOUR_PROJECT_ID}', // 프로젝트 ID 입력
			metadata: const PairingMetadata(
				name: 'Example App',
				description: 'Example app description',
				url: 'https://example.com/',
				icons: ['https://example.com/logo.png'],
				redirect: Redirect(  // OPTIONAL 이지만 (준)필수인 항목입니다
					native: 'exampleapp://', // 위에서 정의한 url scheme
					universal: 'https://reown.com/exampleapp',
					linkMode: true|false,
				),
			),
		);


    appKitModal.init();
    appKitModal.addListener(updateAddress);
	}

	void updateAddress() {
    setState(() {
      address = appKitModal.session
              ?.getAddress(ReownAppKitModalNetworks.getNamespaceForChainId(
            appKitModal.selectedChain?.chainId ?? "1",
          )) ??
          "none";
    });
  }
// ...
```

### 2.4. Add Wallet Connection Widgets

Create widgets for connecting to a wallet.
There are four main widget types.
- Wallet connection widgets
	- AppKitModalConnectButton: Opens the modal to connect a wallet or use a social option.
	- AppKitModalNetworkSelectButton: Lets users choose an available network.
- Wallet account widgets
	- AppKitModalAccountButton: Opens the account view after connecting.
	- AppKitModalBalanceButton: Opens the balance view after connecting.
	- AppKitModalAddressButton: Opens the address view after connecting.

```dart title="/lib/page_wallet.dart"
// _PageWalletState 클래스 내부
	@override
	Widget build(BuildContext context) {
		return Scaffold(
			backgroundColor: Colors.white,
			body: Center(
				child: Stack(
					children: [
						Column(
							mainAxisAlignment: MainAxisAlignment.center,
							crossAxisAlignment: CrossAxisAlignment.center,
							children: [
								AppKitModalNetworkSelectButton(
									appKit: appKitModal,
									context: context,
								),
								AppKitModalConnectButton(
									appKit: appKitModal,
									context: context,
								),
								AppKitModalAccountButton(
									appKitModal: appKitModal,
								),
								AppKitModalAddressButton(
									appKitModal: appKitModal,
									onTap: appKitModal.openModalView,
								),
								Text(address),
							],
						),
					],
				),
			),
		);
	}
```
