## Before We Begin
> This guide uses firebase_auth ^5.5.0.

> It assumes you've created a project in the [Firebase console](https://console.firebase.google.com/) and registered your app. If you haven't registered it yet, follow the [app registration guide](/blog/post/134-flutter-firebase-apps).

Several services support phone verification, including Naver Cloud Console, Kakao AlimTalk, and NICE. This guide shows how to implement it in Flutter with *Firebase Auth*.

## 1. Configure Firebase Auth
In the Firebase console, go to Build > Authentication and click Get started.

## 2. Add SHA Certificate Fingerprints for Android
### 2.1. Get the Fingerprints
To use Firebase Auth in the Android app, add its signing certificate fingerprints. Run the relevant command below to find them. If prompted for the default password, enter `android`.
```bash title="MAC/Linux"
keytool -list -v \
-alias androiddebugkey -keystore ~/.android/debug.keystore
```
```bash title="Windows"
keytool -list -v \
-alias androiddebugkey -keystore %USERPROFILE%\.android\debug.keystore
```
Successful output looks like this.
<Img src="/posts/250225-132418.png" width={500} alt="Finding the SHA certificate fingerprints"/>

### 2.2. Register the Fingerprints
Open the settings for your registered Android app in the Firebase console.
<Img src="/posts/250225-151601.png" width={300} alt="Android app settings"/>
Under Your apps on the General tab, click Add fingerprint.
<Img src="/posts/250225-151739.png" width={400} alt="Adding a fingerprint"/>
Add the SHA-1 and SHA-256 fingerprints separately.

### 3.1. Add the Firebase Auth Plugin
Run this command from the project root to add the plugin.
```bash
flutter pub add firebase_auth
```

### 3.2. Write page_onboarding.dart
Add the following code to page_onboarding.dart, using the test phone number you added in [section 1](#1-firebase-auth-설정).
```dart title="/lib/page_onboarding.dart" {17}
import 'package:firebase_auth/firebase_auth.dart';
import 'package:flutter/material.dart';

class PageOnboarding extends StatelessWidget {
  const PageOnboarding({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            TextButton(
                onPressed: () async {
                  await FirebaseAuth.instance.verifyPhoneNumber(
                    phoneNumber: '+1 1234567812', // 테스트 번호
                    verificationCompleted: (PhoneAuthCredential credential) {
                      print("credential: $credential");
                    },
                    verificationFailed: (FirebaseAuthException e) {
                      print("verificationFailed: $e");
                    },
                    codeSent: (String verificationId, int? resendToken) {
                      print("codeSent: $verificationId");
                      print("codeSent: $resendToken");
                    },
                    codeAutoRetrievalTimeout: (String verificationId) {
                      print("codeAutoRetrievalTimeout: $verificationId");
                    },
                  );
                },
                child: const Text("Phone Number Verification"))
          ],
        ),
      ),
    );
  }
}
```
Tap the text, complete the CAPTCHA, and check for the verification success message in the logs. If you see the error below, see [Error When Requesting Verification](#인증-요청-시-오류-발생).
```bash
Fatal error: Please register custom URL scheme app-1-****** in the app's Info.plist file.
```

## 4. Understand the verifyPhoneNumber Callbacks
### 4.1. verificationCompleted
This callback handles automatic SMS code verification on Android devices.
```dart
verificationCompleted: (PhoneAuthCredential credential) {
  print("credential: $credential");
	await auth.signInWithCredential(credential); // 자동 인증 과정 진행
},
```

### 4.2. verificationFailed
This callback handles failures such as an invalid phone number or an exceeded SMS quota.
```dart
verificationFailed: (FirebaseAuthException e) {
	if (e.code == 'invalid-phone-number') {
		print('The provided phone number is not valid.');
	} else {
		print("verificationFailed: $e");
	}
},
```

### 4.3. codeSent
This runs when Firebase sends the code to the device. Use it to prompt the user to enter the code.

```dart
codeSent: (String verificationId, int? resendToken) {
  print("codeSent: $verificationId");
  print("codeSent: $resendToken");
},
```
### 4.4. codeAutoRetrievalTimeout
This runs if automatic SMS code retrieval times out.
```dart
codeAutoRetrievalTimeout: (String verificationId) {
  print("codeAutoRetrievalTimeout: $verificationId");
},
```

## 5. Finish Verification
After the user enters the SMS code, use the following code to complete verification. Use the verificationId received from [4.3. codeSent](#43-codeSent). See the complete example below.
```dart title="/lib/page_onboarding.dart"
TextButton(
	onPressed: () async {
		PhoneAuthCredential credential =
				PhoneAuthProvider.credential(
						verificationId: verificationId,
						smsCode: "123654",
						);
		await FirebaseAuth.instance
				.signInWithCredential(credential)
				.then((value) {
				print("signInWithCredential: $value");
		}).catchError((error) {
			print("signInWithCredential: $error");
		});
	},
	child: const Text("Sign In"),
),
```

### Build Error: Firebase Version Conflict
Podfile.lock pins Firebase/CoreOnly to 11.6.0, while the firebase_core plugin requires 11.8.0.
```bash
!] CocoaPods could not find compatible versions for pod "Firebase/CoreOnly":
  In snapshot (Podfile.lock):
    Firebase/CoreOnly (= 11.6.0)

  In Podfile:
    firebase_core (from .symlinks/plugins/firebase_core/ios) was resolved to 3.12.0, which depends on
      Firebase/CoreOnly (= 11.8.0)

You have either:
 * changed the constraints of dependency Firebase/CoreOnly inside your development pod firebase_core.
   You should run pod update Firebase/CoreOnly to apply changes you've made.
```
#### Fix
Delete Podfile.lock and reinstall the pods.
```bash
rm ios/Podfile.lock
pod install --repo-update
```

### Error When Requesting Verification
On iOS, you may see this error when the app opens a browser for reCAPTCHA and the return URL scheme hasn't been registered.
```bash
Fatal error: Please register custom URL scheme app-1-****** in the app's Info.plist file.
```
#### Fix
Add the URL scheme to Info.plist as shown below.
```xml title="/ios/Runner/Info.plist"
<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleURLSchemes</key>
        <array>
            <string>app-1-******</string>
        </array>
    </dict>
</array>
```

import 'package:firebase_auth/firebase_auth.dart';
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

class PageOnboarding extends StatefulWidget {
  const PageOnboarding({super.key});

  @override
  State<PageOnboarding> createState() => _PageOnboardingState();
}

class _PageOnboardingState extends State<PageOnboarding> {
  String verificationId = '';

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            TextButton(
              onPressed: () async {
                await FirebaseAuth.instance.verifyPhoneNumber(
                  phoneNumber: '+1 1234567812', // 테스트 번호
                  timeout: const Duration(seconds: 60),
                  verificationCompleted: (PhoneAuthCredential credential) {
										print("verificationCompleted: $credential");
                  },
                  verificationFailed: (FirebaseAuthException e) {
										print("verificationFailed: $e");
                  },
                  codeSent: (String verificationId, int? resendToken) {
                    this.verificationId = verificationId;
										print("codeSent: $verificationId");
										print("codeSent: $resendToken");
                  },
                  codeAutoRetrievalTimeout: (String verificationId) {
										print("codeAutoRetrievalTimeout: $verificationId");
                  },
                );
              },
              child: const Text("Phone Number Verification"),
            ),
            const SizedBox(height: 20),
            SizedBox(
              width: 200,
              child: TextField( 	// 인증 코드 입력 (123654)
                onChanged: (value) {
                  setState(() {
                    smsCode = value;
                  });
                },
              ),
            ),
            TextButton(
              onPressed: () async {
                PhoneAuthCredential credential = PhoneAuthProvider.credential(
                    verificationId: verificationId, smsCode: smsCode);
                await FirebaseAuth.instance
                    .signInWithCredential(credential)
											.then((value) {
										print("signInWithCredential: $value");
                }).catchError((error) {
										print("signInWithCredential: $error");
                });
              },
              child: const Text("Sign In"),
            ),
          ],
        ),
      ),
    );
  }
}
