## Before We Begin
Hello!
Today we will send the news data we processed in Part 3 to a messaging app on a smartphone.
<br/>
Once we have collected and cleaned the data, we need to deliver it in a format people can read easily.
This post shows how to use Telegram, a developer-friendly platform, as the final destination of an automation pipeline.
All setup takes place in a web browser, so the steps are the same on macOS, Windows, and Linux.

## Create a Telegram Bot and Connect the API
Telegram makes it straightforward to create a bot and obtain API access. The official management bot, BotFather, lets you create a bot and get a unique authentication key.

### Get a Token from BotFather
Search for *BotFather* in the Telegram app and open a chat with the official account.
Enter the `/newbot` command and follow the prompts to set the bot's name and username.
<Img src="/260222-233824.webp" width={500} alt="Creating a Telegram bot"/>
Once setup is complete, BotFather issues a long *API token* containing letters and numbers.
<br/>
The API token works like a password for controlling the bot, so keep it private.

### Add Credentials in n8n
In the n8n workflow editor, add a *Telegram* node and connect it to the preceding node.
Select *Send Message*. Open the Credentials dropdown in the node settings and choose to create a new credential.
<br/>
Paste the API token you received and save it to authorize n8n to communicate with Telegram's servers.
<Img src="/260222-235114.webp" width={500} alt="Creating credentials"/>
To finish the basic setup, enter the Chat ID, the unique identifier of the chat that will receive the message.
In Telegram, open the chat where you interact with the bot, go to channel management, and look under Channel Type → Link for the URL beginning with `t.me/`.
The final part of the URL identifies the chat. For example, if the link is `t.me/your_channel_name`, the Chat ID is `@your_channel_name`.

## Format Messages and Control Traffic
Raw data can be difficult to read. Use Markdown to make messages easier to read, and account for limits on requests between servers.

### Write a Markdown Template
Enable Expression mode in the message field.
Combine Markdown syntax with JSON variables to build a message template like the one below.

```javascript title="메시지 템플릿 표현식 예시" showLineNumbers
// 대괄호에 텍스트를 넣고 소괄호에 URL을 넣어 하이퍼링크를 생성합니다.

```

This hides long URLs behind link text, making messages easier to read on mobile devices.

### Rate Limits and the Token Bucket Algorithm
What happens if you send hundreds of messages to the messaging server in one second?
To prevent overload, the server enforces a *rate limit* and blocks requests.
<br/>
This relates to the *token bucket* algorithm used in networking. Tokens, which represent permission to make requests, are added to a bucket at regular intervals. Every request consumes one token.
When the bucket runs out of tokens, the server rejects further requests and returns an error.
<br/>
To stay within those limits, use n8n's *Loop Over Items (Split In Batches)* and *Wait* nodes.
Split the data into small batches and wait a few seconds between batches so you can send all the data without triggering the server's restrictions.
