## Before We Begin

> “I can see my assets on my computer, but the list is empty on my phone. Did they fail to save?”

An empty screen can be confusing the first time you sign in on another device. If the screen is bright at night, you may also want to find dark mode. Start with the `계정` (Account) screen.

<br/>

In [Part 8, Asset History](https://www.promleeblog.com/blog/post/443-portrhythm-asset-history-guide), we recorded valuations, deposits, and withdrawals. Here we'll check which account holds those records and where display preferences are saved. Check those differences before entering assets again.

<br/>

**Asset data and display preferences are stored in different places.** Saved assets and portfolio settings belong to your login account. Light and dark mode are saved in the current browser, so your computer and phone can look different even when you use the same login.

<Bbox>
If assets are missing on another device, check the sign-in method and account you usually use before adding them again. The screenshots use a local QA account. Your actual account may show the name and email supplied by your sign-in provider.
</Bbox>

## 1. Opening the Account Screen

On desktop, click `계정` (Account) in the left menu. You can also open it from the profile area at the bottom of the sidebar.

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-desktop-account-20261009.webp" width={800} alt="Desktop My Account screen with sign-in details, display mode, investment settings, and help"/>

`내 계정` (My Account) brings together these options.

- Signed-in account. See whose asset workspace you are viewing.
- Display settings. Choose light or dark mode.
- Investment settings. Go to the screen for target weights and rebalancing criteria.
- Help. Open the user guide and information about data management.
- Sign-out and service information. End the session or open the service overview and GitHub links.

### 1.1. Mobile Menu

On mobile, tap the profile button at the top or open `전체` (All) in the bottom menu. In `전체` (All), scroll to `기록과 계정` (History and Account) and choose `계정` (Account).

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-menu-20261009.webp" width={350} alt="Account under History and Account in the mobile All menu"/>

The signed-in account and display settings appear first. Help and sign-out are farther down.

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-account-20261009.webp" width={350} alt="Mobile My Account screen showing the signed-in account and light and dark mode controls"/>

## 2. Checking Your Sign-In Account

Check the name under `로그인한 계정` (Signed-In Account). An email appears if the provider supplies one. This area displays your current sign-in details. To change them, use the provider's account settings.

<br/>

Suppose you normally use Kakao but sign in with Naver this time. **The service keeps accounts from different providers separate**, even if they belong to the same person. Check the provider you usually use and which account you selected with that provider.

<br/>

If you saved assets with Kakao account A on your computer, sign in with that same Kakao account A on your phone. A browser already signed in to a different social account may select an unexpected account, so check the name too.

<Toggle title="Do matching names mean the accounts are the same?">
A display name alone cannot identify the account. Kakao and Naver may show the same name even though the providers differ. Check both the provider you normally use and the actual social account.

<br/>

The QA screen shows no email. Some accounts may also have no email displayed, so its absence alone does not indicate a save error.
</Toggle>

### 2.1. When Assets Are Missing

Check these items in order to avoid adding duplicates.

- Confirm the signed-in account. Check that it is the Kakao or Naver account you normally use.
- Check whether you saved your entries. Seeing values in a form and successfully saving them are separate steps.
- Check the connection and any loading messages. See whether the app is still loading or shows a connection error.
- Check again in your usual account. If you need to switch, resolve unsaved changes before signing out and signing back in.

<br/>

Distinguish *being in a different account* from *waiting for data to load*. Adding the assets again before checking can cause confusion when you return to the original account.

## 3. Light and Dark Mode

In `화면 설정` (Display Settings), go to `화면 모드` (Display Mode) and choose `라이트` (Light) or `다크` (Dark). The sun or moon button at the top changes the same setting.

<br/>

The choice applies immediately and needs no separate save. As the screen indicates, it is **saved in this browser**. Signing in with the same account on a different device or browser does not carry over the display mode.

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-storage-boundaries-20261009.webp" width={800} alt="Saved assets and portfolio settings belong to the login account, display mode to the browser, and the current screen and selected asset to the page address"/>

### 3.1. Where Each Item Is Stored

| Item | Where it is kept | What to check on another device |
| --- | --- | --- |
| Saved assets and portfolio settings | Login account | Sign in to the same account |
| Light or dark mode | Current browser | Choose the mode in that browser |
| Current screen and selected asset | Page address | Open the same screen address |
| Unsaved input | Pending changes | Confirm saving first |

Dark mode leaves share quantities and target weights alone. Clearing browser settings leaves assets saved to your account intact, though it may affect your display preferences or sign-in state depending on what you clear.

<Toggle title="Why is the screen bright again in a new browser?">
Each browser stores its own display mode. A new browser or separate profile may have no saved preference. Choose your preferred mode there. This alone says nothing about whether your assets were saved.
</Toggle>

## 4. Target Settings and the User Guide

Under `투자 설정` (Investment Settings), choose `목표 비중과 리밸런싱 기준` (Target Weights and Rebalancing Criteria) to open `목표 설계` (Target Design). Enter weights on that screen.

<br/>

Use this route to change target weights or tolerances. See [Part 2, Setting Up Target Portfolios and Investment Weights](https://www.promleeblog.com/blog/post/437-portrhythm-portfolio-setup-guide) for the details.

### 4.1. User Guide

Under `이용 안내` (Help), click `사용 가이드` (User Guide). It covers getting started, updating assets after trades, rebalancing, and frequently asked questions.

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-desktop-guide-20261009.webp" width={800} alt="Desktop user guide with the introduction, getting started, editing assets, rebalancing, and frequently asked questions"/>

The `목표 설계` (Target Design), `주식 등록` (Add Stocks), `자산 배정` (Asset Assignment), `포트 비중` (Portfolio Weights), and `리밸런싱` (Rebalancing) buttons open the corresponding screens. Follow the guide in order at first, then use the buttons to jump to the features you need.

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-guide-20261009.webp" width={350} alt="Mobile user guide with the introduction and getting-started contents"/>

<br/>

On mobile, tap a heading in the contents or scroll to the section you need. The guide uses illustrative weights. Check your own portfolio structure and targets in Target Design.

## 5. How Your Data Is Managed

Tap `내 데이터는 어떻게 관리되나요?` (How Is My Data Managed?) to expand three notes.

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-desktop-data-20261009.webp" width={800} alt="Expanded desktop notes on asset storage, balance screenshot processing, and maintaining holding quantities"/>

### 5.1. Assets Saved to Your Account

Registered assets and portfolio settings are saved to your login account. Sign in again with the same account to see **what you saved**. Pending edits do not carry over between devices.

### 5.2. Balance Screenshot Processing

The app analyzes balance screenshots in the browser. The original image stays off the app server. After you review the results and save them, the recognized holding information is stored in your account. The screenshot and the saved asset record are separate.

<br/>

[Part 3, Adding Assets](https://www.promleeblog.com/blog/post/438-portrhythm-asset-registration-guide) explains how to check tickers, quantities, and purchase prices before saving. If recognition is wrong, verify and correct the value yourself. The app does not automatically reprocess the original image to correct it.

### 5.3. Updating Holding Quantities Manually

Quote updates and brokerage balance synchronization are separate. After a trade, update the actual quantity and purchase price yourself. Reconcile cash to the actual balance too.

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-data-20261009.webp" width={350} alt="Expanded mobile notes on account storage, keeping original screenshots off the server, and updating quantities manually"/>

<Bbox>
If you sold two of ten shares, update the holding to the actual balance of eight shares. A quote update cannot change the share count. Check the actual cash balance after the sale and save the changes.
</Bbox>

## 6. Navigation and Refreshing

When you navigate, the page address reflects the current screen. Refreshing the Account screen returns you to it. You can use the browser's Back and Forward buttons to revisit screens. On an asset detail screen, the address also identifies the selected asset.

<br/>

**Remembering the screen and saving form input are separate actions.** If you edited a target or asset, check that it was saved before refreshing or switching devices.

<Ybox>
If you plan to refresh because of a connection problem, check for pending edits first. Refreshing can return to the same screen while losing unsaved input.
</Ybox>

<Toggle title="Can someone see my assets if I send them the page address?">
A screen address opens a location in the app. It does not share your account's assets or grant the other person access to your sign-in. Treat the page address and login account data separately.

<br/>

Before sharing, decide what you want to show. Check that you are not passing along unnecessary asset identifiers from a detail URL or account information from a screenshot.
</Toggle>

## 7. Signing Out and Signing Back In

Use `로그아웃` (Sign Out) at the bottom of the Account screen to end the session in this browser and return to the first screen.

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-service-20261009.webp" width={350} alt="Sign-out button and links to the service overview, GitHub repository, and bug reporting on mobile"/>

**Signing out keeps assets saved in your account.** Choose your usual provider and account to see them again. Other browsers or devices can retain their own sessions.

<br/>

Check that your changes are saved before you finish. On a shared browser, avoid leaving your asset screen open. This screen has no separate control for closing the account or deleting all assets.

<Toggle title="Why do I see a connection error after returning to my phone?">
If the screen offers a way to retry, check your connection and follow that prompt. A temporary network problem can look different from an expired session.

<br/>

If the app asks you to sign in again, use the original account. Switching providers or adding assets again does not resolve the connection problem.
</Toggle>

## 8. Service Information and Support

`서비스 정보` (Service Information) appears below sign-out. The three links serve different purposes.

| Link | Purpose |
| --- | --- |
| Service Overview | Read about PortRhythm's purpose and main features |
| GitHub Repository | View project code and documentation |
| Bug Reports and Feature Suggestions | File a report or suggestion in public Issues |

`서비스 소개` (Service Overview) opens a public page. The GitHub link opens in a new tab. Posting an issue requires a GitHub login.

### 8.1. Describing a Problem

Specify which screen you were on and the steps that led to the problem.

- Environment. Say whether you were on desktop or mobile and name the browser.
- Screen and actions. List the actions in order, such as Account → User Guide.
- Expected and actual results. Explain what you expected to open and what you saw.
- Messages. If there was an error message, include the relevant part.

<Ybox>
GitHub Issues are public. Redact account numbers, email addresses, and holding amounts from both screenshots and text. Keep passwords and API keys out of reports. Images uploaded to GitHub directly do not use the app's local balance screenshot processing.
</Ybox>

<br/>

For example, you could write:

> In mobile Safari I tapped All → Account → User Guide.
> I expected the guide to open, but the previous screen stayed visible.
> The same steps produce the same result after reconnecting.

This illustrates how to file a report and describes no confirmed bug.
