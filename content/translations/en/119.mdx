## Before getting started
### What is Homebrew?
>Homebrew is the easiest and most flexible way to install the UNIX tools Apple didn’t include with macOS.
It can also install software not packaged for your Linux distribution without requiring sudo.
> Homebrew is the easiest and most flexible way to install UNIX tools that macOS does not include.
It can also install software not packaged for your Linux distribution without requiring sudo.

[Homebrew documentation](https://docs.brew.sh/Manpage)
It is useful for installing packages and casks, or applications, on macOS.

## Installing Homebrew
Open a terminal and enter the following command.
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
During installation, follow the prompts, including confirmation requests and password entry.
Once installation finishes, run the following command to verify it.
```bash
brew --version
```
If installation succeeded, a version is displayed as follows.
```bash
Homebrew 4.3.18
```

## Troubleshooting
### Configuring environment variables
If brew does not work after installation, you may need to configure the environment.
Enter the following command in the terminal.
```bash
echo "eval "$(/opt/homebrew/bin/brew shellenv)"" >> ~/.zshrc
source ~/.zshrc
```
Reopen the terminal and run brew to check that it works.
```bash
brew --version
brew doctor # 홈브루의 상태 확인
```

## Conclusion
Homebrew can install, uninstall, update, and search for packages.
It simplifies package management and lets you manage package versions.
You can even create packages of your own.
It is an almost indispensable tool for MacBook users, so I recommend trying it.

#### Other Homebrew commands
> brew update: Update Homebrew.

> brew list: List installed packages.
> brew search [package-name]
> brew uninstall [package-name]
> brew info [package-name]
