## Portfolios and Assets

A portfolio is **a group for tracking holdings**. Assets are the stocks, ETFs, crypto, cash, and other holdings that go into those groups.

| Setting | Meaning | Example |
| --- | --- | --- |
| Overall portfolio name | Name of your entire investment plan | My Investment Plan |
| Portfolio name | Name of a group you track | Portfolio A |
| Target weight | Share of the total you want to assign to the group | 50% |
| Holdings | Assets and quantities or amounts you actually own | Ten shares and KRW 500,000 in cash |

Creating a portfolio named Cash does not add KRW 500,000. At this stage, you're **creating groups and setting their target allocations**.

<br/>

Use these three groups for the exercise.

| Portfolio | Target weight |
| --- | ---: |
| Portfolio A | 50% |
| Portfolio B | 30% |
| Portfolio C | 20% |
| Total | 100% |

*These are examples for practicing the controls. Choose names and weights that fit your own plan.* Securities, weights, and valuations in the screenshots illustrate the interface rather than investment recommendations or actual performance.

## 2. Choosing a Starting Setup

With no saved portfolio, a welcome prompt asks you to start by defining your investment principles. Choose one of the two options.

| Option | What it creates | When to choose it |
| --- | --- | --- |
| Start With an Example | Several example portfolios, target weights, and security assignment rules | To explore the setup before editing it |
| Start With an Empty Portfolio | One group called New Portfolio at 100% | To define your own groups from scratch |

<br/>

### 2.1 Example Setup

The app creates sample portfolios such as U.S. Index, Korean Index, Blue Chip, Gold, and Bitcoin. You can edit names, colors, and weights. The example also includes ticker-based assignment rules. After adding holdings, check Asset Assignment to verify that each one landed in the portfolio you intended. Add actual holdings separately.

<br/>

### 2.2 Empty Portfolio

This option creates one New Portfolio at 100%. For the exercise, rename it Portfolio A and add two more groups. The next section explains the fields.

<Ybox>
The starting setup stays in the editor until you click Save Changes.
</Ybox>

An account with a saved plan may skip this choice. In that case, edit the existing plan. The current app supports one strategy per account.

## 3. Editing Portfolios in Target Design

Start by locating the controls for names and weights.

<Img src="/portrhythm-allocation-strategy-20261008.webp" width={800} alt="Target Design screen for editing portfolio names, weights, and tolerance"/>

**The same fields appear on mobile.**

<Img src="/portrhythm-setup-mobile-strategy-20261008.webp" width={350} alt="Mobile Target Design fields for tolerance, portfolio names, and target weights"/>

Each mobile row shows the name and target together, with the current weight bar and difference below. If the list is long, scroll to see the remaining rows and total. The fixed bottom menu navigates between screens. The target fields and save controls are in Target Design.

| Location | Control | Purpose |
| --- | --- | --- |
| Top of screen | Save Changes / Saved | Save to your account or check status |
| Right of target weight editor | Add Portfolio | Add a group |
| Above portfolio rows | Rebalancing Tolerance | Set the threshold for reviewing weight differences |
| Left of row | Color and name | Change the chart color and portfolio label |
| Middle of row | Bar, current weight, difference, and amount | Review current holdings |
| Right of row | Target and delete icon | Enter a weight or delete a portfolio |
| Below list | Target Total | Check whether targets add to 100% |

<br/>

### 3.1 Adding and Naming Portfolios

Click **Add Portfolio** on the right. A New Portfolio row appears at the bottom with a target of 0%.

<Img src="/portrhythm-setup-add-port-20261008.webp" width={800} alt="Add Portfolio creates a New Portfolio row with a target of zero percent"/>

Enter a distinct name in each new row.

- Each name is required.
- Names must be unique after trimming leading and trailing spaces.
- Portfolio names can be up to 60 characters.
- You can manage one to twenty portfolios.

<br/>

For the exercise, use Portfolio A, Portfolio B, and Portfolio C. In your own plan, choose recognizable names such as Long-Term Investments or Cash. Renaming a portfolio leaves security markets and tickers unchanged.

<br/>

### 3.2 Choosing a Portfolio Color

Click the small color swatch to the left of the name and choose a color in your browser or device's picker. The color distinguishes the portfolio in charts. It leaves weights and quantities alone. Choose visibly different colors for portfolios you compare often.

<br/>

### 3.3 Entering Target Weights

Edit the **Target** field at the right of each row. The app displays `%` next to it, so enter the number alone.

| Desired target | Enter |
| --- | ---: |
| 50% | 50 |
| 30% | 30 |
| 20% | 20 |
| 12.5% | 12.5 |

**Entering 0.5 sets a target of 0.5%.** Enter 50 for 50%. The range is 0–100%, and the field can step by 0.1. Decimal targets still need to add up to 100%.

<br/>

### 3.4 Checking the Target Total

Check **Target Total** below the list.

| Entries | Total | What to do |
| --- | ---: | --- |
| A 50 / B 30 / C 20 | 100% | Target total is ready |
| A 50 / B 30 / C 10 | 90% | Decide where to put the remaining 10% |
| A 100 / B 30 / C 20 | 150% | Revise the weights, including the original 100% |

When the total reaches 100%, look for `저장할 수 있습니다.` (Ready to save). Otherwise, the app asks you to adjust the total.

<Bbox>
Adding a portfolio does not redistribute targets automatically. Review existing weights when adding a group.
</Bbox>

`목표 합계 100%` (Target Total 100%) confirms the weight requirement. Duplicate names and other validation errors can still prevent saving, so check the final result.

<br/>

### 3.5 Current and Target Weights

The middle of each row shows the current weight, difference from target, and valuation. “Current 28% · Difference +8 percentage points” means the portfolio is eight points above a 20% target. A negative difference means it is below target. Editing the target changes that comparison baseline.

<br/>

### 3.6 Deleting a Portfolio

Click the trash icon on the right to remove a portfolio from the editor. The final portfolio cannot be deleted. Check what is linked to a portfolio before deleting it.

- Ticker assignment rules linked to it are removed.
- Manual assignments and links from crypto and other assets are cleared.
- The underlying holdings stay registered.
- After saving, check the affected holdings in Asset Assignment.

<Ybox>
To rename a portfolio, edit its name in place. Deleting it and creating a new one means checking its links again.
</Ybox>

Deleting a portfolio with a target reduces the total. Adjust the remaining targets before saving.

## 4. Setting Tolerance

Find **Rebalancing Tolerance** near the top of Target Design. The field shows `±` and `%p` around the number. The same threshold applies to all portfolios.

<br/>

Take a target of 20% and a tolerance of five percentage points.

| Current weight | Difference from target | Interpretation |
| --- | ---: | --- |
| 15% | −5 percentage points | At the boundary, within range |
| 20% | 0 percentage points | On target |
| 25% | +5 percentage points | At the boundary, within range |
| 26% | +6 percentage points | Outside the range, review for adjustment |

The range is 15–25%. Review an adjustment when the difference **exceeds** five percentage points in either direction.

<br/>

Enter **5** to set a tolerance of five percentage points. Leave `±` and `%p` out of the field. The range is zero to thirty percentage points, with a 0.1 step.

<Toggle title="What's the difference between 5% and five percentage points?">
Moving from 20% to 25% is a difference of **five percentage points**. By contrast, 5% of 20% is 20 × 0.05 = 1, or **one percentage point**. PortRhythm uses the first meaning for tolerance.
</Toggle>

A tolerance flag is a starting point for review. Check holdings and your investment plan before deciding whether to trade.

<br/>

## 5. Opening Exchange Rate and Other Settings

In Target Design, click **Exchange Rate and Other Settings** to expand additional fields on the same screen.

<Img src="/portrhythm-setup-settings-auto-20261008.webp" width={800} alt="Expanded settings showing the overall portfolio name and exchange rate fields"/>

**On mobile, exchange rate fields appear below the name.**

<Img src="/portrhythm-setup-mobile-settings-20261008.webp" width={350} alt="Expanded mobile name and exchange rate settings"/>

Check the overall name, exchange rate mode, and USD → KRW field. The expanded panel pushes the portfolio list down. Tap the heading again to collapse it.

| Setting | What it controls |
| --- | --- |
| Overall portfolio name | Name of the entire investment plan |
| Exchange rate mode | Automatic or manual |
| USD → KRW exchange rate | Won used to value one dollar |

<br/>

### 5.1 Naming the Overall Portfolio

Enter a title such as My Investment Plan. It is separate from Portfolio A and the other group names. **The overall portfolio name is the plan's title. Each portfolio name labels a group.** The title is required and can be up to 80 characters. Renaming it edits the same strategy.

<br/>

### 5.2 Choosing the Automatic Rate

Select **Automatic · ECB Daily Reference Rate**. The USD → KRW field becomes read-only. The app values dollar assets in won using the ECB daily reference rate. Your brokerage's live FX quote and actual conversion can differ.

<br/>

While a lookup is pending or after a failure, the app may display the last saved rate. Check **View Price and Exchange Rate Basis** on the dashboard to see what was applied.

<Toggle title="How often does the app check the automatic rate?">
In automatic mode, the app checks whether to fetch the rate at intervals of up to one hour. The underlying data is the ECB daily reference rate. It does not provide live conversion quotes. If the lookup fails, the app may indicate that it is using the last saved rate.
</Toggle>

<br/>

### 5.3 Entering the Rate Manually

Select **Manual** in the same menu to edit USD → KRW.

<Img src="/portrhythm-setup-settings-manual-20261008.webp" width={800} alt="Manual mode makes the won-per-dollar exchange rate editable"/>

To value one dollar at KRW 1,350, enter **1350**. The field expects a rate as a number. Omit the currency from `1,350원` (KRW 1,350) and keep your dollar balance in the asset entry.

| Desired rate | Enter |
| --- | ---: |
| USD 1 = KRW 1,350 | 1350 |
| USD 1 = KRW 1,350.50 | 1350.50 |

Rates from KRW 100 to KRW 100,000 can be saved. Check the rate you intend to use and save it.

<br/>

### 5.4 What Changing the Rate Affects

The change applies to the **won valuation** of U.S. stocks and manually entered dollar assets. Total won valuation and current weights can change. For example, USD 100 is worth KRW 130,000 at a rate of 1,300 and KRW 140,000 at 1,400. The dollar amount stays the same.

<Gbox>
**Changing the exchange rate changes the valuation basis.** Actual conversions and orders are handled separately.
</Gbox>

Switch from Automatic to Manual before editing the rate. The field is locked in Automatic mode.

## 6. Saving and Checking the Result

After entering names and figures, save the edits.

### 6.1 Before Saving

- **Portfolio names.** Check for blanks and duplicates.
- **Target total.** Confirm that all weights add to 100%.
- **Tolerance.** Check the threshold in percentage points.
- **Overall name and exchange rate.** Verify the title, rate mode, and rate.
- **Existing asset links.** If you deleted a portfolio, check the impact on assignments.

<br/>

### 6.2 Clicking Save Changes

**On mobile, Save Changes is below the title.**

<Img src="/portrhythm-setup-mobile-save-20261008.webp" width={350} alt="Refresh Prices and Save Changes under the mobile Target Design title"/>

Tap Save Changes to the right of Refresh Prices. If you edited rows farther down, scroll back up. Dismiss the keyboard if it covers the button.

<br/>

Use Save Changes at the top of Target Design. The app shows **Saving**, then **Saved** when successful. Look for the notice that it saved the portfolio and today's valuation. Saving can update today's valuation record. Actual orders and trades take place separately.

<br/>

### 6.3 Confirming That Changes Persist

After saving, reopen Target Design or refresh. Check that the names, target weights, tolerance, and rate mode remain. If the results are still unexpected, verify that you are using the same login.

<Ybox>
Wait until saving succeeds before refreshing. Unsaved edits are lost on refresh.
</Ybox>

Opening menus or navigating does not save changes. If you change another setting, click Save Changes again.

## Practice the Full Workflow

Follow these steps in order. *The weights and exchange rate are examples for practicing, separate from recommendations or live rates.*

- **Open Target Design.** On a new account, choose Start With an Empty Portfolio.
- **Name the groups.** Rename the first portfolio Portfolio A and click Add Portfolio twice for B and C.
- **Enter targets.** Enter 50 for A, 30 for B, and 20 for C. Check that the total is 100%.
- **Check tolerance.** Enter 5 for an example tolerance of ±5 percentage points.
- **Check the overall name and rate.** Expand Exchange Rate and Other Settings, enter the title, and choose Automatic or Manual.
- **Verify saving.** Click Save Changes and look for Saved.

<br/>

Your portfolios and targets are now ready. Current weights can differ from targets. **If you have yet to add holdings, the next step will populate current weights.**

## Troubleshooting

Expand the question that matches what you are seeing.

<Toggle title="Why can't I see Save Changes?">
If your setup is saved and has no edits, the screen shows Saved. Change a name or target weight to reveal the button. For a first plan, verify that you selected an example setup or an empty portfolio.
</Toggle>

<Toggle title="Why won't it save even though the total is 100%?">
Check the other fields too.

- Look for blank or duplicate portfolio names.
- Check the 60-character portfolio name and 80-character overall name limits.
- Check the 0–100% target range and zero to thirty percentage point tolerance.
- Check that a manual exchange rate is numeric and within KRW 100–100,000.
- Read any save error displayed by the app.

For a connection or sign-in issue, keep a copy of the inputs before checking the session. Refreshing before a successful save can clear the edits.
</Toggle>

<Toggle title="Why are all the new groups named New Portfolio?">
New Portfolio is a default name. Edit each name field. Keeping identical names can prevent saving. The app supports up to twenty portfolios, so organize the groups you need within that limit.
</Toggle>

<Toggle title="Why is the current weight still 0% after I set a target of 30%?">
The target is your plan. The current weight uses the valuation of registered holdings. Check whether you added and assigned holdings to the portfolio. If you did, check prices and assignments.
</Toggle>

<Toggle title="Why did assignments change after I deleted a portfolio?">
Deletion clears links to the portfolio and removes its ticker assignment rules. The actual securities stay in your holdings. Adjust remaining targets to 100%, save, and verify the affected holdings in Asset Assignment.
</Toggle>

<Toggle title="Why can't I see a portfolio I saved before?">
Check that you used the original social provider and account. Kakao and Naver sign-ins load separate data. Check whether you closed or refreshed before saving. If the login and save status are correct, look for an error message.
</Toggle>

<Toggle title="Can I split one ETF across two portfolios here?">
Each registered holding has one portfolio assignment. You cannot specify a 60% split into A and a 40% split into B for a single entry. Create the groups in Target Design and review the actual links in Asset Assignment.
</Toggle>
