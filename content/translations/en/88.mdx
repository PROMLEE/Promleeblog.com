## Network layer functions
*Recall*: The network layer has two functions.
- **Forwarding**: The process of a router sending a packet toward its destination — the data plane.
- **Routing**: The process of determining the path a packet takes to its destination — the control plane.

[Two ways to structure the network control plane (link!)](/blog/post/84-network-layer-overview#라우터-별-제어-평면-router-by-router-control-plane)
- Per-router control: The traditional approach, which remains popular.
- Logically centralized control: Used in software-defined networking (SDN).
