## Before You Begin

Last time, we learned how to run MongoDB easily in the cloud with MongoDB Atlas.
Atlas provides excellent management features, but the MongoDB ecosystem also includes tools and utilities that make development and operations more efficient.
They are useful when you want to inspect data visually, back it up safely, or import and export data in other formats.

## 1. MongoDB Compass

> A GUI tool

MongoDB Compass is an official *graphical user interface (GUI)* tool from MongoDB.
Whereas we have used the command-line interface (CLI) `mongosh` to interact with MongoDB through text, Compass lets us explore and manage databases through a visual interface and mouse clicks.

### Key Features of Compass

- **Connect to servers and browse databases and collections**
  You can connect to a local MongoDB server or a MongoDB Atlas cluster using its connection string.
  Databases and collections appear in a tree view that is easy to navigate.
- **View and edit documents**
  Documents in a collection can be displayed as a table, JSON, or tree.
  You can add, update, and delete documents conveniently in the GUI.
- **Run queries and filter results**
  Enter a JSON condition for the `find` command in the intuitive Query Bar and view the result immediately.
  Filtering options help you find documents that match specific conditions.
- **Manage indexes**
  Inspect a collection's indexes visually, create new ones, and delete existing ones in the GUI.
- **Aggregation Pipeline Builder**
  Create and test a complex pipeline with multiple stages, and preview the results step by step.
  This is much more intuitive than writing the code directly.
- **Schema Analysis**
  Compass samples collection documents and analyzes and visualizes each field's data type, distribution, and value range.
  This helps you understand the data structure and improve your data model.
- **Performance Monitoring**
  View live server performance metrics such as slow queries, network traffic, and operation counts to help diagnose performance issues.
  Atlas clusters provide more detailed monitoring in the Atlas UI.
- **Geospatial Data Visualization**
  Compass can also show GeoJSON data visually on a map.

### Install and Use Compass

MongoDB Compass can make MongoDB development and management much easier, and it is simple to install.

#### Download Compass

Go to the Compass download page on the official MongoDB website.
[https://www.mongodb.com/try/download/compass](https://www.mongodb.com/try/download/compass)
The page detects or lets you select a version for your operating system (Windows, macOS, or Linux).
- **Version**: The latest stable release is usually a good choice.
- **Platform**: Select your operating system, such as Windows 64-bit (msi), macOS 64-bit (dmg), or a Linux distribution package (deb/rpm).
- **Package**: In most cases, choose the default package format, such as .msi for Windows or .dmg for macOS.

Click Download to get the installer.

#### Install on Each Operating System

**Windows**
1. Double-click the downloaded `.msi` installer.
2. Follow the setup wizard. Usually, you only need to click Next a few times and accept the license; there are few options to change.
3. After installation, open MongoDB Compass from the Start menu or desktop.

**macOS**
1. Double-click the downloaded `.dmg` file to open it.
2. Usually, you install Compass by dragging its icon into the Applications folder.
   <Img src="/250508-100015.webp" width={500} alt="Drag and drop installation"/>
3. After installation, open Compass from Launchpad or the Applications folder.
   The first launch may show a security warning; choose Open to continue.

**Linux**
- For a `.deb` package (Debian/Ubuntu), install it in the terminal with `sudo dpkg -i <다운로드된_compass.deb_파일경로>` and resolve dependencies with `sudo apt-get install -f` if needed.
- For an `.rpm` package (Red Hat/Fedora/CentOS), install it with `sudo rpm -ivh <다운로드된_compass.rpm_파일경로>`.
- After installation, launch Compass from the applications menu or run `mongodb-compass` (or a similar command) in the terminal.

#### Launch Compass and Connect to a Server

When Compass starts for the first time, it shows a screen to set up a New Connection.
Enter a *connection string (Connection String URI)* for your MongoDB server, or fill in individual fields such as Hostname, Port, and Authentication.
**Connecting to a local server**: Try the default `mongodb://localhost:27017` setting.
**Connecting to a MongoDB Atlas cluster**: The easiest option is to copy and paste the connection string from the Atlas dashboard. See the [Atlas setup guide from Day 11](/blog/post/265-11-mongodb-atlas).
<Img src="/250508-100313.webp" width={300} alt="New Connection screen"/>

Enter the required credentials (username and password) and click Connect.
After a successful connection, you can explore databases and collections from Compass's main screen.
<Img src="/250508-100701.webp" width={300} alt="Connected Atlas databases and collections"/>

Compass is especially useful for people new to MongoDB or those who are not comfortable with the command line; it helps them understand the database structure and perform basic tasks.
Try its features to become more familiar with MongoDB.

## 2. mongodump and mongorestore: Back Up and Restore Data

Data is valuable, so regular *backups* are essential for protecting it against unexpected problems such as hardware failures or user mistakes.
mongodump and mongorestore are command-line utilities for backing up and restoring MongoDB data.

### mongodump

> Back up a database

`mongodump` exports data from a MongoDB server into BSON (Binary JSON) files to create a backup.

#### Basic Usage

```bash
mongodump --uri="mongodb://<username>:<password>@host:<port>/<databaseName>" --out="/path/to/backup_directory"
```

- `--uri`
  The connection string for the MongoDB server.
  It can include authentication details, host, port, and the name of a specific database to back up.
  If no database is specified, it backs up all databases on the server.
- `--out` or `-o`
  Sets the directory where backup files are stored.
  If the directory does not exist, it is created automatically.
  If omitted, a directory named `dump` is created under the current directory.

#### Main Options

- `--db <databaseName>` backs up only the specified database.
- `--collection <collectionName>` backs up only the specified collection (use it with `--db`).
- `--gzip` compresses the backup files to save storage space.
- `--archive` combines all backup data into one archive file.
- `--username <user>`, `--password <pass>`, `--authenticationDatabase <authDB>` specify authentication details.

#### Example

Compress and back up the entire `test` database into the `~/mongodb` directory.

```bash
mongodump --uri="mongodb://localhost:27017/test" --out="~/mongodb"
```

<Img src="/250508-103805.webp" width={1000} alt="mongodump output"/>

### mongorestore

> Restore backup data

`mongorestore` restores data by importing backup files (BSON) created by `mongodump` back into a MongoDB server.

#### Basic Usage

```bash
mongorestore --uri="mongodb://<username>:<password>@<host>:<port>/<targetDatabaseName>" /path/to/backup_directory
```

- `--uri`: The connection string for the MongoDB server where you want to restore data.
- Final argument: The directory containing backup files created by `mongodump`.

#### Main Options

- `--db <targetDatabaseName>` restores to a specific database.
- `--collection <targetCollectionName>` restores to a specific collection.
- `--gzip` restores a compressed backup.
- `--archive` restores from a single archive file.
- `--drop` deletes all existing documents in the target collection before restoring. Use with care.
- `--nsInclude <namespacePattern>` and `--nsExclude <namespacePattern>` include or exclude specific namespaces.

#### Example

Restore the backup from above into the `restoredDB` database.

```bash
mongorestore --uri="mongodb://localhost:27017/restoredDB" ~/mongodb/test
```

## 3. mongoimport and mongoexport

> Convert data formats

Sometimes you need to export MongoDB data to another format, such as JSON or CSV, or import data from another format into MongoDB.
`mongoimport` and `mongoexport` are command-line utilities for these tasks.

### mongoexport

> Export MongoDB data to an external file

`mongoexport` exports collection data in JSON, CSV, or TSV format.

#### Basic Usage (JSON)

```bash
mongoexport --uri="mongodb://username:password@host:port/databaseName" --collection="collectionName" --out="output_file.json"
```

#### Main Options

- `--type <json|csv|tsv>` sets the file format (default: json).
  - JSON: Use `--jsonArray` to wrap the output in an array.
  - CSV/TSV: You must specify the field list using `--fields` or `--fieldFile`.
- `--query <JSON_query_string>` exports only documents that match a condition.
- `--pretty` formats the JSON for readability.

#### Example

> Export the `name` and `email` fields of users whose status is "active" from the `users` collection as CSV.

Create sample data in the test collection with this command.

```js
db.users.insertMany([
  { name: "Alice", email: "alice@example.com", status: "active" },
  { name: "Bob", email: "bob@example.com", status: "disabled" },
  { name: "Charlie", email: "charlie@example.com", status: "active" },
  { name: "Daisy", email: "daisy@example.com", status: "inactive" }
])
```

```bash
mongoexport --uri="mongodb://localhost:27017/test" --collection="users" --type="csv" --fields="name,email" --query='{"status": "active"}' --out="active_users.csv"
```

<Img src="/250508-110130.webp" width={500} alt="Generated CSV file"/>

### mongoimport

> Import external data into MongoDB

`mongoimport` imports JSON, CSV, or TSV files into a MongoDB collection.

#### Basic Usage (JSON)

```bash
mongoimport --uri="mongodb://username:password@host:port/databaseName" --collection="collectionName" --file="input_file.json"
```

##### Main Options

- `--type <json|csv|tsv>` sets the file format (default: json).
  - JSON: The file can contain one JSON object per line, or you can use `--jsonArray`.
  - CSV/TSV: Specify fields with `--headerline` (use the first line as field names), `--fields`, or `--fieldFile`.
- `--drop` deletes existing data before importing.
- `--mode <insert|upsert|merge>` specifies the insert method (requires `--upsertFields`).

##### Example

> Import the `active_users.csv` file exported above into the `importedUsers` collection.

```bash
mongoimport --uri="mongodb://localhost:27017/test" --collection="importedUsers" --type="csv" --headerline --file="active_users.csv"
```
