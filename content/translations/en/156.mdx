## Before You Begin

Web images and videos sometimes need to be converted for performance or quality reasons.
Doing this manually can be tedious and time-consuming, so this guide shows how to automate file conversion on a Mac with Folder Actions.
I automated converting MP4, GIF, and PNG files into WebP images for my blog, which saves time and removes repetitive work.

## Set Up the Environment

First, install ffmpeg on a system that has Homebrew.
If Homebrew is not installed, follow [How to Install Homebrew](/blog/post/119-homebrew), then run this command.
```bash
brew install ffmpeg
```

Create a folder wherever you like and give it a name.
I created an `mp4_to_webp` folder on my desktop for converting MP4 files to WebP.
<Img src="/posts/250317-162026.webp" width={100} alt=""/>
<Rbox>Once you finish configuring a Folder Action, you will not be able to rename its folder. Choose the folder name carefully before continuing.</Rbox>

Open `Automator` from the Finder Applications menu and choose `폴더 적용 스크립트` (Folder Action).
<Img src="/posts/250317-162241.webp" width={500} alt=""/>

Select the folder you created and add `선택된 finder 항목 가져오기` (Get Selected Finder Items).
<Img src="/posts/250317-162603.webp" width={500} alt=""/>

From the Utilities category, add `쉘 스크립트 실행` (Run Shell Script) and change the input setting to “as arguments.”
<Img src="/posts/250317-162751.webp" width={500} alt=""/>

The setup is complete. Now let's write the scripts.

## Write the Scripts

All examples delete the original file and save the converted file in `/Users/{사용자명}/Documents`.
Change the destination to the path you want to use.
### Convert Video to WebP (MP4, MOV to WebP)
```bash
for f in "$@"; do
    /opt/homebrew/bin/ffmpeg -n -loglevel error -i "$f" -vf "fps=15,scale=720:-1:flags=lanczos" -loop 0 "/Users/promlee/Documents/$(date +"%y%m%d-%H%M%S").webp"
    rm -f "$f"
done
```


The table below explains the commands and options used in the script.
| Command | Description |
| --- | --- |
| for f in "\$@" | A loop that processes each input file (f) in sequence. |
| /opt/homebrew/bin/ffmpeg | Runs the Homebrew installation of ffmpeg. |
| -n | Does not overwrite an existing file with the same name. |
| -loglevel error | Prints errors only and hides other unnecessary logs. |
| -i "\$f" | Specifies the input file (\$f, the video to convert). |
| -vf | Sets the video filter options. |
| "fps=15" | Converts at 18 frames per second to reduce the output size by lowering the frame count. |
| "scale=720:-1" | Sets the width to 720 px and keeps the aspect ratio (-1 is calculated automatically). |
| "flags=lanczos" | Uses a high-quality resampling (scaling) algorithm. |
| -loop 0 | Makes the animated WebP loop indefinitely. |
| -f | Deletes the original video file (\$f) after conversion. |

### Convert PNG to WebP
```bash
for f in "$@"; do
    /opt/homebrew/bin/cwebp -q 70 "$f" -o "/Users/promlee/Documents/$(date +"%y%m%d-%H%M%S").webp";
    rm -f "$f"
done
```


### Convert Video to GIF
```bash
for f in "$@"; do
    /opt/homebrew/bin/ffmpeg -n -loglevel error -i "$f" -vf "fps=15,scale=720:-1:flags=lanczos" "/Users/promlee/Documents/$(date +"%y%m%d-%H%M%S").gif";
    rm -f "$f"
done
```
