# Block ciphers
## Block cipher design
A symmetric block cipher consists of multiple **rounds**, made up of **substitutions** and **permutations** controlled by a **key**.
Parameters and design characteristics of symmetric block ciphers:
- Block size.
- Key size.
- Number of rounds → **A key element of encryption**.
- Subkey schedule algorithm.
- Round function.
- Encryption and decryption speed in software and hardware.
- Ease of security analysis.

## Computational security
An encryption scheme can be considered computationally secure if the resulting ciphertext satisfies one or both of the following conditions.
- The cost of breaking the cipher exceeds the value of the encrypted information.
- The time required to break the cipher exceeds the useful lifetime of the information.
