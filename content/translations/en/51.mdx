## Introduction
A multiple-access network:
- Each node is connected to a receiver and communicates through a medium shared with other nodes.
- A transmission from any node is received by all other nodes.

## Multiple access
The multiple-access problem:
- Collisions occur when several nodes transmit on the broadcast channel at the same time.
- A way to decide which node may transmit is needed.
*Multiple-access protocols*:
- Protocols for solving the multiple-access problem.

## Multiple-access protocols
1. Contention-free protocols
	- Dynamic allocation: Reservation.
	- Static allocation.
2. Contention-based protocols
3. Hybrid protocols
