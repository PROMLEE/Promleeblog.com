## Visibility
An object's ability to *see* another object, or to hold a reference to it.
More generally, this is a question of *scope*: Is one resource, such as an instance, within the scope of another?
Visibility from object A to object B:
- Parameter visibility: B is a parameter of a method on A. → UML dependency.
- Local visibility: B is a local object, rather than a parameter, within a method on A. → UML dependency.
- Attribute visibility: B is an attribute of A. → UML association.
- Global visibility: B is globally visible in some way. → UML association.

Why consider visibility?
- For object A to send a message to object B, B must be visible to A.
