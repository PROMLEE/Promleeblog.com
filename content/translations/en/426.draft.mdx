## What Is a Feature?

A feature is an input the model uses to make a prediction. A training row usually represents a room and a candidate venue. Each feature represents some property of that pair as a number or a category. For example, `eta_mean` is the average travel time, and `eta_range` is the gap between participants' travel times. `purpose_match` indicates whether the venue category fits the purpose of the meeting.

### Labels and Features

- A label is the target the model learns to predict.
- A feature is information the model uses to predict that label.

This exercise uses `target_score`, constructed from behavioral logs, as the label. ETA statistics and intent information are the features.

## Why Use ETA to Capture Fairness?

For meeting venue recommendations, the average can hide an uneven burden. If three participants have ETAs of 15, 15, and 45 minutes, the mean of 25 minutes may look reasonable. One participant still faces a much longer trip. Providing information about the ETA distribution gives the model a way to learn about perceived fairness.

### Travel Cost Features

- `eta_mean` is the average travel time across participants.
- `eta_std` measures the spread of travel times.
- `eta_range` is the difference between the shortest and longest ETA.
- `eta_min` is the shortest travel time.
- `eta_max` is the longest travel time.
- `eta_p90` is a conservative measure that captures the upper end of the travel-time distribution.

### Intent Features

- `purpose_match` indicates whether `purpose` and `category` match in meaning.
- `hour_bucket` groups times into periods such as morning, afternoon, and evening.
- `group_size` counts participants and captures the potential for wider differences.

## Core Training Logic

Start with the central calculations in the Python training code.

### Scoring Candidates

```python title="ml/synthetic_generator_part3.py" showLineNumbers
eta_range = float(np.max(etas) - np.min(etas))
eta_mean = float(np.mean(etas))
bonus = _purpose_category_bonus(purpose, str(place.get("category", "")))

score = 1.2 * eta_range + 0.3 * eta_mean - 8.0 * bonus
```

- `eta_range` and `eta_mean` capture both overall travel burden and how evenly it is shared.
- A substantial bonus for matching the meeting purpose emphasizes intent.

### Combining Signals Into Labels

```python title="ml/label_builder.py" showLineNumbers
click_score = weights.click if int(action.get("is_clicked", 0)) == 1 else 0.0
vote_score = weights.vote if int(action.get("is_voted", 0)) == 1 else 0.0
final_score = weights.final if int(action.get("is_final_selected", 0)) == 1 else 0.0

rating = float(action.get("rating", 0) or 0)
rating = max(0.0, min(5.0, rating))
feedback_score = (rating / 5.0) * weights.rating_max_bonus

return click_score + vote_score + final_score + feedback_score
```

- Combine funnel actions into one continuous label for ranking.

### Generating ETA Features

```python title="ml/feature_builder_part3.py" showLineNumbers
etas_np = np.array(etas, dtype=float)

eta_mean = float(np.mean(etas_np))
eta_std = float(np.std(etas_np))
eta_max = float(np.max(etas_np))
eta_min = float(np.min(etas_np))
eta_range = float(eta_max - eta_min)
eta_p90 = float(np.percentile(etas_np, 90))
```

- Include distribution statistics alongside the mean to preserve information about fairness.

### Calculating NDCG

```python title="ml/evaluate_part3.py" showLineNumbers
def ndcg_at_k(y_true, y_score, group_ids, k):
    ndcgs = []
    for gid in np.unique(group_ids):
        m = group_ids == gid
        t = y_true[m]
        s = y_score[m]

        order = np.argsort(-s)
        ideal = np.argsort(-t)

        dcg = _dcg(t[order], k=k)
        idcg = _dcg(t[ideal], k=k)
        ndcgs.append(0.0 if idcg == 0.0 else dcg / idcg)

    return float(np.mean(ndcgs)) if ndcgs else 0.0
```

- Evaluate the quality of the top ranks within each `room_id` group.

## Inside the Scripts

### 1. Environment Setup

```bash title="scripts/setup_mac_linux.sh" showLineNumbers
#!/usr/bin/env bash
set -euo pipefail

python3 -m venv .venv-ml
source .venv-ml/bin/activate

python -m pip install --upgrade pip
pip install -r requirements-ml.txt

echo "Environment ready."
```

- `set -euo pipefail` surfaces failures immediately and reduces silent errors.
- A virtual environment separates dependencies from the system Python installation.

### 2. Data Generation and Labeling

```bash title="scripts/generate_part3.sh" showLineNumbers
#!/usr/bin/env bash
set -euo pipefail

source .venv-ml/bin/activate

python ml/synthetic_generator_part3.py   --stations ml/out/stations.csv   --places ml/out/places.csv   --n-rooms 80   --seed 42   --out-rooms ml/rooms_part3.jsonl   --out-actions ml/synthetic_actions_part3.jsonl

python ml/label_builder.py   --input ml/synthetic_actions_part3.jsonl   --output ml/synthetic_actions_part3_labeled.jsonl
```

- Convert the generated behavioral logs into the `target_score` label so the model can train on them.
