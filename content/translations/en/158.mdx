## Before We Begin
> This post assumes that you already have a basic Expo project. For instructions on creating one, see the guides for [Windows](/blog/post/117-expo-proj-init) or [Mac](/blog/post/143-expo-init-mac).

Let's explore how to connect and use Reown WalletKit in a React Native (Expo) app. Reown WalletKit is a library that helps developers easily implement digital wallet features such as wallet connections, transaction history, and authentication. Before connecting with WalletConnect, see this [post on creating a blockchain wallet in React Native](/blog/post/144-expo-mnemonic-gen).

### What Is Reown WalletKit?
> Reown is a company focused on user experience, offering AppKit and WalletKit toolkits to help people building onchain unlock better experiences. (Source: [Reown website](https://reown.com))

Reown's SDKs fall into two main categories.
*AppKit* is a comprehensive SDK for creating a seamless onchain experience, with email and social login, gas sponsorship, multichain support, onramps, swaps, user insights, and access to more than 600 wallets.
*WalletKit* is an open-source SDK for seamless wallet connections across blockchains. It offers one-click authentication, secure transaction signing, phishing protection, and advanced onchain features such as batch transactions and paymasters.
Simply put, AppKit is an SDK for building Dapps, while WalletKit is an SDK for connecting wallets. In this post, we will use **WalletKit** to add digital wallet functionality to a React Native app.

## Installation and Initial Setup
### 1. Install the Reown WalletKit Packages

Open a terminal and enter the following commands.  
(This assumes you have already created a project.)

```bash title="npm 사용 시"
npm install @reown/walletkit @walletconnect/react-native-compat
npm install @react-native-async-storage/async-storage @react-native-community/netinfo react-native-get-random-values fast-text-encoding
npm install @walletconnect/jsonrpc-types --dev
```

```bash title="yarn 사용 시"
yarn add @reown/walletkit @walletconnect/react-native-compat
yarn add @react-native-async-storage/async-storage @react-native-community/netinfo react-native-get-random-values fast-text-encoding
yarn add @walletconnect/jsonrpc-types --dev
```

For an **Expo project**, also run the following command.
```bash
npx expo install expo-application
```

### 1. Initialize WalletKit
First, create a blank screen and initialize WalletKit with `WalletKit.init`. Pass the Core object provided by Reown as the core property, and set the wallet's name, description, icons, redirect URLs, and other details in metadata. The WalletKit.init method returns a Promise, so you can use the returned WalletKit object when initialization completes. Here, we will use useState to keep the WalletKit object in state.
For Core's projectId, use the project ID from [Create a Reown Project](#2-reown-프로젝트-생성).
```tsx title="/app/index.tsx"
import '@walletconnect/react-native-compat';
import { WalletKit } from '@reown/walletkit';
import { WalletKit as WalletKitType } from '@reown/walletkit/dist/types/client';
import { Core } from '@walletconnect/core';
import { useEffect, useState } from 'react';
import { Text } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';

const core = new Core({
  projectId: 'your_project_id', // reown 프로젝트 ID
});

const App = () => {
  const [walletKit, setWalletKit] = useState<WalletKitType>();

  useEffect(() => {
    WalletKit.init({
      core,
      metadata: { // 지갑 메타데이터 (본인 상황에 맞게 수정)
        name: 'Demo React Native Wallet Promlee',
        description: 'Demo RN Wallet to interface with Dapps',
        url: 'www.promleeblog.com',
        icons: ['https://your_wallet_icon.png'],
        redirect: {
          native: 'promleewallet://',
        },
      },
    }).then((kit) => {
      setWalletKit(kit);
    });
  }, []);

  return (
    <SafeAreaView style={{ padding: 20 }}>
      <Text>{walletKit?.metadata.name}</Text>
    </SafeAreaView>
  );
};

export default App;
```
This example simply displays the metadata as Text after initializing WalletKit. Run the app, and the wallet name will appear on the screen.
