## Before We Begin
Firebase provides services including App Distribution, Authentication, Crashlytics, and Analytics. This guide shows how to register the iOS and Android versions of a Flutter app separately.
<Rbox>Unless you have a specific reason to register the apps manually, use the Flutter workflow that registers both platforms together.</Rbox>
[See how to register both apps together](/blog/post/134-flutter-firebase-apps)

## 1. Create a Firebase Project
Sign in with Google in the [Firebase console](https://console.firebase.google.com/u/0) and click Create a project.
<Img src="/posts/250225-114901.png" width={500} alt="Creating a Firebase project"/>
<Img src="/posts/250225-115137.png" width={300} alt="Firebase project setup"/>
Click `계속` (Continue) to create the project.

<Ads1 />
## 2. Register the Android App
After creating the project, add an app from Project Overview. Start with Android.
<Img src="/posts/250225-134924.png" width={300} alt="Registering an Android app"/>

### 2.1. Enter the Package Name
Enter the app name and package name.
The original example looks for `android.namespace` in `/android/app/src/build.gradle`, or the `package` attribute in `/android/app/src/main/AndroidManifest.xml`, with `com.example.promleeblog` as an example. Use the application ID of the installed build if it differs from the namespace. We'll add the SHA-1 fingerprint later.
<Img src="/posts/250225-135316.png" width={300} alt="Entering the Android package name"/>

### 2.2. Add the Configuration File
Download the configuration file and add it to the project. Use the directory structure below as a guide.
<Img src="/posts/250225-135357.png" width={300} alt="Downloading the Android configuration file"/>
```
📦android
┣ 📂app
┃ ┣ 📂src
┃ ┃ ┣ 📂debug
┃ ┃ ┣ 📂main
┃ ┃ ┗ 📂profile
┃ ┣ 📜build.gradle
┗ ┗ 📜google-services.json // 구성 파일
```
Add the following code so the app can use the configuration file.
```kotlin title="android/build.gradle"
plugins {
	// ...
	id 'com.google.gms.google-services' version '4.4.2' apply false
}
```

```kotlin title="android/app/build.gradle"
plugins {
	// ...
  id 'com.android.application'
  id 'com.google.gms.google-services'
}
dependencies {
	// ...
  implementation platform('com.google.firebase:firebase-bom:33.9.0')
  implementation 'com.google.firebase:firebase-analytics'
}
```
That completes the Android setup. Next, register the iOS app.

<Ads2 />
## 3. Register the iOS App
Select the option to add an iOS app as shown below.
<Img src="/posts/250225-140648.png" width={300} alt="Registering an iOS app"/>

### 3.1. Enter the Bundle ID
Enter the app name and bundle identifier. The bundle ID is the `PRODUCT_BUNDLE_IDENTIFIER` value in `/ios/Runner.xcodeproj/project.pbxproj`, for example `com.example.promleeblog`.
<Img src="/posts/250225-141228.png" width={300} alt="Entering the iOS bundle ID"/>

### 3.2. Add the Configuration File
Download the configuration file and add it to the project, using the directory structure below.
<Img src="/posts/250225-141459.png" width={300} alt="Downloading the iOS configuration file"/>
```
📦ios
┣ 📂Runner
┗ ┗ 📜GoogleService-Info.plist // 구성 파일
```

### 3.3. Add the Firebase SDK
Right-click the ios folder and open it in Xcode.
<Img src="/posts/250225-141753.png" width={200} alt="Opening the project in Xcode"/>
With the project open, select File > Add Package Dependencies.
<Img src="/posts/250225-141949.png" width={200} alt="Adding package dependencies"/>
Enter `https://github.com/firebase/firebase-ios-sdk` in the search field at the top right. Once the result appears, click Add Package, add FirebaseAnalytics to the Runner target, and click Add Package again.
<Img src="/posts/250225-142445.png" width={500} alt="Finding the Firebase iOS SDK package"/>
Skip the native initialization code in step 4 and finish the wizard. For Flutter, put the initialization code in main.dart.

## Conclusion
We registered the Android and iOS versions of a Flutter project separately in Firebase. You can now register your apps in the Firebase console and test them. Next time, we'll look at the Flutter workflow for registering both apps together.
