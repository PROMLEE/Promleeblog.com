## Algorithm categories
Mathematics, strings, greedy algorithms, parsing.

## Problem description
Given an expression made up of positive integers and the `+` and `-` operators, write a program that places parentheses to minimize its value.

### Input
The expression is provided on the first line.
It consists of positive integers from `1` to `1000000` and the `+` and `-` operators, with at least one operator.
The expression has a maximum length of `50`.
```txt
50-50+40-30+20-10
```
### Output
Print the minimum possible result for the test case.
50-(50+40)-(30+20)-10 = 50 - 50 - 40 - 30 - 20 - 10 = -100
```txt
-100
```

<Img src="/250506-185802.webp" width={300} alt="Problem explanation"/>

## Solution
1. Split the expression at each `-` to separate it into groups.
2. Always add the first group.
3. Treat each subsequent group as parenthesized: Split it at +, sum its numbers, and subtract the result.
4. Print the result after processing every group.

<Ads1 />

## Code — Python
```python
expression = input().strip()

  # 1. '-'를 기준으로 먼저 나눈다.
parts = expression.split('-')

  # 2. 첫 번째 덩어리는 무조건 더한다.
total = sum(map(int, parts[0].split('+')))

  # 3. 그 이후 덩어리는 모두 괄호로 묶인다고 생각하고 각각 +로 쪼개서 합산한 뒤 빼기
for part in parts[1:]:
    total -= sum(map(int, part.split('+')))

print(total)
```

## Key points
To get the minimum value, group all numbers following the subtraction sign into parentheses and subtract them together.
- + only affects the sum inside a group.
- - marks the start of a group.
- Think of everything after the first - as belonging inside ().

### Time complexity
- split('-') → O(N).
- split('+') for each group → O(N) in total.
- Converting each number with int() → O(N).
- Calculating the total → O(N).

Overall time complexity: O(N).
