> https://www.acmicpc.net/problem/1927
## 算法分类
数据结构、优先队列

## 解题思路
1. 可以使用Python内置的heapq模块解决这道题，也可以自行实现堆。
2. 当输入不为0时：通过heapq.heappush(列表, 数据)插入数据。
3. 当输入为0时：检查列表是否为空；不为空时使用heapq.heappop(列表)弹出并输出结果。

## 代码 — Python
```python
import heapq
import sys

H = []
n = int(sys.stdin.readline())
for i in range(n):
    k = int(sys.stdin.readline())
    if k == 0:
        if len(H) == 0:
            print(0)
            continue
        else:
            print(heapq.heappop(H))
    else:
        heapq.heappush(H, k)
```

## 遇到的问题与解决方法
1. 第5行和第7行使用input()读取数据时出现了超时。
   - 在Python中，这里的输入处理应使用sys模块的readline，而不是input()。

## 要点
- 可以通过heapq模块实现最小堆。
- 使用heapq.heappush(列表, 数据)插入。
- 使用heapq.heappop(列表)弹出。
- 对空列表执行弹出操作会引发IndexError，因此必须处理列表为空的情况。
- 时间复杂度：O(NlogN)
