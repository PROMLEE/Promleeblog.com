## 开始之前
大家好！一起来搭建 Vue.js 3 的开发环境。Vue.js 是一个用于构建用户界面的渐进式框架。
与此前的版本相比，Vue 3 的性能有很大提升，开发体验也更便捷。
本文将从用 *Vite* 快速创建 Vue 3 项目讲起，再逐步介绍 Vue 的核心概念之一：*单文件组件（SFC）*的结构。

## 创建 Vite + Vue 3 项目
现在开始创建 Vue 3 项目。
以前，人们主要使用 *Vue CLI* 创建 Vue 项目。如今，*Vite* 由于更快、更轻量，常用于创建和运行项目。

### 什么是 Vite？
Vite 是新一代前端开发工具。
与 Webpack 等传统打包工具的做法不同，Vite 利用原生 ES 模块运行开发服务器，因此启动项目快得多。
开发服务器往往不到一秒就能启动。无需像 Webpack 那样进行复杂配置，就能快速开始开发，这是它的一大优势。

### 创建项目
创建项目之前，电脑上需要安装 *Node.js*，以及 *npm* 或 *yarn*。安装 Node.js 时，通常也会一起安装 npm。
打开终端，例如命令提示符或 PowerShell，输入以下命令。
```bash
npm create vite@latest
```
运行命令后，Vite 会提出几个问题。
1. `project name:` 输入项目名称，例如 `my-vue-app`。
2. `Select a framework:` 用方向键选择 `Vue`，再按回车。
3. `Select a variant:` 在 `JavaScript` 和 `TypeScript` 中选择一种。本次练习建议选 `JavaScript`。

选择完成后，Vite 会自动生成项目目录和基础文件。
接下来进入生成的项目目录，安装所需的依赖包。
```bash
cd my-vue-app
npm install
```
`npm install` 用于下载并安装项目所需的依赖包。
安装完成后，就可以启动开发服务器。
```bash
npm run dev
```
运行这个命令后，终端会显示类似 `http://localhost:5173` 的地址。
在浏览器中打开该地址，就能看到“You did it!”的提示以及旋转的 Vue 标志。

## 理解 SFC 结构（.vue 文件）
Vue 的主要特点之一是使用 `.vue` 文件编写*单文件组件（Single File Component）*，简称 *SFC*。
就像乐高积木，每个 `.vue` 文件都是一个独立的组件。
一个文件可以同时包含 HTML、JavaScript 和 CSS，把相关代码放在一起，便于管理。

### SFC 文件的基本结构
打开刚生成的项目中的 `src/components/HelloWorld.vue`，应该能看到类似以下结构。

```html
<script setup>
// JavaScript 로직이 들어가는 부분
// 컴포넌트의 데이터, 함수 등을 정의합니다.
import { ref } from 'vue'

defineProps({
  msg: String,
})

const count = ref(0)
</script>

<template>
  <h1>{{ msg }}</h1>

  <div class="card">
    <button type="button" @click="count++">count is {{ count }}</button>
  </div>

  <p>
    Edit
    <code>components/HelloWorld.vue</code> to test HMR
  </p>
</template>

<style scoped>
/* CSS 스타일이 들어가는 부분 */
/* `scoped` 속성을 사용하면 이 스타일은 현재 컴포넌트에만 적용됩니다. */
.read-the-docs {
  color: #888;
}
</style>
```

<br />
#### `<template>`
    这里放组件的 *HTML 结构*。
    要在界面上显示的内容，例如文字、按钮和图片，都写在这里。
    Vue 使用 `template` 内的特殊语法（例如 `{{ }}`）将数据呈现在界面上。

#### `<script setup>`
    这里放组件的 *JavaScript 逻辑*。
    组件的数据（状态）、修改数据的函数、导入和使用其他组件等 JavaScript 代码，都写在这里。
    在 Vue 3 中，借助 `setup` 属性可以更简洁地编写组件逻辑。
    使用 `setup` 时，这段代码就像在创建组件时执行一次的函数，可以在其中声明响应式数据并定义函数。

#### `<style scoped>`
    这里放组件的 *CSS 样式*。关键是 `scoped` 属性。
    添加 `scoped` 后，这个 `<style>` 标签里的 CSS 规则*只应用于当前组件*。
    这些规则不会影响其他组件或全局样式，因此可以独立管理各个组件的样式，无须担心 CSS 冲突。

### SFC 的优点
- **可读性**：HTML、JavaScript 和 CSS 集中在一个文件里，容易理解和修改特定组件。
- **可维护性**：不同组件各自有独立文件，便于按功能管理和维护代码。
- **可复用性**：写好的组件可以方便地导入到其他地方，提高代码复用率。
