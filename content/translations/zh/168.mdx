## 开始之前

> 在基本的 React Native CLI 开发环境中，也可以通过额外配置使用这个组件。
### 什么是底部面板？
底部面板（Bottom Sheet）是移动应用中常见的界面形式，可以从屏幕底部提供补充信息或引导用户执行后续操作。它与模态框类似，特点是从屏幕底部出现。我们将把它做成可在各页面复用的组件。

```bash title="React Native CLI - npm"
npm install react-native-reanimated react-native-gesture-handler
```

```bash title="React Native CLI - yarn"
yarn add react-native-reanimated react-native-gesture-handler
```

## 使用底部面板
先在空白页面实现最简单的打开和关闭功能。导入 BottomSheet 组件并创建 ref，然后调用 expand 和 close 打开或关闭面板。
```tsx title="/app/index.tsx"
import React, { useCallback, useRef } from "react";
import { Text, StyleSheet, View, Button } from "react-native";
import BottomSheet, { BottomSheetView } from "@gorhom/bottom-sheet";

const App = () => {
  // ref
  const bottomSheetRef = useRef<BottomSheet>(null);

  // callbacks
  const handleSheetChanges = useCallback((index: number) => {
    console.log("handleSheetChanges", index);
  }, []);

  // renders
  return (
    <View style={styles.container}>
      <Button title="expand" onPress={() => bottomSheetRef.current?.expand()} />
      <BottomSheet ref={bottomSheetRef} onChange={handleSheetChanges}>
        <BottomSheetView style={styles.contentContainer}>
          <Text>Awesome 🎉</Text>
          <Button
            title="close"
            onPress={() => bottomSheetRef.current?.close()}
          />
        </BottomSheetView>
      </BottomSheet>
    </View>
  );
};

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: "center",
  },
  contentContainer: {
    flex: 1,
    padding: 36,
    alignItems: "center",
  },
});

export default App;
```

### 了解底部面板的 props
在创建自定义底部面板之前，先看看几个常用的 props。
| props | 说明 | 类型 | 默认值 | 必填 |
| ---- | ---- | ---- | ------- | -------- |
| index | 设置初始状态（0、-1） | number | 0 | NO |
| snapPoints | 设置停靠点 <br/> 由数字和字符串组成的数组，表示面板停靠的高度。<br/> 例如 [200, "60%"] <br/> enableDynamicSizing 为 false 时必填 | [] | - | YES |
| animateOnMount | 挂载时是否播放动画 | boolean | true | NO |
| backdropComponent | 底部面板的背景遮罩组件 | BottomSheetBackdrop | - | NO |
| enablePanDownToClose | 是否允许向下拖动关闭 | boolean | true | NO |

还有其他可用的 props，详见[官方文档](https://gorhom.dev/react-native-bottom-sheet/props)。

## 创建自定义底部面板
先设定几个条件。
1. 通过 props 接收所有设置，便于自定义。
2. 在底部面板中渲染通过 children 传入的组件。
3. 提供默认样式，同时允许自定义。
4. 通过 props 接收回调，以处理面板内部和外部触发的事件。

接下来创建 BottomSheet 组件。先定义接口，再让组件接收 props。
将 snapPoints 的默认值设为 ["30%"]，并原样转发收到的 props。为了让面板外部也能使用 ref，需要传入 *bottomSheetModalRef*。最后，用 *BottomSheetView* 包裹 children。
```tsx title="/app/components/ui/CustomBottomSheet.tsx"
import React from "react";
import BottomSheet, { BottomSheetView } from "@gorhom/bottom-sheet";

interface CustomBottomSheetProps extends BottomSheetProps {
  bottomSheetModalRef: React.RefObject<BottomSheet>;
  children: React.ReactNode;
  snapPoints?: string[];
}

const CustomBottomSheet: React.FC<CustomBottomSheetProps> = ({
  bottomSheetModalRef,
  children,
  snapPoints = ["30%"],
  ...props
}) => {

  return (
    <BottomSheet
      ref={bottomSheetModalRef}
      index={0}
      snapPoints={snapPoints}
      style={{
        zIndex: 10,
        elevation: 10,
      }}
      enableDynamicSizing={false}
      enablePanDownToClose={false}
      {...props}
    >
      <BottomSheetView style={{ flex: 1 }}>{children}</BottomSheetView>
    </BottomSheet>
  );
};

export default CustomBottomSheet;
```

### 添加 backdropComponent
接着添加 backdropComponent，用来定制面板后方的遮罩。这里将它固定在组件内部，无须通过 props 传入。
使用 useCallback 创建 renderBackdrop 函数，让它返回 BottomSheetBackdrop 组件。然后将 renderBackdrop 传给 BottomSheet 的 backdropComponent prop。
为了观察各项 props 的效果，可以将 snapPoints 改为 ["30%", "60%"]，将 enablePanDownToClose 设为 true。再把 BottomSheetBackdrop 的 pressBehavior 设为 "close"，使点击遮罩可以关闭面板。设为 "none" 时，点击不会触发操作。
```tsx title="/app/components/ui/CustomBottomSheet.tsx" {20-30, 41}
//...
const CustomBottomSheet: React.FC<BottomSheetProps> = ({
  bottomSheetModalRef,
  children,
  snapPoints = ["30%", "60%"],
  ...props
}) => {
  const renderBackdrop = useCallback(
    (backdropProps: any) => (
      <BottomSheetBackdrop
        {...backdropProps}
        pressBehavior="close"
        appearsOnIndex={0}
        disappearsOnIndex={-1}
      />
    ),
    []
  );

  return (
    <BottomSheet
      ref={bottomSheetModalRef}
      index={0}
      snapPoints={snapPoints}
      style={{
        zIndex: 10,
        elevation: 10,
      }}
      backdropComponent={renderBackdrop}
      enableDynamicSizing={false}
      enablePanDownToClose={true}
      {...props}
    >
      <BottomSheetView style={{ flex: 1 }}>{children}</BottomSheetView>
    </BottomSheet>
  );
};

export default CustomBottomSheet;
```

```tsx title="/app/components/ui/CustomBottomSheet.tsx"
import BottomSheet, {
  BottomSheetView,
  BottomSheetBackdrop,
  BottomSheetProps,
} from '@gorhom/bottom-sheet';
import { BottomSheetDefaultBackdropProps } from '@gorhom/bottom-sheet/lib/typescript/components/bottomSheetBackdrop/types';
import React, { useCallback } from 'react';

interface CustomBottomSheetProps extends BottomSheetProps {
  bottomSheetModalRef: React.RefObject<BottomSheet>;
  children: React.ReactNode;
  snapPoints?: string[];
}

const CustomBottomSheet: React.FC<CustomBottomSheetProps> = ({
  bottomSheetModalRef,
  children,
  snapPoints = ['30%'],
  ...props
}) => {
  const renderBackdrop = useCallback(
    (backdropProps: BottomSheetDefaultBackdropProps) => (
      <BottomSheetBackdrop
        {...backdropProps}
        pressBehavior="close"
        appearsOnIndex={0}
        disappearsOnIndex={-1}
      />
    ),
    [],
  );

  return (
    <BottomSheet
      ref={bottomSheetModalRef}
      index={0}
      snapPoints={snapPoints}
      style={{
        zIndex: 10,
        elevation: 10,
      }}
      backdropComponent={renderBackdrop}
      enableDynamicSizing={false}
      enablePanDownToClose={true}
      {...props}
    >
      <BottomSheetView style={{ flex: 1 }}>{children}</BottomSheetView>
    </BottomSheet>
  );
};

export default CustomBottomSheet;
```
