## 开始之前
为了改善网页中的性能或画质，有时需要转换图片和视频文件。
手动转换这些文件既麻烦又耗时，本文将介绍如何使用 Mac 文件夹操作自动完成转换。
我把上传到博客的 MP4、GIF、PNG 文件转换为 WebP 的过程自动化了，从而节省了文件转换时间。

## 配置环境
首先，在已安装 Homebrew 的环境中安装 ffmpeg。
如果尚未安装 Homebrew，请参考[安装 Homebrew](/blog/post/119-homebrew)，然后运行以下命令。
```bash
brew install ffmpeg
```
在合适的位置创建一个文件夹并命名。
我先在桌面创建了 `mp4_to_webp` 文件夹，用于将 MP4 转换为 WebP。
<Img src="/posts/250317-162026.webp" width={100} alt=""/>
<Rbox>完成文件夹操作设置后，文件夹名称将无法更改，请谨慎命名！</Rbox>
在 Finder 的应用程序菜单中运行 `Automator`，选择 `폴더 적용 스크립트`（应用到文件夹的操作）。
<Img src="/posts/250317-162241.webp" width={500} alt="在 Automator 中选择文件夹操作"/>
选择刚创建的文件夹，然后添加 `선택된 finder 항목 가져오기`（获取所选 Finder 项目）。
<Img src="/posts/250317-162603.webp" width={500} alt="获取所选 Finder 项目"/>
从“实用工具”中添加 `쉘 스크립트 실행`（运行 Shell 脚本），并将“传递输入”改为“作为自变量”。
<Img src="/posts/250317-162751.webp" width={500} alt="添加运行 Shell 脚本并设置输入方式"/>
准备工作已经完成，接下来编写脚本。

## 编写脚本
以下示例都会先删除原文件，再将转换后的文件保存到 `/Users/{사용자명}/Documents`。
请根据需要修改保存路径。
### 视频转 WebP（MP4、MOV 转 WebP）
```bash
for f in "$@"; do
    /opt/homebrew/bin/ffmpeg -n -loglevel error -i "$f" -vf "fps=15,scale=720:-1:flags=lanczos" -loop 0 "/Users/promlee/Documents/$(date +"%y%m%d-%H%M%S").webp"
    rm -f "$f"
done
```
下表说明了脚本中使用的命令和选项。
| 命令 | 说明 |
| --- | --- |
| for f in "\$@" | 依次处理输入的每个文件（f）。 |
| /opt/homebrew/bin/ffmpeg | 运行通过 Homebrew 安装的 ffmpeg。 |
| -n | 如果已存在同名文件，则不覆盖。 |
| -loglevel error | 只显示错误信息，隐藏其他日志。 |
| -i "\$f" | 输入文件（\$f，即待转换的视频文件）。 |
| -vf | 视频滤镜选项。 |
| "fps=15" | 转换为每秒 15 帧，通过减少帧数来缩小文件体积。 |
| "scale=720:-1" | 将宽度调整为 720px，高度按比例自动计算（-1）。 |
| "flags=lanczos" | 使用高质量的 Lanczos 重采样算法。 |
| -loop 0 | 让动画 WebP 无限循环。 |
| -f | 转换完成后删除原视频文件（\$f）。 |

### PNG 转 WebP
```bash
for f in "$@"; do
    /opt/homebrew/bin/cwebp -q 70 "$f" -o "/Users/promlee/Documents/$(date +"%y%m%d-%H%M%S").webp";
    rm -f "$f"
done
```

### 视频转 GIF
```bash
for f in "$@"; do
    /opt/homebrew/bin/ffmpeg -n -loglevel error -i "$f" -vf "fps=15,scale=720:-1:flags=lanczos" "/Users/promlee/Documents/$(date +"%y%m%d-%H%M%S").gif";
    rm -f "$f"
done
```
