## 开始之前
第 6 篇将介绍更进阶的状态管理方法。
随着应用变复杂，多个组件需要共享相同数据的情况也越来越多。
例如用户登录信息、购物车列表、主题设置等，都需要在应用各处保持一致。
如果只使用 `props` 管理这些“全局状态”，代码就会变得复杂而凌乱。

<br/>
<br/>

为解决这个问题，Vue 提供了官方状态管理库 *Pinia*。
Pinia 充当“中央仓库”，存放所有组件共享的数据。
任何组件都可以自由地向仓库存储数据、从中读取数据，让复杂的数据流变得简单直观。

## 安装与配置 Pinia
首先在项目中安装 Pinia。
在终端输入以下命令。

```bash
npm install pinia
```

安装完成后，需要在 `main.js` 文件中创建并注册 Pinia 实例，让整个 Vue 应用都能使用它。

```javascript title="src/main.js" {2, 8}
import { createApp } from 'vue'
import { createPinia } from 'pinia' // Pinia에서 createPinia를 가져옵니다.
import App from './App.vue'
import router from './router'

const app = createApp(App)

app.use(createPinia()) // Pinia 인스턴스를 생성하여 앱에 등록합니다.
app.use(router)

app.mount('#app')
```

现在，应用已经可以使用 Pinia 了。
通常会在 `src` 文件夹下创建 `stores` 文件夹，统一管理 Pinia store 文件。

## 定义 Store
Store 是一个仓库，将特定用途的状态（state）、计算值（getters）以及修改状态的函数（actions）组织在一起。
例如，可以按功能创建“计数器 store”“用户认证 store”等。
创建 `src/stores/counter.js` 文件，定义计数器 store。

```javascript title="src/stores/counter.js"
import { defineStore } from 'pinia'

// `defineStore`를 사용하여 스토어를 정의합니다.
// 첫 번째 인자는 스토어의 고유 ID(문자열)입니다.
// 두 번째 인자는 state, getters, actions를 포함하는 객체입니다.
export const useCounterStore = defineStore('counter', {
  // 1. state: 스토어의 상태(데이터)를 정의합니다. 반드시 화살표 함수로 반환해야 합니다.
  state: () => ({
    count: 0,
    userName: 'promleeblog'
  }),

  // 2. getters: state를 기반으로 하는 계산된 값입니다. Vue의 computed와 같습니다.
  getters: {
    doubleCount: (state) => state.count * 2,
    doubleCountPlusOne: (state) => {
      // this를 통해 다른 getter에 접근할 수도 있습니다.
      return this.doubleCount + 1
    }
  },

  // 3. actions: state를 변경하는 함수(메소드)입니다. Vue의 methods와 같습니다.
  actions: {
    increment() {
      // state의 속성에 접근할 때는 'this'를 사용합니다.
      this.count++
    },
    reset() {
      this.count = 0
    }
  }
})
```

## 在组件中使用 Store
接下来，在组件中导入并使用刚才定义的 store。
用法就像 Composition API 函数一样简单。

```vue title="src/components/CounterComponent.vue" {3, 6, 10}
<script setup>
import { useCounterStore } from '@/stores/counter'
import { storeToRefs } from 'pinia'

// 정의한 스토어를 호출하여 인스턴스를 만듭니다.
const counterStore = useCounterStore()

// 중요: 스토어의 상태를 구조 분해 할당하면 반응성을 잃게 됩니다.
// 반응성을 유지하면서 가져오려면 `storeToRefs`를 사용해야 합니다.
const { count, doubleCount } = storeToRefs(counterStore)

// actions는 구조 분해 할당해도 괜찮습니다.
const { increment, reset } = counterStore
</script>

<template>
  <div>
    <h2>카운터</h2>
    <p>현재 값: {{ count }}</p>
    <p>두 배 값: {{ doubleCount }}</p>
    
    <button @click="increment">증가</button>
    <button @click="counterStore.reset()">초기화</button>
  </div>
</template>
```

这里的 `storeToRefs` 是一个非常重要的工具函数。
如果像 `const { count } = counterStore` 那样直接解构，`count` 就会变成失去响应性的普通数字。
`storeToRefs` 会将 store 中的 `state` 和 `getters` 属性包装为保留响应性的 `ref` 对象，从而解决这个问题。

## 在多个组件中共享状态
Pinia 真正的优势在于，多个组件可以轻松共享同一份状态。
下面在独立于前面 `CounterComponent` 的 `DisplayComponent` 中，也显示计数器的值。

```vue title="src/components/DisplayComponent.vue"
<script setup>
import { useCounterStore } from '@/stores/counter'
import { storeToRefs } from 'pinia'

// 동일한 스토어를 호출합니다. Pinia가 알아서 같은 인스턴스를 반환합니다.
const counterStore = useCounterStore()
const { count } = storeToRefs(counterStore)
</script>

<template>
  <div>
    <h3>다른 컴포넌트에서 본 카운트 값: {{ count }}</h3>
  </div>
</template>
```

现在，把这两个组件放到 `App.vue` 中。
点击 `CounterComponent` 的按钮时，可以看到 `DisplayComponent` 中的数字也会实时变化。
这就是集中管理状态的好处。

## 与其他状态管理工具比较
- **Pinia 与 React Context API**
React 内置的 Context API 也能解决 props drilling 问题，但在状态频繁变化的大型应用中，可能出现性能问题。
相比之下，Pinia 针对 Vue 响应式系统进行了高度优化。
- **Pinia 与 Recoil／Zustand**
它们都是 React 生态中流行的状态管理库。
这些库侧重于“原子化（atomic）”的状态片段，而 Pinia 采用结构化的方式，将 `state`、`getters`、`actions` 组织在同一个 store 中管理。
最大的区别在于，Pinia 是 Vue 的*官方*库，能够保证与 Vue 的完善集成及长期支持。

## 结语
这次学习了使用 Pinia 管理应用全局状态的方法。
Pinia 可以让组件间复杂的数据流变得简单清晰。
无需再将 props 逐层向下传递，只要在需要的组件中直接调用 store 即可。
这能显著提高应用的可维护性与扩展性。
