## 将设计映射到代码
设计过程中产生的UML成果，例如交互图和设计类图DCD，可作为代码生成过程的输入。
**实现模型**
- 所有实现成果。
	- 包括源代码、数据库定义，以及JSP、XML和HTML页面等。

使用面向对象语言实现时，需要编写：
- 类与接口定义。
- 方法定义。

**从UML设计转换为代码的过程**
- 从类图转换为*类定义*。
- 从交互图转换为*方法体*。

## 从DCD创建类定义（Creating Class Definitions from DCD）
DCD提供的信息足以生成面向对象语言中的基本类定义。
<Img src="/posts/240618-003747.png" width={400}/>
**属性定义，也就是Java字段**：
把DCD中定义的属性声明为Java字段。
- 例如，`quantity: Integer`映射为`private int quantity;`。
- 例如，`description: ProductDescription`映射为`private ProductDescription description;`。

**方法签名**：
把DCD中的方法声明为Java方法。
- 例如，`getSubtotal(): Money`映射为`public Money getSubtotal() { ... }`。

## 从交互图创建方法体（Creating Method Bodies from Interaction Diagrams）
交互图中的消息顺序，会转换为方法定义中的一系列语句。
<Img src="/posts/240618-004009.png" width={500}/>

**从交互图提取消息**：
- `enterItem`消息发给`Register`实例，因此`enterItem`方法定义在`Register`类中。
- 按消息顺序，用代码实现方法的行为。

**消息顺序**：
- 消息1：向`ProductCatalog`对象发送`getProductDescription`消息，获取商品描述。
- 消息2：向`Sale`对象发送`makeLineItem`消息，创建销售明细项。

**Java实现**：
- 将消息顺序转换为代码语句，编写`enterItem`方法。
	```java title="예시 코드" showLineNumbers=true
	public class Register {
			private ProductCatalog catalog;
			private Sale currentSale;
			public Register(ProductCatalog catalog) {
					this.catalog = catalog;
					this.currentSale = new Sale();
			}
			public void enterItem(int itemID, int qty) {
					ProductDescription desc = catalog.getProductDescription(itemID);
					currentSale.makeLineItem(desc, qty);
			}
	}
	```

## 代码中的集合类（Collection Classes in Code）
> 在面向对象编程中，用于管理和操作多个对象的重要工具。
尤其常用于表达*一对多*关系。

面向对象语言通过引入*集合对象*实现这种关系：
- List，例如实现List接口的ArrayList：可增长的有序列表。
- Map，例如实现Map接口的HashMap：按键查询。
- 普通数组。

## 实现顺序（Order of Implementation）
> 应当按照耦合度从低到高的顺序实现类。

<Img src="/posts/240618-004911.png" width={500}/>
- 首先可以实现Payment或ProductDescription。
- 然后实现只依赖前面已实现类的类，例如ProductCatalog或SalesLineItem。
