## 开始之前
> 本文基于 Expo 52 编写。

下文假设基本的 Expo 项目已经配置好。

### 什么是 EVM？
EVM 是以太坊区块链的核心组件，是负责执行智能合约的虚拟机。它保障智能合约的安全性和去中心化。除了以太坊，许多其他区块链也支持 EVM。这让开发者可以构建去中心化应用（DApp），对提升区块链的扩展性和实用性也很重要。
广泛使用 EVM 的一个好处是，在兼容的链上可以使用*同一个地址*，也就是可以在这些区块链上使用同一个钱包。即使用到多条区块链，用户也无须为每条链准备不同的钱包。
下面将介绍如何让用户在 DApp 中创建并使用 EVM 区块链钱包。

### 什么是助记词？
助记词（Mnemonic）是一组由 12 至 24 个英文单词组成的词语，便于记忆和恢复加密货币钱包的私钥。它按 BIP-39 标准生成，有了助记词，即使没有私钥也可以恢复钱包。助记词是敏感信息，请勿存放在网上，并在安全的地方留存备份。
接下来先为用户生成助记词，再用助记词创建钱包。

### 为什么不用 ethers.Wallet.createRandom()？
createRandom() 函数使用随机字节创建钱包，在应用环境中需要向相应的操作系统请求权限。这个过程比较复杂，也缺乏可参考的资料。因此，本文将用 Expo 提供的 expo-crypto 库生成助记词，再用助记词创建钱包。

## 1. 生成助记词
### 1.1. 安装依赖库
用下面的命令安装 expo-crypto 和 bip39。expo-crypto 是 Expo 提供的加密库，bip39 用于生成助记词。buffer 是 expo-crypto 使用的库。
```bash
npx expo install expo-crypto
npm install bip39 buffer
```
### 1.2. 配置 Buffer
使用 expo-crypto 之前，先配置 Buffer。我在 `app/_layout.tsx` 中添加了下面的代码。
```tsx
const RootLayout = () => {
	global.Buffer = require('buffer').Buffer;
	// ...
}
```

### 1.3. 编写生成助记词的函数
下面的代码用于生成助记词。先用 expo-crypto 生成随机字节，再用 bip39 将其转换为助记词。
为方便后续使用，我将结果转换成字符串数组后返回。
```tsx
import { Buffer } from 'buffer';
import * as Crypto from 'expo-crypto';
import * as bip39 from 'bip39';

const generateMnemonic = async () => {
	const randomBytes = await Crypto.getRandomBytesAsync(16);
	const mnemonic = bip39.entropyToMnemonic(Buffer.from(randomBytes).toString('hex'));
	return mnemonic.split(' '); // string 배열로 변환 
}
```

## 2. 创建钱包
### 2.1. 安装 ethers.js
用以下命令安装 ethers.js。这是一个用于与以太坊区块链交互的库。
```bash
npm install ethers
```

### 2.2. 编写创建钱包的函数
下面的代码使用助记词创建钱包，并返回钱包地址。
```tsx
import { ethers } from 'ethers';

const mnemonic = ['word1', 'word2', 'word3', 'word4', 'word5', 'word6', 'word7', 'word8', 'word9', 'word10', 'word11', 'word12'];

const getAccounts = () => {
	if (!mnemonic.length) return;
	const wallet = ethers.Wallet.fromPhrase(mnemonic.join(' '));
	return wallet; // 지갑 반환
};
```

### 2.3. 使用钱包
下面演示如何使用钱包。创建钱包后，可以查看它的地址、私钥和公钥。
```tsx
const wallet = getAccounts();
console.log(wallet.address); // 지갑 주소
console.log(wallet.privateKey); // 개인키
console.log(wallet.publicKey); // 공개키
console.log(wallet?.mnemonic?.phrase); // Mnemonic
```

## 3. 接入 Expo 应用
我通过状态管理把这个功能接入页面，并添加了 Reload 按钮，用于重新生成助记词。
<Toggle title="查看 /app/index.tsx 代码">

```tsx title="/app/index.tsx"
import { Buffer } from 'buffer';

import * as bip39 from 'bip39';
import { ethers } from 'ethers';
import * as Crypto from 'expo-crypto';
import { useEffect, useState } from 'react';
import { FlatList, Pressable, View, Text } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';

import { saveMnemonic } from '@/components/SecureStoreHelper';

const CreateWallet = () => {
  const [mnemonic, setMnemonic] = useState<string[]>([]);
  const [wallet, setwallet] = useState<ethers.HDNodeWallet>();

  function generateMnemonic() {
    const randomBytes = Crypto.getRandomBytes(16);
    const mnemonic = bip39.entropyToMnemonic(
      Buffer.from(randomBytes).toString('hex'),
    );
    setMnemonic(mnemonic.split(' '));
  }

  const getWallet = () => {
    if (!mnemonic.length) return;
    const wallet = ethers.Wallet.fromPhrase(mnemonic.join(' '));
    saveMnemonic(mnemonic.join(' '));
    setwallet(wallet);
  };

  useEffect(() => {
    generateMnemonic();
  }, []);

  useEffect(() => {
    getWallet();
  }, [mnemonic]);

  return (
    <SafeAreaView
      style={{
        flex: 1,
        justifyContent: 'flex-start',
        gap: 20,
        padding: 20,
      }}
    >
      <View>
        <FlatList
          data={mnemonic}
          renderItem={({ item, index }) => (
            <View
              style={{
                flex: 1,
                padding: 5,
                alignItems: 'center',
                borderColor: 'gray',
                borderWidth: 1,
                margin: 5,
                borderRadius: 5,
                position: 'relative',
                flexDirection: 'row',
              }}
            >
              <Text style={{ marginHorizontal: 2 }}>{index + 1}</Text>
              <Text style={{ flex: 1, textAlign: 'center' }}>{item}</Text>
            </View>
          )}
          keyExtractor={(item) => item}
          numColumns={3}
        />
      </View>
      <View style={{ gap: 20 }}>
        <Text>Address: {wallet?.address}</Text>
        <Text>Private Key: {wallet?.privateKey}</Text>
        <Text>Public Key: {wallet?.publicKey}</Text>
      </View>
      <Pressable
        onPress={() => {
          generateMnemonic();
        }}
      >
        <Text style={{ color: 'blue' }}>Reload</Text>
      </Pressable>
    </SafeAreaView>
  );
};

export default CreateWallet;
```
