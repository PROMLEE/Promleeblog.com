## 开始之前

“学开发需要 Linux 环境，可我用的是 Windows 电脑，该怎么办？”你有过这样的疑问吗？
以前可能要配置双系统，或安装独立的虚拟机。现在有了 *WSL（Windows Subsystem for Linux）*，可以直接在 Windows 中轻松使用 Linux。
<br />
本文将介绍如何用 WSL 安装常见的 Linux 发行版 *Ubuntu*，具体选择稳定的长期支持版本 *22.04 LTS*。
<Img src="/250604-144231.webp" width={300} alt="WSL 与 Ubuntu"/>
## 什么是 WSL？
正式安装前，先简单了解 WSL 的含义。
<br />
**WSL（Windows Subsystem for Linux）** 顾名思义，是*让 Windows 能够运行 Linux 可执行文件的子系统*。
这里所说的“原生运行”，指的是相比在虚拟机里运行一整套独立操作系统，可以更轻便、更快地使用 Linux 环境。
WSL 主要有两个版本。

- **WSL 1**：早期版本，通过翻译 Linux 系统调用，让 Windows NT 内核能够理解这些请求。它在文件系统性能等方面有一些限制。
- **WSL 2**：改进了 WSL 1，在轻量级虚拟机（VM）中运行真正的 Linux 内核。系统调用兼容性明显提升，文件系统性能也有很大改善。一般推荐使用 WSL 2。

今天要安装的 Ubuntu 在 WSL 2 中也能获得更好的使用体验。

## 第 1 步：启用 WSL 功能

要在 Windows 中使用 WSL，先启用相关功能。
就像给新玩具装上电池之后才能使用一样。
最简单的办法是以管理员身份运行 PowerShell，并输入命令。

1.  **以管理员身份运行 PowerShell**
    * 右键点击 Windows 开始按钮。
    * 选择“Windows PowerShell（管理员）”或“终端（管理员）”。不同 Windows 版本的菜单名称可能不同。
    * 如果出现“用户帐户控制”窗口，点击“是”。
2.  **输入 WSL 安装命令**
    在以管理员身份运行的 PowerShell 窗口中输入以下命令，然后按 Enter。
    这条命令可以启用 WSL 所需功能，还可能一起安装默认的 Linux 发行版，通常是较新的 Ubuntu LTS。
    ```powershell
    wsl --install
    ```
    如果不指定发行版，只运行 `wsl --install`，默认会安装稳定版 Ubuntu。
    本文的目标是 *Ubuntu 22.04.1 LTS*。可以让命令继续执行默认安装，也可以稍后在 Microsoft Store 中自行选择所需版本。
    <br />
    <br />
    如果 `wsl --install` 无法运行，或者旧版 Windows 只安装了部分 WSL 组件，可能需要手动启用功能。
    这时可以依次执行下列命令。
    <br />
    首先启用 **适用于 Linux 的 Windows 子系统**。
    ```powershell
    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    ```

    接下来启用 **虚拟机平台**，这是 WSL 2 所需的功能。
    ```powershell
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
    ```
    执行这两条命令后，需要*重启计算机*，让改动生效。

3.  **重启计算机**
    无论是使用 `wsl --install` 还是手动启用功能，只要安装程序提示需要重启，就请重启计算机。

4.  **将 WSL 2 设为默认版本（可选）**
    较新的 `wsl --install` 通常默认使用 WSL 2。为了确认设置，或从 WSL 1 改用 WSL 2，可以通过以下命令将 WSL 2 设为默认版本。
    重启后，再次以管理员身份打开 PowerShell，输入以下命令。
    ```powershell
    wsl --set-default-version 2
    ```
    如果出现“WSL 2 requires an update to its kernel component.”之类的提示，请打开提示中的链接，通常是 `https://aka.ms/wsl2kernel`，下载并安装 Linux 内核更新包。

完成这些步骤后，Windows 电脑就可以运行 Linux 了。

<Ads2/>
## 第 2 步：从 Microsoft Store 安装 Ubuntu 22.04 LTS
> 使用上述命令安装 WSL 后，可能已经默认安装了 Ubuntu。这种情况下可以继续下一步。如果想安装其他 Linux 发行版，可以在 Microsoft Store 中选择所需版本。

接下来安装目标版本 *Ubuntu 22.04 LTS*。
最简单的办法是使用 Microsoft Store，类似于在手机上下载应用。

1. **打开 Microsoft Store**
   在 Windows 开始菜单中搜索并打开 Microsoft Store。

2. **搜索 Ubuntu**
   在 Microsoft Store 顶部的搜索框中输入 Ubuntu。
   搜索结果可能包含多个版本。本文要找的是 *Ubuntu 22.04 LTS*，请选择对应的版本。
   如果没有看到精确标注“22.04 LTS”的条目，也可以选择 Ubuntu 22.04 LTS，或直接选择 Ubuntu。后者通常指最新的 LTS 版本，安装后可以查看具体版本。

3. **安装（或“获取”）**
   在所选 Ubuntu 的页面点击“安装”或“获取”。
   下载和安装会自动进行，耗时取决于网速。
   WSL 支持同时安装和使用多个 Linux 发行版。

## 第 3 步：首次启动 Ubuntu 并设置用户
安装完成后，首次启动 Ubuntu 并进行初始化设置。
就像开始新游戏时给角色起名一样，需要创建 Linux 用户名和密码。

1.  **启动 Ubuntu**
    * 在 Windows 开始菜单中找到 Ubuntu 22.04.1 LTS，或你安装的 Ubuntu 名称，点击打开。
    * 也可以在 PowerShell 或命令提示符输入 `wsl` 或 `ubuntu2204.1` 启动。名称可能因所装发行版而异，可通过 `wsl -l -v` 检查。
2.  **等待初始化**
    首次启动时，会出现类似“Installing, this may take a few minutes...”的消息，初始化可能需要几分钟。

3.  **输入新用户名（Username）**
    初始化完成后，会显示“Enter new UNIX username:”。
    输入要在 Linux 中使用的用户名。建议用小写英文字母和数字，取一个简单的名字，例如 `student`、`myubuntu` 或 `devuser`。
    <Rbox>用户名最好避免使用空格和特殊字符。它可以与 Windows 用户名不同。</Rbox>
    输入后按 Enter。

4.  **输入新密码（Password）**
    出现“New password:”后，输入该用户账号的密码。
    输入时屏幕上什么都不会显示，连星号 `*` 也不会出现。
    正确输入后按 Enter 即可。
5.  **再次输入密码**
    出现“Retype new password:”时，再输入一遍相同的密码。
    同样，屏幕上不会显示字符。正确输入后按 Enter。
    密码设置成功后，会看到类似“Password updated successfully”的消息，随后出现 Linux 提示符（`사용자이름@컴퓨터이름:~$`）。
<Img src="/250604-153605.webp" width={500} alt="Ubuntu 启动完成"/>
恭喜，你已经在 Windows 电脑上搭建好了 Ubuntu 22.04 LTS 环境。
看到提示符，就表示已经进入 Linux 终端。

<Ads3/>
## 第 4 步：确认安装并练习基本操作

安装完成后，确认系统能正常运行，再练习几个基本操作。

1.  **确认 Ubuntu 版本**
    在 Ubuntu 终端中输入以下命令并按 Enter。
    ```bash
    lsb_release -a
    ```
    这条命令会显示当前安装的 Linux 发行版的详细信息。
    检查输出中的 `Description:` 是否显示 `Ubuntu 22.04.5 LTS` 或类似版本。
    `Codename:` 应显示 `jammy`，Ubuntu 22.04 LTS 的代号是 Jammy Jellyfish。
    <Img src="/250604-153841.webp" width={400} alt="查看 Ubuntu 版本"/>
2.  **更新软件包列表并升级（推荐）**
    建议将新装的 Linux 系统更新到最新状态。依次运行下面两条命令。
    首先，刷新可用软件包列表。
    ```bash
    sudo apt update
    ```
    系统可能会要求输入刚才设置的 Linux 用户密码。输入后按 Enter，同样不会显示输入的字符。
    `sudo` 是“superuser do”的缩写，表示以管理员权限执行命令。
    <br />
    接下来，将已安装的软件包升级到最新版本。
    ```bash
    sudo apt upgrade
    ```
    如果要升级的软件包较多，可能需要一些时间。出现确认提示 [Y/n] 时，输入 `Y` 并按 Enter 继续。

3.  **试用基本 Linux 命令**
    - `ls`：列出当前目录中的文件和子目录。
    - `pwd`：显示当前工作目录的完整路径。
    - `cd [디렉토리명]`：切换到指定目录。例如，`cd /home` 会进入 `/home` 目录。
    - `mkdir [새디렉토리명]`：创建新目录。
    - `clear`：清空终端画面。

4.  **访问 Windows 文件系统**
    WSL 的一个便利之处是可以访问 Windows 文件系统。
    在 Ubuntu 终端中切换到以下路径。
    ```bash
    cd /mnt/c
    ```
    这会进入 Windows 的 C 盘根目录。执行 `ls`，就能看到熟悉的 `Program Files`、`Users` 和 `Windows` 等目录。
    如果有 D 盘，同样可以通过 `/mnt/d` 访问。


## 结语

本文介绍了如何在 Windows 电脑上通过 WSL 安装 Ubuntu 22.04.1 LTS，并完成基本设置。
现在，你可以在继续使用 Windows 的同时，也使用开发者常用的 Linux 环境。
