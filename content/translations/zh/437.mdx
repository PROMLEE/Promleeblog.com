## 区分投资组合与资产

投资组合是放置资产的**管理篮子**。
资产是放进其中的股票、ETF、加密资产和现金等。

| 应用中的项目 | 含义 | 示例 |
| --- | --- | --- |
| 投资计划名称 | 整体投资计划的名称 | 我的投资计划 |
| 组合名称 | 用于归类管理资产的篮子名称 | 管理组合 A |
| 目标权重 | 从总资产中分给该组合的比例 | 50% |
| 持有资产 | 实际持有的资产及数量或金额 | 股票 10 股、现金 50 万韩元 |

创建名为“现金”的组合后，仍需登记实际现金 50 万韩元。
当前这一步是**创建组合并设定分配标准**。
<br/>

本文用三个组合练习输入。

| 组合名称 | 目标权重 |
| --- | ---: |
| 管理组合 A | 50% |
| 管理组合 B | 30% |
| 管理组合 C | 20% |
| 合计 | 100% |

*这些数值用于演示操作。请按自己的投资计划调整名称和权重。*
截图中的证券、权重和估值用于示范，不代表投资推荐或实际业绩。

如果还没有计划，可能会出现下文的初始配置选择页面。
<br/>

点击底部的**全部**标签。

<Img src="/portrhythm-setup-mobile-menu-20261008.webp" width={350} alt="从移动端全部菜单进入目标设计"/>

移动端的**权重**标签用于比较当前和目标权重。
如需修改名称和目标数值，请打开目标设计。

<Toggle title="分不清菜单名称时">

  设置组合名称、颜色、目标权重和容许偏差。

- **组合权重**

| 从空组合开始 | 一个名为“新组合”的篮子，目标为 100% | 想从头建立自己的分类 |

系统会创建美国指数、韩国指数、优质股、黄金和比特币等示例组合。

示例配置还包含按证券代码分配资产的规则。

选择初始配置后，还需完成输入并点击“保存变更”，才会写入账号。
</Ybox>

这种情况下可直接修改现有目标设计。

## 3. 在目标设计中编辑组合

现在给组合命名并输入权重。
先看看界面上各功能的位置。

<Img src="/portrhythm-allocation-strategy-20261008.webp" width={800} alt="编辑组合名称、目标权重和容许偏差的目标设计页面"/>

**移动端界面如下。**

<Img src="/portrhythm-setup-mobile-strategy-20261008.webp" width={350} alt="移动端目标设计页面的容许偏差、组合名称和目标权重输入框"/>

移动端的设置项目相同。
各组合的名称和目标数值在同一行，当前权重条和目标差额显示在下方。
组合较多时，向下滚动查看剩余行与目标合计。
底部固定菜单用于切换页面。目标数值和保存按钮在内容区。

| 位置 | 项目 | 用途 |
| --- | --- | --- |
| 页面顶部 | 保存变更／已保存 | 把变更保存到账号，或核对保存状态 |
| 目标权重编辑区右侧 | 添加组合 | 新建一个管理组合 |
| 编辑区上方 | 再平衡容许偏差 | 设定何时核对权重差额 |
| 组合行左侧 | 颜色和名称 | 修改图表颜色和分类名称 |
| 组合行中间 | 条形图、当前权重、差额与金额 | 查看已登记资产的当前状态 |
| 组合行右侧 | 目标数值和删除图标 | 输入目标权重或删除组合 |
| 组合列表下方 | 目标合计 | 确认目标总和为 100% |
<br/>

### 3.1 添加组合并命名

点击右侧的**添加组合**。
列表下方会出现一行，名为“新组合”，目标为 0%。

<Img src="/portrhythm-setup-add-port-20261008.webp" width={800} alt="点击添加组合后，列表下方出现目标为 0% 的新组合"/>

点击新行的名称字段，输入要使用的名称。
给每个新增组合起一个可区分的名字。

- 名称留空时无法保存。
- 去掉首尾空格后，名称也不能重复。
- 组合名称最多 60 个字符。
- 可管理的组合最少 1 个，最多 20 个。
<br/>

练习时，将三行分别命名为：

- 管理组合 A
- 管理组合 B
- 管理组合 C

实际使用时，可以起“长期投资”“现金”等容易辨认的名称。
组合改名不会改变资产的市场或证券代码。
<br/>

### 3.2 选择组合颜色

点击名称左边的小色块。
在设备与浏览器提供的颜色选择器中选取颜色。
颜色用于在图表上区别组合。
修改颜色不会改变目标权重或持仓数量。
相近的颜色在图表中不易分辨。
常一起对比的组合，可以选用差异明显的颜色。
<br/>

### 3.3 输入目标权重

编辑各组合右侧的**目标**数字字段。
旁边已显示 `%`，只需输入数字。

| 所需目标 | 输入数字 |
| --- | ---: |
| 50% | 50 |
| 30% | 30 |
| 20% | 20 |
| 12.5% | 12.5 |

**如果要设 50%，输入 0.5 会得到 0.5%。**
正确输入是 50。
输入范围为 0–100%，字段可以按 0.1 调整。
即使采用小数权重，总和也要达到 100%。
<br/>

### 3.4 核对目标合计

查看列表下方的**目标合计**。

| 输入状态 | 合计 | 处理方式 |
| --- | ---: | --- |
| A 50／B 30／C 20 | 100% | 已满足目标合计条件 |
| A 50／B 30／C 10 | 90% | 决定剩余 10% 分给哪个组合 |
| A 100／B 30／C 20 | 150% | 重新调整各项权重，包括首个组合的 100% |

达到 100% 后会出现 `저장할 수 있습니다.`，表示可以保存。
未达到 100% 时，页面会提示调整合计。

<Bbox>
应用不会自动为新增组合重新分摊权重。创建新组合后，请同时核对原有组合的目标。
</Bbox>

`목표 합계 100%` 表示目标合计达到 100%，只说明权重条件已满足。
名称重复或其他输入错误仍可能阻止保存，请核对最终结果。
<br/>

### 3.5 当前权重与目标

组合行中间显示当前权重、与目标的差额及估值。
例如，“当前 28% · 目标差额 +8 个百分点”表示比 20% 的目标多了 8 个百分点。
负差额表示低于目标。
修改目标数值会改变这里的比较基准。
<br/>

### 3.6 删除组合

点击对应行右侧的垃圾桶图标，将组合移出编辑列表。
最后剩下的一个组合无法删除。
如果组合已关联资产，删除前先核对关联关系。

- 关联到该组合的证券分配规则会一并移除。
- 手动指定的分配，以及加密资产和其他资产的组合关联会解除。
- 实际持有的资产仍会保留。
- 保存后，在“资产分配”中重新核对原来属于已删组合的资产。

<Ybox>
如果只想改名，直接编辑现有名称字段。删除后重建组合，需要重新核对原有的关联。
</Ybox>

如果被删组合有目标权重，合计也会下降。
重新调整剩余组合的目标后再保存。
<Ads2/>

## 4. 设置容许偏差

查看同一目标设计页面上方的**再平衡容许偏差**。
输入框两边显示 `±` 和 `%p`。
这个数值是所有组合共用的权重差额标准。
各组合使用同一容许偏差。
<br/>

以目标 20%、容许偏差 5 个百分点为例。

| 当前权重 | 与目标的差额 | 判断 |
| --- | ---: | --- |
| 15% | −5 个百分点 | 边界值，未超出范围 |
| 20% | 0 个百分点 | 与目标相同 |
| 25% | +5 个百分点 | 边界值，未超出范围 |
| 26% | +6 个百分点 | 超出范围，考虑调整 |

容许范围为 15% 至 25%。
差额幅度**超过** 5 个百分点时，再核对是否需要调整。
<br/>

要把容许偏差设为 5 个百分点，输入数字 **5**。
无需输入 `±` 或 `%p`。
输入范围为 0–30 个百分点，字段可以按 0.1 调整。

<Toggle title="怎样区分 5% 和 5 个百分点？">
从 20% 变为 25%，差额是 **5 个百分点**。
而 20% 的 5% 是 20 × 0.05 = 1，对应 **1 个百分点**。
PortRhythm 的容许偏差采用前一种含义。
</Toggle>

超出容许偏差是开始核查的信号。
是否实际交易，应在查看资产信息和投资计划后决定。
<br/>

## 5. 展开汇率与其他设置

在目标设计中点击**汇率与其他设置**。
更多字段会在同一页面展开。

<Img src="/portrhythm-setup-settings-auto-20261008.webp" width={800} alt="展开汇率与其他设置后出现投资计划名称和汇率字段"/>

**移动端的汇率字段位于名称字段下方。**

<Img src="/portrhythm-setup-mobile-settings-20261008.webp" width={350} alt="移动端展开汇率与其他设置后显示的名称和汇率字段"/>

先核对投资计划名称，再核对下方的汇率应用方式及 USD → KRW 数字字段。
展开后组合列表会向下移动。
设完后，可以再点击“汇率与其他设置”将其折叠。
这里有三项。

| 项目 | 设置内容 |
| --- | --- |
| 投资计划名称 | 整体投资计划的名称 |
| 汇率应用方式 | 自动或手动输入 |
| USD → KRW 汇率 | 每美元按多少韩元估值 |
<br/>

### 5.1 填写投资计划名称

填写一个用于整体计划的名称，例如“我的投资计划”。
这一字段与组合行中的“管理组合 A”不同。
**投资计划名称是总标题，组合名称是单个管理篮子的名字。**
名称不能为空，最多 80 个字符。
改标题只会更新这份计划的名称。
<br/>

### 5.2 选择自动汇率

在“汇率应用方式”中选择**自动 · ECB 每日参考汇率**。
USD → KRW 数值会变成不可直接编辑。
应用以欧洲央行的每日参考汇率为基础，将美元资产折算为韩元。
该汇率可能与券商实时报价或实际兑换金额不同。
<br/>

等待自动查询或查询失败时，页面可能显示最后保存的汇率。
要判断数值是否刚更新，可以同时查看仪表盘的**查看价格与汇率口径**。

<Toggle title="自动汇率多久检查一次？">
自动模式会以最长约一小时的间隔检查是否需要查询汇率。
基准数据本身是 ECB 的每日参考汇率。
这一间隔用于检查是否需要查询，并不代表每小时获取所有实时换汇报价。
查询失败时，可能显示将采用最后保存汇率的提示。
</Toggle>
<br/>

### 5.3 选择手动汇率

在同一菜单选择**手动输入**。
此时可以编辑 USD → KRW 数字字段。

<Img src="/portrhythm-setup-settings-manual-20261008.webp" width={800} alt="选择手动输入后，可以编辑每美元对应的韩元汇率"/>

如需按 1 美元兑 1,350 韩元估值，填写 **1350**。
该字段只填汇率数字。无需输入完整的 `1,350원`，也无需填持有的美元金额。

| 所需设置 | 输入值 |
| --- | ---: |
| 1 美元 = 1,350 韩元 | 1350 |
| 1 美元 = 1,350.50 韩元 | 1350.50 |

可保存的汇率范围为 100–100,000 韩元。
核对要采用的基准数值，填入后保存。
<br/>

### 5.4 修改汇率会影响什么

它会影响美股和手动录入的美元资产的**韩元估值**。
由于韩元总估值会变化，组合的当前权重也可能改变。
例如，100 美元按 1,300 韩元汇率估值是 13 万韩元，按 1,400 韩元则是 14 万韩元。
美元数量保持相同，变化的是折算后的韩元金额。

<Gbox>
**修改汇率是在更新估值基准。** 实际换汇或下单需要另行操作。
</Gbox>

如果正使用自动模式，想自己修改数字，先切换到手动输入。
自动模式下数字字段锁定属于正常行为。
<Ads3/>

## 6. 保存并核对结果

填好名称和数值后，完成最后的保存。
当前内容还在编辑状态，仍需要**点击保存按钮**。

### 6.1 保存前核对

- **组合名称**  
  检查没有空白名称或重复名称。
- **目标合计**  
  检查全部组合的目标是否合计为 100%。
- **容许偏差**  
  核对是否为预期的百分点标准。
- **投资计划名称与汇率**  
  检查已填写名称，且汇率方式和数值正确。
- **已有资产的关联**  
  如果删除了组合，检查对资产分配的影响。
<br/>

### 6.2 点击保存变更

**移动端的保存按钮位于标题下方。**

<Img src="/portrhythm-setup-mobile-save-20261008.webp" width={350} alt="移动端目标设计标题下方的价格更新和保存变更按钮"/>

点击“价格更新”右侧的“保存变更”。
如果刚编辑过页面下方的组合，回到顶部寻找保存按钮。
如果被键盘挡住，完成输入后收起键盘再查看。
<br/>

点击目标设计顶部的保存变更。
保存过程中会显示**保存中**。
成功后会显示**已保存**。
也可核对“已保存投资计划和今日估值”的通知。
保存时，今日估值记录可能一起更新。
实际订单或交易需要单独执行。
<br/>

### 6.3 再次核对保存结果

确认保存成功后，重新打开目标设计或刷新页面。
核对输入的名称、目标权重、容许偏差和汇率方式是否保留。
如果多次填写后结果仍不确定，也检查当前是否为同一登录账号。

<Ybox>
请确认保存成功后再刷新。未保存的输入在刷新后不会保留。
</Ybox>

切换页面或展开菜单本身不会保存。
如果又修改了一项设置，需要再次点击“保存变更”。
<br/>

## 练习完整流程

如果想一次练习完整流程，可以按以下顺序操作。
*权重和汇率数字仅供练习输入，未采用投资推荐或当前市场汇率。*

- **第一步，打开目标设计。**  
  如果是首次使用的账号，选择“从空组合开始”。
- **第二步，输入组合名称。**  
  将首个组合改名为“管理组合 A”，点击两次“添加组合”创建 B 和 C。
- **第三步，输入目标数字。**  
  输入 A 50、B 30、C 20，核对目标合计为 100%。
- **第四步，核对容许偏差。**  
  输入练习值 5，表示 ±5 个百分点。
- **第五步，核对整体名称和汇率。**  
  展开“汇率与其他设置”，填写整体名称，选择自动或手动输入。
- **第六步，核对保存。**  
  点击“保存变更”，确认显示“已保存”。
<br/>

做到这里，组合和标准就准备好了。
完成本篇操作只要求保存目标。
**如果还没放入持有资产，当前权重将在下一阶段反映出来。**
<br/>

## 输入遇到问题时

下面整理了初次使用时容易困惑的情况。
展开需要的项目查看。

<Toggle title="为什么看不到保存变更按钮？">
如果已保存且没有新修改，页面会显示“已保存”。
更改组合名称或目标权重等项目后，保存按钮会出现。
如果还没有第一份计划，也要检查是否在初始配置页面选了示例配置或空组合。
</Toggle>

<Toggle title="目标合计为 100%，为什么仍无法保存？">
除了目标合计，也要核对其他输入。

- 检查组合名称是否为空或重复。
- 核对组合名称 60 字符、投资计划名称 80 字符的限制。
- 核对目标 0–100% 和容许偏差 0–30 个百分点的范围。
- 确认手动汇率是数字，并处于 100–100,000 韩元之间。
- 查看页面显示的保存错误。

如果是网络连接或登录状态问题，先保留输入，再核对状态。
在保存成功前刷新，编辑内容可能会丢失。
</Toggle>

<Toggle title="继续添加后，名称怎么都叫新组合？">
“新组合”是默认名称。
需要逐个编辑名称字段。
多个新组合保留同一个名称时，可能因重名无法保存。
如果已经有 20 个组合，就无法继续添加。
请整理实际需要的分类再使用。
</Toggle>

<Toggle title="目标已改成 30%，为什么当前仍是 0%？">
目标表示计划，当前权重按已登记资产的估值计算。
填入目标后，还需登记并分配实际资产。
如果已登记，请核对价格或分配状态。
</Toggle>

<Toggle title="删除组合后，为什么资产分配变了？">
已删除组合的关联会解除，相关的证券分配规则也会移除。
实际持有的证券仍然保留。
把剩余组合的目标合计调回 100% 并保存，再到“资产分配”中核对相应资产的归属。
</Toggle>

<Toggle title="为什么看不到以前保存的投资计划？">
核对是否使用最初的社交登录服务和账号。
用 Kakao 保存的内容不会自动连接到 Naver 登录账号。
也要确认之前是否在未保存时关闭应用或刷新。
如果账号和保存状态都核对无误，问题仍然存在，可查看页面显示的错误。
</Toggle>

<Toggle title="可以把同一项 ETF 按比例分到两个组合吗？">
当前为每项已登记资产指定一个所属组合。
界面不提供把同一项证券按 60% 给 A、40% 给 B 这样拆分的输入。
在目标设计中确定分类，再到“资产分配”中核对实际关联。
</Toggle>
<br/>
