## 密钥交换（Key Exchange）
> 安全交换通信所需共同密钥的方法。

Alice和Bob通过*公开信道*交换数据，生成共同的秘密密钥。
Alice与Bob之外的第三方，即使截获公开信道上传输的数据，也无法得知密钥。

## Diffie-Hellman密钥交换（Diffie-Hellman Key Exchange）
> 一种公钥密码方法，用于安全交换秘密密钥。

预先共享参数：素数$p$，以及具有生成元$g$的有限群$\mathbb{Z}_p^*$。

Alice与Bob的操作如下。
- Alice。
	1. 生成秘密值$a$。
	2. 计算$A = g^a \pmod{p}$，发送给Bob。
	3. 接收$B$。
	4. 计算$K_{AB} = B^a \pmod{p}$。
- Bob。
	1. 生成秘密值$a$。
	2. 计算$B = g^b \pmod{p}$，发送给Alice。
	3. 将$B$发送给Alice。
	4. 接收$A$。
	5. 计算$K_{BA} = A^b \pmod{p}$。

$K_{AB} = B^a = (g^b)^a = g^{ab} = (g^a)^b = A^b = K_{BA}$

### Diffie-Hellman密钥交换示例
$p = 31$，$g = 3$。
- Alice。
	1. 生成秘密值$a = 6$。
	2. 计算$A = 3^6 \pmod{31} = 729 \pmod{31} = 16$，发送给Bob。
	3. 接收$B = 20$，计算$K_{AB} = 20^6 \pmod{31} = 64000000 \pmod{31} = 4$。
- Bob。
	1. 生成秘密值$b = 8$。
	2. 计算$B = 3^8 \pmod{31} = 4,294,967,296 \pmod{31} = 4$，发送给Alice。
	3. 接收$A = 16$，计算$K_{BA} = 16^8 \pmod{31} = 4,294,967,296 \pmod{31} = 4$。

密钥交换结果：
- $K_{AB} = 4$
- $K_{BA} = 4$

## Diffie-Hellman密钥交换的安全性（Security of Diffie-Hellman Key Exchange）
> 中间人攻击。

- Eve想知道Alice与Bob之间的共享密钥，即$K_{AB} = K_{BA}$。
- Eve拥有$(p, g), (A = g^a \mod p), (B = g^b \mod p)$。
- 如果Eve知道Alice的秘密值$a$或Bob的秘密值$b$。
	- $K_{AB} = B^a = (g^b)^a = g^{ab} = (g^a)^b = A^b = K_{BA}$
	- 根据上述等式，Eve就可以计算$K_{AB}$。
	- 由于DLP（Diffie-Hellman Problem）很困难，Eve无法计算$a$或$b$。

<Bbox>计算性Diffie-Hellman问题（CDH，Computational Diffie-Hellman）</Bbox>

- 给定$(g, g^a, g^b)$，计算$g^{ab}$。
非正式地说，当底层群的阶为素数时，CDH问题与DLP的难度相当。

## 中间人攻击场景（Man-in-the-Middle Attack Scenario）
1. Alice与Bob执行密钥交换。
2. Eve位于Alice与Bob之间。
3. 向Alice发送$g^e$。
4. 向Bob发送$g^f$。
5. Alice与Bob计算$g^{ef}$。
6. Eve计算$g^{ef}$，从而截获双方通信。

## 中间人攻击的解释与防范（Man-in-the-Middle Attack Description & Prevention）
### 攻击过程
1. Eve生成秘密值$e$，计算$E = g^e \mod p$。
2. Alice与Bob分别向对方发送$A$和$B$。
3. Eve截获它们，并向双方发送$E$。
4. Alice与Bob收到$E$后，分别计算：
	$K_{AE} = E^a = g^{ea} \mod p$、$K_{BE} = E^b = g^{eb} \mod p$。

- 之后，Alice向Bob发送$C = \text{Enc}(K_{AE}, M)$时，Bob无法解密。
- Eve则可以使用$K_{EA} = A^e = (g^a)^e \mod p$，获得$M$。

### 防范中间人攻击
- 使用证书。
	- 例如，Alice与Bob发送公钥时附带签名，让双方能够验证对方公钥。

#### 中间人攻击总结
- Diffie-Hellman密钥交换容易受到中间人攻击。
- Eve可以截获Alice与Bob之间的通信。
- 使用证书可以防范中间人攻击。
