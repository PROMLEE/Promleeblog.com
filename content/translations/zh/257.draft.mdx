## 算法分类
图论、图搜索、广度优先搜索（BFS）。

## 题目说明
本题模拟经典的蛇与梯子游戏。在有100个格子的棋盘上，通过掷骰子前进，骰子点数为1到6。
目标是求从1号格到100号格最少需要掷几次骰子。
<Img src="/250505-185431.webp" width={300} alt="蛇与梯子游戏"/>
### 输入
- 第一行给出梯子数量N（1 ≤ N ≤ 15）和蛇的数量M（1 ≤ M ≤ 15）。
- 从第二行到第N+1行，给出梯子的起点与终点（1 ≤ 起点 < 终点 ≤ 100）。
- 从第N+2行到第N+M+1行，给出蛇的起点与终点（1 ≤ 起点 < 终点 ≤ 100）。
### 输出
- 输出从1号格到100号格所需的最少掷骰次数。

## 解题思路
0. 创建字典，以蛇和梯子的起点为key，终点为value。
1. 用一维数组保存100个格子各自所需的最少掷骰次数，初始值设为99。
2. 从1号格出发，检查掷出1到6后能够到达的格子，将其次数更新为前一个格子的次数加1。
3. 如果该格子的值被更新，就将它加入队列。
4. 再从队列取出格子，检查掷出1到6后可以到达的格子。
5. 重复这一过程，直到队列为空。
6. 输出最后一个格子，也就是100号格的掷骰次数。

## Python代码
```python
import sys
from collections import deque

N, M = list(map(int, sys.stdin.readline().split()))
arr = [99] * 101 # 1부터 100까지의 칸을 저장하는 배열, 기본값은 99로 설정
snakes = {} # 사다리와 뱀의 위치를 저장하는 딕셔너리

for _ in range(N + M):
  a, b = list(map(int, sys.stdin.readline().split()))
  snakes[a] = b # 사다리와 뱀의 시작 위치를 key로, 끝 위치를 value로 저장

arr[1] = 0
dq = deque([1]) # 큐에 1번 칸을 추가

while dq:
  x = dq.pop() # 큐에서 꺼낸 칸
  for i in range(1, 7): # 1부터 6까지의 주사위를 굴려서 이동할 수 있는 칸을 확인
    if x + i > 100: # 100번 칸을 넘어가면 무시
      continue
    elif x + i in snakes.keys(): # 사다리와 뱀의 위치를 확인
      if arr[x] + 1 < arr[snakes[x+i]]: # 값이 업데이트되는 경우
        arr[snakes[x+i]] = arr[x] + 1
        dq.append(snakes[x+i]) # 업데이트된 칸을 큐에 추가
    else: # 사다리와 뱀의 위치가 아닌 경우
      if arr[x] + 1 < arr[x + i]: # 값이 업데이트되는 경우
        arr[x + i] = arr[x] + 1
        dq.append(x + i) # 업데이트된 칸을 큐에 추가

print(arr[-1]) # 마지막 칸(100번 칸)의 주사위 굴리기 횟수를 출력
```

## 核心要点
- 使用BFS寻找从1号格到100号格的最短路径。
- 使用字典管理蛇和梯子的位置，便于确定可以移动到的格子。
- 使用队列实现BFS。
