## 开始之前
最近开发React Native与Expo应用时，刚把Xcode升级到16.3，就开始出现意外构建错误。控制台反复输出与`std::char_traits<unsigned char>`有关的模板错误，部分Pod也无法继续编译。
为了尽快解决问题，我决定将Xcode*降级*到16.2。本文结合实际遇到的情况，逐步介绍安全回退Xcode版本的方法。

### 升级Xcode16.3后出现的错误
升级后，构建停止并显示以下错误。
```
static_assert(is_same<_CharT, typename traits_type::char_type>::value,
              ^ implicit instantiation of undefined template 'std::char_traits<unsigned char>'
```
错误发生在与`string_view`相关的C++标准库内部，看起来与`RCT-Folly`、`React-perflogger`等React Native内部Pod存在兼容性问题。

简单来说，就是*新Xcode与部分既有C++原生代码不兼容*。Expo环境一般不直接处理C++代码，因此相比寻找根本修复方案，回到稳定的旧版本是更快的处理方式。

## Xcode降级步骤：16.3到16.2
大致分为四个步骤。
### 1. 删除或重命名Xcode16.3
在Mac上，同一路径只能有一个名为`Xcode.app`的应用，因此需要先删除旧版本，或修改名称。
**删除方式：**
```
sudo rm -rf /Applications/Xcode.app
```
**也可以改名后保留：**
```
sudo mv /Applications/Xcode.app /Applications/Xcode-16.3.app
```
这样可以备份16.3，方便以后重新使用。

### 2. 下载Xcode16.2
通过以下链接下载Xcode16.2。
🔗 [Apple Developer Downloads](https://developer.apple.com/download/all/)
- 使用Apple ID登录。
- 搜索“Xcode 16.2”，下载`.xip`文件。
<Img src="/posts/250402-101948.webp" width={500} alt=""/>

### 3. 安装Xcode16.2
下载完成后，双击`.xip`解压，将应用移动到`/Applications`。
也可以通过拖放移动。
```
sudo mv ~/Downloads/Xcode.app /Applications/
```
<Img src="/posts/250402-102241.webp" width={300} alt="确认应用程序"/>

### 4. 激活Xcode16.2
最后，通过`xcode-select`指定系统使用的Xcode版本。
```
sudo xcode-select -s /Applications/Xcode.app
```
使用以下命令，确认版本是否已经正确应用。
```
xcodebuild -version
```
预期输出：
```
Xcode 16.2
Build version 16Cxxx
```
现在重新构建项目，就可以确认错误已经消失。
## 结论
这次经历让我再次感受到，*最新版本并不总是最稳定*。尤其是React Native这类与原生组件紧密连接的框架，更需要留意Xcode或Android Studio的兼容性。
今后在升级主要版本之前，我会先查看GitHub Issue和Expo发布说明，再决定是否更新。
