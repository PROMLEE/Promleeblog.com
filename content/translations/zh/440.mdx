## 开始之前

> “资产已经登记了，这个收益数字是按什么算出来的？”

完成[第 4 篇：资产分配](https://www.promleeblog.com/blog/post/439-portrhythm-asset-assignment-guide)后，各项资产都有了对应的管理组合。
现在来仪表盘看看资产金额和损益。

<br/>

从大数字看起更容易。
先看持有多少，再核对按什么口径增减，最后点击想了解的证券。

<br/>

<Bbox>

今天的目标是看懂资产估值与损益，并能修改必要的持仓信息。
可以同时打开应用，选一项资产跟着操作，把页面与数字对应起来。

</Bbox>

[打开 PortRhythm](https://pf.promleeblog.com)
页面使用测试账号的示例资产。
价格会随查询时间变化，下面的计算示例与截图金额分开说明。

<br/>

## 1. 仪表盘

仪表盘是集中查看分散资产的首页。
电脑端点击左侧的仪表盘 `대시보드`，移动端点击底部的资产 `자산`。

<Img src="/portrhythm-guide5-desktop-dashboard-20261008.webp" width={800} alt="电脑端仪表盘显示总估值、整体损益和证券列表"/>

可分三步查看。

- **总估值**  
  按当前采用的价格和汇率计算已登记资产的金额。
- **整体收益／日内收益**  
  选择与买入价或上一交易日收盘价比较。
- **持有资产列表**  
  查看各证券的金额和损益，点击名称打开详情。

电脑端右侧还显示各组合的权重。
当前与目标权重的比较方法将在第 6 篇介绍。

<br/>

### 1.1 移动端界面

移动端先显示估值和证券列表。
点击顶部数字下方的整体收益／日内收益 `전체 수익 / 일간 수익`，摘要和投资项目的损益会一起切换。

<Img src="/portrhythm-guide5-mobile-dashboard-20261008.webp" width={350} alt="移动端仪表盘的日内损益和资产列表"/>

向下滚动，可看到损益汇总口径 `손익 집계 기준` 和最近行情确认时间。
这里既能看收益多少，也能核对计算采用了哪些数据。

<br/>

## 2. 总估值

**总估值是当前已登记资产折算成韩元后的合计。**
它汇总股票、ETF、加密资产，以及手动录入的现金和其他资产。

| 资产 | 估值方法 |
| --- | --- |
| 韩国股票和 ETF | 现价 × 持仓数量 |
| 美国股票和 ETF | 美元现价 × 持仓数量 × 采用的汇率 |
| 加密资产 | Bithumb 韩元现价 × 持仓数量 |
| 韩元现金及其他 | 手动输入的韩元金额 |
| 美元现金及其他 | 手动输入的美元金额 × 采用的汇率 |

例如，登记了 12 万韩元的股票和 8 万韩元的韩元现金，总估值就是 20 万韩元。
累计投入和累计入金则是另外两个口径。

<br/>

### 2.1 现金与汇率

现金属于资产，因此计入总估值。
手动录入的现金及其他资产不按买入价计算投资损益。

<br/>

美股和美元现金按目标设计中设定的自动汇率或手动汇率折算成韩元。
即使美元价格相同，采用的汇率不同，韩元估值也可能变化。

<Ybox>

总估值包含现金，整体收益率使用的分母则是可计算损益的股票与加密资产的买入金额。

</Ybox>

<br/>

## 3. 整体收益与日内收益

**两个按钮切换的是比较基准。**
整体收益与平均买入价比较，日内收益与各市场上一交易日的收盘价比较。

### 3.1 整体收益

整体损益反映当前持有的股票与加密资产相对买入价涨跌了多少。

- 整体损益 =（现价 − 平均买入价）× 持仓数量
- 整体收益率 = 整体损益 ÷ 买入金额 × 100

平均买入价是买入每股股票或每枚代币的平均价格。
如果应用中没有买入价，就无法查看该资产的损益。

<br/>

汇总多项资产时，也无需对各项收益率取简单平均。
用数据可确认的资产损益总和除以相应买入金额总和。

<br/>

### 3.2 日内收益

日内损益将各市场上一交易日收盘价至现价的变化应用到当前持仓数量。

- 日内损益 =（现价 − 上一交易日收盘价）× 持仓数量
- 日内收益率 = 日内损益 ÷ 按上一交易日收盘价计算的持仓金额 × 100

只计算已确认现价与上一交易日收盘价的资产。
可以通过 `전일 종가 확인 2/2개` 等提示查看覆盖范围，例如两项资产的前收盘价均已确认。

<Img src="/portrhythm-guide5-desktop-daily-20261008.webp" width={800} alt="选择日内收益后一起切换的摘要与各证券损益"/>

*日内损益可能与韩国时间零点以来账户实际赚取或亏损的金额不同。*
各市场的前收盘时间不同，这项计算也没有计入盘中交易和出入金记录。

<br/>

### 3.3 对比同一笔 10 股持仓

假设持有某只股票 10 股。
平均买入价 10,000 韩元，上一交易日收盘价 11,500 韩元，现价 12,000 韩元。

| 核对项目 | 计算 | 结果 |
| --- | --- | --- |
| 估值 | 12,000 韩元 × 10 股 | 120,000 韩元 |
| 整体损益 |（12,000 韩元 − 10,000 韩元）× 10 股 | +20,000 韩元 |
| 整体收益率 | 20,000 韩元 ÷ 100,000 韩元 | +20% |
| 日内损益 |（12,000 韩元 − 11,500 韩元）× 10 股 | +5,000 韩元 |
| 日内收益率 | 5,000 韩元 ÷ 115,000 韩元 | 约 +4.35% |

整体收益表示比买入价上涨多少，日内收益表示相对上一交易日收盘价变化多少。
切换按钮时，12 万韩元的估值不变。

<br/>

再加 8 万韩元现金，总估值变为 20 万韩元。
加入现金后，本例整体损益仍为 +2 万韩元，整体收益率仍为 +20%。

<br/>

<Toggle title="为什么与券商显示的收益不同？">

PortRhythm 的整体损益是当前持仓的估值损益。
券商账户的累计收益还可能计入已卖资产的已实现损益、分红、手续费和税费。

美股用美元现价与美元买入价之差乘以当前采用的汇率。
买入时与当前汇率不同产生的汇兑损益不纳入计算。
日内损益也按价格变化计算，排除汇率变化和现金。

如果数字不同，先统一持仓数量、平均买入价、价格时点与损益统计范围再比较。

</Toggle>

## 4. 证券列表与排序

仪表盘列表分为投资 `투자` 和现金及其他 `현금·기타`。
投资区显示股票、ETF 和加密资产，现金及其他区显示手动录入的资产。

<br/>

可逐项核对名称、代码、持仓数量和估值。
投资项目的损益会使用上方选中的整体或日内口径。

<br/>

### 4.1 排序依据

在列表上方选择希望使用的排序方式。

- `평가액 높은순 / 낮은순`（按估值降序或升序）  
  从金额较大或较小的资产开始查看。
- `손익 높은순 / 낮은순`（按损益降序或升序）  
  按所选期间的盈利或亏损金额查看。
- `수익률 높은순 / 낮은순`（按收益率降序或升序）  
  按所选期间的比例查看。
- `이름순`（按名称排序）  
  按证券名称查找。

损益金额反映对总体结果的贡献，收益率反映相对买入额或上一交易日基准金额的变化幅度。
收益率高的资产如果持仓金额小，对整体损益的影响也可能较小。

<br/>

无法确认损益的项目排在后面。
对不计算损益的现金及其他列表，选择损益或收益率排序时，仍会按估值降序显示。

<br/>

整体／日内选择和排序方式按账号保存在当前浏览器。
切换页面或刷新后仍会保留，因此看到陌生的数字时，先确认所选口径。

<br/>

### 4.2 合并同一证券

仪表盘会合并市场、交易所和证券代码相同的股票。
例如，在 A 账户登记苹果 3 股，在 B 账户登记 7 股，列表会显示合计 10 股。

<br/>

打开详情可以核对分账户持仓。
仅名称相同，而交易所或代码不同的条目不会合并。

<Toggle title="多个账户的平均买入价如何计算？">

按数量计算加权平均。
如果 A 账户有 3 股，每股 100 美元，B 账户有 7 股，每股 200 美元，总买入额就是 1,700 美元。
除以合计 10 股，平均买入价为 170 美元。

直接对两个单价取平均则是 150 美元。
如果部分账户缺少买入价，合并项目的损益无法完整计算，需要核对对应账户的单价。

</Toggle>

<br/>

## 5. 搜索持有资产

要按账户查看股票详情，请打开持有资产 `보유 자산`。
电脑端通过左侧菜单进入，移动端依次点击底部的全部 `전체` 和持有资产 `보유 자산`。

<Img src="/portrhythm-guide5-desktop-holdings-20261008.webp" width={800} alt="电脑端持有资产的市场筛选、搜索及分账户股票列表"/>

这里显示股票和 ETF 的分账户持仓。
加密资产与现金可在仪表盘查看。

### 5.1 市场筛选与搜索

- 选择全部／韩国／美国 `전체 / 국내 / 미국`。  
  只显示希望查看的市场。
- 在搜索框输入证券名称、证券代码或券商。  
  例如搜索“苹果”“AAPL”或已登记的券商名称。
- 点击所需证券的名称。  
  即可打开该账户的持仓详情。

移动端用单项证券卡片代替横向表格。
按顺序查看卡片上的数量、价格、估值和损益即可。

<Img src="/portrhythm-guide5-mobile-holdings-20261008.webp" width={350} alt="移动端持有资产的搜索框与股票卡片"/>

<br/>

### 5.2 金额使用的币种

仪表盘统一折算为韩元，持有资产页面里的美股则用美元显示。
如果同一证券看起来金额不同，先区分韩元与美元。

| 页面 | 显示范围 | 金额口径 |
| --- | --- | --- |
| 仪表盘 | 股票、加密资产、现金及其他 | 折算为韩元 |
| 持有资产 | 各账户的股票和 ETF | 韩国用韩元，美国用美元 |
| 资产详情 | 所选资产或合并后的证券 | 估值用韩元，现价与买入价用资产原币 |

持有资产中的估值损益是以买入价为基准的整体损益。
在仪表盘选择日内收益，不会改变这个页面的口径。

<br/>

排序方式与仪表盘共享。
不过，在全部市场按金额排序时，韩国市场与美国市场分别排序，避免直接比较韩元和美元数字。

<br/>

## 6. 资产详情

点击仪表盘中的资产，或持有资产中的证券名称，即可打开详情。
数字异常时，可以在这里同时核对输入和价格。

<Img src="/portrhythm-guide5-desktop-detail-20261008.webp" width={800} alt="股票详情中的估值、数量、现价和分账户持仓"/>

### 6.1 详情项目

- `평가 금액`（估值）  
  根据现价算出的韩元金额。
- `보유 수량`（持仓数量）  
  股票以股为单位，加密资产以枚为单位。
- `현재가`（现价）  
  一股股票或一枚代币的价格。
- `평균 매입단가`（平均买入价）  
  一股股票或一枚代币的平均买入价格。
- `평가손익`（估值损益）  
  当前持仓相对平均买入价产生的损益。

**详情中的估值损益按买入价计算。**
即使从仪表盘的日内收益视图进入，详情中也显示整体估值损益。

<br/>

美股的现价和买入价用美元显示。
加密资产的买入价是每枚代币的韩元价格。
现金及其他资产则显示输入金额与估值口径。

<br/>

### 6.2 分账户持仓

在股票详情的分账户持仓 `계좌별 보유` 中，查看券商、账户名、数量和买入价。
如果从仪表盘打开合并证券，可通过这份列表分账户核对。

<br/>

如果从持有资产页面打开某账户的持仓，则显示选中账户的详情。
同一证券会根据进入的页面采用不同的汇总范围。

<Img src="/portrhythm-guide5-mobile-detail-20261008.webp" width={350} alt="移动端股票详情的买入价和分账户修改按钮"/>

点击返回上一页 `← 이전 화면` 可回到列表。
修改数量时，同时确认证券名称和要修改的账户名称。

## 7. 修改持仓信息

加仓或部分卖出后，按实际余额更新数量和平均买入价。
只更新行情不会改变持仓数量。

### 7.1 修改股票

在股票详情的分账户持仓 `계좌별 보유` 中，点击相应账户的修改 `수정`。
输入区会在同一页面下方展开。

<Img src="/portrhythm-guide5-desktop-edit-20261008.webp" width={800} alt="股票详情下方展开的数量和平均买入价编辑区"/>

- 在持仓数量 `보유 수량` 中填写当前总余额。  
  10 股再加仓 2 股时，填写总数 12 股。
- 在平均买入价 `평균 매입단가` 中填写券商显示的每股平均价。  
  美股用美元，韩国股票用韩元。
- 核对输入后点击保存 `저장`。  
  对应持仓会保存，同一页面上的金额和损益也会更新。

要放弃修改，点击取消 `취소`。
移动端同样可在详情中点击对应账户的修改 `수정`，再向下滚动到输入区操作。

<br/>

### 7.2 加密资产与现金

加密资产、现金和其他资产可点击详情中的修改资产 `자산 수정`。
可改字段因资产类型而异。

| 资产 | 可修改的值 | 输入依据 |
| --- | --- | --- |
| 加密资产 | 持仓数量、平均买入价 | 代币数量、每枚的韩元买入价 |
| 韩元现金及其他 | 资产名称、韩元金额 | 当前剩余韩元金额 |
| 美元现金及其他 | 资产名称、美元金额 | 折算为韩元之前的美元金额 |

例如，0.01 BTC 的总买入额为 100 万韩元，每枚的买入价就是 1 亿韩元。
数量填写 0.01，平均买入价填写 100,000,000。

<br/>

现金按当前余额修改。
如果把 500 美元换算成韩元再填进美元栏，币种就会出错。请先核对字段单位。

<br/>

<Bbox>

不清楚买入价时，可以留空，待核实后再填。
仍可用可确认的价格和数量计算估值，缺少买入价的资产则保留为损益待确认状态。

</Bbox>

### 7.3 修改其他信息

数量和单价之外的信息通过以下路径修改。

- 证券代码与交易所  
  依次进入修改资产 `자산 수정`、修改此证券 `이 종목 수정`、确认或更改证券代码 `종목코드 확인·변경`。
- 资产所属组合  
  在资产分配 `자산 배정` 中修改并保存。详细方法见[第 4 篇：资产分配](https://www.promleeblog.com/blog/post/439-portrhythm-asset-assignment-guide)。

详情编辑区的保存 `저장` 会直接保存对应条目。
无需另到目标设计或资产分配页面保存。

<br/>

## 8. 价格来源与更新

数量和买入价正确而金额有出入时，请核对价格来源与时点。
持有资产页面会在现价下方注明采用的是韩国投资证券的行情还是截图价格。

<br/>

仪表盘下方的查看价格与汇率口径 `가격·환율 기준 보기` 可以核对行情和汇率的汇总依据。
移动端也可在列表下方一起查看损益汇总口径 `손익 집계 기준` 与最近行情时间。

<Img src="/portrhythm-guide5-desktop-price-20261008.webp" width={800} alt="仪表盘下方的价格和汇率口径及最近确认时间"/>

### 8.1 核对价格的顺序

- 点击价格更新 `가격 갱신`。  
  移动端仪表盘点击总估值旁的刷新图标。
- 查看现价和最近确认时间。  
  如果还在查询，等结果返回后再核对。
- 如果仍显示截图价格，查看证券代码和交易所。  
  核对登记证券与实际持有证券是否相同。
- 如果没有日内损益，查看上一交易日的收盘价是否已确认。  
  估值所需的价格齐全时，日内损益所需的数据仍可能不完整。

如果无法从 API 确认新价格，系统可能使用上次确认的价格或截图价格。
要判断行情是否刚刚更新，还需核对时间和来源。

<br/>

### 8.2 更新范围

页面打开且处于活跃状态时，系统尝试每约 5 分钟更新股票，每约 1 分钟更新 Bithumb 加密资产。
查询时间与交易所实际成交时间可能不同。

<br/>

**价格更新用于查询行情。**
在券商买入或卖出的数量，以及现金余额，都需要自行登记或修改。

<br/>

## 9. 常见问题

<Toggle title="为什么整体损益为正，日内损益却为负？">

现价高于买入价、但低于上一交易日收盘价时，就会出现这种情况。
例如，以 10,000 韩元买入，昨天为 12,000 韩元，现在为 11,800 韩元，整体损益为正，日内损益为负。
两个数值使用不同的比较基准。

</Toggle>

<Toggle title="资产能看到，为什么没有损益？">

整体损益需要平均买入价和价格，日内损益则需要 API 现价及上一交易日收盘价。
检查对应计算所需的数据是否齐全。

`조회 중`（查询中）表示正在等待数据，`정보 없음`（无信息）表示尚未确认计算所需的信息。
损益空白时，金额处于未知状态。
手动录入的现金及其他资产不计算投资损益。

</Toggle>

<Toggle title="为什么仪表盘与持有资产的数量不同？">

仪表盘合并同一股票，持有资产按账户显示。
先把各账户数量相加，再与仪表盘数量比较。

如果总数也不一致，检查同一账户的同一证券是否重复登记，以及代码和交易所是否登记一致。

</Toggle>

<br/>

## 结论

初次使用时，可以逐个查看数字。
先用总估值了解资产规模，再选择整体或日内口径，最后点开一项证券核对数量和买入价。

数字有出入时，按**币种 → 汇总范围 → 数量与单价 → 价格时点**的顺序核查，比较容易找到原因。

理清金额和持仓后，就可以查看各个组合比目标多了还是少了。
