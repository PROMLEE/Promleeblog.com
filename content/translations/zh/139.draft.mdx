## 开始之前

> 本文基于 Flutter 3.24 编写。

下文假设 Flutter 项目已经与 Firebase 项目关联。如果还没有 Firebase 项目，请参考下面的文章创建。
[向 Firebase 注册 Flutter 应用](/blog/post/134-flutter-firebase-apps)

### 什么是 FCM？

<Img src="https://firebase.google.com/static/docs/cloud-messaging/images/diagram-FCM.png?hl=ko" width={500} alt="FCM 架构概览（来源： https://firebase.google.com/docs/cloud-messaging/fcm-architecture）"/>

Firebase Cloud Messaging（FCM）是一种可以免费、可靠地发送消息的跨平台消息服务。
要实现 FCM 消息收发，主要需要两个组件。

1. 可信的发送环境，例如 Cloud Functions for Firebase 或应用服务器，负责撰写消息、选择接收对象并发送。
2. Apple、Android 或 Web（JavaScript）客户端应用，通过各平台的传输服务接收消息。

第一个组件通常是后端服务器，第二个通常是 Flutter 应用。本文主要介绍第二个组件，也就是如何在 Flutter 应用中获取 FCM 令牌并接收推送通知。

## 1. 配置 iOS

> 需要 Apple Developer 账号。如果还没有，可以在 [Apple Developer](https://developer.apple.com/) 注册，也可以跳过这一步，只配置 Android。

## 3. 编写接收推送通知的 Flutter 代码

### 3.1. 安装 firebase_messaging 软件包

```bash
flutter pub add firebase_messaging
```

### 3.2. 请求通知权限

在需要请求通知权限的位置添加以下代码。

```dart
import 'package:firebase_messaging/firebase_messaging.dart';

// 적절한 위치에 선언
FirebaseMessaging messaging = FirebaseMessaging.instance;
NotificationSettings settings = await messaging.requestPermission(
  alert: true,
  announcement: false,
  badge: true,
  carPlay: false,
  criticalAlert: false,
  provisional: false,
  sound: true,
);
print('User granted permission: ${settings.authorizationStatus}');
```

### 3.3. 编写后台接收推送通知的代码

在入口文件 main.dart 中添加以下代码。

> 使用后台消息处理函数时，有几点需要留意。

1. 不能使用匿名函数。
2. 必须是顶层函数，例如不能是需要先初始化类的类方法。
3. 如果使用 Flutter 3.3.0 或更高版本，必须在消息处理函数的声明正上方添加 @pragma('vm:entry-point') 注解，否则该函数可能在发布模式下被树摇优化移除。

```dart title="/lib/main.dart"
import 'package:firebase_messaging/firebase_messaging.dart';

@pragma('vm:entry-point')
Future<void> _firebaseMessagingBackgroundHandler(RemoteMessage message) async {
  await Firebase.initializeApp();
}

void main() {
  FirebaseMessaging.onBackgroundMessage(_firebaseMessagingBackgroundHandler);
  runApp(MyApp());
}
```

### 3.4. 编写前台接收推送通知的代码

在入口文件中添加以下监听器。

```dart title="/lib/main.dart"
import 'package:firebase_messaging/firebase_messaging.dart';

void main(){
	// ...
	FirebaseMessaging.onMessage.listen((RemoteMessage message) {
		print('Got a message whilst in the foreground!');
		print('Message data: ${message.data}');

		if (message.notification != null) {
			print('Message also contained a notification: ${message.notification}');
		}
	});
  runApp(MyApp());
}
```

## 4. 获取 FCM 令牌
### 4.1. 什么是 FCM 令牌？
FCM 令牌是 Flutter 应用与 FCM 服务器通信时使用的唯一标识符。Flutter 应用取得 FCM 令牌后，就可以接收推送通知。

### 4.2. 获取 FCM 令牌

```dart
import 'package:firebase_messaging/firebase_messaging.dart';

// 적절한 위치에 선언
final req = await FirebaseMessaging.instance.requestPermission(
	alert: true,
	badge: true,
	sound: true,
);
final fcmToken = await FirebaseMessaging.instance.getToken();
if (req.authorizationStatus == AuthorizationStatus.authorized && fcmToken != null) {
	print('FCM Token: $fcmToken');
} else {
	print('FCM Token: null');
}
```

## 常见问题与解决方法

### iOS 上获取 FCM 令牌失败

> apns token has not been set yet. please ensure the apns token is available by calling getapnstoken()

如果基本配置都已正确完成，却仍然收到这条错误，可能是 Flutter 未能自动获取 APNs 令牌。此时需要手动获取 APNs 令牌。

```dart title="/lib/main.dart" {16}
import 'package:firebase_messaging/firebase_messaging.dart';
import 'package:flutter/material.dart';

void main() async {
	WidgetsFlutterBinding.ensureInitialized();
	FirebaseMessaging messaging = FirebaseMessaging.instance;
	await messaging.requestPermission(
		alert: true,
		announcement: false,
		badge: true,
		carPlay: false,
		criticalAlert: false,
		provisional: false,
		sound: true,
	);
	messaging.getAPNSToken(); // 이 코드 추가
	await messaging.getToken();
	runApp(MyApp());
}
```

在 iOS 真机上安装并运行应用时，可能出现上述错误。这是因为在 iOS 上获取 FCM 令牌之前，需要先取得 APNs 令牌。解决办法是在应用启动后先获取 APNs 令牌，再获取 FCM 令牌。可以按上述方式修改代码。
