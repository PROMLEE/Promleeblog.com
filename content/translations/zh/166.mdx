## 开始之前
> 假设已经创建基础Expo项目。如需创建方法，请参考[Windows](/blog/post/117-expo-proj-init)或[Mac](/blog/post/143-expo-init-mac)教程。

### 什么是Expo Vector Icons
Expo Vector Icons是Expo提供的图标库。通常使用SVG文件需要下载图标并安装`react-native-svg`，而使用Expo Vector Icons，不必额外配置就能调用所需图标。
可以通过[expo.fyi](https://icons.expo.fyi/Index)查看提供的图标。
## 安装Expo Vector Icons
通过npx create-expo-app创建项目时，通常已经预装。如果没有安装，可以使用以下命令。
```bash
npm i @expo/vector-icons
```

## 使用Expo Vector Icons
先在[expo.fyi](https://icons.expo.fyi/Index)中搜索需要的图标。点击图标后，会出现两段代码。
<Img src="/posts/250325-111936.webp" width={400} alt=""/>

第一段是`import { 아이콘 패키지 } from '@expo/vector-icons';`，第二段是`<아이콘 컴포넌트 />`。把两段代码复制到项目中，就能显示图标。下面给出示例与结果。
```tsx title="/app/index.tsx"
import AntDesign from '@expo/vector-icons/AntDesign';
import { SafeAreaView } from 'react-native-safe-area-context';

const App = () => {
  return (
    <SafeAreaView
      style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}
    >
      <AntDesign name="checkcircle" size={24} color="black" />
    </SafeAreaView>
  );
};

export default App;
```

## 按钮组件
@expo/vector-icons还提供一个特殊组件：`Icon.Button`可以同时显示图标与文字。下面是示例和结果。
```tsx title="/app/index.tsx"
import AntDesign from '@expo/vector-icons/AntDesign';
import { SafeAreaView } from 'react-native-safe-area-context';

const App = () => {
  return (
    <SafeAreaView
      style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}
    >
      <AntDesign.Button
        name="checkcircle"
        size={24}
        color="white"
        backgroundColor={'green'}
        onPress={() => console.log('Button Pressed')}
      >
        Press Me
      </AntDesign.Button>
    </SafeAreaView>
  );
};

export default App;
```

### 详细属性
| Prop | 说明 | 类型 | 默认值 |
|---|---|---|---|
| name | 图标名称 | string | X |
| size | 图标大小 | number | 20 |
| color | 图标颜色 | string | white |
| backgroundColor | 按钮背景色 | string | \#007AFF |
| onPress | 点击按钮时执行的函数 | () => void | null |
| borderRadius | 按钮圆角 | number | 5 |
| iconStyle | 图标样式 | StyleProp | \{marginRight: 10\} |

## 结论
Expo默认提供常用图标集合，几乎不需要额外配置即可使用，很方便。尤其Button组件，无需配置大量CSS和样式就能实现，因此我应该会经常使用。
