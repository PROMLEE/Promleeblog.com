## 经典同步问题
### 生产者—消费者问题（Producer-Consumer）
生产者向共享缓冲区添加数据，消费者从中取出数据。如果缓冲区已满或为空，对应的一方就要等待。
解决方法是使用两个信号量和一个互斥锁，协调生产者与消费者的操作。
```c title="C 코드"
sem_t empty, full;
pthread_mutex_t mutex;

void producer() {
  while (1) {
    // 데이터 생성
    sem_wait(&empty); // 버퍼가 비어있는지 확인
    pthread_mutex_lock(&mutex); // 버퍼에 접근하기 위한 락
    // 데이터 추가
    pthread_mutex_unlock(&mutex); // 락 해제
    sem_post(&full); // 버퍼가 채워진 것을 알림
  }
}

void consumer() {
  while (1) {
    sem_wait(&full); // 버퍼가 채워진 것을 확인
    pthread_mutex_lock(&mutex); // 버퍼에 접근하기 위한 락
    // 데이터 소비
    pthread_mutex_unlock(&mutex); // 락 해제
    sem_post(&empty); // 버퍼가 비어있는 것을 알림
  }
}
```
### 哲学家就餐问题（Dining Philosophers）
五位哲学家围坐在圆桌旁，相邻两人之间放着一把叉子。每位哲学家必须同时拿到左右两把叉子才能开始用餐，这就产生了同步问题。
如果所有哲学家同时拿起一侧的叉子，然后等待另一侧，就可能发生死锁。
可以让奇数号和偶数号哲学家按不同顺序拿叉子，或限制同时参与的哲学家人数。

## 内核中的同步
操作系统内部同样需要同步，因为多个进程可以通过系统调用同时访问内核。
例如，在文件系统中，多个进程尝试同时修改同一个文件时，可以使用*锁（lock）*协调操作顺序。
常用方案包括自旋锁（spinlock）和读写锁（reader-writer lock）。
### 自旋锁（spinlock）
自旋锁会不断循环，直到锁被释放。
未获取到锁的线程不会让出 CPU，而是继续循环等待，*反复尝试获取锁*。
- 无需上下文切换，适合持锁时间非常短的场景。
- 常用于多核环境。
- 持锁时间较长时效率低，会浪费 CPU 资源。
- 通常用于内核或接近硬件的代码。
```c title="C 코드"
while (__sync_lock_test_and_set(&lock, 1)) {
  // 락이 해제될 때까지 계속 대기 (spin)
}
```
### 读写锁（reader-writer lock）
读写锁分别控制读取（read）和写入（write）。
多个读者可以同时访问，读操作可以并行。
写者独占访问，在写入期间阻止其他读写操作。
- 读多写少时可以提升性能。
- 在保持数据一致性的同时，尽可能提高并发度。
- 读锁：多个线程可以同时获取。
- 写锁：同一时间只能由一个线程独占。
- 可以选择读者优先或写者优先策略。
```c title="C 코드"
pthread_rwlock_t lock;
pthread_rwlock_rdlock(&lock);  // 읽기 락
// 읽기 작업 수행
pthread_rwlock_unlock(&lock);  // 락 해제

pthread_rwlock_wrlock(&lock);  // 쓰기 락
// 쓰기 작업 수행
pthread_rwlock_unlock(&lock);  // 락 해제
```

## POSIX 线程同步示例
> 什么是 POSIX？
POSIX 是 Portable Operating System Interface（可移植操作系统接口）的缩写，是一个提供标准化操作系统接口的项目。POSIX 标准旨在保证不同操作系统上的行为一致。Linux、macOS 和 Windows 等大多数常用操作系统都遵循 POSIX 标准。

在 POSIX 环境中，可以通过 `pthread` 库使用互斥锁和信号量。
```c
pthread_mutex_t lock;
pthread_mutex_init(&lock, NULL);
pthread_mutex_lock(&lock);
// 임계구역 코드
pthread_mutex_unlock(&lock);
```
信号量示例
```c
sem_t sem;
sem_init(&sem, 0, 3); // 동시 접근 가능 횟수: 3
sem_wait(&sem);
// 공유 자원 접근
sem_post(&sem);
```
## Java 中的同步
在 Java 中，可以使用 `synchronized` 关键字方便地定义临界区。
```java
public synchronized void increment() {
  count++;
}
```
也可以显式使用锁对象。
```java
ReentrantLock lock = new ReentrantLock();
lock.lock();
try {
  // 임계구역
} finally {
  lock.unlock();
}
```

## 其他方案
同步问题很难完全避免，但可以通过调整结构来降低风险。
- 异步处理：分散对资源的访问，尽量减少加锁的需要。
- 锁拆分（Lock splitting）：只锁住一部分，而不是锁住整体。
- 无锁结构（lock-free）：使用基于 CAS 的数据结构。

这些技术越来越常用于高性能系统。
