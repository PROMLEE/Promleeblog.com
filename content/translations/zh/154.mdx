## 开始之前
> 本文假设你已创建基本的 Expo 项目。创建方法请参阅 Expo 项目创建：[Windows](/blog/post/117-expo-proj-init)、[Mac](/blog/post/143-expo-init-mac)。
> 在基本的 React Native CLI 开发环境中，也可以通过额外配置使用它。
### 什么是 SecureStore？
> Expo SecureStore 可以加密键值对，并将其安全地保存在设备本地。每个 Expo 项目都有独立的存储空间，无法访问其他 Expo 项目的存储。（官方文档）

React Native 已经有可在设备本地保存键值对的 [AsyncStorage](/blog/post/129-async-storage)，那为什么 Expo 还提供 SecureStore？正如它的名字所示，SecureStore 提供了比 AsyncStorage 更安全的数据存储方式。
在 Android 上，值存放在由 Android 密钥库系统加密的 SharedPreferences 中。在 iOS 上，值通过钥匙串服务以 kSecClassGenericPassword 保存。iOS 还允许设置 kSecAttrAccessible 属性，以控制何时可以读取这些值。
### SecureStore 的特点
使用 expo-secure-store 保存的数据会随应用卸载而删除。此外，如果用户更改生物识别设置，例如添加新指纹，所有以 requireAuthentication 为 true 保存的数据都将无法访问。

## 安装和配置 SecureStore
用以下命令安装 SecureStore。
```bash
npx expo install expo-secure-store
```
### 配置 Expo 环境
在 Expo 项目的 `app.json` 文件中添加以下配置。
```json title="app.json"
{
  "expo": {
    "plugins": [
      [
        "expo-secure-store",
        {
          "configureAndroidBackup": true,
          "faceIDPermission": "Allow $(PRODUCT_NAME) to access your Face ID biometric data."
        }
      ]
    ]
  }
}

```
### 配置 React Native CLI 环境
在 React Native CLI 环境中，只需运行以下命令。
```bash
npx pod-install
```
### 添加 Apple 审核所需的加密配置
App Store Connect 会提示选择应用采用的加密算法类型。这属于出口合规信息，发布应用或提交到 TestFlight 时会遇到这个提示。
如下图所示，提交 Apple 审核时，需要在这个项目中说明应用使用了哪种加密。
<Img src="/posts/250314-133431.png" width={400} alt=""/>
使用 expo-secure-store 时，可以在应用配置中将 `ios.config.usesNonExemptEncryption` 设为 false，以声明应用未使用非豁免加密。
```json title="app.json"
{
  "expo": {
    "ios": {
      "config": {
        "usesNonExemptEncryption": false
      }
    }
  }
}
```

## 使用 SecureStore
要使用 SecureStore，在页面组件中添加以下代码。
<Toggle title="查看 /app/index.tsx 代码">

```tsx title="/app/index.tsx" {6, 10}
import * as SecureStore from 'expo-secure-store';
import { useState } from 'react';
import { Text, View, StyleSheet, TextInput, Button, Alert } from 'react-native';

async function save(key: string, value: string) {
  await SecureStore.setItemAsync(key, value);
}

async function getValueFor(key: string) {
  let result = await SecureStore.getItemAsync(key);
  if (result) {
    Alert.alert("🔐 Here's your value 🔐 \n" + result);
  } else {
    Alert.alert('No values stored under that key.');
  }
}

const App = () => {
  const [key, onChangeKey] = useState('Your key here');
  const [value, onChangeValue] = useState('Your value here');

  return (
    <View style={styles.container}>
      <Text style={styles.paragraph}>Save an item, and grab it later!</Text>
      {}

      <TextInput
        style={styles.textInput}
        clearTextOnFocus
        onChangeText={(text) => onChangeKey(text)}
        value={key}
      />
      <TextInput
        style={styles.textInput}
        clearTextOnFocus
        onChangeText={(text) => onChangeValue(text)}
        value={value}
      />
      {}
      <Button
        title="Save this key/value pair"
        onPress={() => {
          save(key, value);
          onChangeKey('Your key here');
          onChangeValue('Your value here');
        }}
      />
      <Text style={styles.paragraph}>🔐 Enter your key 🔐</Text>
      <TextInput
        style={styles.textInput}
        onSubmitEditing={(event) => {
          getValueFor(event.nativeEvent.text);
        }}
        placeholder="Enter the key for the value you want to get"
      />
    </View>
  );
};

export default App;

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    paddingTop: 10,
    backgroundColor: '#ecf0f1',
    padding: 8,
  },
  paragraph: {
    marginTop: 34,
    margin: 24,
    fontSize: 18,
    fontWeight: 'bold',
    textAlign: 'center',
  },
  textInput: {
    height: 35,
    borderColor: 'gray',
    borderWidth: 0.5,
    padding: 4,
  },
});
```

上面的代码演示如何用 `SecureStore.setItemAsync(key, value)` 保存值，再用 `SecureStore.getItemAsync(key)` 读取值。用法与 AsyncStorage 类似，但可以更安全地保存数据。
可以使用 SecureStore.deleteItemAsync(key, options) 删除指定键的值。原文也提到可以使用 SecureStore.deleteAllItemsAsync() 删除所有值。

## 添加生物识别
SecureStore 支持生物识别。如下所示，可以用 `requireAuthentication` 设置是否要求认证，并用 `authenticationPrompt` 设置认证提示。
可以使用 SecureStore.canUseBiometricAuthentication() 检查设备是否可使用生物识别。
```tsx title="/app/index.tsx" {5,6}
// ...
async function save(key: string, value: string) {
	if (SecureStore.canUseBiometricAuthenticationAsync()) {
		await SecureStore.setItemAsync(key, value, {
			requireAuthentication: true,
			authenticationPrompt: 'Authenticate to save the value',
		});
	} else {
		await SecureStore.setItemAsync(key, value);
	}
}
// ...
```
各平台的行为有所不同。在 Android 上，所有操作都需要用户认证。在 iOS 上，只在读取或更新已有值时向用户显示认证提示，创建新值时不会显示。
模拟器不支持生物识别，因此需要用真机测试。

## 结语
根据场景选择 SecureStore 或 AsyncStorage，可以避免不必要的资源开销。登录令牌、用户信息等适合使用 SecureStore，简单的设置值、主题等可以用 AsyncStorage。
