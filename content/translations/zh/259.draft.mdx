## 算法分类
图论、图搜索、BFS、DFS。

## 题目说明
一块宽为M、高为N的白菜田中种有白菜。
每棵白菜占1×1个格子，没有白菜的位置用0表示。
有白菜的位置用1表示。
为了防止害虫，需要往田里放置白菜白蚯蚓。
一条蚯蚓可以保护所有相邻、连通的白菜。
编写程序，求至少需要放多少条蚯蚓。
<Img src="/250506-145917.webp" width={300} alt="#1012 有机白菜"/>
### 输入
第一行给出测试用例数量T。
每个测试用例的第一行依次给出田地宽M、高N和白菜位置数量K。
接下来K行给出白菜坐标。
坐标格式为(x, y)，其中x为横坐标，y为纵坐标。
(0 ≤ x < M, 0 ≤ y < N)

### 输出
对每个测试用例，输出所需蚯蚓的最少数量。

## 解题思路
1. 根据输入信息创建二维数组。
2. 将每个白菜位置标记为ground[y][x] = 1。
3. 遍历整块田地；遇到尚未访问的白菜，就通过BFS搜索所有与之连通的白菜。
4. 每启动一次BFS，就代表找到一个独立的白菜群，蚯蚓数量加1。
5. 所有群组搜索完毕后，输出蚯蚓数量count。

## Python代码
```python
import sys
from collections import deque

sys.setrecursionlimit(10000)  # DFS 사용 시 재귀 제한 증가 (예방 차원)

T = int(sys.stdin.readline())  # 테스트 케이스 수
dx = [0, 0, 1, -1]  # 좌우
dy = [1, -1, 0, 0]  # 상하

for _ in range(T):
    M, N, K = map(int, sys.stdin.readline().split())  # 가로(M), 세로(N), 배추 위치 수(K)
    ground = [[0] * M for _ in range(N)]  # 배추밭 초기화 (세로 x 가로)
    visited = [[False] * M for _ in range(N)]  # 방문 체크 배열

    for _ in range(K):  # 배추 위치 표시
        x, y = map(int, sys.stdin.readline().split())
        ground[y][x] = 1

    # BFS로 연결된 배추 그룹 탐색
    def bfs(y, x):
        queue = deque()
        queue.append((y, x))
        visited[y][x] = True
        while queue:
            cy, cx = queue.popleft()
            for d in range(4):
                ny, nx = cy + dy[d], cx + dx[d]
                if 0 <= ny < N and 0 <= nx < M:
                    if not visited[ny][nx] and ground[ny][nx] == 1:
                        visited[ny][nx] = True
                        queue.append((ny, nx))

    count = 0  # 지렁이 수
    for i in range(N):
        for j in range(M):
            if not visited[i][j] and ground[i][j] == 1:
                bfs(i, j)
                count += 1  # 새로운 연결 그룹 발견 시 증가

    print(count)
```

## 核心要点
### 图搜索
- 使用BFS（广度优先搜索）或DFS（深度优先搜索）遍历连通的白菜。
- BFS通过队列实现，DFS可以用递归或栈实现。
### 时间复杂度
输入规模：$M x N <= 50 x 50 = 2500, K <= 2500$
最坏情况下，2500棵白菜互不相邻，需要执行O(K)次BFS。
BFS内部，每个格子最多检查四个方向，O(K x 4) = O(K)。
总时间复杂度：O(K)。
