## 算法分类
递归、二叉树。

## 题目说明
给定0或正整数，将其转换成二进制后放入二叉树，判断能否构成合法的树。
例如，9转换成二进制后是1001，对应的二叉树如下。
```
 1
  \
   0
  / \
 0   1

1 0 0 1
```
这是一棵*不合法的树*。本题将值为0的节点视为空节点。下面展示把7转为二进制后放入二叉树的结果。
```
  1
 / \
1   1

1 1 1
```
这棵树不存在以空节点作为父节点的实际子节点，因此是*合法的树*。题目要求对合法的树返回1，否则返回0，并以列表形式返回结果。

## 解题思路
1. 将给定数字转换为二进制。
2. 计算二进制长度，再确定容纳它的二叉树高度：不断增加n，直到2的n次方大于或等于二进制长度。
3. 补0，使二进制长度达到2的n次方。
4. 编写函数，判断二叉树是否合法。
5. 判断函数的步骤如下。
		1. 如果列表长度为0，返回True。
		2. 如果中间值为0，表示当前节点为空，但子节点中存在1，则返回False。
		3. 否则递归检查列表的前半部分和后半部分，也就是左右子树。
6. 对所有给定数字进行判断，并将结果存入列表返回。

## Python代码

```python
def solution(numbers):
    answer = []
    for s in numbers:
        binnum, height = bin(s)[2:], 0  # 주어진 수를 이진수로 변환
        while 2 ** height <= len(binnum):  # 이진수의 길이가 2의 n승이 되도록 높이를 구함
            height += 1
        binnum = binnum.zfill(2 ** height - 1) # 이진수의 길이가 2의 n승이 되도록 0을 채움
        answer.append(1 if check(binnum) else 0 )
    return answer

def check(lst): # 이진 트리가 온전한 지 확인하는 함수
    n = len(lst) // 2
    if n == 0:  # 리스트의 길이가 1이면 True
        return True
    elif lst[n] == "0" and ("1" in lst): # 빈 노드이지만 자식 노드에 1이 있는 경우 False 
        return False
    else: 
        return check(lst[:n]) and check(lst[n + 1:]) # 재귀적으로 확인
```

## 核心要点
- 如何确定二叉树的高度。
- 如何递归检查子节点，判断二叉树是否合法。
