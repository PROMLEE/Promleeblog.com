## 开始之前
### 注释的重要性
软件开发中，代码的可读性与可维护性非常重要。尤其是多人合作时，仅看代码，往往难以理解意图。
最近，我在工作中负责制定开发约定，因此一直思考怎样才能写出团队成员都容易理解的代码。查看npm模块文件时，经常能见到一半以上内容都是注释的文件，而这些注释确实帮助我理解代码。因此，本文介绍JavaScript与TypeScript中的注释写法，以及适合团队协作的注释方式。

### 什么是JSDoc
[JSDoc](https://jsdoc.app/)是一种为JavaScript代码添加注释的方式，用于说明代码含义与用法。编写JSDoc后，IDE可以提取并展示信息，帮助开发者理解代码。此外，还能用它自动生成API文档。
下图展示在VSCode中将鼠标悬停于Next.js的Link组件时显示的信息。这些内容由JSDoc提供，包括必要参数、返回值，甚至完整的文字说明。

JavaScript与TypeScript可以通过`JSDoc`统一注释格式，让协作开发者更容易理解代码的目的与用法。
本文将介绍**JSDoc基础语法与使用方式**，以及**面向团队协作的有效注释方法**。

## 1. JSDoc基础语法
JSDoc是一种用于JavaScript和TypeScript的注释风格，帮助清楚表达代码含义。基本格式如下。
```ts
/** @type {string} */
var win;
```
代码中，`/** ... */`表示JSDoc注释。函数注释可以这样编写。


```ts
/**
* 책의 정보를 나타내는 함수입니다.
* @constructor
* @param {string} title - 책의 제목
* @param {string} author - 책의 저자
*/
function Book(title: string, author: string) {
}
```

1. 使用`/** ... */`形式的注释块。
2. 第一行简要说明函数用途。
3. 使用`@param`描述参数的类型与职责。
4. 使用`@returns`说明返回值的类型与意义。

<Img src="/posts/250307-200516.png" width={500} alt=""/>
这种注释会让IDE自动显示类型信息与说明，帮助开发者理解代码。

## 2. 其他JSDoc标签
JSDoc支持多种标签，下面介绍一些常用选项。
### 2.1. @example：提供使用示例
```ts
/**
 * 숫자를 세제곱합니다.
 * @param {number} x - 입력 숫자
 * @returns {number} x의 세제곱 값
 * @example
 * cube(3); // 27
 */
function cube(x: number): number {
  return x * x * x;
}
```

### 2.2. @deprecated：标记不再使用的函数
```ts
/**
 * 이 함수는 더 이상 사용되지 않습니다. 대신 newMethod를 사용하세요.
 * @deprecated
 */
function oldMethod() {
  console.log("이 메서드는 더 이상 사용되지 않습니다.");
}
```

<Ads2 />
### 2.3. @throws：说明异常
```ts
/**
 * 숫자를 나눕니다.
 * @param {number} x - 나눌 숫자
 * @param {number} y - 나누는 숫자
 * @returns {number} x를 y로 나눈 값
 * @throws {DivideByZero} y가 0인 경우
 */
function divide(x: number, y: number): number {
	if (y === 0) {
		throw new Error("y는 0이 될 수 없습니다.");
	}
	return x / y;
}
```

### 2.4. @async：标记异步函数
```js
/**
 * 비동기적으로 사용자 정보를 가져옵니다.
 * @param {string} userId - 사용자 ID
 * @returns {Promise<User>} 사용자 정보
 * @async
 */
async function fetchUser(userId: string): Promise<User> {
	const response = await fetch(`/users/${userId}`);
	return response.json();
}
```

### 2.5. @typedef：定义类型
```js
/**
 * 숫자 또는 숫자가 포함된 문자열입니다.
 * @typedef {(number|string)} NumberLike
 */

/**
 * 매직넘버를 설정합니다.
 * @param {NumberLike} x - 매직넘버.
 */
 function setMagicNumber(x: NumberLike) {
}
```
