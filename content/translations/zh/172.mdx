## 开始之前
> 本文假设你已创建基本的 Expo 项目。创建方法请参阅：[Windows](/blog/post/117-expo-proj-init)、[Mac](/blog/post/143-expo-init-mac)。

### 在 Expo 中支持多语言包
为了让使用不同语言、来自不同文化背景的用户方便地使用应用，需要对应用进行本地化。应用本地化后，可以根据用户设备的区域设置调整内容，并显示用户熟悉的译文与货币。
可以使用 Expo 提供的 [expo-localization](https://docs.expo.dev/guides/localization/) 来支持多语言。它让应用可以读取语言设置，再交给 [i18n-js](https://github.com/fnando/i18n) 等翻译库处理。面向全球提供服务时，多语言支持很重要。
通常可以借助基于 i18n 的库实现多语言。再配合 Expo 的 SDK，读取设备设置也会更简单。
<br/><br/>
本文结合 [i18next](https://www.i18next.com/) 实现多语言包。有关 i18next 的基本用法，请参阅[用 i18next 实现多语言翻译（React、Expo、React Native）](/blog/post/171-i18next-init)。

## 安装 expo-localization 和 react-i18next
### 安装
先执行以下命令，安装 `expo-localization`、`react-i18next`、`i18next` 和 `@react-native-async-storage/async-storage`。
```bash
npx expo install expo-localization react-i18next i18next @react-native-async-storage/async-storage
```
安装后，可以导入 `expo-localization`，编写读取设备当前语言设置的代码。

```tsx title="/app/index.tsx"
import React from "react";
import { View, Text } from "react-native";
import { getLocales } from "expo-localization";

const App = () => {
  const deviceLanguage = getLocales()[0].languageCode;

  return (
    <View
      style={{
        flex: 1,
        justifyContent: "center",
        alignItems: "center",
      }}
    >
      <Text style={{ fontSize: 20 }}>현재 기기 언어: {deviceLanguage}</Text>
    </View>
  );
};

export default App;
```
<Img src="/posts/250328-110529.webp" width={300} alt=""/>

上面的 `getLocales()` 会根据设备的*系统设置*返回当前区域信息，应用可以据此自动检测用户偏好的语言。
<Bbox>较新的 Android 和 iOS 支持为单个应用设置语言。可以据此判断应用内是否需要提供语言切换按钮。</Bbox>

## 使用 i18next 实现多语言翻译

<Toggle title="预览 /app/index.ts 完整代码">

```tsx title="/app/index.ts"
import React from "react";
import { View, Text, Button } from "react-native";
import { initReactI18next, useTranslation } from "react-i18next";
import { getLocales } from "expo-localization";
import i18n from "i18next";

const resources = {
  en: {
    translation: {
      welcome: "Welcome to the app!",
    },
  },
  ko: {
    translation: {
      welcome: "앱에 오신 것을 환영합니다!",
    },
  },
  ar: {
    translation: {
      welcome: "مرحبًا بك في التطبيق!",
    },
  },
};

i18n.use(initReactI18next).init({
  resources,
  lng: getLocales()[0].languageCode || "ko",
	fallbackLng: {
		"en-*": ["en"],
		"ko-*": ["ko"],
		"ar-*": ["ar"],
		default: ["en"],
	},
  interpolation: {
    escapeValue: false,
  },
  react: {
    useSuspense: false,
  },
});

const App = () => {
  const { t, i18n } = useTranslation();

  return (
    <View
      style={{
        flex: 1,
        justifyContent: "center",
        alignItems: "center",
        gap: 20,
      }}
    >
      <Text>{t("welcome")}</Text>
      <Button title="English" onPress={() => i18n.changeLanguage("en")} />
      <Button title="Korean" onPress={() => i18n.changeLanguage("ko")} />
      <Button title="Arabic" onPress={() => i18n.changeLanguage("ar")} />
    </View>
  );
};

export default App;
```

## 将语言包和 i18n 初始化拆到单独文件
上面的代码将翻译数据作为变量定义在组件外部。随着内容增加，文件会变长，也会难以管理。下面把翻译数据拆到单独的文件中。
在终端执行以下命令，创建保存翻译数据的目录与文件。
```bash
mkdir -p src/i18n/locales/{en-US,ko-KR,ar-SA} && \
touch src/i18n/index.ts \
src/i18n/locales/en-US/translations.json \
src/i18n/locales/ko-KR/translations.json \
src/i18n/locales/ar-SA/translations.json
```
这会生成下面的目录结构。
```
📦 src
 ┣ 📂 i18n
 ┃ ┣ 📂 locales
 ┃ ┃ ┣ 📂 ar-SA
 ┃ ┃ ┃ ┗ 📜 translations.json
 ┃ ┃ ┣ 📂 en-US
 ┃ ┃ ┃ ┗ 📜 translations.json
 ┃ ┃ ┗ 📂 ko-KR
 ┃ ┃ ┃ ┗ 📜 translations.json
 ┗ ┗ 📜 index.ts
```
在各个 JSON 文件中编写翻译数据。
```json title="/src/i18n/locales/en-US/translations.json"
{
	"welcome": "Welcome to the app!"
}
```
```json title="/src/i18n/locales/ko-KR/translations.json"
{
	"welcome": "앱에 오신 것을 환영합니다!"
}
```
```json title="/src/i18n/locales/ar-SA/translations.json"
{
	"welcome": "مرحبًا بك في التطبيق!"
}
```
接着在 `src/i18n/index.ts` 中编写读取翻译数据的代码。
```tsx title="/src/i18n/index.ts"
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import { getLocales } from "expo-localization";
import translationEn from "./locales/en-US/translations.json";
import translationKo from "./locales/ko-KR/translations.json";
import translationAr from "./locales/ar-SA/translations.json";

const resources = {
  en: { translation: translationEn },
  ko: { translation: translationKo },
  ar: { translation: translationAr },
};

const initI18n = async () => {
	i18n.use(initReactI18next).init({
		resources,
		lng: getLocales()[0].languageCode || "ko",
		fallbackLng: {
			"en-*": ["en"],
			"ko-*": ["ko"],
			"ar-*": ["ar"],
			default: ["en"],
		},
		interpolation: {
			escapeValue: false,
		},
		react: {
			useSuspense: false,
		},
	});
};

initI18n();

export default i18n;
```

最后，导入 `src/i18n/index.ts` 并使用。这样管理翻译数据会更方便。也可以在 `/app/_layout.tsx` 中导入，让设置应用到整个项目。
```tsx title="/app/index.ts" {1}
import "@/src/i18n";

// ... App 컴포넌트 밖의 i18n 초기화 코드 제거
```

## 保存语言偏好
如果希望应用关闭并重新打开后，仍使用用户选定的语言，可以通过 `AsyncStorage` 保存语言设置。`AsyncStorage` 可以异步存取应用数据。
在 `/src/i18n/index.ts` 中用 `AsyncStorage` 保存并读取语言设置，步骤如下。
1. 检查 AsyncStorage 是否已有保存的语言设置。
2. 如果没有，就读取设备的语言设置并使用该语言。
3. 如果已经保存过，就使用保存的语言。
4. 将语言设置写入 AsyncStorage。

语言标识通常采用 \{语言代码\}-\{国家代码\} 格式，例如韩语是 `ko-KR`，英语是 `en-US`。当前的翻译数据使用 `ko`、`en`、`ar` 这类简短代码，因此从设备读到设置后，只提取语言代码并保存。为防止出错，将 `en` 设为默认语言。
<Toggle title="/src/i18n/index.ts 完整代码">

```tsx title="/src/i18n/index.ts"
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import * as Localization from "expo-localization";
import AsyncStorage from "@react-native-async-storage/async-storage";
import translationEn from "./locales/en-US/translations.json";
import translationKo from "./locales/ko-KR/translations.json";
import translationAr from "./locales/ar-SA/translations.json";

const resources = {
  en: { translation: translationEn },
  ko: { translation: translationKo },
  ar: { translation: translationAr },
};

const LANGUAGE_KEY = "@app_language";

const initI18n = async () => {
  try {
    const savedLanguage = await AsyncStorage.getItem(LANGUAGE_KEY);
    let selectedLanguage = savedLanguage;

    if (!selectedLanguage) {
      const deviceLocales = Localization.getLocales();
      const deviceLocale = deviceLocales[0]?.languageTag || "en-US";
      const languageCode = deviceLocale.split("-")[0];

      if (languageCode in resources) {
        selectedLanguage = languageCode;
      } else {
        selectedLanguage = "en";
      }
    }

    await i18n.use(initReactI18next).init({
      resources,
      lng: selectedLanguage,
      fallbackLng: {
        "en-*": ["en"],
        "ko-*": ["ko"],
        "ar-*": ["ar"],
        default: ["en"],
      },
      interpolation: {
        escapeValue: false,
      },
      react: {
        useSuspense: false,
      },
    });

    if (!savedLanguage) {
      await AsyncStorage.setItem(LANGUAGE_KEY, selectedLanguage);
    }
  } catch (error) {
    await i18n.use(initReactI18next).init({
      resources,
      lng: "en",
      fallbackLng: "en",
      interpolation: {
        escapeValue: false,
      },
      react: {
        useSuspense: false,
      },
    });
  }
};

initI18n();

export default i18n;
```
</Toggle>

在 `/app/index.tsx` 中，每次点击语言切换按钮时，都将语言设置写入 AsyncStorage。
<Toggle title="/app/index.ts 完整代码">

```tsx title="/app/index.ts"
import React from "react";
import "@/src/i18n";
import { View, Text, Button } from "react-native";
import { useTranslation } from "react-i18next";
import AsyncStorage from "@react-native-async-storage/async-storage";

const App = () => {
  const { t, i18n } = useTranslation();

  const changeLanguage = async (language: "en" | "ko" | "ar") => {
    i18n.changeLanguage(language);
    await AsyncStorage.setItem("@app_language", language);
  };

  return (
    <View
      style={{
        flex: 1,
        justifyContent: "center",
        alignItems: "center",
        gap: 20,
      }}
    >
      <Text>{t("welcome")}</Text>
      <Button title="English" onPress={() => changeLanguage("en")} />
      <Button title="Korean" onPress={() => changeLanguage("ko")} />
      <Button title="Arabic" onPress={() => changeLanguage("ar")} />
    </View>
  );
};

export default App;
```
</Toggle>

## 结语
本文介绍了如何在 Expo 中支持多语言包。通过 Expo 提供的 `expo-localization` 读取设备语言设置，再使用 `i18next` 实现多语言翻译。
我们也把翻译数据拆到单独的文件中，并用 AsyncStorage 保存语言设置。如果应用面向全球用户，多语言包可以让不同语言的用户更方便地使用应用。
