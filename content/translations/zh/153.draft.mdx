## 开始之前
> 本文假定你已经创建了基本的 Expo 项目。
> 创建 Expo 项目的方法请参考：[Windows](/blog/post/117-expo-proj-init)、[Mac](/blog/post/143-expo-init-mac)。
> 基本的 React Native CLI 开发环境也可以使用，只需补充相应配置。

### 手机生物识别
手机生物识别可以有效增强设备安全性。
它利用指纹、面部或虹膜等信息验证用户身份，也让用户在使用手机时更加方便。
使用 expo-local-authentication 可以调用生物识别提示框（Android）或 Face ID、Touch ID（iOS），通过指纹或面部扫描验证用户。
## 安装 expo-local-authentication
```bash
expo install expo-local-authentication
```
## 额外配置
### Expo 环境
在 Expo 环境中，在项目根目录的 `app.json` 添加以下设置。
```json
{
  "expo": {
    "plugins": [
      [
        "expo-local-authentication",
        {
          "faceIDPermission": "Allow $(PRODUCT_NAME) to use Face ID."
        }
      ]
    ]
  }
}
```
### React Native CLI 环境
其他配置请查看 [react-native-local-authentication](https://github.com/expo/expo/tree/main/packages/expo-local-authentication#installation-in-bare-react-native-projects)。
Android 环境需要在 `android/app/src/main/AndroidManifest.xml` 中添加以下配置。
```xml
<uses-permission android:name="android.permission.USE_BIOMETRIC" />
<uses-permission android:name="android.permission.USE_FINGERPRINT" />
```
iOS 环境需要在终端运行以下命令。
```bash
npx pod-install
```
此外，还要在 `ios/Info.plist` 中添加以下配置。
```xml
<key>NSFaceIDUsageDescription</key>
<string>Allow $(PRODUCT_NAME) to use FaceID</string>
```

## 使用方法
```tsx
import * as LocalAuthentication from 'expo-local-authentication';
import React from 'react';
import { Button, Text, View } from 'react-native';

export default function App() {
	const handleAuthentication = async () => {
		const hasHardware = await LocalAuthentication.hasHardwareAsync();
		if (!hasHardware) {
			alert('생체 인증을 사용할 수 없는 기기입니다.');
			return;
		}
		const isEnrolled = await LocalAuthentication.isEnrolledAsync();
		if (!isEnrolled) {
			alert('생체 인증이 등록되어 있지 않습니다.');
			return;
		}
		const result = await LocalAuthentication.authenticateAsync({
			promptMessage: '생체 인증을 사용하여 로그인하세요.',
		});
		if (result.success) {
			alert('로그인 성공!');
		} else {
			alert('로그인 실패!');
		}
	};

	return (
		<View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
			<Text>생체 인증을 사용하여 로그인하세요.</Text>
			<Button title="로그인" onPress={handleAuthentication} />
		</View>
	);
}
```

下面看看各个函数的作用。

### LocalAuthentication.hasHardwareAsync
用于判断设备是否提供面部或指纹扫描器。
返回值为 `Promise<boolean>`。

### LocalAuthentication.isEnrolledAsync
用于判断设备是否已注册指纹或面部信息。
返回值为 `Promise<boolean>`。
### LocalAuthentication.authenticateAsync
尝试通过指纹、Touch ID 或设备支持时的 Face ID 进行认证。
它接收 `LocalAuthenticationOptions` 作为参数。
下面介绍其中几个实用参数。
- promptMessage: string
显示在 Touch ID 或 Face ID 提示框中的消息。
建议填写它，让用户知道为什么需要认证。
- cancelLabel: string
Touch ID 或 Face ID 提示框中取消按钮的文字。
默认值为 'Cancel'。
- biometricsSecurityLevel: 'strong' | 'weak'
设置允许的生物识别安全等级。
`strong` 只允许 Android Class 3 生物识别，例如指纹或 3D 面部扫描。
`weak` 允许 Android Class 3 和 Class 2 生物识别。
Class 2 的安全性低于 Class 3，例如基于摄像头的面部解锁。
- disableDeviceFallback: boolean
多次认证失败后，系统会默认回退到设备密码。
启用此选项可以关闭这一回退方式，改由应用自行处理；某些自定义认证流程会需要这样做。

整体流程如下。
1. 使用 `hasHardwareAsync` 确认设备是否支持生物识别。
2. 使用 `isEnrolledAsync` 确认用户是否已注册生物识别信息。
3. 使用 `authenticateAsync` 执行生物识别认证。

## 总结
在 React Native 中使用 Expo Local Authentication，可以为用户认证提供安全、便捷的方案。
借助 Expo Local Authentication，开发者可以轻松地将生物识别功能集成到 React Native 应用中，从而提升安全性和用户体验。
生物识别可以在无需输入密码的情况下验证用户身份，降低数据泄露风险。
这种简单有效的方式有助于构建更安全的移动应用。
