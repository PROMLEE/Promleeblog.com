## 开始之前
### 什么是Homebrew
>Homebrew is the easiest and most flexible way to install the UNIX tools Apple didn’t include with macOS.
It can also install software not packaged for your Linux distribution without requiring sudo.
> Homebrew是安装macOS未自带的UNIX工具的一种简单、灵活的方式。
它也能在不使用sudo的情况下，安装Linux发行版未打包的软件。

[Homebrew文档](https://docs.brew.sh/Manpage)
在macOS中安装各种软件包和Cask应用时，它非常方便。

## 安装Homebrew
打开终端，输入以下命令。
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
安装开始后，会出现是否继续、输入密码等提示，按照说明操作即可。
完成后，输入以下命令，确认安装是否成功。
```bash
brew --version
```
如果安装成功，会显示如下版本信息。
```bash
Homebrew 4.3.18
```

## 遇到的问题与解决方法
### 配置环境变量
安装之后，如果brew命令不能运行，可能需要设置环境变量。
在终端中输入以下命令。
```bash
echo "eval "$(/opt/homebrew/bin/brew shellenv)"" >> ~/.zshrc
source ~/.zshrc
```
重新打开终端，输入brew命令，检查是否正常。
```bash
brew --version
brew doctor # 홈브루의 상태 확인
```

## 结论
Homebrew支持软件包安装、卸载、更新和搜索等功能。
它让软件包管理更加方便，也能管理软件版本。
甚至还可以制作自己的软件包。
对于MacBook用户，它几乎是必备工具，推荐尝试使用。

#### 其他Homebrew命令
> brew update：更新Homebrew。
> brew upgrade [包名]：更新已安装的软件包。
> brew list：列出已安装的软件包。
> brew search [包名]
> brew uninstall [包名]
> brew info [包名]
> brew cleanup：清理不再使用的软件包。
> brew doctor：检查Homebrew状态。
