## 什么是流密码（Stream Cipher）
> 按比特处理数据的对称密钥加密方式。

输入：持续接收元素。
输出：每次输出一个元素。
比分组密码更快。
密钥只使用一次。
容易受到已知明文攻击：$M \oplus C = M \oplus (M \oplus k) = k$。
例如：LFSR、RC4、ChaCha。

## 随机数（Random Numbers）
- 在密码学中用途广泛。
	- 公钥加密中的私钥。
	- 流密码密钥。
	- 用作临时会话密钥的对称密钥。
- 要求：
	- 随机性。
		- 均匀分布：各数字出现频率应相同。
		- 独立性：不能从其他值推断出某个值。
	- 不可预测性。
		- 每个数字与其他数字在统计上相互独立。
		- 任何人都不应根据序列前面的元素预测后面的元素。

## 真随机数与伪随机数（Random Numbers vs Pseudo-Random Numbers）
- 真随机数生成器（True Random Number Generator，TRNG）。
	- 实现成本较高。
	- 使用非确定性来源。
	- 测量放射性、气体放电和电容漏电等不可预测的自然过程。
	- 越来越多现代处理器提供这类能力。
- 伪随机数（Pseudorandom Numbers）。
	- 生成能够通过统计随机性测试的序列。
	- 使用确定性来源，可预测性较高。

## RC4概述（RC4 Overview）
RC代表Rivest Cipher。
它是一种密钥长度可变、按字节执行操作的流密码。
- 预期在软件实现中具有较快速度。

其基础是使用随机置换。

## RC4：初始化S（RC4: Initialization of S）
S是长度为256字节的数组。
- 0到255各出现一次，初始按升序排列。
T是临时向量，前keylen个元素从k复制。
- keylen表示密钥长度。
- k表示密钥；填满T所需时，重复使用密钥内容。
使用T对S执行置换。
```python
j = 0
for i=0 to 255 do
	j = (j + S[i] + T[i]) mod 256;
	Swap(S[i], S[j]);
```
## RC4：生成密钥流（RC4: Stream Generation）
遍历S[i]中的所有元素。
```python
i = 0
j = 0
while(true)
	i = (i + 1) mod 256
	j = (j + S[i]) mod 256
	Swap(S[i], S[j])
	t = (S[i] + S[j]) mod 256
	k = S[t]
```
加密：将k值与明文的下一个字节执行XOR。
解密：将k值与密文的下一个字节执行XOR。

## RC4：安全分析（RC4: Security Analysis）
当密钥长度合理，例如128比特时，RC4被认为是安全的。
在WEP（Wired Equivalent Privacy）协议中存在漏洞。

# 工作模式（Modes of Operation）
## 什么是工作模式（Modes of Operation）
> 使用分组密码加密消息的方法。

分组密码的限制是明文长度固定。
工作模式则使用分组密码加密任意长度的消息。
- ECB（Electronic Codebook）模式。
- CBC（Cipher Block Chaining）模式。
- CFB（Cipher Feedback）模式。
- OFB（Output Feedback）模式。
- CTR（Counter）模式。

## ECB模式（Electronic Codebook Mode）
加密：随时间按分组加密。
- 在时刻n加密$P_n$，得到$C_n$。
解密：随时间按分组解密。
- 在时刻n解密$C_n$，得到$P_n$。

优点：
- 不需要分组同步。
- 传输错误只影响对应分组。
- 可以并行处理。

缺点：
- 加密过程是确定性的。
- 容易受到代换攻击：相同明文分组可以转换为相同密文分组。

## CBC模式（Cipher Block Chaining Mode）
加密：与前一个分组密文及密钥K结合执行XOR。
- $C_n = E_K(P_n \oplus C_{n-1})$
解密：与前一个分组密文及密钥K结合执行XOR。
- $P_n = D_K(C_n) \oplus C_{n-1}$

需要初始化向量。

## CFB模式（Cipher Feedback Mode）
加密：使用初始化向量与密钥K执行XOR并加密后使用。
