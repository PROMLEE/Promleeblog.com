## 路由协议（Routing Protocols）
路由协议的目标
- 通过路由器网络，确定从发送主机到接收主机的*良好路径*（或路由）。
  - 路径：数据包从给定的发送主机到最终目的主机时，依次经过的路由器序列。
  - 良好路径：成本最低、速度最快（延迟最低、吞吐量最高）、拥塞最少等。
## 网络图抽象（Network Graph Abstraction）
<Img src="/posts/240528-171257.png" width={300}/>
图：G = (N, E)
N = 路由器集合 = ${u, v, w, x, y, z}$
E = 链路集合 = ${(u, v), (u, x), (v, x), (v, w), (x, w), (x, y), (w, y), (w, z), (y, z)}$

c(x, x') = 链路 (x-x') 的成本
例如：c(w, z) = 5

- 成本可以始终为 1，也可以与带宽成反比，或与延迟、拥塞有关。
- 路径 $(x_1, x_2, ..., x_n)$ 的成本为 $c(x_1, x_2) + c(x_2, x_3) + ... + c(x_{n-1}, x_n)$。

问题：$u$ 与 $z$ 之间成本最低的路径是什么？
- 路由算法：寻找该最低成本路径的算法。

## 路由算法分类（Routing Algorithm Classification）
路由算法有两组基本分类：
- **全局（Global）**或**分散式（Decentralized）**
- **静态（Static）**或**动态（Dynamic）**

### 全局与分散式
**全局**：所有路由器都掌握整个网络的信息。
- 利用整个网络的信息确定最优路径。

**分散式**：每个路由器只掌握相邻路由器的信息。
- 仅利用相邻路由器的信息确定最优路径。

### 静态与动态
**静态**
- 用于网络链路状态变化缓慢的情况。

**动态**
- 用于网络链路状态变化迅速的情况。

# 5.2.1 路由协议——链路状态（Link State Routing Protocol）
## 链路状态路由算法（Link State Routing Algorithm）
**Dijkstra 算法**
网络拓扑和链路成本对*所有节点*都是已知的。
- 通过*链路状态广播*实现。
- 所有节点掌握相同的信息。

寻找一个节点（路由器）到所有其他节点的最短路径。
- 构建该节点的转发表。

迭代过程：经过 $k$ 次迭代后，找到到达 $k$ 个节点的最短路径。
符号说明
- $N'$：已经找到最短路径的节点集合。
- $D(v)$：到节点 $v$ 的最短路径长度。
- $p(v)$：到节点 $v$ 的最短路径上，$v$ 的前一个节点。
- $c(x, x')$：链路 $x-x'$ 的成本。

```python
def dijkstra(G, s):
		N' = {s}
		for each node v in G:
				if v != s:
						D(v) = c(s, v)
						p(v) = s
		while N' != N:
				find v not in N' such that D(v) is a minimum
				add v to N'
				update D(w) for each neighbor w of v and not in N':
						D(w) = min{D(w), D(v) + c(v, w)}
						p(w) = v
```
### 复杂度分析（Complexity Analysis）
- $O(n^2)$：对每个节点，寻找最短路径需要 $O(n)$。

使用堆优化
- $O(n\log n + m)$：存在 $n$ 个节点和 $m$ 条链路时。

# 5.2.2 路由协议——距离向量（Distance Vector Routing Protocol）
## 距离向量路由算法（Distance Vector Routing Algorithm）
**Bellman-Ford 算法**——动态规划
$d_x(y)$：从节点 $x$ 到节点 $y$ 的最短路径长度。
- $d_x(y) = \min_v\{c(x, v) + d_v(y)\}$
  - $c(x,v)$：从 $x$ 到相邻节点 $v$ 的成本。
  - $d_v(y)$：从相邻节点 $v$ 到目的节点 $y$ 的成本。
  - $\min$ 遍历 $x$ 的所有相邻节点 $v$ 计算。
- $D_x(y)$：从 $x$ 到 $y$ 的最低成本估计值。
  - $x$ 维护距离向量 $D_x = [D_x(y) : y \in N]$。

迭代、异步：向相邻节点发送距离向量。
- 每次本地迭代由以下情况触发：
  - 本地链路成本变化。
  - 收到相邻节点的距离向量更新。
- 分布式：
  - 每个节点只有在自身距离向量变化时才通知相邻节点。

### LS 与 DV 路由算法比较（LS vs. DV Routing Algorithm Comparison）
**消息复杂度**
- LS：对于 $n$ 个节点和 $E$ 条链路，复杂度为 $O(nE)$。
- DV：只在相邻节点之间交换消息，因此消息复杂度更低。

**收敛速度**
- LS：$O(n^2)$ 算法需要 $O(nE)$ 条消息。
  可能发生振荡。
- DV：收敛可能较慢。

**健壮性**
- LS：节点可能通告错误的链路成本。
- DV：节点可能传播错误的路径信息。
