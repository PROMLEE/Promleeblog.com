## 开始之前

昨天才看过账户，却记不清上个月为什么买那只 ETF。
截图不少，数字也很多，却没有一句写下自己当时的想法。
这时，比继续收集数字更有用的是**一张简短回答相同问题的记录表**。
<br/>
这是“读懂自己的投资组合”的最后一篇。
我们会把前七篇的表格汇总成月度检查表。
月度检查并不要求每月都买点什么。
**即使决定这次不交易，也可以记下理由。**

<Rbox>
本文的余额、交易和检查日期用于演示月度记录方法，不代表实际投资记录，也不构成建议。
</Rbox>

## 检查前先统一口径

每次用不同的尺子量身高，就很难知道长高了多少。
比较资产时，上个月和这个月也要使用相同的范围、币种与时间标准。
本例仍只合计普通账户 A、普通账户 B 和长期投资账户 C 的投资资产，生活费与应急资金不纳入。
<br/>
除了标注“月末”，还应记录**价格和汇率的核对时间**。
如果有标的价格尚未核实，或余额是后来补录的，也要记下来。
这样可以避免把本月才录入的遗漏资产误认成投资收益。
起始余额列在下表中。

## 从 1,000 万韩元增至 1,100 万韩元的一个月

先确定日期。
起点是 `2026-09-01 09:00`，终点是 `2026-10-01 09:00`，采用韩国时间，以韩元计价。
**假设所有资产价格不变，分配金、费用和税费均为零。**
<br/>
假设这个月只发生了以下事项。
金额均按成交金额计算，账户间转账属于投资范围内的资金移动。

| 时间 | 交易与资金进出 | 新增外部资金 |
| --- | --- | ---: |
| 9 月 15 日 10:00 | 在 C 卖出 40 万韩元的债券 ETF D | 0 韩元 |
| 同日 10:10 | 将 C 的 40 万韩元现金转入 A | 0 韩元 |
| 同日 10:20 | 在 A 买入 60 万韩元的 ETF A | 0 韩元 |
| 10 月 1 日 08:30 | 从投资范围外向 C 存入 100 万韩元 | +100 万韩元 |
| 同日 08:40 | 在 C 买入 60 万韩元的债券 ETF D | 0 韩元 |
| 同日 08:45 | 在 C 买入 5 万韩元的黄金 ETF E | 0 韩元 |

第一次买入股票，用了 A 原有的 20 万韩元现金和转入的 40 万。
最后存入的 100 万韩元中，60 万用于债券，5 万用于黄金，35 万留作现金。
结果如下。

| 账户与资产 | 起始金额 | 本次金额 |
| --- | ---: | ---: |
| A／美国股票 ETF A | 300 万韩元 | 360 万韩元 |
| A／个股 X | 50 万韩元 | 50 万韩元 |
| A／韩元现金 | 50 万韩元 | 30 万韩元 |
| B／美国成长股 ETF B | 150 万韩元 | 150 万韩元 |
| B／韩国股票 ETF C | 100 万韩元 | 100 万韩元 |
| C／韩元债券 ETF D | 200 万韩元 | 220 万韩元 |
| C／黄金 ETF E | 50 万韩元 | 55 万韩元 |
| C／韩元现金 | 100 万韩元 | 135 万韩元 |
| 合计 | **1,000 万韩元** | **1,100 万韩元** |

分账户看，A 为 440 万韩元，B 为 250 万，C 为 410 万。
股票金额增加 60 万韩元，原因是**用账户里的其他资金加仓**。
总额增加 100 万韩元，是因为有外部资金存入。
按 `1,100만 − 1,000만 − 100만 = 0원` 计算，投资本身带来的收益为零。

## 从前面的表格带过来的内容

除了余额，也把之前核对的信息补上。
分别记录**用本月余额计算的数值**和**需要保留的判断标准**。

### 构成与目标权重

股票 660 万韩元、债券 220 万、黄金 55 万、现金 165 万，当前权重分别为 60%、20%、5% 和 15%。
这些权重与目标一致。
核对已登记的交易后，可以记录本次无须因权重再做交易。
至于目标是否仍适合自己的投资期限和资金情况，需要单独核对。

### 企业持仓重叠与汇率

X 在 ETF A 中占 6%，在 ETF B 中占 10%，其他持有项目没有 X 股票。
由于增持了 ETF A，X 的合计金额为 `360만 × 6% + 150만 × 10% + 50만 = 86.6만 원`，即 86.6 万韩元。
除以 1,100 万韩元总额，约为 7.87%。
<br/>
X 的金额比之前的 83 万韩元高，但权重低于之前的 8.3%。
原因是新增资金让**总额也变大了**。
金额和比例都记下来，才看得出变化的原因。
<br/>
未进行汇率对冲、与美国股票相关的 A、B、X 共计 560 万韩元，约占 50.91%。
其中用美元交易的 A 和 X 为 410 万韩元，约占 37.27%。
用韩元交易的 B 也会受到汇率影响。
黄金 ETF E 占 5%，仍未核实其结构，因此标注为*待核实汇率对冲*。
这里检查直接的汇率影响，企业进出口等间接影响则另行考虑。

### 投资表现与下跌情景

因为价格从未变化，剔除资金进出影响的收益率 `TWR` 为 0%，计入存款时间的 `XIRR` 也为年化 0%。
重点是**没有把 100 万韩元的新投入算作收益**。
<br/>
对当前 1,100 万韩元应用股票 −30%、债券 −5%、黄金 +10%、现金 0% 的变化，资产会减少 203.5 万韩元。
即使权重相同，投入金额增加，可能减少的金额也会增加。
因此要重新核对生活费、应急资金与近期支出。

## 一张自己的月度检查表

可以复制下表，把数字与备注换成自己的记录。
这是一张**留给下个月自己的交接笔记**。

| 问题 | 本月记录 |
| --- | --- |
| 管理哪些钱？ | 三个账户的长期投资资产，不含生活费与应急资金 |
| 何时比较？ | 2026-09-01 09:00 → 2026-10-01 09:00，韩国时间，以韩元计价 |
| 总额和资金进出？ | 1,000 万 → 1,100 万韩元，外部净流入 100 万韩元 |
| 投资结果？ | 盈亏 0 韩元，TWR 0%，XIRR 年化 0%，假设价格不变 |
| 资产如何构成？ | 股票 60%、债券 20%、黄金 5%、现金 15%，与目标一致 |
| 企业持仓重叠？ | X 为 86.6 万韩元、约 7.87%，按 A 中 6% 与 B 中 10% 计算 |
| 汇率方面？ | 未对冲的美国股票部分约 50.91%，黄金 E 的结构待查 |
| 如果下跌？ | −203.5 万韩元，与自己所需资金对照 |
| 现金用在哪里？ | 165 万韩元分为下次投资 80 万、结算准备 50 万、调仓 35 万 |
| 本次判断及理由？ | 权重符合目标，无须追加交易，核对黄金 ETF 说明书 |
| 下次什么时候检查？ | 2026-11-01，资金情况变化时提前检查 |

如果自己的表里有不清楚的栏位，就记下**待核实项目与要查的资料**。

<Bbox>
可以先把本月总额、外部资金进出和现金用途核对好。
下次再补充企业重叠或汇率项目。
知道哪里还空着，也能帮助决定下一步。
</Bbox>

## 按顺序检查 PortRhythm

查看应用时，可以按这个顺序走一遍。

- **账户管理与持仓**
  检查遗漏账户、数量错误、重复现金和价格核对状态。
- **资产分配**
  检查是否放错篮子，是否还有未分类项目。
- **组合权重**
  按相同范围对比当前与目标。
- **资产记录**
  对照同一期间的估值变化和外部资金进出。

详细操作见[账户管理](https://www.promleeblog.com/blog/post/445-portrhythm-brokerage-account-guide)、[资产分配](https://www.promleeblog.com/blog/post/439-portrhythm-asset-assignment-guide)、[权重比较](https://www.promleeblog.com/blog/post/441-portrhythm-current-target-allocation-guide)和[资产记录指南](https://www.promleeblog.com/blog/post/443-portrhythm-asset-history-guide)。
将页面上核对的信息与计算结果、判断理由放在一起，就完成了月度报告。
<br/>
如果计划和数字相符，但还是因为新消息想交易，可以先用一句话记下理由。
“我要用钱的日期变了”和“今天的股价让我害怕”，是两种不同的变化。
记录能让你**回过头来读懂当时为什么那样判断**。

## 结语

最初只是把账户汇总起来。
现在可以用一张表说明钱在哪里、各有多少、涉及哪些企业和汇率、为什么增加，以及还有什么要核对。
每月的目标是**用同一标准重新检查相同的问题**。
<br/>
打开 [PortRhythm](https://pf.promleeblog.com/)，先记下本月总额和外部资金进出。
然后用一句话记下“这次做了什么，为什么这样做”。
如果没有交易，理由也值得记录。
