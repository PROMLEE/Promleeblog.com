## 开始之前

> “电脑上能看到资产，手机上却是空的。是不是没保存？”

第一次在另一台设备上登录，看到空白页面，很容易不知所措。
晚上打开应用，如果屏幕太亮，往往也会先找深色模式。
这时可以先到账号页面 `계정` 查看。

<br/>

[第 8 篇：资产记录](https://www.promleeblog.com/blog/post/443-portrhythm-asset-history-guide)介绍了如何记录估值和资金进出。
这次看看从哪个账号查看记录，以及界面设置保存在哪里。
重新录入资产前，有几个细节值得先核对。

<br/>

**资产数据与界面设置保存在不同位置。**
已保存的资产和投资组合设置关联到登录账号。
浅色和深色模式则保存在当前浏览器中。
因此，即使用同一个账号登录，手机和电脑的界面颜色也可能不同。

<Bbox>
如果在其他设备上看不到资产，先核对平时的登录方式和账号，再考虑重新登记。
本文截图来自本地 QA 账号。
实际账号可能显示登录服务提供的姓名和电子邮箱。
</Bbox>

## 1. 打开账号页面

在电脑端，点击左侧菜单的账号 `계정`。
也可通过侧栏底部的个人资料区域进入账号页面。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-desktop-account-20261009.webp" width={800} alt="电脑端我的账号页面，显示登录账号、界面模式、投资设置和使用说明"/>

我的账号 `내 계정` 集中了以下内容。

- 已登录账号  
确认当前查看的是谁的资产空间。
- 界面设置  
选择浅色或深色模式。
- 投资设置  
前往设置目标权重与再平衡标准的页面。
- 使用说明  
查看使用指南和数据管理说明。
- 退出登录与服务信息  
结束登录，或前往服务介绍和 GitHub。

### 1.1. 移动端菜单

在移动端，点击顶部个人资料按钮，或进入底部全部菜单 `전체`。
进入 `전체` 后，向下滚动，在记录和账号 `기록과 계정` 区域选择账号 `계정`。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-menu-20261009.webp" width={350} alt="移动端全部菜单中，记录和账号区域里的账号入口"/>

账号页面可从上往下查看。
先显示登录账号和界面设置，使用说明和退出登录位于下方。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-account-20261009.webp" width={350} alt="移动端我的账号页面，显示已登录账号以及浅色和深色模式选项"/>

## 2. 核对登录账号

在上方的已登录账号 `로그인한 계정` 中查看姓名。
如果登录方提供了电子邮箱，也会一起显示。
此处只展示当前登录信息，姓名和电子邮箱无法在这里编辑。

<br/>

例如，平常用 Kakao 的人这次改用 Naver 登录。
即使是同一个人，服务也**不会自动合并不同登录提供方的账号**。
需要核对平常所用的提供方，以及在该平台选中的账号。

<br/>

如果电脑上用 Kakao 账号 A 保存，就在手机上也用同一个 Kakao 账号 A 登录。
浏览器已登录其他社交账号时，可能选到不同的账号，请同时核对账号名称。

<Toggle title="名字相同就是同一个账号吗？">
只看显示名称，很难判断是否为同一个账号。
Kakao 和 Naver 上的姓名即使相同，登录提供方仍可能不同。
一起核对平时使用的提供方和实际社交账号。

<br/>

QA 截图中没有电子邮箱。
邮箱并非总会显示，单凭没有邮箱不能判断保存出错。
</Toggle>

### 2.1. 看不到资产时

按以下顺序核对，可以减少重复登记。

- 核对当前登录账号。  
检查是否与平常使用的 Kakao 或 Naver 账号一致。
- 回想之前是否已保存输入。  
输入值曾出现在页面上，并不表示保存已经完成。
- 核对连接状态和加载提示。  
查看是否仍在加载，或是否有连接错误提示。
- 回到原先使用的账号核对。  
若需切换账号，先处理未保存的修改，再退出并重新登录。

<br/>

*登录了不同账号*和*数据尚未加载*需要分开判断。
核对前就重复录入同一资产，之后回到原账号时可能更难理清。

## 3. 浅色和深色模式

在界面设置 `화면 설정` 的界面模式 `화면 모드` 中，选择浅色 `라이트` 或深色 `다크`。
也可以通过顶部的太阳或月亮图标切换。
账号页面和顶部按钮控制的是同一个界面模式。

<br/>

选择后立即生效。
界面模式无需像资产录入一样另按保存。
如页面所示，它会**保存在当前浏览器中**。
即使在其他设备或浏览器登录同一个账号，界面模式也不会自动同步。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-storage-boundaries-20261009.webp" width={800} alt="保存位置对照：资产和组合设置关联到登录账号，界面模式保存在当前浏览器，当前页面和所选资产反映在页面地址中"/>

### 3.1. 保存位置的差异

| 项目 | 保存依据 | 在其他设备上如何核对 |
| --- | --- | --- |
| 已保存的资产与组合设置 | 登录账号 | 登录同一个账号 |
| 浅色或深色模式 | 当前浏览器 | 在该浏览器中选择 |
| 当前页面与所选资产 | 页面地址 | 打开相同的页面地址 |
| 未保存的输入 | 保存前的状态 | 先确认已经保存 |

切换深色模式不会改变持仓数量或目标权重。
清除浏览器设置也不会连带删除账号中已保存的资产。
根据删除浏览器数据的范围，界面设置或登录状态可能会变化。

<Toggle title="为什么新浏览器的界面又变亮了？">
界面模式按浏览器分别保存。
新的浏览器或独立的浏览器配置文件中，可能没有之前的选择。
在对应浏览器重新选用所需模式即可。
这种情况本身与资产保存状态无关。
</Toggle>

## 4. 目标设置和使用指南

账号页面的投资设置 `투자 설정` 包含目标权重与再平衡标准 `목표 비중과 리밸런싱 기준`。
点击后前往目标设计 `목표 설계`。
权重是在跳转后的页面输入的。

<br/>

可以通过这条路径修改目标权重和容许偏差。
具体输入方法见[第 2 篇：设置目标投资组合和投资权重](https://www.promleeblog.com/blog/post/437-portrhythm-portfolio-setup-guide)。

### 4.1. 使用指南

在使用说明 `이용 안내` 中点击使用指南 `사용 가이드`。
指南包括入门步骤、交易后修改资产、再平衡以及常见问题。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-desktop-guide-20261009.webp" width={800} alt="电脑端使用指南的介绍，以及入门步骤、修改资产、再平衡和常见问题目录"/>

指南中的目标设计 `목표 설계`、股票登记 `주식 등록`、资产分配 `자산 배정`、组合权重 `포트 비중` 和再平衡 `리밸런싱` 按钮会前往相应页面。
初次使用可按指南顺序操作，熟悉后可以直接点击需要的功能。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-guide-20261009.webp" width={350} alt="移动端使用指南的介绍和入门步骤目录"/>

<br/>

在移动端，可点目录或向下滚动，找到需要的说明。
指南所列权重用于举例。自己的组合构成和目标权重，可在目标设计中查看。

## 5. 数据管理说明

点击“我的数据如何管理？” `내 데이터는 어떻게 관리되나요?`，会展开三项说明。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-desktop-data-20261009.webp" width={800} alt="电脑端账号页面展开的资产保存、余额截图处理和持仓数量管理说明"/>

### 5.1. 保存在账号中的资产

登记的资产和投资组合设置保存在登录账号中。
重新登录同一账号后，即可查看已保存的内容。
关键在于**内容已经保存**。
尚未保存的输入无法在不同设备间延续。

### 5.2. 余额截图的处理

应用在浏览器中分析余额截图，不会把截图原件上传或保存到应用服务器。
核对识别结果后保存的证券信息会保留在账号里。
*截图原件的处理*与*已登记资产信息的保存*有各自的规则。

<br/>

如何在保存前核对证券代码、数量和买入价，可参阅[第 3 篇：资产登记](https://www.promleeblog.com/blog/post/438-portrhythm-asset-registration-guide)。
如果识别有误，需要手动核对待保存的值，系统不会自动重新分析原件来修正。

### 5.3. 手动管理持仓数量

查询行情和同步账户余额是两项不同的操作。
价格更新后，实际交易带来的持仓数量和买入价变化仍需手动修改。
现金也要按实际余额调整。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-data-20261009.webp" width={350} alt="移动端展开的说明，涵盖保存到登录账号、不保留截图原件和手动维护数量"/>

<Bbox>
例如，从 10 股中卖出 2 股，就把持仓改为实际剩余的 8 股。
仅更新行情不会把持仓数量改为 8 股。
卖出后也要核对实际现金余额，并保存改动。
</Bbox>

## 6. 页面跳转和刷新

切换页面后，页面地址会反映当前所在页面。
刷新账号页面会回到同一页面，也可通过浏览器的后退和前进按钮切换。
在资产详情页，所选资产也会反映在地址中。

<br/>

保存输入仍要使用相应的保存功能。
**记住页面位置与保存输入内容是两回事。**
修改目标或资产信息后，先确认已保存，再刷新或切换设备。

<Ybox>
如果连接异常而要刷新，请先查看是否有未保存的改动。
刷新后即使回到同一页面，未保存的输入也不会原样恢复。
</Ybox>

<Toggle title="把页面地址发给别人，对方也能看到我的资产吗？">
分享页面地址不会共享账号下的资产，也不会把自己的登录权限交给对方。
页面地址与账号中的数据分别处理。

<br/>

如果需要分享，先确定想展示什么。
检查详情地址中是否包含不必发送的资产标识，以及截图中是否含有账户信息。
</Toggle>

## 7. 退出和重新登录

账号页面底部有退出登录 `로그아웃`。
点击后结束当前浏览器的登录会话，并返回初始页面。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-service-20261009.webp" width={350} alt="移动端账号页面下方的退出登录按钮，以及服务介绍、GitHub 仓库和缺陷反馈链接"/>

**退出登录后，账号中已保存的资产仍然保留。**
要重新查看，请选择平常使用的登录提供方和账号。
退出操作针对当前浏览器，其他浏览器或设备上的会话可能仍在。

<br/>

使用完毕前先确认保存状态。
尤其在多人共用的浏览器中，用完后建议关闭自己的资产页面。
这个页面没有单独的注销账号或删除全部资产按钮。

<Toggle title="回到手机上时看到连接错误怎么办？">
如果页面提供重试提示，请先核对连接状态，再按提示操作。
临时网络问题与登录会话结束是两种情况。

<br/>

如果页面要求重新登录，请用原来的账号登录。
切换登录提供方或重复登记资产无法解决连接问题。
</Toggle>

## 8. 服务信息和反馈

退出登录下方有服务信息 `서비스 정보`。
三个链接各有用途。

| 链接 | 用途 |
| --- | --- |
| 服务介绍 | 了解 PortRhythm 的用途和主要功能 |
| GitHub 仓库 | 查看项目代码和文档 |
| 缺陷反馈与功能建议 | 在公开 Issues 中提交问题或建议 |

服务介绍 `서비스 소개` 会打开无需登录即可查看的介绍页。
GitHub 链接在新标签页中打开。
发布 Issue 需要登录 GitHub。

### 8.1. 如何描述问题

写清在哪个页面、经过哪些步骤出现问题，比只说“用不了”更容易核查。

- 使用环境  
注明电脑端还是移动端，以及浏览器名称。
- 页面与操作  
例如，写下从账号进入使用指南等点击顺序。
- 预期结果与实际结果  
说明本来预期打开什么页面，以及实际看到什么。
- 提示文字  
如果出现错误提示，只摘录必要部分。

<Ybox>
GitHub Issues 公开可见。
请在截图和正文中遮盖或删去无需公开的账号号码、电子邮箱和持仓金额等信息。
不要把密码或 API 密钥写进问题描述。
直接上传到 GitHub 的图片不适用应用内的余额截图处理方式。
</Ybox>

<br/>

例如，可以这样写。

> 在移动版 Safari 中，我依次点击了全部、账号、使用指南。
> 我预期会打开指南，但页面仍停在上一个界面。
> 重新访问后，按相同步骤仍会出现。

这是反馈写法示例，并未确认存在这一故障。
