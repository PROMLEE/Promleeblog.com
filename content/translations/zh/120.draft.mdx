## 开始之前
### 什么是Node.js
>Node.js is an open-source and cross-platform JavaScript runtime environment. It is a popular tool for almost any kind of project!
>Node.js是一个开源、跨平台的JavaScript运行时，广泛用于各种项目。

[Node.js](https://nodejs.org/en/learn/getting-started/introduction-to-nodejs)
JavaScript通常在浏览器中运行，Node.js则提供了让它在服务器端运行的环境。
使用React、Angular和Vue.js等框架时，它也是常用基础工具。
此外，还可以通过npm包管理器安装和管理各种库。
### 什么是npm
>npm is the world's largest Software Registry. Open source developers from every continent use npm to share and borrow packages, and many organizations use npm to manage private development as well.
>npm是全球最大的软件注册中心。世界各地的开源开发者通过它共享和使用软件包，许多组织也用它管理私有开发。

[NPM](https://docs.npmjs.com/about-npm)
npm是安装Node.js时自动安装的包管理器，用于安装和管理各种库。

### 什么是NVM
>Node Version Manager - Simple bash script to manage multiple active node.js versions
>NVM是用于管理多个Node.js版本的简单Bash脚本。

[NVM](https://github.com/nvm-sh/nvm)
它用于管理Node.js版本。
同时开发多个项目时，每个项目可能要求不同的Node.js版本。
这时使用NVM，就能方便地切换和管理。

### 在macOS上安装Node.js
[Node.js](https://nodejs.org/ko/)
在macOS上，也可以从Node.js官网下载安装程序。
不过，为了使用版本管理功能，这里介绍先安装NVM，再安装Node.js的方式。
#### 安装Homebrew
为方便安装NVM，先准备Homebrew。
请参考以下链接安装后再继续。
[在macOS上安装Homebrew](/blog/post/119-homebrew)
## 安装NVM
打开终端，执行以下命令。
```bash
brew install nvm
```
<Img src="/posts/240831-161255.png" width={500} alt=""/>

### 配置环境变量
在终端中执行以下命令，设置使用NVM所需的环境变量。
```bash
echo '[ -s "/opt/homebrew/opt/nvm/nvm.sh" ] && . "/opt/homebrew/opt/nvm/nvm.sh"' >> ~/.zshrc
echo '[ -s "/opt/homebrew/opt/nvm/etc/bash_completion.d/nvm" ] && . "/opt/homebrew/opt/nvm/etc/bash_completion.d/nvm"' >> ~/.zshrc
source ~/.zshrc
```
完成后，执行以下命令，确认nvm是否可用。
```bash
nvm --version
```
## 安装Node.js
执行以下命令，安装Node.js的LTS，也就是最新稳定版本。
```bash
nvm install --lts
```
安装完成后，检查Node.js和npm版本。
```bash
node -v
npm -v
```

## NVM命令
- nvm install [version]：安装指定版本Node.js。
- nvm use [version]：使用指定版本。
- nvm ls：列出已安装版本。
- nvm ls-remote：列出可安装版本。
- nvm uninstall [version]：移除指定版本。
- nvm alias default [version]：设置默认版本。
- nvm alias [name] [version]：为指定版本设置别名。
