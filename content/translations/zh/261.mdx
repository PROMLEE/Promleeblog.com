## 算法分类
数学、字符串、贪心算法、解析。

## 题目说明
给定一个由正整数和`+`、`-`运算符组成的表达式，编写程序，通过适当添加括号，使表达式的值最小。

### 输入
第一行给出表达式。表达式由大于等于`1`、小于等于`1000000`的正整数和`+`、`-`运算符组成，至少包含一个运算符。表达式长度最多为`50`。
```txt
50-50+40-30+20-10
```
### 输出
输出测试表达式可以得到的最小值。
50-(50+40)-(30+20)-10 = 50 - 50 - 40 - 30 - 20 - 10 = -100
```txt
-100
```

<Img src="/250506-185802.webp" width={300} alt="题目说明"/>

## 解题思路
1. 以表达式中的`-`分隔，得到各个部分。
2. 第一个部分直接相加。
3. 之后的每个部分都视为被括号包围，再按+拆开、求和，最后减去该和。
4. 输出所有部分计算后的结果。

<Ads1 />

## Python代码
```python
expression = input().strip()

  # 1. '-'를 기준으로 먼저 나눈다.
parts = expression.split('-')

  # 2. 첫 번째 덩어리는 무조건 더한다.
total = sum(map(int, parts[0].split('+')))

  # 3. 그 이후 덩어리는 모두 괄호로 묶인다고 생각하고 각각 +로 쪼개서 합산한 뒤 빼기
for part in parts[1:]:
    total -= sum(map(int, part.split('+')))

print(total)
```
### 炫技写法
<Rbox>请不要模仿，不要这样编写代码。</Rbox>
```python
line = input().strip().split("-")
answer = sum(list(map(int, line[0].split("+"))))
print(answer if len(line) <= 1 else answer - sum([list(map(int, s.split("-")))[0] for s in "+".join(line[1:]).split("+")]))

```
## 核心要点
把减号之后的数全部用括号组织起来、一起减去，就能得到最小值。
- +只影响括号内部。
- -成为括号的起点。
- 可以把第一个-之后的全部内容视为放在括号中处理。

### 时间复杂度
- split('-')：O(N)。
- 对各个部分执行split('+')：合计O(N)。
- 对每个数字执行int()转换：O(N)。
- 计算总和：O(N)。

最终时间复杂度：O(N)。
