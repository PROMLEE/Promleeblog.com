## アルゴリズム分類
グラフ理論、グラフ探索、幅優先探索（BFS）

## 問題の説明
100マスの盤面でサイコロを振って進む、典型的な蛇と梯子のゲームです。サイコロの目は1から6までです。
1番のマスから100番のマスへ進むのに必要な、サイコロを振る最小回数を求めます。
<Img src="/250505-185431.webp" width={300} alt="蛇と梯子ゲーム"/>
### 入力
- 1行目に梯子の数N（1 ≤ N ≤ 15）と蛇の数M（1 ≤ M ≤ 15）が与えられます。
- 2行目からN + 1行目まで、梯子の開始位置と終了位置が与えられます（1 ≤ 開始 < 終了 ≤ 100）。
- N + 2行目からN + M + 1行目まで、蛇の開始位置と終了位置が与えられます（1 ≤ 開始 < 終了 ≤ 100）。
### 出力
1番から100番のマスへ進むのに必要な、サイコロを振る最小回数を出力します。

## 解き方
0. 蛇や梯子の開始位置をキー、移動先を値とする辞書を作ります。
1. 100マス分の一次元配列を作り、各マスへ到達する最小のサイコロ回数を保存します。初期値は99にします。
2. 1番からサイコロを1〜6まで振り、移動可能なマスに現在の回数+1を記録します。
3. 値が更新されたら、そのマスをキューに追加します。
4. キューから次のマスを取り出し、同じように1〜6マス先への移動を調べます。
5. キューが空になるまで繰り返します。
6. 最後に100番のマスへのサイコロ回数を出力します。

## コード — Python
```python
import sys
from collections import deque

N, M = list(map(int, sys.stdin.readline().split()))
arr = [99] * 101 # 1부터 100까지의 칸을 저장하는 배열, 기본값은 99로 설정
snakes = {} # 사다리와 뱀의 위치를 저장하는 딕셔너리

for _ in range(N + M):
  a, b = list(map(int, sys.stdin.readline().split()))
  snakes[a] = b # 사다리와 뱀의 시작 위치를 key로, 끝 위치를 value로 저장

arr[1] = 0
dq = deque([1]) # 큐에 1번 칸을 추가

while dq:
  x = dq.pop() # 큐에서 꺼낸 칸
  for i in range(1, 7): # 1부터 6까지의 주사위를 굴려서 이동할 수 있는 칸을 확인
    if x + i > 100: # 100번 칸을 넘어가면 무시
      continue
    elif x + i in snakes.keys(): # 사다리와 뱀의 위치를 확인
      if arr[x] + 1 < arr[snakes[x+i]]: # 값이 업데이트되는 경우
        arr[snakes[x+i]] = arr[x] + 1
        dq.append(snakes[x+i]) # 업데이트된 칸을 큐에 추가
    else: # 사다리와 뱀의 위치가 아닌 경우
      if arr[x] + 1 < arr[x + i]: # 값이 업데이트되는 경우
        arr[x + i] = arr[x] + 1
        dq.append(x + i) # 업데이트된 칸을 큐에 추가

print(arr[-1]) # 마지막 칸(100번 칸)의 주사위 굴리기 횟수를 출력
```

## 要点
- BFSを使い、1番から100番までの最短経路を探します。
- 蛇と梯子の位置は辞書で管理すると、移動先を簡単に確認できます。
- キューを使ってBFSを実装します。
