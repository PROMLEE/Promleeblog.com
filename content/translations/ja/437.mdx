[第1回](https://www.promleeblog.com/blog/post/436-portrhythm-asset-allocation-rebalancing)で、目標比率の考え方を学びました。
今回は、その基準を**PortRhythmの画面に入力します。**
ログインからポート名、目標比率、許容誤差、為替設定、保存まで、画面を一つずつ進めると、最初の投資計画ができます。

<br/>

<Bbox>
今回の目標は、目標設計を保存することです。株式や暗号資産の登録は次の第3回で行います。
</Bbox>

<br/>

アプリと記事を並べて開き、一つずつ進めてください。
[PortRhythmを開く](https://pf.promleeblog.com)

<br/>

## ポートと資産を区別する

ポートは資産を入れる**管理用のかご**です。
資産は、その中に入れる株式、ETF、暗号資産、現金などです。

| アプリで指定する項目 | 意味 | 例 |
| --- | --- | --- |
| ポートフォリオ名 | 投資計画全体の名前 | 私の投資計画 |
| ポート名 | 資産をまとめて管理するかごの名前 | 管理用のかごA |
| 目標比率 | 全体からそのかごに配分する割合 | 50% |
| 保有資産 | 実際に保有する資産と数量・金額 | 株式10株、現金50万ウォン |

「現金」というポートを作っただけでは、現金50万ウォンは登録されません。
ここでは**かごと配分基準を作ります。**

<br/>

この記事では、次の三つのかごを使って入力を練習します。

| ポート名 | 目標比率 |
| --- | ---: |
| 管理用のかごA | 50% |
| 管理用のかごB | 30% |
| 管理用のかごC | 20% |
| 合計 | 100% |

*操作を説明するための例です。名前と比率は自分の投資計画に合わせて変更します。*
画像内の銘柄、比率、評価額は、投資の推奨や実際の運用成果を示すものではありません。

<br/>

## 1. ログインとメニューの移動

### 1.1 ログイン画面

[PortRhythm](https://pf.promleeblog.com)を開くと、ソーシャルログインのボタンが表示されます。

<Img src="/portrhythm-setup-login-20261008.webp" width={800} alt="KakaoまたはNaverのアカウントで始めるログイン画面"/>

- **Kakaoで続ける**
  Kakaoアカウントで認証し、PortRhythmに入ります。
- **Naverで続ける**
  Naverアカウントで認証し、PortRhythmに入ります。

今後も使うアカウントでログインしてください。
保存したポートフォリオは、ログインしたアカウントに基づいて読み込まれます。

<Ybox>
KakaoとNaverのアカウントは自動で統合されません。以前の保存内容が表示されない場合は、最初に使ったログイン方法とアカウントを確認してください。
</Ybox>

ログイン前に機能を確認するなら、[サービス紹介](https://pf.promleeblog.com/about)や[利用ガイド](https://pf.promleeblog.com/guide)を開けます。

<br/>

### 1.2 目標設計

#### PCで目標設計を開く

左のメニューで**ポートフォリオ → 目標設計**を押します。
画面のタイトルが「目標設計」になっていることを確認してください。
計画を保存済みなら、既存のポートが表示されます。
まだ計画がなければ、以下で説明する初期構成の選択画面が表示される場合があります。

<br/>

#### モバイルで目標設計を開く

下部の**すべて**タブを押します。
メニューから**目標設計**を選びます。

<Img src="/portrhythm-setup-mobile-menu-20261008.webp" width={350} alt="モバイルのすべてのメニューから目標設計を開く手順"/>

モバイルの**構成比**タブでは、現在と目標を比較します。
名前や目標値を変更するには、「目標設計」を開きます。

<Toggle title="メニュー名の違いが分かりにくいとき">
- **目標設計**
  ポート名、色、目標比率、許容誤差を設定します。
- **資産割り当て**
  登録した資産をどのポートに入れるかを決めます。
- **ポート構成比**
  現在比率と目標比率を比較します。

**かごを作る → 資産を入れる → 比較する**と覚えると区別しやすくなります。
</Toggle>

## 2. 最初の構成を選ぶ

保存済みのポートフォリオがない場合は、自分の投資方針を先に決めるよう案内が出ます。
二つのボタンから一つを選びます。

| ボタン | 選択後の構成 | 適した場面 |
| --- | --- | --- |
| サンプル構成で始める | 複数のサンプルポート、目標比率、銘柄の割り当てルール | アプリの構成を見てから変更したい |
| 空のポートで始める | 「新しいポート」というかご一つ、目標100% | 自分の分類を最初から作りたい |

<br/>

### 2.1 サンプル構成

米国株指数、韓国株指数、優良株、金、ビットコインなどのサンプルポートが作られます。
名前、色、比率は変更できます。
サンプル構成には、銘柄コードに基づく割り当てルールも含まれます。
資産を登録したら、資産割り当て画面で、実際の資産が意図したポートに入ったかを確認してください。
保有資産は別途登録します。

<br/>

### 2.2 空のポート

最初は、「新しいポート」が一つ、目標100%で作られます。
入力例を試すなら、名前を「管理用のかごA」に変え、ポートを二つ追加します。
詳しい入力方法は次の節で説明します。

<Ybox>
初期構成を選んだだけではアカウントに保存されません。入力後に「変更を保存」を押します。
</Ybox>

計画を保存済みのアカウントでは、この選択画面が表示されない場合があります。
その場合は、既存の目標設計を編集します。
現在は、一つのアカウントで複数の投資戦略を個別に作り、切り替える機能はありません。

## 3. 目標設計でポートを編集する

ここで、かごに名前を付け、比率を入力します。
まず画面の各項目の位置を確認します。

<Img src="/portrhythm-allocation-strategy-20261008.webp" width={800} alt="ポート名、目標比率、許容誤差を編集する目標設計画面"/>

**モバイルでは次のように表示されます。**

<Img src="/portrhythm-setup-mobile-strategy-20261008.webp" width={350} alt="モバイルの目標設計画面にある許容誤差、ポート名、目標比率の入力欄"/>

モバイルでも、設定項目は同じです。
各ポートの名前と目標値は同じ行にあり、現在比率のバーと目標との差はその下に表示されます。
ポートが多ければ、下にスクロールして残りの行と目標の合計を確認してください。
下部の固定メニューは画面の移動に使います。
目標値の入力欄と保存ボタンは、別の場所にあります。

| 位置 | 項目 | 用途 |
| --- | --- | --- |
| 画面上部 | 変更を保存／保存済み | アカウントに変更を保存し、保存状態を確認 |
| 目標比率編集欄の右 | ポートを追加 | 管理用のかごを追加 |
| 編集欄の上 | リバランス許容誤差 | 比率の差を検討する基準を設定 |
| ポート行の左 | 色と名前 | グラフの色と分類名を変更 |
| ポート行の中央 | バー、現在比率、差、金額 | 登録資産の現在の状態を確認 |
| ポート行の右 | 目標値と削除アイコン | 目標比率の入力、ポートの削除 |
| ポート一覧の下 | 目標の合計 | 全体で100%かを確認 |

<br/>

### 3.1 ポートを追加し、名前を入力する

画面右の**ポートを追加**を押します。
一覧の下に、「新しいポート」という名前で目標0%の行ができます。

<Img src="/portrhythm-setup-add-port-20261008.webp" width={800} alt="ポートを追加すると、一覧の下に新しいポートと目標0%の行が表示される画面"/>

新しい行の名前欄を押し、使う名前を入力します。
追加したポートには、それぞれ見分けられる名前を付けてください。

- 名前が空欄だと保存できません。
- 前後の空白を除いたときに、同じ名前が重複しないようにします。
- ポート名は60文字以内です。
- ポートは1個以上、最大20個まで管理できます。

<br/>

練習では、三つの行の名前を次のように変更します。

- 管理用のかごA
- 管理用のかごB
- 管理用のかごC

実際に使う場合は、「長期投資」や「現金」など、自分が見分けられる名前を付けます。
ポート名だけを変更しても、資産の市場や銘柄コードは変わりません。

<br/>

### 3.2 ポートの色を選ぶ

名前の左にある小さな色の欄を押します。
端末とブラウザーが提供するカラーピッカーで色を選びます。
色は、グラフ上でポートを見分けるための表示です。
色を変えても、目標比率や保有数量は変わりません。
似た色ばかりでは、グラフで見分けにくくなります。
よく比較するポートには、はっきり異なる色を使ってみてください。

<br/>

### 3.3 目標比率を入力する

各ポートの右にある**目標**の数値欄を変更します。
横に `%` が表示されるので、数字だけを入力します。

| 目標比率 | 入力する数値 |
| --- | ---: |
| 50% | 50 |
| 30% | 30 |
| 20% | 20 |
| 12.5% | 12.5 |

**50%にしたい場合に0.5を入力すると、目標は0.5%になります。**
50を入力します。
入力範囲は0〜100%で、0.1刻みで調整できます。
小数を使う場合も、全体の合計を100%にします。

<br/>

### 3.4 目標の合計を確認する

一覧の下にある**目標の合計**を確認します。

| 入力の状態 | 合計 | 確認・修正すること |
| --- | ---: | --- |
| A 50／B 30／C 20 | 100% | 合計の条件を満たす |
| A 50／B 30／C 10 | 90% | 残りの10%をどのポートに配分するか決める |
| A 100／B 30／C 20 | 150% | 最初のポートの100%を含め、各比率を調整する |

100%になると「保存できます」（`저장할 수 있습니다.`）と表示されます。
100%でなければ、合計をそろえるよう案内されます。

<Bbox>
新しく追加したポートに、アプリが自動で目標比率を配分することはありません。かごを追加したら、既存のかごの目標も確認してください。
</Bbox>

目標の合計100%（`목표 합계 100%`）は、比率の条件を満たしたという意味です。
名前の重複やほかの入力エラーが残っている場合もあるので、最後に保存結果を確認します。

<br/>

### 3.5 現在比率と目標

ポート行の中央には、現在比率、目標との差、評価額が表示されます。
例えば「現在28%・目標との差+8ポイント」なら、目標20%を8ポイント上回っています。
差がマイナスなら、目標を下回っています。
ここで目標値を編集すると、比較基準が変わります。

<br/>

### 3.6 ポートを削除する

行の右にあるごみ箱アイコンを押すと、編集一覧からポートが外れます。
最後に残った一つのポートは削除できません。
すでに資産をひも付けている場合は、削除前に関連する設定を確認します。

- そのポートにひも付く銘柄の割り当てルールも削除されます。
- 手動の割り当てと、暗号資産やその他の資産とのひも付けが解除されます。
- 保有資産そのものが売却されたり消えたりすることはありません。
- 保存後に資産割り当てを開き、削除したポートに属していた資産の割り当てを確認します。

<Ybox>
名前だけを変更する場合は、既存の名前欄を編集してください。削除して作り直すと、既存のひも付けも確認し直す必要があります。
</Ybox>

削除したポートに目標比率があった場合は、合計も減ります。
残ったポートの目標を調整してから保存します。

<Ads2/>

## 4. 許容誤差を設定する

同じ目標設計画面の上部にある**リバランス許容誤差**を確認します。
入力欄の両側に `±` と `%p` が表示されます。
この値は、全ポートに共通して適用する比率差の基準です。
ポートごとに個別の許容誤差を指定する方式ではありません。

<br/>

目標20%、許容誤差5ポイントを例に見てみます。

| 現在比率 | 目標との差 | 判定 |
| --- | ---: | --- |
| 15% | −5ポイント | 境界値。範囲内 |
| 20% | 0ポイント | 目標と同じ |
| 25% | +5ポイント | 境界値。範囲内 |
| 26% | +6ポイント | 範囲外。調整を検討 |

許容範囲は15〜25%です。
差の大きさが5ポイントを**超えた場合**に、調整対象として検討します。

<br/>

許容誤差を5ポイントに設定するには、数字の**5**を入力します。
`±` や `%p` は入力しません。
入力範囲は0〜30ポイントで、0.1刻みで調整できます。

<Toggle title="5%と5ポイントの違いが分かりにくい場合">
20%から25%に変わると、差は**5ポイント**です。
一方、「20%の5%」は20 × 0.05＝1なので、**1ポイント**です。
PortRhythmの許容誤差は、前者の意味で使います。
</Toggle>

許容誤差を超えたという表示は、検討を始める目安です。
実際に売買するかは、資産情報と投資計画を確認してから決めます。

<br/>

## 5. 為替とその他の設定を開く

目標設計で**為替・その他の設定**を押します。
同じ画面内に追加の入力欄が開きます。

<Img src="/portrhythm-setup-settings-auto-20261008.webp" width={800} alt="為替・その他の設定を開くと表示されるポートフォリオ名と為替レートの入力欄"/>

**モバイルでは、名前欄の下に為替レートの設定項目が並びます。**

<Img src="/portrhythm-setup-mobile-settings-20261008.webp" width={350} alt="モバイルで開いた為替・その他の設定にある名前と為替レートの入力欄"/>

まずポートフォリオ名を確認し、その下の為替レートの適用方式とUSD → KRWの数値欄を確認します。
欄を開くと、ポート一覧が下に移動します。
設定後は、見出しをもう一度押して閉じられます。
ここには三つの項目があります。

| 項目 | 設定すること |
| --- | --- |
| ポートフォリオ名 | 投資計画全体の名前 |
| 為替レートの適用方式 | 自動または手入力 |
| USD → KRWの為替レート | 1ドルを何ウォンと評価するか |

<br/>

### 5.1 ポートフォリオ名を入力する

例えば「私の投資計画」のように、全体の計画に付ける名前を入力します。
先ほどポートの行に入力した「管理用のかごA」とは別の項目です。
**ポートフォリオ名は全体のタイトル、ポート名は個々のかごの名前です。**
名前は空欄にせず、80文字以内で入力します。
タイトルを変更しても、新しい戦略が別に作られるわけではありません。

<br/>

### 5.2 自動の為替レートを選ぶ

為替レートの適用方式で**自動・ECBの日次参照レート**を選びます。
USD → KRWの数値欄は手動編集できなくなります。
アプリはECBの日次参照レートをもとに、ドル資産をウォンで評価します。
証券会社のリアルタイムの両替レートや実際の両替額とは異なる場合があります。

<br/>

自動取得を待っている間や、取得に失敗した場合は、最後に保存したレートを表示することがあります。
レートが表示されたら、ダッシュボードの**価格・為替の基準を見る**も開き、取得状況を確認してください。

<Toggle title="自動の為替レートはどのくらいの頻度で確認しますか？">
自動モードでは、アプリは1時間に1回まで、為替レートを取得するかどうかを確認します。
データ自体はECBの日次参照レートです。
すべてのリアルタイム両替レートを1時間ごとに取得する機能ではありません。
取得に失敗すると、最後に保存したレートを適用する旨が表示される場合があります。
</Toggle>

<br/>

### 5.3 為替レートを手入力する

同じメニューで**手入力**を選びます。
これで、USD → KRWの数値欄を編集できます。

<Img src="/portrhythm-setup-settings-manual-20261008.webp" width={800} alt="手入力を選ぶと、1ドルあたりのウォン換算レートを編集できる画面"/>

1ドルを1,350ウォンで評価するなら、**1350**を入力します。
`1,350원` のような通貨単位付きの文字列や、ドルの保有額は入力しません。

| 設定するレート | 入力値 |
| --- | ---: |
| 1ドル＝1,350ウォン | 1350 |
| 1ドル＝1,350.50ウォン | 1350.50 |

保存できるレートは100〜100,000ウォンです。
実際に使う基準値を確認して入力し、保存してください。

<br/>

### 5.4 為替レートを変えると

米国株と、ドルで登録した手入力資産の**ウォン換算評価額**に反映されます。
ウォン換算の総評価額が変わるため、現在のポート構成比も変わる場合があります。
例えば100ドルは、1ドル＝1,300ウォンなら13万ウォン、1,400ウォンなら14万ウォンと評価されます。
ドルの保有額は同じでも、ウォン換算額は変わります。

<Gbox>
**為替レートの変更は評価基準を変える操作です。** 実際の両替や注文は行いません。
</Gbox>

自動モードから数値を直接変更したい場合は、先に手入力へ切り替えます。
自動モードでは、数値欄はロックされています。

<Ads3/>

## 6. 保存と結果の確認

名前と数値を入力したら、最後に保存します。
編集内容を反映するには、**保存ボタンを押します。**

### 6.1 保存前の確認

- **ポート名**
  空欄や重複がないか確認します。
- **目標の合計**
  全ポートの目標を足して100%か確認します。
- **許容誤差**
  意図したパーセントポイントになっているか確認します。
- **ポートフォリオ名と為替レート**
  タイトルが入力され、為替レートの方式と数値が合っているか確認します。
- **既存資産とのひも付け**
  ポートを削除した場合は、資産割り当てへの影響を確認します。

<br/>

### 6.2 変更を保存する

**モバイルの保存ボタンは、タイトルの下にあります。**

<Img src="/portrhythm-setup-mobile-save-20261008.webp" width={350} alt="モバイルの目標設計タイトルの下にある価格更新と変更を保存するボタン"/>

「価格を更新」の右にある「変更を保存」を押します。
下にあるポートを編集した場合は、上に戻って保存ボタンを確認してください。
キーボードに隠れていれば、入力後にキーボードを閉じます。

<br/>

目標設計上部の「変更を保存」を押します。
処理中は**保存中**と表示されます。
成功すると、ボタンの代わりに**保存済み**が表示されます。
ポートフォリオと今日の評価額を保存したという案内も確認します。
保存時に、その日の評価額の記録も更新される場合があります。
この操作で注文や売買が実行されることはありません。

<br/>

### 6.3 保存できたか確認する

保存が成功したら、目標設計を開き直すか、再読み込みします。
入力した名前、目標比率、許容誤差、為替レートの方式が維持されているか確認してください。
何度入力しても結果が安定しない場合は、同じアカウントでログインしているかも確認します。

<Ybox>
再読み込みは、保存が成功したことを確認してから行ってください。未保存の入力は再読み込み後に残りません。
</Ybox>

画面の移動やメニューの開閉では、編集内容は保存されません。
設定を追加で変更したら、もう一度「変更を保存」を押します。

<br/>

## 一連の操作を練習する

操作の流れを一度に試したい場合は、次の順番で進めてください。
*比率と為替レートは入力練習用です。投資の推奨や現在の市場レートを示すものではありません。*

- **1. 目標設計を開く**
  初めて使うアカウントなら、「空のポートで始める」を選びます。
- **2. かごの名前を入力する**
  最初のポートを「管理用のかごA」に変更し、「ポートを追加」を2回押してBとCを作ります。
- **3. 目標値を入力する**
  Aに50、Bに30、Cに20を入力し、合計が100%であることを確認します。
- **4. 許容誤差を確認する**
  練習用に5を入力すると、基準は±5ポイントです。
- **5. 全体の名前と為替レートを確認する**
  「為替・その他の設定」を開き、全体のタイトルを入力し、自動または手入力を選びます。
- **6. 保存を確認する**
  「変更を保存」を押し、「保存済み」と表示されたか確認します。

<br/>

ここまでで、かごと配分基準の準備ができました。
この時点で、現在比率が目標と一致する必要はありません。
**保有資産をまだ入れていなければ、現在比率は次の段階で反映されます。**

<br/>

## 入力で困ったとき

初めて使うときに迷いやすい場面をまとめました。
必要な項目を開いて確認してください。

<Toggle title="変更を保存するボタンが表示されません">
保存済みで、新しく変更した項目がなければ、「保存済み」と表示されます。
ポート名や目標比率などを変更すると、保存ボタンが表示されます。
まだ最初の計画を作っていない場合は、開始時の画面でサンプル構成か空のポートを選んだか確認します。
</Toggle>

<Toggle title="合計が100%ですが、保存できません">
目標の合計以外の入力も確認します。

- ポート名に空欄や重複がないか確認します。
- ポート名60文字、ポートフォリオ名80文字の制限を確認します。
- 目標0〜100%、許容誤差0〜30ポイントの範囲を確認します。
- 手入力の為替レートが数値で、100〜100,000ウォンの範囲にあるか確認します。
- 画面に表示された保存エラーの案内を確認します。

インターネット接続やログイン状態に問題がある場合は、入力内容を控えてから状態を確認してください。
保存に成功する前に再読み込みすると、編集内容が消える場合があります。
</Toggle>

<Toggle title="ポートを追加しても、新しいポートという名前のままです">
「新しいポート」は既定の名前です。
それぞれの名前欄を編集します。
複数のポートを同じ名前にすると、名前の重複で保存できない場合があります。
すでに20個ある場合は、追加できません。
管理に必要な分類を整理して使います。
</Toggle>

<Toggle title="目標を30%に変更しましたが、現在は0%のままです">
目標は計画値で、現在比率は登録した資産の評価額から計算します。
目標だけを入力しても、資産は追加されません。
そのポートに資産を登録し、割り当てたか確認してください。
登録済みなら、価格や割り当ての状態を調べます。
</Toggle>

<Toggle title="ポートを削除したら資産の割り当てが変わりました">
削除したポートとのひも付けが解除され、関連する銘柄の割り当てルールも削除されます。
実際の保有銘柄が売却されるわけではありません。
残ったポートの目標の合計を100%にそろえて保存し、資産割り当て画面で対象資産の割り当てを確認します。
</Toggle>

<Toggle title="以前保存したポートフォリオが表示されません">
最初に使ったソーシャルログインサービスとアカウントでログインしたか確認します。
Kakaoで保存してNaverで入った場合、同じデータには自動でつながりません。
保存せずにアプリを閉じたり、再読み込みしたりしなかったかも確認します。
アカウントと保存状態を確認しても問題が続く場合は、画面に表示されたエラーも確認してください。
</Toggle>

<Toggle title="同じETFを二つのポートに分けて入れる設定ですか？">
現在は、登録資産ごとに所属先のポートを指定します。
同じ銘柄をAに60%、Bに40%のように、比率で分割する入力はありません。
目標設計で分類を決め、実際のひも付けは資産割り当て画面で確認します。
</Toggle>
