## はじめに

証券会社のアプリを3つ開いて、残高を見て閉じました。
それでも「投資資金のうち、株式はどれくらいだろう？」と聞かれると、また電卓を探すことになります。
引き出しごとに何が入っているかは知っていても、家に靴下が全部で何足あるかは分からないのと似ています。
**今回は口座という引き出しを開け、同じ種類の資産を一か所にまとめます。**
<br/>
「自分のポートフォリオの読み方」は、**PortRhythmで始める資産配分と投資の点検**シリーズです。
初回の目標は、3口座に分かれた1,000万ウォンを一つの表にまとめ、「株式は600万ウォン、現金は150万ウォン」と言えるようになることです。
PortRhythmを使わなくても、保有明細と電卓があれば進められます。

<Rbox>
本文の計算は理解を助けるための例であり、投資の推奨ではありません。
PortRhythmの画面はテストアカウントのもので、本文の金額と異なる場合があります。
</Rbox>

## 表に入れる資産を決める

冷蔵庫の整理を始めるとき、机の引き出しまで同時に開けると作業が大きくなります。
お金もまず、**どこまで合計するか**を決めておくと簡単です。
今回は投資用の株式・ETF・現金だけを集め、生活費や緊急時に備えた資金は表の外に置きます。
「一般A・B」「長期投資C」は口座につけた呼び名です。
<br/>
表に記入するのは、**現在の価格で計算した金額**、つまり「評価額」です。
100万ウォンで買った株式が今120万ウォンなら、表には120万ウォンと記入します。
今のお金がどこにどれだけあるかを知るためです。
<br/>
外貨建て資産はウォンに換算して合計します。
米ドル建て資産なら、数量に米ドル建て価格と1米ドルあたりのウォン額を掛けます（`수량 × 달러 가격 × 1달러당 원화 금액`）。
証券会社のアプリにウォン換算額が表示されていれば、為替レートを再度掛ける必要はありません。
ここでは集計の単位をそろえます。実際の両替は発生しません。
<br/>
価格と為替レートは同じ時点を基準にウォン換算します。
この基準時点を `T0` と呼びます。
自分の表には基準日と、価格や為替レートを確認した時刻も記録します。
市場によって確認時刻が異なる場合は、その違いもメモしておきます。

## 口座は引き出し、ポートはかご

口座はお金を置いている場所です。
PortRhythmの「ポート」は、保有資産をひとまとめにして管理するためのかごです。
A口座とB口座の株式を同じかごに入れて見ることも、一つの口座の株式と現金を別々のかごで見ることもできます。

| 名前 | 簡単な問い | 例 |
| --- | --- | --- |
| 口座 | どこにありますか？ | 一般A、一般B、長期投資C |
| 資産クラス | どんな種類ですか？ | 株式、債券、金、現金 |
| ポート | どのグループで管理しますか？ | 米国株指数、長期保有、投資用現金 |

「資産クラス」は、ここでは性質の似た資産をまとめた分類だと考えてください。
アプリで資産をポートに「割り当てる」のは、かごの名前を資産につけるようなものです。
証券会社間で実際にお金や株式を移す操作は発生しません。
[PortRhythmの資産割り当てガイド](https://www.promleeblog.com/blog/post/439-portrhythm-asset-assignment-guide)
<br/>
ETFという名前だけを見て、すべて株式に分類する必要はありません。
ETFはさまざまな資産を組み入れられる商品なので、中身を確認します。
この例では、債券ETF Dは債券、金ETF Eは金に分類します。
実際の商品に複数の種類が含まれている場合は、説明書を確認するまで「未確認」として構いません。

## 3口座を一つの表に

3口座の保有明細を一か所に集めました。
大きな数字を読みやすくするため、金額は「万ウォン」で記載します。

| 口座 | 資産 | 現在の評価額 | 種類 | 全体に占める割合 |
| --- | --- | ---: | --- | ---: |
| 一般A | 米国株ETF A | 300万ウォン | 株式 | 30% |
| 一般A | 個別株X | 50万ウォン | 株式 | 5% |
| 一般A | ウォン現金 | 50万ウォン | 現金 | 5% |
| 一般B | 米国成長株ETF B | 150万ウォン | 株式 | 15% |
| 一般B | 韓国株ETF C | 100万ウォン | 株式 | 10% |
| 長期投資C | ウォン建て債券ETF D | 200万ウォン | 債券 | 20% |
| 長期投資C | 金ETF E | 50万ウォン | 金 | 5% |
| 長期投資C | ウォン現金 | 100万ウォン | 現金 | 10% |
| 合計 | | **1,000万ウォン** | | **100%** |

まず口座ごとに合計すると、Aは400万ウォン、Bは250万ウォン、Cは350万ウォンです。
元の口座残高と照合できたら、今度は同じ行を株式・債券・金・現金にまとめ直します。
**資産の分け方が変わっても、金額の合計は同じです。**
合計は引き続き1,000万ウォンになります。

## 1,000万ウォンのうち株式はいくら？

株式の4行を足すと600万ウォンになります（`300만 + 50만 + 150만 + 100만 = 600만 원`）。
全体の1,000万ウォンのうち600万ウォンなので、10等分すると6つ分が株式です。
この「全体に占める部分」が**構成比**です。
電卓で計算すると、`600만 ÷ 1,000만 × 100 = 60%` です。

| 種類 | 現在の評価額の合計 | 全体に占める割合 |
| --- | ---: | ---: |
| 株式 | 600万ウォン | 60% |
| 債券 | 200万ウォン | 20% |
| 金 | 50万ウォン | 5% |
| 現金 | 150万ウォン | 15% |
| 合計 | **1,000万ウォン** | **100%** |

これで、「口座が3つあります」から一歩進んで、「投資資金の60%が株式です」と説明できます。
<br/>
ここで、現金150万ウォンを外して計算するとどうなるでしょうか。
割り算の基準となる金額が850万ウォンに減り、`600만 ÷ 850만 × 100 ≈ 70.6%` になります。
株式の保有量は同じでも、割合は変わります。
**60%は現金を含む全体が基準、70.6%は現金を除いた金額が基準**だからです。
割り算の基準になる1,000万ウォンや850万ウォンを「分母」と呼びます。

> 構成比を見るときは、「何パーセントか？」の次に「何を全体としたか？」を確認します。

資産配分とは、投資資金を株式・債券・現金などに分けることです。
自分に合う配分は、資金を運用する期間や、損失をどの程度受け入れられるかによって変わります。
[Investor.govの資産配分ガイド](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)

## PortRhythmで自分の表と照合する

アプリでは**口座管理 → 保有明細 → 資産の割り当て → ポート構成比**の順に確認します。
まず、実際の保有口座と銘柄、数量、現在の評価額が漏れなく入っているかを確認します。
現金を含めて証券会社の残高と照合します。
入力が必要なら、[資産登録ガイド](https://www.promleeblog.com/blog/post/438-portrhythm-asset-registration-guide)と[口座管理ガイド](https://www.promleeblog.com/blog/post/445-portrhythm-brokerage-account-guide)を参照してください。
<br/>
次に、保有項目ごとにどのかごに入っているかを確認します。
同じ株式を2口座で実際に買った場合は、両方の残高を記入します。
*一つの残高を2つのポートに入れるために複製すると、金額も二重に集計されます。*
一つの保有項目には、集計先のポートを一つ指定します。

<Img src="/portrhythm-assignment-desktop-overview-20261008.webp" width={750} height={422} alt="資産ごとの評価額を確認し、割り当て先のポートを選ぶ資産割り当て画面"/>

確認するのは、各資産の右側にあるポートの選択欄です。
「米国株指数」のかごに現金を入れた場合、そのかごの全額を米国株として集計すると実態とずれます。
名前と中身を一緒に確認するのはそのためです。
<br/>
最後に、ポート構成比画面の**現在の構成比**を自分の表と照合します。
各項目は次のように読みます。

| アプリで見る項目 | 読み方 |
| --- | --- |
| 総額 | 割り当て済みと未分類の資産のウォン換算評価額の合計 |
| ポート別の金額 | そのかごに割り当てた資産の評価額の合計 |
| 手入力で登録した現金 | 集計に含まれるので、入力漏れや重複がないかを確認 |
| 未分類 | かごを指定していない資産も全体に含まれ、金額があれば別に表示 |

「現在」は今の構成、「目標」はこれから目指す構成です。
今回作った表は「現在」と比較します。
画面の読み方は[現在・目標構成比ガイド](https://www.promleeblog.com/blog/post/441-portrhythm-current-target-allocation-guide)にまとめています。
<br/>
アプリと自分の表で総額が違う場合は、資産の抜け漏れと価格を先に確認します。
市場価格を取得できない資産では、保存済みの価格を使うことがあります。価格がなければ、評価額が合計に反映されない場合もあります。
*登録済みの資産でも、評価額が集計に入っているかを確認します。*
ポートの名前が株式・債券などの分類と違う場合は、アプリのかごをそのまま使い、別の表で資産の種類ごとに集計しても構いません。

## 見落としやすい3点

整理の最後に、元の残高をもう一度確認します。

- **現金は一度だけ数えます。**
口座の総額に現金が含まれている場合、別に加算していないかを確認します。
RPやCMAなど、商品名で表示される資金についても、現金欄と重複していないか照合します。
- **種類が分からない資産も表に残します。**
種類が分からない50万ウォンは「未確認50万ウォン」とします。
表から外すと、全体に占める割合も変わります。
- **同じ銘柄と同じ残高を区別します。**
2口座でそれぞれ買った株式は両方を合計します。
同じ口座残高を画像と手入力で二重に登録した場合は、片方を修正します。

<Bbox>
最初は口座を一つだけ入力し、元の残高と合計が一致するか確認しても構いません。
次に口座を一つずつ追加すると、どこで差が生じたかを見つけやすくなります。
構成比の合計が99.9%や100.1%の場合は、表示上の丸めによる差かどうかも確認します。
</Bbox>

今回作ったのは、**どこに何がいくらあるかを一目で確認できる統合資産表**です。
