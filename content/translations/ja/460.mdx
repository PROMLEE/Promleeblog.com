## はじめに

米国株が10%上がったと聞いて、口座を開きました。
ところが、ウォンで見た資産は4.5%しか増えていません。
アプリの計算ミスでしょうか。
その間に、米ドルをウォンに換算する為替レートが変われば、このようなことが起こります。
<br/>
**海外資産のウォン換算額は、資産価格と為替という2つの要因で動きます。**
今回は、その2つを順に見ていきます。
最後に「何の通貨で買い、何に投資し、為替の影響を減らす仕組みがあるか」を書くチェックリストを作り、保有商品と為替の関係を確認します。

<Rbox>
本文の計算は理解のための例で、投資の推奨ではありません。
PortRhythmの画面はテスト用アカウントのデータで、本文の金額と異なる場合があります。
</Rbox>

## ウォンで買っても海外投資になる

韓国の通販サイトでウォンで決済しても、商品は海外から届くことがあります。
ETFも同じです。
**どの通貨で買うかと、どこに投資するかは別の問いです。**
ウォンで売買する韓国上場ETFも、米国株に投資できます。
<br/>
説明書では、次の3項目を確認します。
専門用語を、答えやすい問いに置き換えます。

| 説明書の用語 | 問い | 例 |
| --- | --- | --- |
| 取引通貨 | 何で売買するか | ウォンまたは米ドル |
| 原資産 | 何の価格に連動するか | 米国株、ウォン建て債券、金 |
| 為替ヘッジ | 為替の影響を抑える仕組みはあるか | ウォンと米ドルのレート変動に備える取引など |

為替ヘッジは、為替が動いたときの影響を抑える方法です。為替の影響を小さくするもので、株価の下落までは防ぎません。
サムスン資産運用は、同じS&P500に連動するKODEX米国S&P500とKODEX米国S&P500(H)を、為替ヘッジなしとありの商品に分けています。
どちらもウォンで取引していても、為替の扱いが異なる例です。
[サムスン資産運用の為替ヘッジと為替エクスポージャーの説明](https://samsungfundblog.com/archives/54620)
<br/>
商品名に `(H)` があれば、説明書を確認する手がかりにします。
どの通貨の影響をどの程度減らすか、費用はあるかを確認します。
*為替ヘッジがあっても、為替の影響が正確に0になるとは限りません。*

## 同じ米ドルでもウォン換算額は違う

1,000米ドルの資産を持っているとします。
1米ドルが1,400ウォンなら、ウォンでは `1,000 × 1,400 = 140만 원`（140万ウォン）です。
**米ドル建ての金額に、1米ドル当たりのウォンの金額を掛けます。**
レートが下がれば、同じ米ドルを換えても受け取るウォンは減ります。
為替が海外投資のリターンを増減させることは、Investor.govでも説明されています。
[Investor.govの海外投資ガイド](https://www.investor.gov/introduction-investing/investing-basics/investment-products/international-investing)
<br/>
資産価格が10%上がり、為替レートが5%下がったと仮定します。
米ドル建ての額は1,100米ドル、レートは1,330ウォンです。

| 確認する値 | 最初 | あと |
| --- | ---: | ---: |
| 米ドル建ての資産 | 1,000米ドル | 1,100米ドル |
| 1米ドル当たりのウォン | 1,400ウォン | 1,330ウォン |
| ウォン換算の資産 | 140万ウォン | 146万3,000ウォン |

あとの金額は `1,100 × 1,330 = 146만 3,000원`（146万3,000ウォン）です。
米ドル建ての資産は10%上がりましたが、ウォンでは6万3,000ウォン増えました。
`63,000 ÷ 1,400,000 × 100 = 4.5%` です。
**上昇した米ドル建て資産を下がったレートで換算した結果、ウォン建てのリターンは4.5%になりました。**
<br/>
数量は同じで、追加の入金、分配金、費用、税、為替ヘッジはないとします。
実際に両替する場合は、適用レートと両替費用も確認します。

## 10%から5%を引くだけでは足りない理由

急いで計算すると `10% − 5% = 5%` と思いがちです。
しかし為替レートは最初の1,000米ドルではなく、上昇後の1,100米ドル全体に適用されます。
**増えた金額に、変わったレートを掛けて**計算します。
<br/>
倍率で表すと `1.10 × 0.95 = 1.045` です。
最初の金額の104.5%になり、リターンは+4.5%です。
式が難しければ、表のように米ドル建ての金額とレートを掛けても同じ答えになります。

<Img src="/portfolio-reading-03-currency-exposure-20261017.webp" width={750} height={500} alt="米ドル建て資産価格+10%とウォン対米ドルのレート−5%で、ウォン建てリターンが+4.5%になる過程"/>

反対の方向も、同じ方法で計算できます。

| 米ドル建て資産の価格 | 1米ドル当たりのウォン | ウォン建てリターン |
| ---: | ---: | ---: |
| +10% | +5% | +15.5% |
| +10% | −5% | +4.5% |
| −10% | +5% | −5.5% |
| −10% | −5% | −14.5% |

この条件では為替レートが上がるとウォン換算額を押し上げますが、株価の下落をすべて補うわけではありません。
3行目でも、価格−10%と為替+5%が合わさって、結果は−5.5%です。
<br/>
韓国でウォン建て取引をする海外資産ETFには、もう1つ注意があります。
ETFのウォン建て価格には、すでに為替の影響が反映されている場合があります。
**ウォン建て価格から求めたリターンに、さらに為替を掛けると、同じ影響を二重に数えることがあります。**
ファンド内の資産価値と実際の取引価格は異なる場合があるため、実際のリターンでは取引価格、受け取った分配金、費用も見ます。
[Investor.govのETFの説明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-24)

## 自分の1,000万ウォンに通貨の情報を付ける

[第1回の資産表](https://www.promleeblog.com/blog/post/458-portfolio-reading-consolidated-holdings)に通貨情報を加えます。
AとXは米ドルで取引し、Bはウォンで取引する韓国上場の米国株ETFです。
3資産とも為替ヘッジはありません。
金ETF Eの仕組みは未確認とします。

| 資産 | 全体比率 | 取引通貨 | 為替のメモ |
| --- | ---: | --- | --- |
| 米国株ETF A | 30% | 米ドル | 米国株、為替ヘッジなし |
| 個別株X | 5% | 米ドル | 米ドル建ての株式、別途ヘッジなし |
| 米国成長株ETF B | 15% | ウォン | 米国株、為替ヘッジなし |
| 韓国株ETF C | 10% | ウォン | 企業への間接的な為替影響は別に考える |
| ウォン建て債券ETF D | 20% | ウォン | ウォン建て債券 |
| 金ETF E | 5% | ウォン | 価格の基準通貨、仕組み、ヘッジは未確認 |
| ウォン現金 | 15% | ウォン | 2口座の現金の合計 |
| 合計 | **100%** | | |

米ドルで売買するのはAとXなので `30 + 5 = 35%` です。
為替ヘッジなしで米国株に連動するとした部分はBも含み、`30 + 5 + 15 = 50%` です。
**ウォンで買ったBも為替を確認する対象なので、2つの値は異なります。**
後者のように、為替変動の影響を受ける部分を確認することを、為替エクスポージャーの点検と呼びます。
<br/>
金ETF Eの5%は、為替の影響がないという意味ではなく、説明書を確認する必要があるという意味です。
残る45%も、為替と完全に無関係だと判断したわけではありません。
韓国企業も、輸出入の費用や外貨建て債務を通じて為替の影響を受けます。
ただし、そうした間接的な影響は、米国株のウォン換算と同じ方法では計算していません。

<Ybox>
「未確認」と「影響なし」は異なります。
わからない欄に0を入れるより、追加で確認する資料を書きます。
</Ybox>

## PortRhythmで確認する2つの金額

保有資産の詳細で、単価の横の通貨表示とウォン建て評価額を見ます。
米国銘柄なら、米ドル建て価格がウォン換算額にどうつながるかを確認します。
数量、価格、為替を確認した時点も合わせます。
入力と画面の読み方は、[資産登録](https://www.promleeblog.com/blog/post/438-portrhythm-asset-registration-guide)と[保有資産ガイド](https://www.promleeblog.com/blog/post/440-portrhythm-dashboard-holdings-guide)を参照してください。

<Img src="/portrhythm-guide5-desktop-detail-20261008.webp" width={650} height={428} alt="米ドル建ての現在値と数量、ウォン建て評価額を確認する資産詳細画面"/>

見るのは、米ドル記号が付いた現在値とウォン建て評価額です。
米国の保有資産と米ドル現金は、適用レートでウォンに換算します。韓国の保有資産には、ウォン建ての価格を使います。
米国に投資する韓国上場ETFでも、ウォン建て価格に為替を掛け直しません。
<br/>
アプリでウォン換算額を表示することと、ETFが為替ヘッジを行うことは別です。
**為替ヘッジは商品の説明書で確認し、チェックリストに書きます。**
商品ごとに次の問いに答え、公式資料のリンクと確認日を残します。

- どの通貨で売買するか。
- 実際に何に投資するか。
- どの通貨の影響を抑えるのか。
- まだ確認できていないことは何か。

## おわりに

米ドル建ての資産は10%上がりましたが、為替レートが5%下がり、ウォン換算額は4.5%増えました。
ウォンで買った商品でも、為替を確認する必要があることを見てきました。
今回の成果は、**決済通貨、投資対象、為替ヘッジ、未確認項目を書いたチェックリスト**です。
<br/>
[PortRhythmの保有資産](https://pf.promleeblog.com/?view=holdings)で海外投資商品を1つ選び、4つの問いに答えてみてください。
次回は、残高が増えるもう1つの理由である新規入金を切り分けます。
「資金が増えた」と「投資で利益を得た」を分けて考えます。
