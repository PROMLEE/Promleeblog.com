## はじめに
### i18nextとは

`i18next`は多言語対応のためのJavaScriptライブラリで、React、React Native、Expoなどのプロジェクトで翻訳を実装する際に使います。
`i18next`には多様な機能があり、効率的に多言語翻訳を実装できます。
> あなたのソフトウェアはi18nextを使っていますか。ぜひ世界に知らせましょう。
オープンソースプロジェクトの翻訳管理方法を探していませんか。
Locizeはオープンソースの理念を支持し、サポートを提供しています。[i18next-introduction](https://www.i18next.com/)

オンラインビジネスが成功し、ほかの国の顧客へも届けるために事業を広げたいと想像してください。
その市場で成功するには、ウェブサイトやアプリが現地の言語を使い、地域の文化を理解する必要があります。
こうした理由から、多言語対応は非常に重要です。

## i18nextのインストール
まず次のコマンドで`i18next`をインストールします。

```bash
 # npm
npm install i18next --save

 # yarn
yarn add i18next
```
## i18nextの初期化
`i18next`を初期化し、翻訳データを設定します。
`i18next`を初期化するには、`i18next`オブジェクトを作り、翻訳データを渡します。

```tsx
import i18next from 'i18next';

await i18next.init({
  lng: 'en',
  debug: true,
  resources: {
    en: {
      translation: {
        "key": "hello world"
      }
    }
  }
});

console.log(i18next.t('key'));
```
### 設定オプション
よく使う`i18next`の初期化オプションは次のとおりです。
ほかの設定は[i18nextの初期化オプション](https://www.i18next.com/overview/configuration-options)を参照してください。
| オプション | 説明 | 型 | 既定値 |
| --- | --- | --- | --- |
| lng | 現在の言語 | string | undefined |
| debug | デバッグモードとログの有効化 | boolean | false |
| resources | 翻訳データ | object | undefined |
| fallbackLng | 言語が指定されていない場合の言語<br/>https://www.i18next.com/principles/fallback#language-fallback | string | 'en' |

## 言語パックを作る
`i18next`で翻訳データを管理し、言語パックを作ります。
翻訳データは`resources`に保存し、`lng`に現在の言語を設定します。

```json title="en-US.json"
{
	"key": "value of key"
}
```

```json title="ko-KR.json"
{
	"key": "키 값"
}
```

```tsx
import i18next from 'i18next';
import translationEn from "./en-US.json";
import translationKo from "./ko-KR.json";

await i18next.init({
	lng: 'en', // 언어 설정은 여기서 변경
	debug: true, 
	resources: {
		en: {
			translation: translationEn
		},
		ko: {
			translation: translationKo
		}
	}
});

console.log(i18next.t('key')); // "value of key"
console.log(i18next.t('key', { lng: 'ko' })); // "키 값"
```

## 翻訳を使う
初期化後は、`i18next`から翻訳データを取得して使います。
`i18next.t`で翻訳データを取得できます。

```json title="en-US.json"
{
	"key": "value of key",
	"look": {
		"deep": "value of look deep"
	},
  "error": {
    "unspecific": "Something went wrong.",
    "404": "The page was not found."
  }
}
```
### 基本の使い方

```tsx
i18next.t('key'); // "value of key"
i18next.t('look.deep'); // "value of look deep"
```
翻訳キーが見つからなければ、次のように既定値を渡せます。

```tsx
i18next.t('notkey', 'default value to show'); // "default value to show"
```
キーの配列でt関数を呼ぶと、個別のフォールバック値がない動的キーを翻訳できます。

```tsx
// const error = '404';
i18next.t([`error.${error}`, 'error.unspecific']); // -> "The page was not found"

// const error = '502';
i18next.t([`error.${error}`, 'error.unspecific']); // -> "Something went wrong"
```

### 引数の受け渡しと変数
キーは、基本的には波括弧で囲まれた文字列です。
これらは`i18next.t`へ渡したオブジェクトのプロパティで置き換えられます。

```json title="en-US.json"
{
    "key": "{{what}} is {{how}}"
}
```

```tsx
i18next.t('key', { what: 'i18next', how: 'great' });
// -> "i18next is great"
```
データモデル全体を値として渡すこともできます。

```json title="en-US.json"
{
    "key": "I am {{author.name}}"
}
```

```tsx
const author = { 
    name: 'Jan',
    github: 'jamuhl'
};
i18next.t('key', { author });
// -> "I am Jan"
```

### 書式設定
`i18next`は設定に応じた書式整形をサポートします。
数値、日付、通貨などを整形できます。
少し複雑なので、[i18nextの書式設定](https://www.i18next.com/translation-function/formatting)を参照しながら進めてください。
基本の形は次のとおりです。
- `{{value, formatname(options1: options1Value)}}`：`value`を`formatname`で整形します。
- `t('key', { option1: option1Value })`：ルートオプションで書式を設定します。
- `t('key', { formatParams: { value: { option1: option1Value } })`：`value`ごとに異なる書式を設定します。

標準で利用できる整形方法を紹介します。
#### 数値：number
`number`は数値を整形します。
`formatname`は`number`で、`minimumFractionDigits`は小数点以下の桁数を指定します。

```json  title="en-US.json"
{
	"intlNumber": "Some {{val, number}}",
	"intlNumberWithOptions": "Some {{val, number(minimumFractionDigits: 2)}}"
}
```

```tsx
i18next.t('intlNumber', { val: 1000 });
// --> Some 1,000
i18next.t('intlNumber', { val: 1000.1, minimumFractionDigits: 3 });
// --> Some 1,000.100
i18next.t('intlNumber', { val: 1000.1, formatParams: { val: { minimumFractionDigits: 3 } } });
// --> Some 1,000.100
i18next.t('intlNumberWithOptions', { val: 2000 });
// --> Some 2,000.00
i18next.t('intlNumberWithOptions', { val: 2000, minimumFractionDigits: 3 });
// --> Some 2,000.000

// 다국어 설정
i18next.t('intlNumber', { val: 1000.1, lng: 'de' }); 
// or: i18next.t('intlNumber', { val: 1000.1, locale: 'de' });
i18next.t('intlNumber', { val: 1000.1, formatParams: { val: { lng: 'de' } } }); 
// or: i18next.t('intlNumber', { val: 1000.1, formatParams: { val: { locale: 'de' } } });
```

#### 通貨：currency
`currency`は通貨を整形します。
`formatname`は`currency`で、`currency`オプションに通貨コードを指定します。

```json  title="en-US.json"
{
  "intlCurrencyWithOptionsSimplified": "The value is {{val, currency(USD)}}",
  "intlCurrencyWithOptions": "The value is {{val, currency(currency: USD)}}",
  "twoIntlCurrencyWithUniqueFormatOptions": "The value is {{localValue, currency}} or {{altValue, currency}}",
}
```

```tsx
i18next.t('intlCurrencyWithOptionsSimplified', { val: 2000 });
// --> The value is $2,000.00
i18next.t('intlCurrencyWithOptions', { val: 2300 });
// --> The value is $2,300.00
i18next.t('twoIntlCurrencyWithUniqueFormatOptions',
	{
		localValue: 12345.67,
		altValue: 16543.21,
		formatParams: {
			localValue: { currency: 'USD', locale: 'en-US' },
			altValue: { currency: 'CAD', locale: 'fr-CA' },
		},
	},);
// --> The value is $12,345.67 or 16 543,21 $ CA
```

#### 日付：datetime
`datetime`は日付と時刻を整形します。
`formatname`は`datetime`で、`format`オプションに日付と時刻の形式を指定します。

```json  title="en-US.json"
{
  "intlDateTime": "On the {{val, datetime}}", 
}

```

```tsx
i18next.t('intlDateTime', { val: new Date(Date.UTC(2012, 11, 20, 3, 0, 0)) });
// --> On the 12/20/2012
i18next.t('intlDateTime',
  {
    val: new Date(Date.UTC(2012, 11, 20, 3, 0, 0)),
    formatParams: {
      val: { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' },
    },
  });
// --> On the Thursday, December 20, 2012
```
#### リスト：list
`list`は配列を整形します。
`formatname`は`list`で、`type`オプションにリストの形式を指定します。

```json  title="en-US.json"
{
  "intlList": "A list of {{val, list}}"
}
```

```tsx
// JSON
i18next.t('intlList', { val: ['locize', 'i18next', 'awesomeness'] });
// --> A list of locize, i18next, and awesomeness
```
### 単数形と複数形
<Rbox>単数形と複数形を区別するには、必ずcount変数を使用します。</Rbox>

#### 基本的な単数・複数の形式
`i18next`は単数形と複数形をサポートします。
キーに`_one`または`_other`を追加して区別できます。

```json title="en-US.json"
{
  "key_one": "item",
  "key_other": "items",
  "keyWithCount_one": "{{count}} item",
  "keyWithCount_other": "{{count}} items"
}
```

```tsx
i18next.t('key', {count: 0}); // -> "items"
i18next.t('key', {count: 1}); // -> "item"
i18next.t('key', {count: 5}); // -> "items"
i18next.t('key', {count: 100}); // -> "items"
i18next.t('keyWithCount', {count: 0}); // -> "0 items"
i18next.t('keyWithCount', {count: 1}); // -> "1 item"
i18next.t('keyWithCount', {count: 5}); // -> "5 items"
i18next.t('keyWithCount', {count: 100}); // -> "100 items"
```
#### 別の指定方法
oneのほかにも、合計5種類の表現があります。
- `_zero`：0
- `_one`：1
- `_two`：2
- `_few`：3〜10
- `_many`：11〜99
- `_other`：100以上

```json title="en-US.json"
{
  "key_zero": "zero",
  "key_one": "singular",
  "key_two": "two",
  "key_few": "few",
  "key_many": "many",
  "key_other": "other"
}
```

```tsx
i18next.t('key', {count: 0}); // -> "zero"
i18next.t('key', {count: 1}); // -> "singular"
i18next.t('key', {count: 2}); // -> "two"
i18next.t('key', {count: 3}); // -> "few"
i18next.t('key', {count: 4}); // -> "few"
i18next.t('key', {count: 5}); // -> "few"
i18next.t('key', {count: 11}); // -> "many"
i18next.t('key', {count: 99}); // -> "many"
i18next.t('key', {count: 100}); // -> "other"
```
