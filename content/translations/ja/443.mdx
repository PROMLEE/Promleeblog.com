## はじめに

> 「資産が150万ウォン増えました。でも今月は新たに100万ウォンを入れたんです。」

残高が増えるとうれしいものです。
ただ、増えた額をすべて投資の成果と読むと、自分で新たに入れたお金まで利益に見えてしまいます。
逆に生活費を引き出した日は、投資の結果に関係なく残高が減ることもあります。

<br/>

[第7回 リバランス](https://www.promleeblog.com/blog/post/442-portrhythm-rebalancing-guide)では、目標に合わせて数量を検討しました。
今回はその後の話です。
取引や資金移動の後に、資産がどう変化したかを記録します。

<br/>

資産記録（`자산 기록`）画面には、二種類の記録があります。
一つは**その日の資産評価額**、もう一つは**管理中の資産に入ったお金と、そこから出たお金**です。
評価額は資産のスナップショット、入出金はその間に自分が足したお金と取り出したお金のメモだと考えると分かりやすくなります。

<Bbox>
最初は資産全体の今日の評価額を確認し、外部との入出金があった日だけ別に記録してみてください。
この記事の金額は計算方法を理解するための例です。
画面は説明用のQAアカウントで撮影しました。価格の更新時点によって、画像ごとに評価額が異なる場合があります。
</Bbox>

## 1. 資産記録画面

PCでは、左のメニューで資産記録（`자산 기록`）を押します。
上にポート別の資産推移（`포트별 자산 추이`）、下に開閉できる入出金記録（`입출금 기록`）があります。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide8-desktop-overview-20261009.webp" width={800} alt="PCの資産記録画面にある今日の評価額を記録するボタン、全資産の推移、三つの増減指標"/>

最初は、三つの箇所を確認します。

- 今日の評価額を記録（`오늘 기록`）
現在保存されている資産情報を使って、今日の評価額を残します。
- 推移を表示するポート（`추이를 볼 포트`）
全資産、未分類、個別ポートのどの記録を表示するか選びます。
- 入出金記録（`입출금 기록`）
管理範囲の外から入れたお金と、外に出したお金を記録します。

<br/>

グラフの下には、最初の記録日、最後に記録した評価額、最後の記録日が表示されます。
全資産（`전체 자산`）を選ぶと、さらに下に評価額の変化と純入金に関する指標が表示されます。
個別ポートを選んだ場合は、この三つの指標は表示されません。

### 1.1. モバイルのメニュー

モバイルでは、下部のすべて（`전체`）を押します。
メニューを下にスクロールし、記録とアカウント（`기록과 계정`）の資産記録（`자산 기록`）を開きます。

画面が狭くても、確認する順序は同じです。
今日の評価額を記録（`오늘 기록`）するボタンとポート選択欄を確認し、グラフの下の指標を読んでから、入出金欄を開きます。

## 2. 今日の評価額を記録する

今日の評価額を記録（`오늘 기록`）を押す前に、実際の残高とアプリの保有情報が一致するか確認します。
株式を売ったのに数量がそのまま、あるいは生活費を引き出したのに現金残高を直していない場合は、その差が記録にも反映されます。

<br/>

次の順番で準備します。

- 取引した銘柄の数量と現金残高を実際の口座に合わせます。
- 変更があれば先に保存します。
- 最新価格で残したい場合は、価格を更新（`가격 갱신`）し、完了を確認します。
- 資産記録（`자산 기록`）で今日の評価額を記録（`오늘 기록`）を押します。

<br/>

**このボタンは、保存済みの保有情報と価格を使って評価額を記録します。**
新たな価格取得は別の操作です。
未保存の変更があれば先に保存します。
価格がない資産や古い価格を使っている資産がないかも確かめてください。

### 2.1. 記録は1日1件

画面には「1日1件、同じ日は最新値で更新」（`하루 한 기록 · 같은 날에는 최신 값으로 갱신`）と表示されます。
韓国の日付を基準に同じ日にもう一度記録すると、その日の評価額が最新値に置き換わります。
午前と午後の評価額が別々の点として追加されるわけではありません。

<br/>

例えば10月9日の午前に1,000万ウォンを記録し、午後に1,010万ウォンを記録し直した場合、10月9日には1,010万ウォンの1件だけが残ります。
10月10日に次の記録を残すと、日付の異なる二つの点になります。
記録が1日分だけなら点が一つ表示され、次の記録から線で表示する旨が案内されます。

<Toggle title="今日の評価額を記録するボタンを押したときだけ保存されますか？">
ポートフォリオや保有情報を保存したときや、価格を更新したときにも、その日の評価額の記録が更新される場合があります。
同じ日にすでに記録があっても、その後の保存や更新で値が変わることがあります。

<br/>

終値を毎日自動で集めたり、記録のない日を埋めたりする機能はありません。
定期的に比べるなら、毎回なるべく同じ時間帯に、同じ手順で確認して記録するとよいでしょう。
</Toggle>

### 2.2. 二つの記録ボタンの違い

入出金欄にも記録（`기록`）ボタンがあります。
名前は似ていますが、保存する内容は異なります。

| ボタン | 保存する内容 | 使う場面 |
| --- | --- | --- |
| 今日の評価額を記録 | 今日の資産評価額 | 保有情報と価格を確認した後 |
| 入出金欄の記録 | 日付、入出金額、メモ | 外部から資金を入れたとき、または外に出したとき |

入出金を記録しても、現金残高や今日の評価額は、その金額分だけ自動で変わるわけではありません。
この違いは後の例で改めて確認します。

## 3. ポート別の資産推移

推移を表示するポート（`추이를 볼 포트`）から、見たい項目を選びます。

- 全資産（`전체 자산`）
登録したすべての資産の評価額の推移を見ます。
未分類の資産も含みます。
- 未分類（`미분류`）
まだポートに割り当てていない資産の推移を見ます。
- 個別ポート
米国株指数や現金など、自分で作ったポートの推移を見ます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide8-desktop-port-20261009.webp" width={800} alt="PC版で米国株指数ポートを選んだ資産推移画面"/>

モバイルでも同じ選択欄を使います。
全体の金額を確認してから関心のあるポートを選ぶと、そのポートの評価額の動きが分かります。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide8-mobile-port-20261009.webp" width={350} alt="モバイル版で米国株指数ポートを選んだときの評価額の推移"/>

### 3.1. ポートの金額が変化する理由

ポートの金額が増える理由は、銘柄の値上がりだけではありません。
銘柄を追加購入したり、別のポートの資産をこのポートに割り当て直したりした場合もあります。
現金の割り当てや為替の変動も、評価額に影響します。

<br/>

例えば、未分類の100万ウォンを米国株指数ポートに割り当てると、全資産は変わらなくても、二つの分類の金額は変わります。
**ポートの金額の変化と投資収益は区別します。**
過去の記録には、その時点の割り当てと評価額が残ります。今日の割り当てを変えても、過去の構成は再計算されません。

<Toggle title="グラフの傾きはそのまま比較できますか？">
現在のグラフは、記録された点を順番に並べます。
10月6日と7日の間隔、7日と9日の間隔は、実際の日数に比例するわけではありません。
記録のない日をまたいで線が引かれる場合も、その日の評価額を測ったわけではありません。

<br/>

縦軸の範囲も、表示する金額に合わせて調整されます。
わずかな金額差が画面では大きく見えることがあります。
線の角度だけで収益率を判断せず、開始日と終了日、最後の評価額も確認してください。
</Toggle>

## 4. 入金を記録する

今月の給与から100万ウォンを、管理している投資口座に入れたとします。
このお金は、既存資産の価格変動と区別して記録する外部入金です。

<br/>

入出金記録（`입출금 기록`）を開き、次のように入力します。

- 日付は実際に入金した日を選びます。
今日記録する場合も、入金日が別の日ならその日に変更します。
- 区分は入金（`입금`）を選びます。
- 金額はウォンで `1000000` と入力します。
- 必要に応じてメモを入力します。
例えば、月の投資資金（`월 투자금`）のように、後で思い出せる短い内容にします。
- 内容を確認し、記録（`기록`）を押します。
入出金はこのボタンでそのまま保存されます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide8-desktop-deposit-20261009.webp" width={800} alt="PC版の入出金欄に100万ウォンの入金と月の投資資金というメモを入力した例"/>

モバイルでは、入力項目が縦に並びます。
先に日付と区分を確認し、金額とメモを入力してから、下の記録（`기록`）を押します。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide8-mobile-deposit-20261009.webp" width={350} alt="モバイル版で入金日と100万ウォンの金額、メモを入力し、記録ボタンを確認する例"/>

この画面は保存前の入力例です。
撮影では入出金の明細を実際に追加していないため、記録は0件です。
保存した後は、一覧に日付、メモ、入金額が追加されたか確認します。

### 4.1. ウォン建ての金額

入出金額は**ウォン建て**で入力します。
ドルを入金した際にドルの数値をそのまま入力すると、ウォンの金額として解釈されます。
外貨の入出金では、ウォンで記録する金額を確認し、必要に応じて外貨額と換算基準をメモに残します。
この入力欄で外貨を自動換算することはありません。

<br/>

メモは任意で、最大120文字です。
長い取引の説明より、10月の投資資金（`10월 투자금`）や生活費の引き出し（`생활비 인출`）のように見分けやすい内容にすると、後から確認しやすくなります。

## 5. 出金を記録する

今度は投資口座から生活費として20万ウォンを引き出したとします。
区分を出金（`출금`）に変え、金額に `200000` と入力します。
出金でも、金額欄にマイナス符号は付けません。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide8-desktop-withdrawal-20261009.webp" width={800} alt="PC版で出金を選び、20万ウォンと生活費の引き出しというメモを入力した例"/>

**資金の方向は入金・出金の選択で指定し、金額には正の値を入力します。**
保存後の一覧では、入金はプラス、出金はマイナスで表示されます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide8-mobile-withdrawal-20261009.webp" width={350} alt="モバイル版で20万ウォンの出金と生活費の引き出しというメモを入力した例"/>

### 5.1. 誤った記録を直す

日付、方向、金額を間違えた場合は、該当する明細を削除し、正しい内容で記録し直します。
現在の一覧に個別の編集ボタンはありません。
削除する前に、日付、メモ、金額で対象の明細を確認します。

<Ybox>
入出金明細を削除すると、同期間の純入金や、純入金を除いた増減も変わる場合があります。
現在の画面では削除を取り消せないので、日付と金額を確認してから処理してください。
この削除で、実際の現金残高や記録済みの評価額が元に戻るわけではありません。
</Ybox>

## 6. 外部入出金の範囲

ここで迷いやすいのが、「証券会社AからBにお金を移したら、出金と入金の両方を記録するのか」という疑問です。
判断の基準は**PortRhythmで管理している資産の範囲**です。

<br/>

AとBの両方を登録していれば、二つの口座間の移動は、管理中の資産の置き場所が変わっただけです。
外部出金と外部入金として重複して記録する必要はありません。
一方、アプリの管理対象に含めていない生活費口座から、管理中の投資口座に資金を入れた場合は、外部入金として扱います。

| 資金の移動 | 入出金記録 |
| --- | --- |
| 管理範囲外の給与口座 → 登録した投資口座 | 入金 |
| 登録した投資口座 → 管理範囲外の生活費口座 | 出金 |
| 両方とも登録した投資口座A → B | 管理範囲内の移動 |
| 登録した現金で株式を購入 | 管理範囲内の取引 |
| 株式を売却し、登録口座内で現金を保有 | 管理範囲内の取引 |

株式の売買は、管理中の現金と銘柄の交換です。
売買自体を入出金として記録すると、資金を誤って調整することがあります。
配当や手数料も、口座に入出金と表示されただけで新しい投資資金と見なさず、管理範囲の外から資金を追加したかを確認します。

### 6.1. 現金残高と入出金記録

100万ウォンを入金したら、二つの項目を別々に確認します。

- 保有資産の現金残高
実際にいくら保有しているかに合わせます。
- 入出金記録の100万ウォンの入金
評価額の変化のうち、いくらを新たに入れたかを残します。

<Bbox>
現金残高が50万ウォンで、100万ウォンが入ったなら、実残高は150万ウォンです。
アプリ内の現金を実残高の150万ウォンに合わせ、入出金には100万ウォンの入金を別途記録します。
すでに現金を150万ウォンに更新したなら、100万ウォンを再度足す必要はありません。
入出金記録は資金移動のメモです。残高への自動加算は行いません。
</Bbox>

登録済みの口座間で資金を移した場合も、各口座の現金を実残高に合わせます。
外部入出金の記録が不要な場合でも、保有情報は更新します。

## 7. 三つの増減指標

全資産（`전체 자산`）のグラフ下に三つの指標があります。
期間内の増減を計算するには、異なる日付の記録が2件以上必要です。
同じ日に何度記録しても、この条件は満たしません。

<br/>

開始評価額が1,000万ウォン、終了評価額が1,150万ウォンだったとします。
その間、外部から100万ウォンを入金し、出金はありませんでした。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide8-cash-flow-example-20261009.webp" width={800} alt="評価額の変化150万ウォンから純入金100万ウォンを引くと、純入金を除いた増減が50万ウォンになる計算例"/>

### 7.1. 記録期間中の評価額の変化

終了評価額から開始評価額を差し引きます。
例では1,150万ウォンから1,000万ウォンを引いて、プラス150万ウォン（`+150만 원`）です。
新たに入れたお金も含めた、全体の評価額の差です。

### 7.2. 同じ期間の純入金

計算期間に含まれる入金の合計から、出金の合計を差し引きます。
入金100万ウォン、出金0ウォンなら、純入金はプラス100万ウォン（`+100만 원`）です。
入金100万ウォン、出金20万ウォンなら、純入金はプラス80万ウォン（`+80만 원`）です。
出金のほうが大きければ、純入金はマイナスになります。

### 7.3. 純入金を除いた増減

評価額の変化から純入金を差し引きます。
最初の例では150万ウォンから100万ウォンを引いて、プラス50万ウォン（`+50만 원`）です。
つまり、増えた評価額から自分で新たに入れた金額を除いた差を見ます。

<br/>

**純入金を除いた増減は、残高差を説明するための参考金額です。**
*残高がどれだけ変化したかを読み解く数値*として使います。
パーセントで表す投資収益率とも、保有情報の修正などの影響をすべて除いた純粋な投資利益とも異なります。
最初に漏れていた資産を追加したり、数量を訂正したりすると、新たな資金を入れていなくても評価額に差が生じます。
為替、配当、手数料などの影響も、この数値だけでは分けられません。

<Toggle title="出金したのに、純入金を除いた増減がプラスになることはありますか？">
開始評価額が1,000万ウォン、終了評価額が950万ウォンだったとします。
その間に管理範囲の外へ100万ウォンを出金し、入金はありませんでした。

<br/>

評価額の変化はマイナス50万ウォン、純入金はマイナス100万ウォンです。
純入金を除いた増減は、マイナス50万ウォンからマイナス100万ウォンを引くので、プラス50万ウォンです。
残高は減っていても、引き出したお金を考慮すると差がプラスになる場合があります。
これも参考金額なので、出金以外の変化は別途確認します。
</Toggle>

## 8. 記録期間の計算基準

「入金を記録したのに、純入金が0ウォンなのはなぜでしょうか？」
入出金一覧にあっても、すべての明細が現在の指標に反映されるわけではありません。
全資産の最初と最後の記録で、計算期間が決まります。
現在の画面には、月ごとの期間を直接選ぶ機能はありません。

<br/>

計算に含まれる入出金は、**最初の記録日の翌日から、最後の記録日まで**です。
最初の記録日の入出金は除外し、最後の記録日の入出金は含めます。
例えば最初の記録が10月6日で、最後が10月9日の場合は次のとおりです。

| 入出金日 | 例 | 現在の期間の計算 |
| --- | --- | --- |
| 10月6日 | 最初の記録当日の入金 | 除外 |
| 10月7日 | 100万ウォンの入金 | 対象 |
| 10月9日 | 20万ウォンの出金 | 対象 |
| 10月10日 | 最後の記録後の入金 | 除外 |

この例の純入金は、100万ウォンから20万ウォンを引いた80万ウォンです。
同じ期間に評価額が150万ウォン増えたなら、純入金を除いた増減は70万ウォンです。
入出金の件数には期間外の明細も含まれるため、件数と計算に反映された金額は別々に確認します。

<Ybox>
現在の計算は日付単位です。
最初の記録日に評価額を保存してから入金しても、その日の入金は計算期間から外れます。
最後の記録日には、評価額を記録した後に入れたり出したりしたお金も、同じ日付なら含まれます。
同じ日の記録と入出金の前後関係まで反映した成果計算ではない点に注意してください。
</Ybox>

<Toggle title="初日の入金が反映されないように見えるときは？">
数値を合わせるために入出金日を変えるより、実際の入金日と、最初の評価額がどの時点の残高かを確認します。
初日の入金がすでに最初の評価額に含まれていれば、その後の変化と区別できます。
最初の評価額を記録した後、同じ日に入金した場合は、現在の日付単位の計算ではその順序を反映できない点を考慮します。

<br/>

評価額と入出金は実際の内容に合わせて記録し、計算範囲が合わない期間は、指標だけで成果を判断しません。
現在の画面には、過去の評価額の日付を直接選び、入力し直す機能はありません。
</Toggle>

## 9. 取引後に記録する順序

毎日多くのボタンを押すより、実残高と記録の基準をそろえることが先です。
次の順番で確認すると、二つの記録を混同せずに管理できます。

- 実際の取引と資金の移動を確認します。
株式の売買、管理範囲内の振替、外部との入出金を区別します。
- 保有数量と現金を実残高に合わせて保存します。
保有情報の確認方法は[第5回 ダッシュボードと保有資産](https://www.promleeblog.com/blog/post/440-portrhythm-dashboard-holdings-guide)で説明します。
- 外部との入出金があれば、実際の日付と金額を記録します。
売買金額や登録口座間の振替を、新規投資資金として重複入力しません。
- 価格と為替を確認し、今日の評価額を記録します。
同じ日に記録し直すと、今日の値が更新されます。
- 全資産の記録期間と三つの指標を併せて読みます。
ポートごとの変化については、割り当ての変更や買い増しの有無も確認します。

<br/>

入出金がない日に、0ウォンの明細を作る必要はありません。
数日記録を飛ばした場合は、次に記録した実際の評価額から確認を再開します。
その間の日付の値がすべてグラフに保存されているわけではありません。

### 9.1. よくある質問

<Toggle title="同じ日に何度も記録したのに、点が増えません">
評価額を1日1件ずつ残すためです。
同じ日の記録は最新値に更新されます。
次の日付に記録すると、新しい点が追加されます。
</Toggle>

<Toggle title="入金を記録しましたが、資産総額が変わりません">
入出金の記録では、保有資産の現金は自動で変更されません。
実際の現金残高を保有情報に反映し、保存したか確認してください。
すでに反映したなら、同じ額を再度加える必要はありません。
</Toggle>

<Toggle title="純入金を除いた増減が表示されません">
まず、全資産を選択しているか確認します。
個別ポートや未分類では、期間に関する三つの指標は表示されません。
全資産でも、異なる日付の記録が2件以上必要です。
</Toggle>

<Toggle title="資産を追加したら急に大きく増えました">
アプリに未登録だった既存資産を登録すると、記録の管理範囲が変わります。
新しいお金を入れていなくても、評価額は増える場合があります。
増加分をすべて投資の成果と読んだり、数値を合わせるため架空の入金を記録したりしないでください。
登録範囲が変わった日付を別途メモすると、比較するときに役立ちます。
</Toggle>

## まとめ

資産記録を使うと、今日の評価額を確認するだけでなく、時間の経過に沿って変化を追えます。
評価額を残し、その間に自分が入れたり出したりしたお金を分けて記録すると、残高が変わった理由を確認しやすくなります。

<br/>

今日の評価額は、実際の保有情報と価格を確認したうえで記録します。
入出金には、管理範囲の外とやり取りした資金を別に記録します。
最後に日付の範囲を確認し、純入金を除いた増減は参考金額として読みます。

<br/>

最初は正確な記録が一つあれば十分です。
次の記録が加わると、一つの数字だった資産が、変化の流れとして見えてきます。
[PortRhythm](https://pf.promleeblog.com)で、現在の残高を確認し、最初の記録を残してみてください。
