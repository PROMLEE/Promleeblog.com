## アルゴリズムの分類
グラフ理論、グラフ探索、BFS、DFS

## 問題の説明
横M、縦Nの白菜畑に白菜が植えられています。
白菜は1×1のマスに植えられ、植えられていないマスは0、植えられているマスは1で表します。
害虫を防ぐため、白菜畑に白菜ミミズを置きます。
白菜ミミズは隣り合う白菜をすべて守れます。
必要な白菜ミミズの最小数を求めるプログラムを書きます。
<Img src="/250506-145917.webp" width={300} alt="#1012 有機栽培の白菜"/>
### 入力
最初の行に、テストケースの数Tが与えられます。
各ケースの最初の行に、畑の横幅M、縦幅N、白菜が植えられている場所の数Kが順に与えられます。
続くK行に白菜の位置が与えられます。
位置は (x, y) で、xが横の座標、yが縦の座標です。
(0 ≤ x &lt; M, 0 ≤ y &lt; N)

### 出力
各テストケースについて、白菜ミミズの最小数を出力します。

## 解き方
1. 入力された畑の情報から二次元配列を作ります。
2. 白菜がある位置を ground[y][x] = 1 とします。
3. 畑全体を走査し、未訪問の白菜があればBFSでつながっている白菜をすべて探索します。
4. BFSを始めるたびに独立した白菜のグループを1つ見つけたことになるので、ミミズの数を1増やします。
5. すべてのグループを探索したら、ミミズの数（count）を出力します。

## コード - Python
```python
import sys
from collections import deque

sys.setrecursionlimit(10000)  # DFS 사용 시 재귀 제한 증가 (예방 차원)

T = int(sys.stdin.readline())  # 테스트 케이스 수
dx = [0, 0, 1, -1]  # 좌우
dy = [1, -1, 0, 0]  # 상하

for _ in range(T):
    M, N, K = map(int, sys.stdin.readline().split())  # 가로(M), 세로(N), 배추 위치 수(K)
    ground = [[0] * M for _ in range(N)]  # 배추밭 초기화 (세로 x 가로)
    visited = [[False] * M for _ in range(N)]  # 방문 체크 배열

    for _ in range(K):  # 배추 위치 표시
        x, y = map(int, sys.stdin.readline().split())
        ground[y][x] = 1

    # BFS로 연결된 배추 그룹 탐색
    def bfs(y, x):
        queue = deque()
        queue.append((y, x))
        visited[y][x] = True
        while queue:
            cy, cx = queue.popleft()
            for d in range(4):
                ny, nx = cy + dy[d], cx + dx[d]
                if 0 <= ny < N and 0 <= nx < M:
                    if not visited[ny][nx] and ground[ny][nx] == 1:
                        visited[ny][nx] = True
                        queue.append((ny, nx))

    count = 0  # 지렁이 수
    for i in range(N):
        for j in range(M):
            if not visited[i][j] and ground[i][j] == 1:
                bfs(i, j)
                count += 1  # 새로운 연결 그룹 발견 시 증가

    print(count)
```

## ポイント
### グラフ探索
- BFS（幅優先探索）またはDFS（深さ優先探索）で、つながっている白菜を探索します。
- BFSはキューで実装し、DFSは再帰またはスタックで実装できます。
### 時間計算量
入力サイズは $M x N <= 50 x 50 = 2500, K <= 2500$ です。
最悪の場合、2,500個の白菜がすべて離れていると、BFSをO(K)回実行します。
BFSの内部では各マスから最大4方向を確認するため、O(K x 4) = O(K)です。
全体の時間計算量はO(K)です。
