## はじめに

携帯に、ETFの分配金が入金されたという通知が届きました。
毎月入金があるので、給料が振り込まれる口座がもう1つできたようです。
ところが、残高を見ると評価額は減っていました。
受け取った金額だけでは見落とすことがあります。
<br/>
**いくら分配されたかと、投資全体でいくら得たかは、別の問いです。**
今回は、配当ETFとカバードコールETFがどこからお金を得て、何を手放す仕組みなのかを見ていきます。

<Rbox>
商品説明は2026年10月21日に確認した公式資料に基づきます。
損益計算は、1期間の単純な仕組みを示す例です。実際の分配金や将来のリターン、特定商品の推奨を示すものではありません。
</Rbox>

## 配当ETFが選ぶ銘柄

配当株ETFは、配当を支払う企業を一定のルールで選びます。
配当利回りだけを見る場合も、配当の持続性や企業の財務状態も見る場合もあります。
同じ「配当」という言葉が付いていても、銘柄の選定ルールを確認します。
<br/>
実際の商品であるSCHDは、`Dow Jones U.S. Dividend 100 Index` のトータルリターンへの連動を目指します。
運用会社は、配当の質と持続性、企業の財務指標を重視しています。
この説明だけから、すべての配当ETFが同じ企業を組み入れるとは考えません。
[SchwabのSCHD公式案内](https://www.schwabassetmanagement.com/products/schd)
<br/>
企業が減配したり、株価が下がったりする可能性は残ります。
分配金を支払う頻度は、リターンの保証とは別です。
どの企業が現金を生み、ファンドがどんなルールで保有し、いくら支払うかを分けて見ます。

## カバードコールで加わる契約

カバードコールは、資産を保有しながら、その資産に連動するコールオプションを売る仕組みです。
コールの買い手は、決められた条件で資産を買う権利を得ます。
売り手はその権利を渡す対価として、**プレミアム**を受け取ります。
この記事では、保有資産と同じ数量に相当するコールを売る場合を計算します。
[OICのカバードコール解説](https://www.optionseducation.org/strategies/all-strategies/covered-call-buy-write)
<br/>
「決めた価格を超える上昇分を手放す可能性がある代わりに、今お金を受け取る契約」と考えるとわかりやすくなります。
そのため、株価が大きく上がると、上昇分をすべて得られない場合があります。
プレミアムを受け取っても、株価下落のリスクは残ります。

## 100で買い、105で買う権利を売る

原資産の価格を100、コールの権利行使価格を105、受け取るプレミアムを2とします。
権利行使価格は、オプション契約で決めた基準価格です。
1期間の満期時点で評価し、資産1単位と、それに相当するコールを組み合わせます。
配当、税、手数料、プレミアムに付く利息、途中の売買は除外します。
<br/>
資産だけを持つ場合の損益は `만기 가격 − 100`（満期価格 − 100）です。
カバードコールの損益は `만기 가격 − 100 + 2 − max(만기 가격 − 105, 0)`（満期価格 − 100 + 2 − max(満期価格 − 105, 0)）です。
`max` は2つの値の大きいほうを選びます。
満期価格が105を超えた分は、コールを売った側の損失で相殺されます。

| 満期価格 | 資産だけを保有した損益 | カバードコールの損益 |
| --- | ---: | ---: |
| 80 | −20 | −18 |
| 100 | 0 | +2 |
| 105 | +5 | +7 |
| 120 | +20 | +7 |

120まで上昇しても、カバードコールの利益は7にとどまります。
80まで下がればプレミアム2が損失の一部を補いますが、損失は18残ります。
**上昇分の一部を渡す対価と、残る下落リスクを一緒に見ます。**
損益7は、当初の資産価格100に対して7%です。プレミアムを差し引いた正味投資額98を分母にしたリターンとは区別します。

## 実際の商品で異なる項目

すべてのカバードコール商品が、上の105の条件で運用されるわけではありません。
原資産、コールを売る比率、権利行使価格、契約期間、入れ替え方法が異なります。
一部だけを対象にコールを売る戦略や、売る比率を変える戦略も、商品資料で見分けます。
<br/>
QYLDは、Nasdaq-100の株式を保有し、同じ指数のコールオプションを売る商品と説明されています。
確認した公式ページでのベンチマークは `Cboe Nasdaq-100 BuyWrite V2 Index`、コードは `BXNT` です。
指数の算出方法では、満期が1か月のアット・ザ・マネーのコールを継続的に売る戦略が説明されています。
アット・ザ・マネーとは、契約時の原指数に近い権利行使価格という意味です。
[Global X QYLD](https://www.globalxetfs.com/funds/qyld) · [Cboe Nasdaq BuyWriteの算出方法](https://cdn.cboe.com/api/global/us_indices/governance/Cboe_NASDAQ_BuyWrite_Indices_Methodology.pdf)
<br/>
したがって、「権利行使価格105で一度だけ満期まで保有する」上の計算は、商品の実際の期間リターンを求める式とは異なります。
実際の指数で契約を入れ替える時期や、決済する時期も確認します。
1本の損益線で、数か月にわたる分配と再投資の成果を代用しません。

## 分配金とオプション料を区別する

株式配当、オプションのプレミアム、ファンドが実際に支払った分配金は、それぞれ異なる金額です。
プレミアムを受け取ると、オプションに対応する義務が生じます。
受取額のすべてを、条件のない投資利益として数えることはできません。
<br/>
QYLDの公式ページは、分配に元本の払い戻しが含まれる場合があり、表示される分配率はトータルリターンではないと説明しています。
元本の払い戻しは米国商品の開示上の分類です。韓国の口座での課税に、そのまま当てはめることはできません。
ファンドの支払履歴と分配内訳を確認し、自分の口座での課税は別途確認します。
[Global Xの分配率と分配内訳の説明](https://www.globalxetfs.com/funds/qyld)
<br/>
1回の分配金を12倍した年率と、直近12か月の支払額を合計した分配率も異なる場合があります。
分母が現在のNAVか市場価格かも、脚注で確認します。
大きく見える数値を選ぶ前に、期間と分母をそろえます。

## 受け取ったお金と残った資産

最初に100を投じ、1期間に現金12を受け取り、期末に資産価値が88だったらどうでしょうか。
再投資、外部からの入出金、税、手数料を除き、同じ通貨で計算します。
トータルリターンは `(88 − 100 + 12) ÷ 100 = 0%` です。
**現金12を受け取っただけで、12%の利益を得たとはいえません。**
<br/>
現金を生活費に使った場合、その支出と投資の成果を別々に記録します。
配当と現金の目的を分ける方法は[前シリーズの第7回](https://www.promleeblog.com/blog/post/464-portfolio-reading-distributions-cash)をご覧ください。

## インカム商品の比較表

| 項目 | 配当株ETFで確認すること | カバードコールETFで追加確認すること |
| --- | --- | --- |
| 何を保有するか | 配当企業の選定と入れ替えのルール | 原資産とオプションの対象 |
| 資金の出どころは | 配当、実現損益、分配方針 | プレミアム、オプション損益、分配の内訳 |
| 上昇にどれだけ参加するか | 企業の株価変動と組入比率 | コールの売却比率、権利行使価格、契約期間 |
| どんな成果か | 分配金込みのトータルリターン | 同じ定義のトータルリターンと支払額 |
| 自分の目的は | 必要な現金、期間、株式のリスク | 手放す上昇分と残る下落リスク |

SCHDとQYLDは、原資産も戦略も異なります。
分配率だけで1つの順位を作るより、各構造の中で目的が同じ候補を比べます。
PortRhythmでは、「インカム」という名前に加えて、必要な現金と許容する株式比率も結びつけて考えます。

<Bbox>
今の生活費に充てる現金が必要か、受け取ったお金を再投資する予定かを先に書きます。
同じ分配金でも、目的によって使い道は変わります。
商品比較表には支払いの頻度とともに、資産全体の変化も記録します。
</Bbox>

## おわりに

配当ETFがどんな企業を選ぶか、カバードコールETFがどんな権利をどれだけ売るかを見てきました。
分配率は受け取った現金の比率で、トータルリターンは残った資産も合わせた成果です。
**入金通知と残高を合わせて見ると、自分の投資で何が起きたかがわかります。**
<br/>
