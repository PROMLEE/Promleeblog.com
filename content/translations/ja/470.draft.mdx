## はじめに

中古品の取引で「直近の取引価格は10万ウォン」と表示されていました。
ところが、今の出品価格は10万2,000ウォンで、買い手が提示するのは9万9,000ウォンです。
直近に成立した価格と、今買える価格は違います。
ETFの取引画面にも、こうした価格が並びます。
<br/>
**今すぐ買える価格と、ETFが保有する資産の価値は、別々に確認します。**
今回は、価格、時刻、数量をまとめる取引チェックリストを作ります。

<Rbox>
以下の価格は取引の仕組みを説明するための計算例です。
特定商品のリアルタイムの気配値や売買シグナルではありません。商品構造は2026年10月21日に確認した公式資料に基づいて説明します。
</Rbox>

## 3種類の価格

まず用語を分けます。

| 価格 | 意味 |
| --- | --- |
| 市場価格 | 取引所で投資家が売買する価格 |
| NAV | 資産から負債を引いた金額を1口当たりに換算した純資産価値 |
| iNAV | 取引時間中に原資産価格などを反映して推定する1口当たりの純資産価値 |

NAVはファンドの中身を計算した値で、市場価格は取引所で決まる値です。
iNAVは取引中の参考になる推定値であり、その価格での約定を保証するものではありません。
画面では、それぞれの値の基準時刻と算出方法も確認します。
[韓国取引所のNAVと乖離率](https://m.krx.co.kr/contents/04/0401/040101/JHPETP040101M01.jsp) · [Investor.govのNAVと市場価格](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-24)
<br/>
画面の「現在値」が直近の約定価格なら、自分の注文も同じ値で約定するとは限りません。
すぐ買うときは最良**売り気配値**を、すぐ売るときは最良**買い気配値**を見ます。
売り手が提示した値で自分が買い、買い手が提示した値で自分が売る関係です。

## 純資産価値との間隔を示す乖離率

NAVが10,000ウォン、市場価格が10,100ウォンなら、次のように計算します。
`(10,100 − 10,000) ÷ 10,000 × 100 = +1%` です。
NAVより高く取引される状態をプレミアム、低く取引される状態をディスカウントと呼びます。
正負は、この引き算の向きに基づきます。
[Investor.govのプレミアムとディスカウントの説明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-24)
<br/>
+1%を見つけても、「すぐに1%下がる」とは判断できません。
まず、**何と、いつ比較した1%か**を確認します。
午前の取引価格と前日の終値時点のNAVを比べると、その間に新しい情報が出ている場合があります。

## 売買気配値の間隔を示すスプレッド

次は同時点の気配値を見ます。
最良買い気配値は10,090ウォン、最良売り気配値は10,110ウォンです。
両者の中間値は10,100ウォンです。
売買の気配値の差、つまりスプレッドは20ウォンです。
<br/>
中間値で割ると `20 ÷ 10,100 × 100 ≈ 0.198%` です。
NAVと市場価格の乖離率1%とは別の値です。
2つを混同せず、片方だけで取引条件の良し悪しを判断しないようにします。
[韓国取引所の市場価格とスプレッド](https://m.krx.co.kr/contents/04/0401/040103/JHPETP040103M01.jsp)
<br/>
表示数量をすべて約定でき、価格も変わらなければ、100口をすぐに買って売った場合の価格差は2,000ウォンです。
手数料と税は含めていません。
しかし、100口買いたいのに10,110ウォンの売り気配に10口しかなければ、残りは次の気配値を確認します。
**板の1行に表示された価格と、注文全体の平均価格は異なる場合があります。**

## 海外市場が閉まっている時間

TIGER、ACE、SOLの米国S&P500 ETFは韓国内で取引されますが、米国株式市場に連動しています。
韓国の取引時間には、米国の通常取引が行われていない時間帯があります。
保有株の直近取引価格、先物の値動き、為替レート、評価に用いる価格の基準が、同じ時点の値とは限りません。
<br/>
この場合、市場価格が前日算出のNAVと異なるだけで、誤りとは判断できません。
公式の案内では、海外資産のETFは原市場と取引市場の終了時刻が異なるため、NAVと市場価格の読み方に注意が必要と説明されています。
[Global Xの海外保有資産における評価時刻の説明](https://www.globalxetfs.com/funds/qyld)
<br/>
当日のiNAVでも、すべての原資産がその瞬間に活発に取引されているとは限りません。
推定に使った直近価格と為替、商品の算出方法を確認します。
休場や取引停止も、開示資料や取引画面で確認します。

## 気配値をつなぐ仕組み

ETFでは、設定・解約と裁定取引が、市場価格と資産価値の差を縮める方向に働きます。
流動性供給者も気配値を提示して取引を助けます。
ただし、いつでも希望の数量を希望の価格で取引できるわけではありません。
[韓国取引所のETFの仕組み](https://m.krx.co.kr/contents/06/0609/060901/JHPETP060901M01.jsp) · [Investor.govの設定・解約と裁定取引](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-24)
<br/>
出来高が少ないという1つの数値や、大口注文が一度約定したという事実だけでは、通常の流動性を十分に説明できません。
現在の売買気配値、価格ごとの数量、原資産市場の状況を合わせて見ます。

## 注文前に記録する5項目

証券会社の取引画面で、次の項目をまとめて記録してください。
別の日の数値を並べた表よりも、同時点の記録が取引条件の判断に役立ちます。

| 確認項目 | この例で記録する値 |
| --- | --- |
| 観測時刻 | 気配値と価格の時点がそろっているか |
| 価値の基準 | NAV 10,000ウォン。NAVの基準時刻は別途記録 |
| 市場価格 | 10,100ウォン。最後の約定時刻も確認 |
| 売買気配値 | 買い10,090ウォン、売り10,110ウォン |
| 自分の注文 | 100口。各気配の数量と想定約定範囲を確認 |

この表には、乖離率1%とスプレッド約0.198%を別々に書きます。
分母と比較対象の違いも記録しておくと、あとで読み返しやすくなります。

<Bbox>
指値注文では、許容する価格を指定します。
買いなら指定価格以下、売りなら指定価格以上を条件とします。約定するかどうかは別の問題です。
価格条件と約定の有無を分けて考えます。
</Bbox>

PortRhythmの評価額は、資産規模を把握する出発点として使います。
注文直前の気配値、数量、約定条件は証券会社の取引画面で確認します。
保有資産の評価額は、全量を今すぐ売却できる確定額とは限りません。

## おわりに

NAVはファンドの中身の価値、市場価格は取引所での価格です。
乖離率はその2つの間隔で、スプレッドは売りと買いの気配値の間隔です。
**価格に時刻と数量を添えると、実際にどんな条件で取引できるのかが読み取れます。**
