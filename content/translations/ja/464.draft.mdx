## はじめに

口座に10万ウォンの分配金が入りました。
コーヒーを飲んでいても、つい通知を見直したくなるうれしい瞬間です。
でも、現金が10万ウォン増えただけで、投資資産全体も10万ウォン増えたといえるでしょうか。
**現金が入った理由と、資産全体が増えた理由は分けて考えます。**
<br/>
企業が株主に支払うお金を配当金、ETFなどのファンドが投資家に支払うお金を分配金と呼びます。
この記事では、ファンドの分配金を中心に説明します。
作るのは、**現金の用途と次に使う時期を記録する計画表**です。

<Rbox>
本文の計算は理解のための例であり、投資の推奨ではありません。
PortRhythmの画面はテスト用アカウントのデータで、本文の金額と異なる場合があります。
</Rbox>

## 分配金とトータルリターン

ETFが保有資産からお金を取り分けて投資家に支払うと、その分だけファンド内の資産価値は減ります。
SECの案内も、分配後は純資産価値が下がり、現金などの形で価値が投資家に移ると説明しています。
そのため、**入金額だけで投資成績を判断しません。**
[Investor.govのファンド分配金の説明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/fund-distributions-investor-bulletin)
<br/>
ほかに価格変化がなく、費用や税もないとし、保有する株式ETFから10万ウォンが分配されると仮定します。
[第1回の総額1,000万ウォン](https://www.promleeblog.com/blog/post/458-portfolio-reading-consolidated-holdings)を出発点にします。

| 区分 | 分配前 | 分配後も口座に残す場合 |
| --- | ---: | ---: |
| 株式 | 600万ウォン | 590万ウォン |
| 債券と金 | 250万ウォン | 250万ウォン |
| 投資用現金 | 150万ウォン | 160万ウォン |
| 合計 | **1,000万ウォン** | **1,000万ウォン** |

株式から現金へ、10万ウォンが移りました。
価格変化と受取額を合わせて見る考え方が**トータルリターン**です。
<br/>
分配金が大きくても、同額の利益が生じたとは限りません。
ファンドは損失が出ているときも分配でき、商品によっては元本の払い戻しに当たる分配が含まれます。
予想分配金を確定した給料のように扱わず、原資と支払方法を確認します。
[Investor.govの分配金と成績の違い](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/fund-distributions-investor-bulletin)

## 同じ10万ウォンの3つの使い道

受け取った10万ウォンに、用途の名前を付けます。
口座に置く、資産を買い増す、口座から生活費として引き出す、という選択肢があります。
同じ10万ウォンの**使い道を3つに分けて**見てみましょう。

<Img src="/portfolio-reading-07-distributions-cash-20261017.webp" width={750} height={500} alt="分配金10万ウォンを保管、再投資、引き出しする3つの選択と残高の変化"/>

| 選択 | 株式 | 現金 | 口座内の合計 | 別に記録すること |
| --- | ---: | ---: | ---: | --- |
| そのまま保管 | 590万ウォン | 160万ウォン | 1,000万ウォン | 口座内の現金増加 |
| 10万ウォンを再投資 | 600万ウォン | 150万ウォン | 1,000万ウォン | 口座内で買付 |
| 生活費として引き出す | 590万ウォン | 150万ウォン | 990万ウォン | 外部への出金10万ウォン |

どの場合も、債券と金の250万ウォンはそのままです。
再投資では同じ株式ETFを買うとします。
出金した場合は、口座内の990万ウォンと外に出した10万ウォンを区別します。
口座外に出した分を、現在の投資残高に足し戻しません。
<br/>
[第4回の方法](https://www.promleeblog.com/blog/post/461-portfolio-reading-return-cash-flows)では、引き出した場合の投資損益は `990만 − 1,000만 − (−10만) = 0원`（990万 − 1,000万 − (−10万) = 0ウォン）です。
残高の減少は、外部への出金によるものです。
口座に残した分配金も、外部入金として記録しません。
自分が新たに入れた資金と、投資の中で生じた現金が混ざるからです。

## 現金にも用途を付ける

現金150万ウォンがあると、「全部投資してよいか」と考えがちです。
先に**いつ、何に使うのか**を書けば、考えるべきことを絞れます。
用途が異なる現金を、ひとまとめに「余ったお金」として扱いません。

| お金の名前 | 目的 | このシリーズでの扱い |
| --- | --- | --- |
| 生活費 | 近い日常の支出 | 投資総額に含めない |
| 緊急資金 | 急な支出や収入の途絶に備える | 投資総額に含めない |
| 投資用現金 | 次の投資、決済、比率の調整 | 投資総額に含める |

予期しない状況に備えて貯蓄を別に用意する考え方は、Investor.govの案内でも確認できます。
必要額は、生活費、収入の安定性、近く予定している支出に合わせて決めます。
[Investor.govの緊急資金の説明](https://www.investor.gov/introduction-investing/investing-basics/save-and-invest/save-rainy-day)
<br/>
150万ウォンは、**生活費や緊急資金と分けた投資用現金**です。
同じ残高を、口座の預り金と別の現金項目に重複して入れていないかも確認します。

## 再投資の前に確認すること

分配金を受け取るたびに元のETFを買い増す方法もありますが、先に現在の配分を確認できます。
株式がすでに目標を超えているなら、不足している資産に使うか、現金で残すかを検討します。
分配金の用途と、**資産グループの配分を戻すこと**を結びつけられます。
<br/>
反対に、近く使うお金なら、機会を逃したくないからといって急いで投資する必要があるかを考えます。
現金は値上がりの恩恵を受けられない場合があり、インフレで購買力が落ちることもあります。一方で、必要なときに使う選択肢を残せます。
ここで、**必要なときにお金として取り出しやすいこと**を「流動性」と呼びます。
用語を覚えるより、「必要な日にこのお金を使えるか」とメモしておきます。

<Bbox>
現金の名前の横に、「いつか投資」と書く代わりに、具体的な確認条件を書いてみてください。
例えば「次の点検日に不足する資産を確認してから使う」と書けば、今日すべてを使うか悩む負担が減ります。
</Bbox>

## 自分のキャッシュフロー計画表

分配前の投資用現金150万ウォンには、次のように用途を付けられます。

| 用途 | 現在割り当てた金額 | 確認時期と条件 |
| --- | ---: | --- |
| 次の投資に使う | 70万ウォン | 次回の月次点検後に使うか決める |
| 決済に備える | 50万ウォン | 注文と決済の履歴を照合して振り分け直す |
| 配分の調整に使う | 30万ウォン | 目標との差と必要な資金を確認する |
| 合計 | **150万ウォン** | |

分配金10万ウォンが実際に入ったら、「予定」から「確認済みの現金」に移して用途を決めます。
すでに残高に反映された分配金を二重に足しません。
自動再投資をした場合は、現金だけでなく増えた数量も照合します。

## PortRhythmで現金と記録を照合する

PortRhythmの資産編集で、現金の名称、金額、通貨を確認します。資産の割り当てでは、どのポートに入れたかを見ます。
入力手順は[資産登録ガイド](https://www.promleeblog.com/blog/post/438-portrhythm-asset-registration-guide)を参照してください。
証券会社の分配金履歴と現金残高を照合して反映します。

<Img src="/portrhythm-assets-desktop-cash-20261008.webp" width={750} height={422} alt="現金の名称、金額、通貨、割り当て先のポートを確認する資産編集画面"/>

確認するのは、現金の名称、金額、通貨、割り当て先のポートです。
ウォンと米ドルの現金は通貨を合わせて確認し、口座で実際に使える金額も別途照合します。
<br/>
投資の範囲外にお金を出したら、資産履歴の外部出金にも反映します。
口座に残した分配金や口座内の買付は、外部との入出金と区別します。
記録の確認方法は[資産履歴ガイド](https://www.promleeblog.com/blog/post/443-portrhythm-asset-history-guide)にまとめています。
**分配金、残高の変化、外部出金を、それぞれ一度ずつ照合する**ことが大切です。

## おわりに

10万ウォンの分配金はうれしいものですが、通知1件だけでは投資全体の成果を説明できません。
保管、再投資、引き出しを分け、現金に用途と使う時期を付けました。
今日の成果は、**保有する現金の役割を説明できる計画表**です。
<br/>
[PortRhythmの資産割り当て](https://pf.promleeblog.com/?view=allocation)で現金項目を1つ選び、「何に使うお金か」を書いてみてください。
次の最終回では、これまでの表をまとめます。
毎月同じ問いに答えられる、1枚の月次チェックリストを作ります。
