## はじめに
> Next.js 13から利用できるApp Routerを使ってみましょう。

Next.jsはファイルシステムルーティングを採用しているため、アプリケーションのルートはファイル構造によって決まります。
App RouterはServer Components、Server Actions、Suspenseなどをサポートします。
この記事では基本的な使い方を説明します。

## ルートページの設定
既定で作成される`app/`ディレクトリ内の`page.tsx`と`layout.tsx`で、ルートディレクトリ（`/`）を設定できます。
<img src="https://nextjs.org/_next/image?url=%2Fdocs%2Fdark%2Fapp-getting-started.png&w=1920&q=75"/>

```tsx title="app/layout.tsx"
export default function RootLayout({children,}: {children: React.ReactNode}) {
  return (
    <html lang="en">
      <body>{children}</body> 
	{/* html, body 태그를 사용하여 레이아웃을 구성*/}
	{/* children은 page.tsx 내부의 컴포넌트를 받아서 레이아웃을 구성한다. */}
    </html>
  )
}
```

```tsx title="app/page.tsx"
export default function Page() {
	return <p>Root Page</p>
}
```
<Bbox>*layout.tsx*がなくても、Next.jsは実行時に自動でレイアウトを作成します。</Bbox>
`npm run dev`で起動し、http://localhost:3000/ にアクセスすると、`Root Page`が表示されます。

## ルートの定義
先ほど説明したとおり、Next.jsではファイルシステムルーティングを使うため、ルートはファイルやフォルダーの構造で決まります。
`app/`の下にフォルダーを作ることで、ルートを作成できます。
<img src="https://nextjs.org/_next/image?url=%2Fdocs%2Fdark%2Fdefining-routes.png&w=1920&q=75"/>

```tsx title="app/example/page.tsx"
export default function ExamplePage() {
	return <p>Example Page</p>
}
```
`npm run dev`で起動し、http://localhost:3000/example にアクセスすると、`Example Page`が表示されます。

### 動的ルーティング
フォルダー名に角括弧を使うと、動的ルートを定義できます。

```tsx title="app/example/[slug]/page.tsx"
export default function SlugPage({ params }: { params: { slug: string } }) {
	return <p>{params.slug} Page</p>
}
```
`npm run dev`で起動し、http://localhost:3000/example/hello にアクセスすると、`hello Page`が表示されます。

## Route HandlerによるAPIルーティング
`app/api/`ディレクトリを作ることで、APIルーティングを利用できます。
<img src="https://nextjs.org/_next/image?url=%2Fdocs%2Fdark%2Froute-special-file.png&w=1920&q=75"/>

```tsx title="app/api/hello.ts"
import { NextResponse } from "next/server";

export async function GET() {
  return NextResponse.json({ message: "Hello World" });
}
```

`npm run dev`で起動し、http://localhost:3000/api/hello にアクセスすると、`{"message":"Hello World"}`が表示されます。
<Rbox>route.tsとpage.tsxは同じパスに置けません。</Rbox>
