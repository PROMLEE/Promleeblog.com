## はじめに

昨日も口座を見たのに、先月なぜあのETFを買ったのか、よく思い出せません。
スクリーンショットや数字はたくさんありますが、考えたことを記した文章がありません。
そんなときに必要なのは、さらに数字を集めることより、**同じ問いに短く答えた1枚の記録**です。
<br/>
「自分のポートフォリオの読み方」の最終回です。
これまでの7回の表を月次チェックリストにまとめます。
月次点検で、毎月何かを買う必要はありません。
**今回は取引しないという判断にも理由を残します。**

<Rbox>
この記事の残高、取引、点検日程は月次記録の方法を示す例です。実際の投資記録や推奨ではありません。
</Rbox>

## 点検前に同じ尺度をそろえる

身長を測るたびに違う定規を使うと、どれだけ伸びたかわかりにくくなります。
資産も、先月と今月で範囲、通貨、基準時刻をそろえて比べます。
今回も、一般口座A・一般口座B・長期投資口座Cの投資資産だけを合計し、生活費と緊急資金は除きます。
<br/>
月末という名前だけをそろえるのではなく、**いつ確認した価格と為替か**も記録します。
価格を確認できない銘柄や、あとから追加した残高があればメモします。
今月登録しただけの資産が、投資利益に見えないようにするためです。
開始残高は次の表にまとめます。

## 1,000万ウォンが1,100万ウォンになった1か月

開始は `2026-09-01 09:00`、終了は `2026-10-01 09:00` とし、韓国時間とウォン建てを使います。
**すべての資産価格が変わらず、分配金、費用、税は0**と仮定します。
<br/>
この1か月に起きたことを、次の取引と入出金に限ります。
金額は売買代金で、口座間の振替は投資範囲内の移動です。

| 時点 | 取引と入出金 | 全体への新規入金 |
| --- | --- | ---: |
| 9月15日 10:00 | Cで債券ETF Dを40万ウォン売却 | 0ウォン |
| 同日 10:10 | Cの現金40万ウォンをAへ振替 | 0ウォン |
| 同日 10:20 | AでETF Aを60万ウォン購入 | 0ウォン |
| 10月1日 08:30 | 投資範囲外からCに100万ウォン入金 | +100万ウォン |
| 同日 08:40 | Cで債券ETF Dを60万ウォン購入 | 0ウォン |
| 同日 08:45 | Cで金ETF Eを5万ウォン購入 | 0ウォン |

最初の株式の買付には、Aにあった現金20万ウォンと振り替えた40万ウォンを使いました。
最後の入金100万ウォンは、債券60万ウォン、金5万ウォンに使い、35万ウォンを現金で残しました。
結果は次のとおりです。

| 口座・資産 | 開始時の金額 | 今回の金額 |
| --- | ---: | ---: |
| A・米国株式ETF A | 300万ウォン | 360万ウォン |
| A・個別株X | 50万ウォン | 50万ウォン |
| A・ウォン現金 | 50万ウォン | 30万ウォン |
| B・米国成長株ETF B | 150万ウォン | 150万ウォン |
| B・韓国株式ETF C | 100万ウォン | 100万ウォン |
| C・ウォン建て債券ETF D | 200万ウォン | 220万ウォン |
| C・金ETF E | 50万ウォン | 55万ウォン |
| C・ウォン現金 | 100万ウォン | 135万ウォン |
| 合計 | **1,000万ウォン** | **1,100万ウォン** |

口座別ではAが440万ウォン、Bが250万ウォン、Cが410万ウォンです。
株式が60万ウォン増えたのは、**口座内の別の資金で買い増したから**です。値上がりはありません。
全体が100万ウォン増えたのは外部からの入金によります。
`1,100만 − 1,000만 − 100만 = 0원`（1,100万 − 1,000万 − 100万 = 0ウォン）なので、投資で増えた分はありません。

## これまでの表から持ち込む項目

残高以外に調べたことも加えます。
**今月の残高で計算する値**と、**メモとして残す基準**を分けます。

### 構成と目標比率

株式660万ウォン、債券220万ウォン、金55万ウォン、現金165万ウォンなので、現在比率は60%、20%、5%、15%です。
目標比率と一致しました。
すでに記録した取引を確認し、比率を理由とする追加売買は今回は不要と記録できます。
目標が自分の投資期間と資金事情に合っているかは、別に確認します。

### 同じ企業と為替

ETF Aに含まれるXは6%、ETF Bでは10%で、ほかの保有項目にはX株がありません。
ETF Aを買い増したため、Xの合計は `360만 × 6% + 150만 × 10% + 50만 = 86.6만 원`（360万 × 6% + 150万 × 10% + 50万 = 86.6万ウォン）です。
総額1,100万ウォンで割ると約7.87%です。
<br/>
前回の83万ウォンより金額は増えましたが、比率は8.3%より小さくなりました。
新たな入金で**総額も増えたため**です。
金額と比率を両方残すと、変化の理由がわかります。
<br/>
為替ヘッジなしで米国株に連動するA、B、Xは560万ウォン、全体の約50.91%です。
うち米ドルで取引するAとXは410万ウォン、約37.27%です。
ウォンで取引するBも為替の影響を受ける点を覚えておきます。
金ETF Eの5%は仕組みをまだ確認できていないため、*為替ヘッジを要確認*と記録します。
ここでは直接の為替影響を点検し、企業の輸出入などによる間接的な影響は別に考えます。

### 成績と下落時の試算

価格が変化しなかったので、入出金の影響を除いた `TWR` は0%、入金日を反映した `XIRR` も年率0%です。
指標名より大切なのは、**新たな入金100万ウォンを投資利益に数えなかったこと**です。
<br/>
現在の1,100万ウォンに、株式−30%、債券−5%、金+10%、現金0%を適用すると、203.5万ウォン減ります。
比率が同じでも投資額が増えれば、減り得る金額も増えます。
生活費、緊急資金、近い支出を見直す理由です。

## 自分の月次チェックリスト

次の表をコピーし、数値とメモを自分の記録に置き換えてみてください。
正解を選ぶ試験ではなく、**翌月の自分に残す引き継ぎメモ**です。

| 問い | 今月の記録 |
| --- | --- |
| どのお金を管理するか | 3口座の長期投資資産。生活費と緊急資金は除外 |
| いつ比較するか | 2026-09-01 09:00 → 2026-10-01 09:00、韓国時間・ウォン建て |
| 総額と入出金は | 1,000万 → 1,100万ウォン。外部からの純入金100万ウォン |
| 投資の結果は | 損益0ウォン、TWR 0%、XIRR年率0%。価格不変の仮定 |
| 資産構成は | 株式60%、債券20%、金5%、現金15%。目標と一致 |
| 企業の重複は | Xは86.6万ウォン、約7.87%。Aの6%、Bの10%を使って計算 |
| 為替は | 為替ヘッジなしの米国株は約50.91%。金ETF Eの仕組みは未確認 |
| 下落したら | −203.5万ウォン。必要資金と比較する |
| 現金を何に使うか | 165万ウォンを次の投資80万、決済準備50万、調整用35万に分ける |
| 今回の判断と理由は | 目標と一致するため追加売買なし。金ETFの説明書を確認する |
| 次にいつ点検するか | 2026-11-01。資金事情が変わったら前倒しで確認 |

わからない欄を無理に埋めず、**未確認の項目と確認する資料**を残します。

<Bbox>
最初からすべてを埋める必要はありません。
今月は総額、外部入出金、現金の用途を照合し、次回に企業の重複や為替を補ってもかまいません。
空欄を把握するだけでも、次の行動を決める助けになります。
</Bbox>

## PortRhythmの画面を一巡する

アプリも同じ順で一巡します。

- **口座管理と保有資産**
  口座の抜け、数量の誤り、現金の重複、価格の確認状況を見ます。
- **資産の割り当て**
  割り当て先を間違えたグループと、未分類の項目を確認します。
- **ポート比率**
  現在と目標を同じ範囲で比べます。
- **資産履歴**
  同じ期間の評価額の変化と外部入出金を照合します。

詳しい操作は[口座管理](https://www.promleeblog.com/blog/post/445-portrhythm-brokerage-account-guide)、[資産の割り当て](https://www.promleeblog.com/blog/post/439-portrhythm-asset-assignment-guide)、[比率の比較](https://www.promleeblog.com/blog/post/441-portrhythm-current-target-allocation-guide)、[資産履歴ガイド](https://www.promleeblog.com/blog/post/443-portrhythm-asset-history-guide)をご覧ください。
画面で確認した内容に計算結果と判断理由を添えれば、月次レポートが完成します。
<br/>
計画と数値が合っているのに、新しいニュースで売買したくなったら、理由を1文でメモします。
「資金を使う日が変わった」と「今日の株価が怖かった」は別の変化です。
記録を残すと、**判断した理由をあとで読み返せます。**

## おわりに

最初は口座をまとめるところから始めました。
今では、どこにいくらあるか、どの企業や為替に連動しているか、なぜ資金が増えたか、何を追加で調べるかを1枚で説明できます。
毎月の目標は、**同じ問いを同じ基準で確認し直すこと**です。
<br/>
[PortRhythm](https://pf.promleeblog.com/)を開き、今月の総額と外部入出金から記録してみてください。
次に「今回何をしたか、なぜしたか」を1文で残します。
取引をしなかったなら、その理由も大切な記録です。
