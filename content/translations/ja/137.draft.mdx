## はじめに
> この記事はExpo環境と[react-native-toast-message](https://www.npmjs.com/package/react-native-toast-message) 2.2.1を前提にしています。
React Native CLIでも同じ方法で使えます。

### トーストメッセージとは？
トーストメッセージは、スナックバーと呼ばれることもあり、通知やメッセージを表示する一般的な方法です。例えば、ボタンを押したユーザーに、操作が正常に完了したことを伝える際に役立ちます。

## 1. ライブラリのインストールと設定
まず、プロジェクトのルートディレクトリで次のコマンドを実行してインストールします。
```bash
npm install react-native-toast-message
```
### 1.1. Expo環境で設定する
プロジェクトの最上位ページを構成する `/app/_layout.tsx` に、次の設定を追加します。
```tsx title="app/_layout.tsx"
import Toast from 'react-native-toast-message';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <View>
      {children}
      <Toast />
    </View>
  );
}
```
### 1.2. React Native CLI環境で設定する
プロジェクトの最上位ページを構成する `app.tsx` に、次の設定を追加します。
```tsx title="app.tsx"
import Toast from 'react-native-toast-message';

export function App( props: any ) {
  return (
    <>
      {/* ... */}
      <Toast />
    </>
  );
}
```

## 2. トーストメッセージを表示する
表示したいコンポーネントで、次のように設定します。
```tsx title="app/index.tsx"
import Toast from 'react-native-toast-message';
import { Button } from 'react-native'

export function Page() {
  const showToast = () => {
    Toast.show({
      type: 'success',
      text1: 'Hello',
      text2: 'This is some something 👋'
    });
  }

  return (
    <Button
      title='Show toast'
      onPress={showToast}
    />
  )
}
```

## 3. トーストメッセージのスタイルを設定する
見た目を変更する場合は、トーストを宣言した `/app/_layout.tsx`（Expo）または `app.tsx`（React Native CLI）に、次の設定を追加します。
この例では、3種類のトーストを表示します。successとerrorは標準のトーストを変更して使い、tomatoToastは独自のトーストを使います。
```tsx title="app/_layout.tsx"
import Toast, { BaseToast, ErrorToast } from 'react-native-toast-message';

const toastConfig = { // config 변수 추가
  success: (props) => (
    <BaseToast
      {...props}
      style={{ borderLeftColor: 'pink' }}
      contentContainerStyle={{ paddingHorizontal: 15 }}
      text1Style={{
        fontSize: 15,
        fontWeight: '400'
      }}
    />
  ),
  error: (props) => (
    <ErrorToast
      {...props}
      text1Style={{
        fontSize: 17
      }}
      text2Style={{
        fontSize: 15
      }}
    />
  ),
	tomatoToast: ({ text1, props }) => (
    <View style={{ height: 60, width: '100%', backgroundColor: 'tomato' }}>
      <Text>{text1}</Text>
      <Text>{props.uuid}</Text>
    </View>
  )
}

export default function Page() {
  return (
    <View>
      {children}
      <Toast config={toastConfig} />
    </View>
  );
}
```

## 4. カスタムトーストを使う
表示したいコンポーネントで、次のように設定します。
```tsx title="app/index.tsx"
import Toast from 'react-native-toast-message';
import { Button } from 'react-native'

export function Page() {
  const showToast = () => {
    Toast.show({
			type: 'tomatoToast',
			props: { uuid: 'uuid example' }
    });
  }

	const showErrorToast = () => {
		Toast.show({
			type: 'error',
			text1: 'Error',
			text2: 'This is some something 👋'
		});
	}

  return (
    <Button	
      title='Show toast'
      onPress={showToast}
    />
  )
}
```
## おわりに
不要なモーダルや確認ダイアログを減らし、トーストメッセージで伝えると、ユーザーが作業を続けやすくなります。実装も手軽なので、筆者はトーストメッセージの利用をおすすめします。
