**今月の投資資金は100万ウォン。どこに入れましょうか？**
大きく上がったほうは今から買うのをためらい、下がったほうはさらに下がらないか心配になります。
口座を開いても、迷いが増えるばかりです。

<br/>

このとき、まず確認する基準が*目標比率*です。
「何が上がるか？」を考える前に、「自分のお金をどう分けると決めたか？」を確認します。
この記事では、二つのかごにお金を分ける例で、**資産配分とリバランス**を見ていきます。

<Bbox>
この記事では、目標比率、新しい投資資金で比率を調整する方法、許容誤差の三つを扱います。
</Bbox>

[PortRhythmを初めて使う方はサービス紹介から](https://www.promleeblog.com/blog/post/435-portrhythm-portfolio-asset-management-app)

<br/>

## 資産配分

投資資金を一つのかごに全部入れることも、複数のかごに分けることもできます。
株式、債券、現金など、**どこにどれだけ分けて置くかを決めること**が資産配分です。

<br/>

かごを選ぶ前に、お金の用途を考えてみてください。

- **いつ使うお金ですか？**
  近いうちに必要なお金と長期投資に回すお金では、使う時期が異なります。
- **どれほどの値動きに耐えられますか？**
  損失が出たとき、生活に必要な資金まで影響を受けるかを確認します。
- **なぜこの資産を入れたいのですか？**
  資産ごとに期待する役割を書き出します。
  米国SECの投資家教育サイトでも、投資期間とリスク許容度を資産配分の主な基準として説明しています。

[Investor.govの資産配分ガイド](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)

<Ybox>
かごが多くても、中身が違うとは限りません。複数のETFに同じ企業が重複して組み入れられていないか確認してください。
</Ybox>

ETFの本数だけで判断せず、実際の組入資産を確認することについても、上のInvestor.govの案内で取り上げています。

<br/>

PortRhythmでは、この管理用のかごを**ポート**と呼びます。
「米国株指数」「韓国株式」「現金」のように自分で名前を付けます。
目標比率も自分で決めます。アプリが最適な投資比率を推奨する仕組みではありません。

<br/>

## 目標比率を二つのかごに半分ずつ

AとBの二つのかごに、資金を**50%ずつ**分けると決めたとします。
今の状態を確認すると、次のようになっていました。

| かご | 現在の金額 | 現在比率 | 目標比率 |
| --- | ---: | ---: | ---: |
| A | 600万ウォン | 60% | 50% |
| B | 400万ウォン | 40% | 50% |
| 合計 | 1,000万ウォン | 100% | 100% |

<br/>

1,000万ウォンの半分は**500万ウォン**です。

- Aは目標より**100万ウォン多く**入っています。
- Bは目標より**100万ウォン少なく**なっています。

<Gbox>
目標比率は自分の計画の基準です。現在比率を並べて見ると、どこが多く、どこが不足しているかが分かります。
</Gbox>

<br/>

<Toggle title="現在比率はどう計算しますか？">
現在比率 ＝ かごの評価額 ÷ 全体の評価額 × 100
Aは600 ÷ 1,000 × 100＝60%です。
Bは400 ÷ 1,000 × 100＝40%です。
**現在の評価額**を基準に計算します。
</Toggle>

一度比率をそろえても、価格が異なる動きをすると、比率は変わります。
新しいお金を入れたり引き出したりしても変わります。
そのため、ときどきかごの中身を確認します。

## リバランス

現在比率を目標に合わせて調整することを**リバランス**と呼びます。
Aが600万ウォン、Bが400万ウォンの状態を、再び50対50にするにはどうすればよいでしょうか。
二つの方法を比べます。

### 売却してから購入する

Aから100万ウォンを取り出し、Bに移します。
投資では、Aの資産を売り、その代金でBの資産を買うことに当たります。

| かご | 調整前 | 移す金額 | 調整後 |
| --- | ---: | ---: | ---: |
| A | 600万ウォン | −100万ウォン | 500万ウォン |
| B | 400万ウォン | +100万ウォン | 500万ウォン |

**500万ウォン対500万ウォン**となり、再び50対50です。
総額はそのままで、お金の置き場所だけが変わりました。
*この例では、価格変動と取引費用を除いています。*

<br/>

### 新規資金で購入する

「今持っている資産は売りたくないのですが？」
その場合は、新しい投資資金で不足している側を補う方法を検討できます。
Bに100万ウォンを加えてみます。

| かご | 調整前 | 新たに入れる金額 | 調整後 |
| --- | ---: | ---: | ---: |
| A | 600万ウォン | 0ウォン | 600万ウォン |
| B | 400万ウォン | +100万ウォン | 500万ウォン |

ここでは**600万ウォン対500万ウォン**になり、まだ半分ずつではありません。

<br/>

総額が1,000万ウォンから**1,100万ウォン**に増えたためです。
現在比率はAが約54.55%、Bが約45.45%です。
Aを600万ウォンのままにするなら、Bも600万ウォンになって初めて半分ずつです。
この例で50対50にするには、Bに**200万ウォン**を入れます。

<Bbox>
新しいお金を入れると、全体の金額も増えます。もともとの不足額を補うだけでは、目標比率にぴったり合うとは限りません。
</Bbox>

<br/>

<Toggle title="資金を追加した後の目標額を計算する">
新しい目標額 ＝（現在の総評価額 ＋ 追加資金）× 目標比率
100万ウォンを加えると、総額は1,100万ウォンです。
50%に当たる新しい目標額は、それぞれ550万ウォンです。
200万ウォンを加えると、総額は1,200万ウォンです。
それぞれ600万ウォンなら、50対50になります。
</Toggle>

リバランスは、計画したリスク水準を管理するための手順です。
目標に合わせても、収益が上がることや、損失を防げることは保証されません。
取引費用と税金も考慮します。
[Vanguardのリバランスガイド](https://investor.vanguard.com/investor-resources-education/portfolio-management/rebalancing-your-portfolio)

<br/>

## 許容誤差

目標が20%で、現在比率が20.1%だとします。
これほど小さな差まで毎回取引で解消するのは手間がかかります。
そこで、**どの程度まで差を許容するか**を決めます。
PortRhythmでは、これを**パーセントポイント単位の許容誤差**として設定します。

<br/>

目標20%、許容誤差5ポイントなら、許容範囲は**15〜25%**です。

| 現在比率 | 目標との差 | 判定 |
| --- | ---: | --- |
| 23% | +3ポイント | 範囲内 |
| 25% | +5ポイント | 境界値で範囲内 |
| 28% | +8ポイント | 範囲外。調整を検討 |
| 14% | −6ポイント | 範囲外。調整を検討 |

アプリは、差の大きさが許容誤差を**超えた**ポートを調整の検討対象にします。
範囲を外れたら、データと投資計画を確認し、取引するかを判断します。

<Ybox>
%pは二つの比率の差を表すパーセントポイントです。20%から25%になれば+5ポイントです。「20%の5%」に当たる1ポイントとは異なります。
</Ybox>

## 構成比を確認する

「Aが目標より多いので、大きな利益が出たということですよね？」
そうとは限りません。
Aの価格が下がっていても、Bがさらに大きく下がれば、Aの比率は上がることがあります。
**収益率は取得価格との比較、構成比は全資産に占める割合**です。

<br/>

次の順に確認してください。

- **数字は合っていますか？**
  資産の漏れや重複登録、数量、価格、為替レートを確認します。
- **保有する理由は今も同じですか？**
  比率が不足しているから買うと決める前に、その資産を入れた理由を確認します。
- **目標は今も適切ですか？**
  お金を使う時期や生活状況が変わったら、目標そのものを見直します。
  投資期間とリスク許容度は、状況によって変わることがあります。

[Investor.govの資産配分ガイド](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)

<Toggle title="構成比はいつ確認すればよいですか？">
決まった日に確認する方法と、比率の差が基準を超えたときに確認する方法があります。
二つを組み合わせることもできます。
[Vanguardのリバランス方法](https://investor.vanguard.com/investor-resources-education/portfolio-management/rebalancing-your-portfolio)
確認時期、許容誤差、追加投資資金を使う基準を自分の計画に書いておくと、次の判断に使えます。
</Toggle>

## PortRhythmでの操作

### 目標設計

ポート名と目標比率を入力します。
目標の合計を100%にし、許容誤差も決めます。

<Img src="/portrhythm-allocation-strategy-20261008.webp" width={800} alt="ポート名、目標比率、許容誤差を設定する画面"/>

<br/>

### 資産割り当て

保有資産を登録し、それぞれが属するポートを指定します。
現金も管理対象にしたなら、現金も登録します。
登録漏れがあれば、アプリが計算した総額と実際の投資資産の金額が異なります。

<br/>

### 構成比の比較

<Img src="/portrhythm-introduction-composition-20261008.webp" width={800} alt="現在比率と目標比率を並べて確認する画面"/>

目標と現在の差を確認します。
未分類の資産や価格未確認の銘柄があれば、先に調べます。

<br/>

### リバランスを検討する

**売却してから購入**、または**新規資金で購入**を選びます。
登録済みの株式と購入候補を基準に、1株単位の数量を検討します。

<Img src="/portrhythm-introduction-rebalance-20261008.webp" width={800} alt="予想取引数量と調整後の構成比を確認する画面"/>

今回調整しない銘柄は除外できます。
1株の価格と予算によって、目標との差や残余資金が残ることがあります。
暗号資産では売買数量を自動で求めず、超過額や不足額を自分で検討します。

<br/>

### 取引後の記録

取引は証券会社や取引所で自分で行います。
費用と実際の約定条件を確認し、取引後にアプリの保有数量を修正します。
外部から入れたお金や外部に出したお金は、入出金にも記録します。

<Gbox>
目標を決める → 資産を割り当てる → 構成比を比べる → 調整を検討する → 記録する。次の投資資金が入ったら、この流れをまた使います。
</Gbox>

<br/>

今月の投資資金をどこに入れるか決める前に、自分のかごを開いてみてください。
**どこが不足し、なぜ補いたいのか、補うと比率がどう変わるのか**を確認する基準になります。
