*PortRhythmは、投資家が自分の資産を効率よく管理するためのサービスです。*
**韓国株のアプリ、海外株のアプリ、暗号資産のアプリ。**
残高を確認するだけで、3つのアプリを行き来していました。
各口座にいくらあるかはわかりますが……。
> 「結局、自分のお金は今、どこにいくら入っているんだろう？」
<br/>

今月の投資資金も入りました。
最近上がった銘柄を買い増しますか？
それとも下がった銘柄を買いますか？
その前に、**最初に自分で決めた投資配分**を確認したいと思いました。
この疑問から作ったのが、**PortRhythm（ポートリズム）**です。
<Bbox>
分散した資産をひと目で把握し、次の配分は自分の方針で決める。
</Bbox>
韓国・米国株、ETF、暗号資産、現金をまとめて見られる、**投資計画と現在の配分を比較する資産管理Webアプリ**です。
[PortRhythmを見る](https://pf.promleeblog.com)
<br/>
## 資産ダッシュボード
「米国ETFはいくらだっけ？ 現金も合わせると？」
口座ごとに確認していた数字を、1か所で見られます。
米ドル建ての資産も、適用した為替レートで韓国ウォンに換算して合計します。
<Img src="/portrhythm-introduction-dashboard-20261008.webp" width={800} alt="評価額の合計と保有資産をまとめて表示するPortRhythmのダッシュボード"/>
- **資産全体の金額**
  株式、暗号資産、現金の評価額を韓国ウォンでまとめて表示します。
- **値動きのあった銘柄**
  全体の損益と当日の損益を切り替えて表示します。
- **複数の口座にある同じ株式**
  銘柄別にまとめて表示し、口座別の明細も確認できます。
<br/>
価格は定期的に取得します。
保有数量と取得単価は自分で管理します。対応する残高画面のスクリーンショットは、OCRで入力を補助できます。

## 目標配分を設定する
最初は「このグループには20%だけ投資しよう」と決めました。
ところが、ある日確認すると28%になっていました。
買い増さなくても、価格が動けば配分は変わります。
<br/>
PortRhythmでは、資産をまとめる**ポート**という管理用のグループを作ります。
「米国株指数」「韓国株」「現金」のように名前を付け、目標配分を決めます。
<Img src="/portrhythm-introduction-composition-20261008.webp" width={800} alt="現在の配分と目標配分を並べて比較する画面"/>
**どこが計画より多く、どこが足りないか**を、グラフと数値で確認します。
<Gbox>
今日値上がりしたかに加えて、資産が自分の計画どおりに配分されているかも確認してみましょう。
</Gbox>
*ポートの名前と配分は自分で決めます。画面の配分は説明用の例です。*
<br/>
## リバランス
目標に届いていないグループが見つかったら、次に知りたいことがあります。
> 「今回の投資資金で、どのくらい不足を埋められるだろう？」
資産配分を計画に合わせて調整することを**リバランス**と呼びます。
<br/>
PortRhythmでは、状況に応じて2つの方法を検討できます。

| 現在の状況 | 選ぶ方法 |
| --- | --- |
| 保有株式を一部売却し、別のグループの不足を埋めたい | **売却後に購入** |
| 保有資産はそのままで、新たな資金を投じたい | **新規資金で購入** |

<Img src="/portrhythm-introduction-rebalance-20261008.webp" width={800} alt="株式の取引予定数量と調整後の配分を確認する画面"/>
登録済みの株式や購入候補をもとに、**何株取引するか、配分がどう変わるか、資金がいくら残るか**を確認します。
今回は動かしたくない銘柄を除外することもできます。
<Ybox>
**取引前の検討を助ける画面です。** 実際の注文は証券会社や取引所で行い、取引費用と約定価格を確認してください。
</Ybox>
<Toggle title="取引数量はどこまで計算されますか？">
株式は1株単位で計算します。
予算や株価によっては目標配分との差が残ったり、資金が余ったりします。
暗号資産は取引数量を自動計算せず、過不足の金額を確認して自分で検討します。
</Toggle>

## 投資記録
資産が増えるとうれしいものです。
ただ、投資資金を追加したなら、増加分をすべて利益とは考えられません。
**日ごとの評価額の推移と入出金の記録**を一緒に残し、資産規模の変化を確認します。
<br/>
取引を終えたら、実際の保有数量と取得単価も更新します。
次の配分チェックでは、その情報を使います。
> **計画を立てる → 資産をまとめる → 配分を確認する → 調整を検討する → 記録する**
このサイクルを無理なく繰り返せるようにすることが、PortRhythmの目標です。
<br/>
## 主な資産から始める
最初からすべての資産を入力しようとすると、始めるのが大変です。
**いくつかのポートと主な保有資産から登録してみましょう。**
- **ログインする**
  KakaoまたはNAVERのアカウントで始めます。
- **自分のグループを作る**
  ポート名と目標配分を決めます。
- **資産を追加する**
  保有資産を登録し、ポートに割り当てます。
- **並べて見る**
  現在の配分と目標配分を比較します。
<Ybox>
一部の資産だけを入力した場合、表示される配分も登録済みの資産が対象です。実際に投資を判断する前に、管理対象の資産を漏れなく確認してください。
</Ybox>
