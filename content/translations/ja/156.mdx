## はじめに
Webで使う画像や動画は、性能や画質の都合で別の形式に変換することがあります。
変換を手作業で繰り返すのは面倒で、時間もかかります。
この記事では、Macのフォルダアクションでファイル変換を自動化する方法を紹介します。
私はブログ用にMP4、GIF、PNGをWebPへ変換する処理を自動化し、作業時間を短縮しました。

## 環境の準備
Homebrewがインストールされた環境で、まずffmpegをインストールします。
Homebrewがまだの場合は[Homebrewのインストール方法](/blog/post/119-homebrew)を参考にしてから、次のコマンドを実行してください。
```bash
brew install ffmpeg
```
任意の場所にフォルダーを作成し、名前を付けます。
私は最初に、デスクトップへMP4からWebPに変換するための`mp4_to_webp`フォルダーを作成しました。

<Rbox>フォルダアクションの設定後はフォルダー名を変更できなくなります。名前は慎重に決めてください。</Rbox>
Finderの「アプリケーション」から`Automator`を起動し、`폴더 적용 스크립트`（フォルダアクション）を選択します。

先ほど作成したフォルダーを選び、`선택된 finder 항목 가져오기`（選択したFinder項目を取得）を追加します。

「ユーティリティ」から`쉘 스크립트 실행`（シェルスクリプトを実行）を追加し、入力の受け渡し方法を「引数」に変更します。

これで準備は完了です。

## スクリプトの作成
以下の例では、変換後のファイルを元ファイルを削除したうえで`/Users/{사용자명}/Documents`に保存します。
必要に応じて保存先を変更してください。
### 動画からWebPへ（MP4、MOV）
```bash
for f in "$@"; do
    /opt/homebrew/bin/ffmpeg -n -loglevel error -i "$f" -vf "fps=15,scale=720:-1:flags=lanczos" -loop 0 "/Users/promlee/Documents/$(date +"%y%m%d-%H%M%S").webp"
    rm -f "$f"
done
```
次の表では、スクリプトで使うコマンドとオプションを説明します。
| コマンド | 説明 |
| --- | --- |
| for f in "\$@" | 入力された各ファイルを順番に処理するループです。 |
| /opt/homebrew/bin/ffmpeg | Homebrewでインストールしたffmpegを実行します。 |
| -n | 同じ名前のファイルがある場合に上書きしません。 |
| -loglevel error | エラーメッセージだけを表示し、その他のログを省きます。 |
| -i "\$f" | 変換対象の動画ファイルを入力します。 |
| -vf | 動画フィルターを指定します。 |
| "fps=15" | 1秒あたり15フレームに変換し、フレーム数を減らして容量を抑えます。 |
| "scale=720:-1" | 幅を720pxにし、高さは縦横比を維持して自動計算します。 |
| "flags=lanczos" | 高品質なLanczosリサンプリングを使います。 |
| -loop 0 | アニメーションWebPを無限ループさせます。 |
| rm -f "\$f" | 変換後に元の動画ファイルを削除します。 |

### PNGからWebPへ
```bash
for f in "$@"; do
    /opt/homebrew/bin/cwebp -q 70 "$f" -o "/Users/promlee/Documents/$(date +"%y%m%d-%H%M%S").webp";
    rm -f "$f"
done
```

### 動画からGIFへ
```bash
for f in "$@"; do
    /opt/homebrew/bin/ffmpeg -n -loglevel error -i "$f" -vf "fps=15,scale=720:-1:flags=lanczos" "/Users/promlee/Documents/$(date +"%y%m%d-%H%M%S").gif";
    rm -f "$f"
done
```
