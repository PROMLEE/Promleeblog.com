## はじめに

「20%くらい下がっても耐えられます。」
そう言うときと、口座から200万ウォンが減ったのを見るときでは、感じ方はかなり違います。
数字の横に、旅行代や数か月分の貯金が思い浮かびます。
**投資リスクは、パーセントを自分のお金の額に直すと見えやすくなります。**
<br/>
[第4回](https://www.promleeblog.com/blog/post/461-portfolio-reading-return-cash-flows)では、追加で入金した効果と投資で得たお金を分けました。
今回は「いくら増えたか」の横に、「途中でいくら下がっても生活と計画を守れるか」と書きます。
作るのは、**損失額、必要な資金、次の行動を記したチェックリスト**です。

<Rbox>
本文の資産とリターンは計算例であり、実際の成績や将来の見通しではありません。
計算した損失は、将来の損失の上限を示すものではありません。
</Rbox>

## 同じ到着点、違う乗り心地

投資の過程を車での旅にたとえます。
行き先が同じでも、平坦な道と急な下り坂のある道では疲れ方が違います。
次の2つの経路は、どちらも100から始まって110で終わります。

| 経路 | 開始 | 途中 | 終了 | 開始時点からの変化 |
| --- | ---: | ---: | ---: | ---: |
| 経路A | 100 | 120 | 110 | +10% |
| 経路B | 100 | 80 | 110 | +10% |

どちらも同じ期間のウォン建て資産価値で、入出金の影響を除き、分配金を含めます。
各区間は、次の端点まで一方向に動くと仮定します。
<br/>
経路Aは最高値120から110へ約8.3%下がりました。
経路Bは100から80へ20%下がってから回復しました。
最終的にはどちらも10%増えましたが、途中で口座を閉じたくなった瞬間は違うかもしれません。

## 最も深かった下落

**直前までの最高値からどれだけ下がったか**を、ドローダウンと呼びます。
定めた期間で最も深いドローダウンが最大ドローダウンで、英語の略称は `MDD` です。
経路Bは `80 ÷ 100 − 1 = −20%` なので、最大の下落幅は20%です。
過去の最高値とその後の価値を比べる方法は、CFA Instituteの説明でも確認できます。
[CFA Instituteのドローダウンの説明](https://rpc.cfainstitute.org/research/cfa-digest/2018/01/dig-v48-n1-3)
<br/>
ここで出金と損失を混同しないようにします。
1,000万ウォンから生活費に200万ウォンを出金し、800万ウォンになったなら、その差だけで投資により20%を失ったとはいえません。
反対に、入金すると損失が残高に隠れることもあります。
そのため、ドローダウンは**入出金の影響を除いた価値の推移**で確認します。
<br/>
実際のデータでは、観測の間隔も重要です。
月末だけを見ていたら、月中のより深い下落を見落とす可能性があります。
比較では、期間、観測間隔、通貨、配当の扱いをそろえます。
過去に経験した下落と、将来耐えられる損失は分けて考えます。

## 1,000万ウォンで計算してみる

株式600万ウォン、債券200万ウォン、金50万ウォン、現金150万ウォンとします。
ここに次の変化率を適用します。

| 資産 | 現在の金額 | 仮定した変化 | 増減額 |
| --- | ---: | ---: | ---: |
| 株式 | 600万ウォン | −30% | −180万ウォン |
| 債券 | 200万ウォン | −5% | −10万ウォン |
| 金 | 50万ウォン | +10% | +5万ウォン |
| 現金 | 150万ウォン | 0% | 0ウォン |
| 合計 | **1,000万ウォン** | **−18.5%** | **−185万ウォン** |

変化率は分配金込みのウォン建てとし、外部との入出金、費用、税は0とします。
`−180만 − 10만 + 5만 = −185만 원`（−180万 − 10万 + 5万 = −185万ウォン）なので、残るのは**815万ウォン**です。
株式の損失を見て「債券と金がすべて埋めてくれるだろう」と考える前に、資産全体を足し合わせます。

<Img src="/portfolio-reading-05-drawdown-risk-20261017.webp" width={750} height={500} alt="株式−180万ウォン、債券−10万ウォン、金+5万ウォンを合計し、1,000万ウォンが815万ウォンになる計算"/>

185万ウォン減ったと想像したとき、何が気になりますか。
近く使うお金が不足するか、不安で眠れそうにないか、次の積立を続けられるかを書きます。
「耐えられそうだ」という気持ちと、**実際にお金が必要で売らざるを得ない状況**は分けて確認します。
適切な資産配分は、投資期間と、損失を負担できる能力や意思によって異なります。
[Investor.govの資産配分の説明](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)

株式がさらに下がる場合や、債券と金も一緒に下がる場合を入れると、どの変化に自分の資金が大きく影響されるか比べられます。

## 一緒に値下がりする資産を確認する

傘を3本用意しても、全部を同じ場所に置けば、そこへ行けない日には役立ちません。
投資も、銘柄名が複数あるだけで、リスクが均等に分かれるわけではありません。
[第2回](https://www.promleeblog.com/blog/post/459-portfolio-reading-etf-overlap)で見た、複数のETFに同じ企業が入っている例もその1つです。
<br/>
異なる資産のリターンがどれだけ似た動きをするかを表すのが、**相関関係**です。
最初は「この2つは同じ理由で一緒に揺れることがあるか」と問うだけでも十分です。
同じ業種や地域の資産が一緒に影響を受け得ることを、FINRAも集中リスクとして説明しています。
[FINRAの集中リスクの説明](https://www.finra.org/investors/insights/concentration-risk)
<br/>
数値で比較するなら、同じ期間、同じ間隔、同じ通貨のリターンを使います。
過去に連動が弱かったとしても、その関係が今後も続くとは限りません。
先ほどの表でも、債券が株式とともに下がるケースを計算しました。
**複数の資産を持つことと、どんな状況でも損失が出ないことは別です。**

## PortRhythmからチェックリストへ

PortRhythmの**ポート比率 → 現在**で、大きいグループを確認します。
ただし「米国指数」グループに現金を入れていれば、すべてが株式とは限りません。資産の割り当ても確認します。
画面の読み方は[現在比率と目標比率のガイド](https://www.promleeblog.com/blog/post/441-portrhythm-current-target-allocation-guide)をご覧ください。
<br/>
確認した金額に変化率を掛け、損失額と必要な資金を次の表に書きます。

| 問い | 自分のメモに書くこと |
| --- | --- |
| いくら減ると仮定したか | 185万ウォン。自分の金額で再計算 |
| 近いうちに使うお金はあるか | 金額、必要な日付、別に保管した場所 |
| 生活費と緊急資金を別にしているか | 投資総額に混ぜていないか確認 |
| ほかに何を確認するか | 重複する企業、為替、現金の用途など |
| 最初に何をするか | 残高の照合、必要資金の分離、目標の見直しなど |

「株価が下がれば必ず買う」のように資金事情を無視したルールより、必要資金を先に確かめるルールを書きます。
売買を決められない日でも、**確認する資料と次の点検日を残せば、点検は進んでいます。**

## おわりに

今回は「どれだけ上がるか」より、「185万ウォン減っても生活と計画を守れるか」を考えました。
過去の最も深い下落と、今後の想定損失を区別し、株式だけでなくすべての資産の金額を足しました。
今日の成果は、**自分のお金に換算した下落リスクのチェックリスト**です。
<br/>
[PortRhythmの現在比率](https://pf.promleeblog.com/?view=composition)から大きいグループを1つ選び、まず計算してみてください。
次回は、この点検をもとに目標比率を決め、ずれた比率を戻す方法を見ます。
毎回売買する代わりに、新しく入れる資金で合わせられるかも計算します。
