## はじめに
GitHubリポジトリからGitHub Actionsを使い、静的ファイルを自動でデプロイする方法を紹介します。
S3バケットとリポジトリは、すでに作成されているものとします。
## AWSの設定
### IAMユーザーの作成
AWSへログインし、[IAM](https://us-east-1.console.aws.amazon.com/iam/home)（Identity and Access Management）を開きます。
ユーザー一覧から、ユーザーを作成するボタンをクリックします。
名前を決めて、次へ進みます。
<Img src="/posts/240622-183516.png" width={500} />
権限設定では、ポリシーを直接アタッチし、`AmazoneS3FullAccess`と`CloudFrontFullAccess`を選択します。
<Img src="/posts/240622-191634.png" width={500}/>
<Img src="/posts/240622-192502.png" width={500}/>
次へ進んで、ユーザーの作成を完了します。
作成後、ユーザーのセキュリティ認証情報から、アクセスキーを作成します。
「その他」を選び、タグも入力します。
<Img src="/posts/240622-192812.png" width={500}/>
<Img src="/posts/240622-192854.png" width={500}/>
作成されたアクセスキーは、大切に保管してください。
**絶対に**公開された場所へ置いてはいけません。
<Img src="/posts/240622-192928.png" width={500}/>

## GitHub Actionsの設定
### GitHub Secretsの追加
リポジトリの`Settings`、`Security`、`Secrets and variables`を開き、`New repository secret`をクリックします。
<Img src="/posts/240622-193058.png" width={500}/>

`AWS_ACCESS_KEY_ID`と`AWS_SECRET_ACCESS_KEY`を追加します。
<Img src="/posts/240622-193252.png" width={500}/>
<Img src="/posts/240622-193336.png" width={500}/>

### ymlファイルの作成
`.github/workflows`に、`deploy.yml`を作成します。
```yml showLineNumbers title="./.github/workflows/deploy.yml"
name: Main CI

on:
  push:
    branches:
      - main
jobs:
  push-to-s3:
    name: Push to S3
    runs-on: ubuntu-20.04

    # 레포지토리에 접근하여 CI서버로 코드를 내려받음
    steps:
    - name: Checkout
      uses: actions/checkout@v3

    # 캐시 사용
    - name: Cache dependencies
      uses: actions/cache@v3
      with:
        path: |
          ./posts
        key: ${{ runner.os }}-posts-${{ hashFiles('**/posts/**') }}

    # aws에 접근하기 위한 권한 설정
    - name: Configure AWS credentials
      uses: aws-actions/configure-aws-credentials@v1
      with:
        aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID }}
        aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
        aws-region: ap-northeast-2

    # s3에 파일 업로드
    - name: Upload to S3
      run: |
        aws s3 sync \
          ./posts s3://promleeblog-cdn
			# file path, s3 버킷 이름
```
追加してmainブランチへpushすると、GitHub Actionsが実行され、S3バケットへファイルがアップロードされます。
