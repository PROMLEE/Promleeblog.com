## はじめに
> この記事はFlutter 3.24を基準に書かれています。
Flutterのインストールが完了しているものとして進めます。

Flutterでページ間を移動できるようにする際に、私がよく使う初期設定の方法を紹介します。
開発を始める前に、目標と条件を決め、必要なパッケージをインストールします。

## 目標・条件を決める
<Bbox>開発の前に、Flutterが標準で提供するページ遷移に加えて、次の条件を設定します。</Bbox>
1. ログインページを作り、ログイン後にだけ、ほかのページへ移動できるようにします。*FlutterSecureStorage*を使います。
   [➡️ リンク：ログインページの分岐 (FlutterSecureStorage)](/blog/post/125-login-branch-paging)
2. ログインページにはナビゲーションバーを表示せず、ログイン後は*すべてのページ*に表示します。
   [➡️ リンク：下部ナビゲーションバーを設定する](/blog/post/126-bt-navigation-paging)
3. 各タブの配下にさらに別のページがあり、深い階層のページを表示中にタブを選んだ場合は*そのタブ*へ移動します。
   ただし、すでに選択しているタブをもう一度選んだときは、そのタブの*最上位ページ*へ戻るようにします。
   [➡️ リンク：ナビゲーションバーのタブイベントを設定する](/blog/post/127-nav-tabevent-paging)
4. ログイン以外のすべてのページで、下部ナビゲーションバーを使わなくても、*別のボタン*でほかのタブへ移動できるようにします。
   [➡️ リンク：ナビゲーションバーのタブイベントをウィジェットから使う](/blog/post/128-nav-tabevent-widget-paging)

## Flutterプロジェクトの作成と実行
Flutterプロジェクトを作成します。
```bash
flutter create navigationbar_example
```
作成したプロジェクトを実行します。
```bash
cd navigationbar_example
flutter run
```
<Img src="/posts/250113-125205.png" width={200} alt="プロジェクトが正常に実行されていることを確認できます。"/>

## FlutterSecureStorageとGetのインストール
ログイン情報の保存用に、[FlutterSecureStorage](https://pub.dev/packages/flutter_secure_storage)をインストールします。
[Get](https://pub.dev/packages/get/install)は、状態管理、ルーティング、ダイアログなどを簡単に扱えるようにするパッケージです。
```bash
flutter pub add flutter_secure_storage get
```
pubspec.yamlにパッケージが追加されていることを確認します。
```yaml
dependencies:
	flutter_secure_storage: ^9.2.4
	get: ^4.6.6
```
