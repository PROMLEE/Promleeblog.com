**「資産はすべて登録したのに、投資のかごがまだ空なのはなぜですか？」**

[第3回](https://www.promleeblog.com/blog/post/438-portrhythm-asset-registration-guide)で株式、ETF、暗号資産、現金を登録しました。
これで、何をどれだけ持っているかがアプリに記録されています。
次に、その資産を**どの投資のかごで管理するか**を指定します。
買ってきたものを冷蔵庫や戸棚にしまう作業に似ています。
資産登録は品物を持ち帰る段階、**資産割り当ては置き場所を決める段階**です。
今回はPCとモバイルで資産割り当て画面を操作します。
手動割り当て、自動分類ルール、未分類の資産、暗号資産と現金の割り当て、保存の確認、3D表示を見ていきます。

<br/>

<Bbox>
今回の目標は、資産ごとに管理するポートを決めることです。分類が済むと、ポート別の現在比率と目標比率を比較できます。ポートの選択はアプリ内での管理用です。証券口座間の移管や実際の注文は行われません。
</Bbox>

[PortRhythmを開く](https://pf.promleeblog.com)

<br/>

## ポート名と保有銘柄を区別する

ポートは、自分で決めた**管理用のかご**です。
株式、ETF、暗号資産、現金は、そこに入れる**保有資産**です。

| 区分 | アプリで決めること | 例 |
| --- | --- | --- |
| 目標設計 | どのかごをどの比率で管理するか | 指数50%、個別株30%、現金20% |
| 資産登録 | 実際に保有している銘柄、数量、金額 | ETF10株、個別株5株、現金50万ウォン |
| 資産割り当て | 各資産をどのかごに集計するか | ETFは指数のかご、個別株は個別株のかご |
| ポート構成比 | 実際の金額が目標からどの程度離れているか | 指数のかごの現在比率と目標比率を比較 |

目標設計で「金」というポートを作っても、金ETFは自動で追加されません。
金ETFを登録した場合も、どのポートに入れるかをルールまたは手動で指定します。

<br/>

#### 始める前に確認する三つのこと

- **目標ポートフォリオを保存しましたか？**
  まだなら、先に[第2回 目標ポートフォリオの設定](https://www.promleeblog.com/blog/post/437-portrhythm-portfolio-setup-guide)の手順をたどります。
- **保有資産を登録しましたか？**
  まだなら、[第3回 資産登録](https://www.promleeblog.com/blog/post/438-portrhythm-asset-registration-guide)で数量と金額を入力します。
- **各ポートに何を入れるか決めましたか？**
  例えば「指数のかご」には指数ETF、「個別株のかご」には個別企業の株式を入れる、というように、自分の管理基準を簡単に整理します。

この記事の画面はローカルのテストアカウントで撮影しました。
画像にある米国株指数、韓国株指数、優良株、金、ビットコインは、ポート名の例です。
資産や比率は投資の推奨ではありません。撮影用に変更した割り当ては保存せず、元に戻しました。

## 1. 資産割り当てメニューを開く

#### 1.1. PC

左の**ポートフォリオ → 資産割り当て**を押します。
画面のタイトルが「資産割り当て」になっていることを確認してください。
下にある**自分の資産割り当て**に、登録した資産が表示されます。
欄が閉じていたら、見出しを押して開きます。

<Img src="/portrhythm-assignment-desktop-overview-20261008.webp" width={800} alt="PC版の資産割り当て画面に表示された資産一覧と、株式・暗号資産・現金のポート選択欄"/>

<br/>

#### 1.2. モバイルではすべてのメニューから開く

下部の**すべて → 資産割り当て**に進みます。
ポートの選択欄は、資産名の下に表示されます。
PCでは横にある選択欄が、モバイルでは下に並びます。

<Img src="/portrhythm-assignment-mobile-direct-20261008.webp" width={350} alt="モバイル版の資産割り当てでAppleを手動・優良株に設定した例と、変更を保存するボタン"/>

一覧が長ければ下にスクロールして、暗号資産と現金まで確認してください。
変更があると、画面上部とモバイルの下部に**変更を保存**ボタンが表示されます。

<br/>

#### 1.3. 一覧で最初に確認する情報

資産名と併せて、銘柄コード、出典、評価額などを確認できます。
同じ株式が複数口座の保有項目として表示されることもあります。
**分類する資産が合っているか確かめてから、ポートを選んでください。**
名前の似たETFを取り違えないように、コードも照合します。
数量や取得単価に誤りがあれば、**資産編集**に進みます。
未登録の株式やETFは、先に**スクリーンショットの取り込み**で登録します。
保有情報の入力と、資産の割り当ては別々に行います。

<br/>

#### 1.4. 変更を保存する

変更を保存すると、資産割り当てが完了します。
保存した内容は後から修正できます。

<br/>

## 2. 株式の自動と手動の選択を理解する

株式・ETFのポート選択欄には、次の項目があります。

| 選択項目 | 意味 | 結果 |
| --- | --- | --- |
| 自動・ポート名 | 銘柄コードのルールに従う | ルールで指定したポートに集計 |
| 自動・未分類 | 自動割り当てだが、一致するルールがない | どのポートにも集計しない |
| 手動・ポート名 | この保有項目のポートを手動で指定 | 自動ルールより手動選択が優先 |
| 手動・未分類 | この保有項目を手動で未分類に指定 | 一致するルールがあっても未分類を維持 |

**「自動」は、銘柄名から投資上の性質を判定する機能ではありません。**
登録した**市場と銘柄コードのルール**に従って割り当てます。

<br/>

#### 2.1. 割り当ての優先順位

> 株式は、手動で割り当てていればその選択に従い、自動に設定していれば銘柄コードのルールに従います。

例えば、AAPLを「個別株のかご」に送る自動ルールがあるとします。
その保有項目を別のかごに手動で指定すると、手動で選んだほうに集計されます。
自動ルールを変えても、手動で指定した項目はそのままです。
ルールを変更したのに銘柄が移らないときは、この違いを確認します。

<br/>

## 3. 株式とETFを手動で割り当てる

最初は手動割り当てから試すと分かりやすくなります。
銘柄が少ない場合や、一部の保有項目だけ例外として管理する場合に便利です。

- **該当する銘柄を探します。**
  名前とコードを確認します。同じ銘柄が複数表示されたら、一つずつ確認します。
- **ポートの選択欄を開きます。**
  「手動・ポート名」の選択肢から目的のかごを選びます。
- **ほかの資産も割り当てます。**
  一つの銘柄を選んでも、ほかの銘柄が一緒に移るわけではありません。
- **変更を保存します。**
  保存完了を確認してから、別の画面に移動します。

<Img src="/portrhythm-assignment-desktop-direct-20261008.webp" width={800} alt="PC版でAppleの保有項目を手動・優良株に割り当て、変更を保存するボタンが表示された画面"/>

<br/>

#### 3.1. Appleをかごに入れる例

画像では、Appleの選択を**手動・優良株**に変えました。
これはテストアカウントでの分類例です。Appleを必ずその名前のポートに入れる必要はありません。
自分で作った「個別株」「長期保有」「管理用のかごA」などから、意図に合うものを選びます。
**韓国市場か米国市場かだけで、ポートが決まるわけではありません。**
例えば韓国上場の米国株指数ETFは、韓国の銘柄ですが、自分で決めた「米国株指数」のかごで管理できます。
登録市場は銘柄の識別と価格取得に使い、ポートは自分の管理基準で決めます。

<br/>

#### 3.2. 同じ株式を二つの口座で保有している場合

同じ銘柄を一般口座と別の口座でそれぞれ保有することがあります。
手動割り当ては**保有項目ごとの選択**なので、二つを別々のポートに入れられます。
一方、同じコードの保有項目をいつも一つのポートに集めたい場合は、自動ルールが便利です。
ルールは口座名ではなく、市場と銘柄コードを基準に適用します。

<Ybox>
**一つの保有項目を二つのポートに分ける比率は入力できません。** 選択欄で、その項目を集計するポートを一つ指定します。分割のために同じ残高を二度登録すると、総評価額に重複計上される場合があります。
</Ybox>

<br/>

## 4. 株式の自動分類ルールを作る

同じ銘柄を毎回同じかごに入れたいときは、自動ルールを使います。
例えば、市場が米国でコードがAAPLの保有銘柄を、指定したポートにひも付けます。

#### 4.1. リバランスでルールを管理する

現在のルール入力欄は、**リバランス → 購入候補銘柄**にあります。
資産割り当て画面の中に、ルール専用の検索欄はありません。
PCでは左の**リバランス**を押します。
モバイルでは下部の**リバランス**を押すか、すべてのメニューから移動します。
下にある**購入候補銘柄**を押して開きます。

<Img src="/portrhythm-assignment-desktop-rule-search-20261008.webp" width={800} alt="PC版のリバランスで購入候補を開き、優良株ポートと米国市場を選び、AAPLを検索してAppleのNAS候補を表示した画面"/>
<Img src="/portrhythm-assignment-mobile-rule-search-20261008.webp" width={350} alt="モバイル版の購入候補欄にある割り当て先のポート、市場、銘柄の検索語、KIS検索、Appleの候補"/>

<br/>

#### 4.2. ポートと市場を先に選ぶ

- **割り当て先ポート**
  この銘柄を自動で入れるかごを選びます。
- **市場**
  韓国上場なら韓国、米国上場なら米国を選びます。
- **銘柄名または銘柄コード**
  保有する商品の正確な名前かコードを入力します。
- **KIS検索**
  検索結果でコードと取引所を確認します。
- **該当する候補の選択**
  結果の銘柄を押すと、登録済み候補の一覧に加わります。

検索語を入れたり検索ボタンを押したりしただけでは、ルールは作成されません。
**検索結果の候補を選ぶ段階**まで進めます。

<br/>

#### 4.3. AAPLを自動で割り当てる例

「割り当て先ポート」で、自分の個別株のかごを選びます。
市場は米国を選び、検索語はAAPLと入力します。
KISの検索結果でAppleのコードと取引所を確認してから選びます。
画像では、テストアカウントの「優良株」を選びました。
候補を追加すると、「登録済み候補」に銘柄が表示されます。
続けて**変更を保存**します。

<Bbox>
**購入候補一覧は、自動割り当てのルールと連動します。** 登録した銘柄は、自動に設定した保有項目の分類に使い、リバランスでは購入候補にもなります。分類のために追加する場合も、計画に合う銘柄とポートかを確認してください。
</Bbox>

候補に加えても、実際に株式を取得したり、購入注文を出したりすることはありません。
保有していない銘柄も候補として登録できます。保有数量と評価額は、資産登録で管理します。
リバランスでの取引数量の読み方は、後の回で扱います。

<br/>

## 5. 保有銘柄を自動に戻す

ルールを保存したら、**資産割り当て**に戻ります。
該当する株式の選択欄を開き、**自動・ポート名**を選びます。
変更の保存まで行います。
例えばAAPLを個別株のかごに入れるルールなら、自動の選択肢にそのポート名が表示されます。
保有項目がまだ手動なら、ルールを追加しても手動の選択が優先されます。

<br/>

#### 5.1. 同じコードの複数の保有項目に適用する

同じ市場・コードの株式を複数の口座で保有していても、自動に設定した項目には同じルールが適用されます。
一つだけ例外にしたい場合は、その項目を手動で割り当てます。

| 保有項目 | 選択状態 | AAPLの自動ルールが個別株のかごの場合 |
| --- | --- | --- |
| 一般口座のAAPL | 自動 | 個別株のかご |
| 別口座のAAPL | 自動 | 個別株のかご |
| 例外として管理するAAPL | 手動・長期保有 | 長期保有のかご |
| ひとまず分類を保留したAAPL | 手動・未分類 | 未分類 |

*表の口座名とポート名は説明用の例です。*

<br/>

#### 5.2. 登録済みのルールを変更する

**リバランス → 購入候補銘柄 → 登録済み候補**へ戻ります。
対象銘柄のポートを選び直して保存します。
同じ市場・銘柄コードを、二つのポートのルールに重複登録することはできません。
登録済みの案内が出たら、候補を増やさず、既存候補のポートを修正してください。
ルールを削除すると、自動設定の銘柄は、ほかに一致するルールがなければ未分類になります。
手動で指定した項目は、その選択に従います。
ルールを変更したら、資産割り当てで自動と手動の状態を確認してください。

<Toggle title="自動割り当てにも仮の価格を入力する必要がありますか？">
不要です。
自動分類では、市場、銘柄コード、ひも付け先のポートを使います。
登録済み候補の「仮の価格」は、市場価格がない場合に購入数量の計算で使う値です。
自動分類のために任意の価格を入れる必要はありません。
価格を使う範囲は、リバランスの回で詳しく説明します。
</Toggle>

<br/>

## 6. 未分類の資産に対応する

未分類は、**アプリで管理するポートがまだ指定されていない状態**です。
登録の失敗や資産の削除を示すものではありません。
株式の選択欄が「自動・未分類」なら、一致するルールがあるか確認します。
コードがなかったり間違っていたりすると、期待したルールが適用されない場合もあります。
希望のポートを手動で選ぶか、正しいコードのルールを登録して自動に設定します。

<br/>

#### 6.1. 自動・未分類と手動・未分類の違い

どちらも今は未分類として集計されます。
後でルールを作ったときの結果が異なります。

| 選択状態 | 現在 | 後で一致するルールを登録した場合 |
| --- | --- | --- |
| 自動・未分類 | 一致するルールがなく未分類 | ルールのポートに割り当て |
| 手動・未分類 | 未分類を手動で指定 | 未分類のまま。自動に戻すとルールが適用される |

<Img src="/portrhythm-assignment-mobile-unassigned-20261008.webp" width={350} alt="モバイル版の株式のポート選択欄で手動・未分類を指定した例"/>

<Ybox>
**手動・未分類を選んだ項目には、自動ルールが適用されません。** ルールで管理する場合は、その項目を自動に戻して保存してください。
</Ybox>

<br/>

#### 6.2. 未分類の金額は総額から外れるか

未分類の資産も、価格を確認して評価額を計算できれば、**資産全体の金額に含まれます。**
どのポートにも割り当てられていないだけで、資産から消えるわけではありません。
例えば資産全体が100万ウォンで、かごAに60万ウォン、かごBに30万ウォン、未分類に10万ウォンがあるとします。

| 割り当て先 | 評価額 | 全資産に占める比率 |
| --- | ---: | ---: |
| かごA | 60万ウォン | 60% |
| かごB | 30万ウォン | 30% |
| 未分類 | 10万ウォン | 10% |
| 合計 | 100万ウォン | 100% |

AとBを合わせると90%です。
残りの10%は未分類に残っています。
計算から外すために未分類を使わないでください。
目標比率を確認するなら、先に管理対象の資産の分類を済ませると見やすくなります。

<Toggle title="未分類の金額が0ウォンなら、すべての資産が割り当て済みですか？">
金額だけでは判断できません。
価格が未確認の資産や、金額が0の手入力資産は、未分類でも合計金額に表れない場合があります。
一覧で各項目の選択状態を確認し、価格未確認などの表示も点検してください。
分類が正しいかと、評価に使える価格があるかは別々に確認します。
</Toggle>

## 7. 暗号資産をポートに割り当てる

暗号資産の選択欄は、株式と構成が異なります。
**自動と手動の区別はなく、ポート名または未分類**を選びます。

- **暗号資産の名前と市場コードを確認します。**
  例えば、ビットコインとKRW-BTCが合っているかを確認します。
- **ポート選択欄で管理するかごを選びます。**
  登録時の既定のポートが、今の計画に合うかも確認します。
- **変更を保存します。**
  保存後、ポート別の構成に反映されたか確認します。

株式の銘柄コードのルールを変更しても、暗号資産の割り当ては変わりません。
暗号資産は、その項目で選択したポートに集計されます。

<br/>

#### 7.1. 暗号資産名とポート名は同じである必要があるか

同じでなくても構いません。
ビットコインを「暗号資産」ポートに入れることも、複数の暗号資産を一つのかごにまとめることもできます。
画像の「ビットコイン」はテストアカウントでのポート名です。
自分の計画に合わせて名前を付け、含める資産の基準をそろえてください。
市場価格が未確認なら、先に価格の取得状況を確認します。
正しいポートに割り当てるだけで価格が取得されるわけではありません。

<br/>

## 8. ウォンとドルの現金を割り当てる

手入力の資産でも、**ポート名または未分類**を選びます。
株式の自動ルールは適用されません。
現金の項目名を探してポートを選び、保存します。
ウォンとドルの現金は同じ手順で割り当てます。ドルの評価額は、設定した為替レートでウォンに換算して集計します。

<Img src="/portrhythm-assignment-mobile-cash-20261008.webp" width={350} alt="モバイル版の資産割り当てにあるビットコインのポート、手入力したQA用現金の未分類、変更を保存するボタン"/>

*画像は現金の選択欄の位置を示す例です。実際の管理では、現金の用途に合うポートを選びます。*

<br/>

#### 8.1. 現金の割り当て先で比率の意味が変わる

例えば株式の評価額が80万ウォン、現金が20万ウォンだとします。
株式は「株式のかご」に割り当てました。
現金20万ウォンをどこに入れるかで、結果は変わります。

| 現金の割り当て先 | 株式のかご | 現金のかご | 未分類 |
| --- | ---: | ---: | ---: |
| 現金のかご | 80% | 20% | 0% |
| 株式のかご | 100% | 0% | 0% |
| 未分類のまま | 80% | 0% | 20% |

**ポート構成比は、かごに割り当てた資産の合計をもとに計算します。**
現金を株式のかごに入れた場合、ポートの構成比が100%でも、全額が株式という意味ではありません。
そのポートの評価額は、株式80万ウォンと現金20万ウォンの合計です。

<br/>

#### 8.2. 現金のかごと投資待ちの資金

現金を別に比較したい場合は、目標設計で現金ポートを用意し、その残高を割り当てます。
新しいポートを追加した場合は、目標比率の合計を100%にそろえて保存します。
特定のポートで使う投資待ちの資金も、そのポートでまとめて管理できます。
比較する範囲を**実際に投資済みの資産だけにするか、投資待ちの資金も含めるか**を先に決めてください。
現金の割り当ては、購入候補の登録や注文の実行とは別です。
リバランスの数量を検討するときは、資産の割り当てと併せて、実際の注文可能額も確認します。

<Toggle title="現金を複数のかごに分けて管理したい場合">
手入力資産の各項目は、一つのポートに割り当てます。
現金50万ウォンを30万ウォンと20万ウォンに分けたい場合は、別々の名前を付けた二つの手入力項目にできます。
二つの合計は実残高の50万ウォンと一致させます。
既存の50万ウォンを残したまま30万ウォンと20万ウォンを追加すると、重複計上で合計100万ウォンになります。
入力項目を分けても、銀行や証券会社で実際の資金が移動することはありません。
</Toggle>

<br/>

## 9. 割り当ての変更を保存し、構成比を確認する

選択欄を変更すると、アプリの画面には変更後の状態が表示されます。
**アカウントに反映するには、変更を保存する必要があります。**
PCでは画面上部の保存ボタンを押します。
モバイルでは、上部のボタンか、下部に固定されたボタンを使えます。
保存後は**保存済み**の表示を確認してください。

<br/>

#### 9.1. 保存後に確認する順序

- **資産割り当てで選択状態を確認します。**
  自動か手動か、ポート名が意図どおりかを確認します。
- **未分類の項目を再確認します。**
  意図して残したのか、漏れていたのかを確認します。
- **ポート構成比に進みます。**
  PCは左の「ポート構成比」、モバイルは下部の「構成比」を開きます。
- **かごの中身と現在比率を見ます。**
  資産が目的のポートに集計されたかを確認します。

割り当てだけを変更し、価格、数量、為替レートが同じなら、資産の総額は同じです。
変わるのは、**ポートごとに集計する金額と現在比率**です。

<br/>

目標比率は、目標設計で定めた基準です。
資産を別のポートに移しても、目標比率は自動では変わりません。
現在の資産の分類を変えたのか、投資目標そのものを変えたのかを区別してください。

<Gbox>
**分類を終えてから構成比を比べてください。** 未分類、重複登録、価格未確認を先に点検すると、目標と比率が異なる原因を探しやすくなります。
</Gbox>

## 10. 3D分析で資産構成を見る

資産割り当て画面上部の**3D分析を開く**を押します。
この機能は任意です。
標準の一覧で割り当てと保存を行えば、分類は完了します。

<Img src="/portrhythm-assignment-desktop-3d-20261008.webp" width={800} alt="PC版の3Dポート構成で銘柄・ポート・証券会社の集計基準と、選択したポートの金額・比率を表示した画面"/>
<Img src="/portrhythm-assignment-mobile-3d-20261008.webp" width={350} alt="モバイル版の3Dポート構成で棒グラフと、選んだポートの金額・比率を確認する画面"/>

<br/>

#### 10.1. 三つの集計基準

| 基準 | 集計方法 | 確認する問い |
| --- | --- | --- |
| 銘柄 | 同じ市場・コードの株式、暗号資産、手入力資産ごと | どの資産の金額が大きいか |
| ポート | 割り当て先のかごごと | 自分で決めた各かごがどの程度の比率か |
| 証券会社 | 株式は証券会社別に合計し、暗号資産と手入力資産はそれぞれまとめる | 資産の出所別にいくらあるか |

「証券会社」を選ぶと、暗号資産は暗号資産のグループ、手入力資産は手入力のグループにまとまります。
個々の暗号資産取引所のアカウントや、現金がある銀行口座を自動で区別する機能ではありません。

<br/>

#### 10.2. 棒グラフと一覧の読み方

棒グラフまたは一覧から項目を選ぶと、**選んだ資産の金額と、全体に占める比率**が表示されます。
PCでは、グラフをドラッグして視点を回転できます。
モバイルでは、一覧の項目をタップして選ぶと、金額を確認しやすくなります。
棒の高さは評価額の大きさを示します。
目標比率を達成したか、投資に適した資産かを判定する指標ではありません。
目標と現在の差は、ポート構成比画面で確認してください。
ポート別の表示では、評価額のある未分類グループも表示される場合があります。
全体の構成から漏れた資産がないかを調べるために使えます。

<Toggle title="3D画面が出ないか、表示される銘柄数が少ない場合">
ブラウザーが3Dグラフに対応していない場合は、金額と比率の一覧を確認できます。
資産の割り当ては、標準の一覧の選択欄で行います。
3D構成には、評価額が0より大きい項目が表示されます。
銘柄が多い場合は大きい項目を先に表示し、残りを「その他」にまとめることがあります。
そのため、棒の本数と登録した保有項目数が常に一致するとは限りません。
項目ごとの正確な内容は、自分の資産割り当てと保有資産の一覧で確認してください。
</Toggle>

## 11. 割り当て完了のチェックリスト

最後に次の項目を確認してください。

| 確認項目 | 完了の基準 |
| --- | --- |
| 株式・ETF | 手動で選んだポートか、意図した自動ルールで割り当てた |
| 自動ルール | 市場、銘柄コード、ポートが実際の管理基準と一致する |
| 例外項目 | 手動割り当てが残っている理由が分かる |
| 暗号資産 | 各暗号資産のポート選択と価格を確認した |
| 現金 | 用途、通貨、金額に合うポートに割り当てた |
| 未分類 | 漏れがなく、残っている項目の状態と理由を確認した |
| 重複資産 | 同じ残高を分割・再登録する際に二重計上していない |
| 保存 | 変更を保存し、保存済みの表示を確認した |
| 構成比 | ポートごとの集計結果が意図した構成と一致する |

## 12. よくある質問

<Toggle title="自動を選んでも未分類のままです">
登録済みのルールに、該当する市場と銘柄コードがあるかを確認します。
資産名が似ているだけでは、ルールは適用されません。
保有銘柄のコードが空欄または誤っている場合は、先に資産編集で確認します。
ルールを追加・編集したら、変更を保存したかも確認してください。
</Toggle>

<Toggle title="ルールのポートを変えたのに、一部の銘柄が移動しません">
その保有項目が手動割り当てになっていないか確認します。
手動の指定は、自動ルールより優先されます。
ルールを適用したい場合は、その項目を自動に戻し、保存します。
手動・未分類も手動の指定なので、そのままでは自動ルールは適用されません。
</Toggle>

<Toggle title="同じ銘柄を別のポートのルールに追加できません">
同じ市場・銘柄コードを重複ルールとして登録することはできません。
登録済み候補の一覧で、既存ルールのポートを修正してください。
口座ごとの保有項目を別々に管理する場合は、その項目を手動で割り当てます。
二つのルールを作ることと、保有項目ごとに例外を指定することは異なります。
</Toggle>

<Toggle title="選びたいポート名が一覧にありません">
目標設計で目的のポートを作成し、保存したか確認します。
ポートを追加したら、目標比率の合計も100%にそろえます。
続けて資産割り当てに戻り、選択します。
別のログインアカウントで作ったポートは、現在のアカウントの一覧に表示されない場合があります。
</Toggle>

<Toggle title="割り当てが保存されないか、再読み込み後に元に戻ります">
変更を保存するボタンを押したか確認します。
保存済みの表示や完了通知を確認してから移動してください。
目標比率の合計が100%でないという案内が出たら、先に目標設計を点検します。
通信エラーが出た場合は選択内容を確認し、保存をやり直して完了したか確かめます。
</Toggle>

<Toggle title="未分類にするとリバランスの対象から外れますか？">
未分類は、分類先が決まっていない状態です。計算から除外する機能とは異なります。
評価できる未分類の金額は全資産に含まれるため、構成比や調整の検討に影響します。
リバランス画面には、今回の調整から除外する保有銘柄を指定する別の機能があります。
使い方と計算範囲は、リバランスの回で扱います。
</Toggle>
