## はじめに

> 「同じ証券会社にISAと海外株式口座があります。どちらにどの銘柄を持っているか、別々に見たいです。」

銘柄ごとにまとめると、全体の保有数量が分かりやすくなります。
ただし、実際の残高と照合するときは、口座ごとに分けて確認します。
同じApple株でも、A口座の10株とB口座の3株は別々に管理する必要があるからです。

<br/>

新しく追加された口座管理（`계좌 관리`）では、証券会社と口座の別名を登録し、その口座の株式やETFを直接追加・編集できます。
残高のスクリーンショットを用意せず、銘柄を検索して始めることもできます。
[口座管理画面](https://pf.promleeblog.com/?view=accounts)で、口座ごとの保有情報を整理します。

<br/>

[第9回 アカウントと画面設定](https://www.promleeblog.com/blog/post/444-portrhythm-account-display-guide)で紹介したアカウント（`계정`）とは、韓国語の画面で名前が似ていますが、役割は異なります。
**アカウントはログイン情報を指し、口座は資産を保管している証券会社と口座を区別するための項目です。**
一つのログインアカウントに複数の証券口座を登録できます。

<Bbox>
まず、証券会社の実際の残高を見て、口座ごとの銘柄コード、現在の保有数量、1株あたりの平均取得単価を用意してください。
この記事の銘柄と金額は、入力方法を説明するための例です。
既存画面は2026年10月9日にローカルのQAアカウントで撮影し、そのときの入力例は保存しませんでした。
2026年10月10日に追加された移動の確認、入力値の検算、口座別評価額の案内を本文に反映しています。
移動の確認画面は、QAアカウントで実際に移動し、元の口座に戻せることを検証してから撮影しました。
</Bbox>

## 1. 口座管理画面

PCでは、左のメニューで口座管理（`계좌 관리`）を選びます。
左に自分の口座（`내 계좌`）の一覧、右に選択した口座の情報と保有銘柄（`보유 종목`）が表示されます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide10-desktop-overview-20261009.webp" width={800} alt="PC版の口座管理画面に表示された口座一覧、選択した口座と保有銘柄、編集と口座移動の操作"/>

まず口座名と証券会社を確認します。
銘柄の追加や編集は、**現在選択している口座**に対して行います。
似た別名を複数使っている場合は、証券会社も併せて確認してください。

### 1.1. モバイルで口座を選ぶ

モバイルでは、下部のすべて（`전체`）メニューから、資産管理（`자산 관리`）の口座管理（`계좌 관리`）を開きます。
PCの左側の口座一覧に代わり、口座選択（`계좌 선택`）の一覧が表示されます。
そこで証券会社と口座の別名を選び、保有銘柄を確認します。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide10-mobile-overview-20261009.webp" width={350} alt="モバイル版の口座選択一覧と、選択したテスト口座の保有銘柄"/>

画面が狭くても、手順は同じです。
口座を選択し、口座情報を確認して、銘柄を追加または編集します。
選択した口座に銘柄がなければ、登録済みの銘柄がない旨が表示されます。
口座が一つもなければ、まず最初の口座を作ります。

### 1.2. 口座別の評価額を確認する

選択した口座の株式・ETF評価額（`주식·ETF 평가액`）を、ウォンと米ドルでそれぞれ集計します。
**現金と暗号資産を除き、為替換算する前の金額**です。実際の口座残高全体とは集計範囲が異なります。
価格を確認できなかった銘柄は合計から除き、その件数を表示します。
スクリーンショットに記載された価格を使っている銘柄数と、取得した価格のうち最も古い確認時刻も確認できます。
全銘柄の価格が不明なら、0ウォンの代わりに `—` を表示します。

## 2. 証券口座を追加する

画面上部の口座を追加（`계좌 추가`）を押します。
新しい口座（`새 계좌`）のフォームに、証券会社（`증권사`）と口座名・別名（`계좌명 · 별칭`）を入力します。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide10-desktop-create-20261009.webp" width={800} alt="PC版の新規口座フォームで、韓国投資証券とISAの別名を入力し、口座を作成する例"/>

- 証券会社（`증권사`）
実際に資産を保管している証券会社名を入力するか、候補から選択します。
- 口座名・別名（`계좌명 · 별칭`）
自分が区別しやすい名前を入力します。
例えば、`ISA`、年金貯蓄（`연금저축`）、海外株式（`해외주식`）のように、目的が分かる名前にできます。
- 口座を作成（`계좌 만들기`）
入力内容を確認して口座を保存します。
保存すると新しい口座が選択されます。

<br/>

**このボタンで作るのは、PortRhythm内で資産を分けて管理するための口座項目です。**
実際の証券口座の開設、証券会社へのログイン、残高の自動連携は行いません。
別名には実際の口座番号を入力する必要はなく、分かりやすい名前で構いません。

### 2.1. モバイルで口座を追加する

モバイルでも上部の口座を追加（`계좌 추가`）を押します。
二つの入力欄を確認し、口座を作成（`계좌 만들기`）で保存します。
作成を取りやめるなら、キャンセル（`취소`）を押します。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide10-mobile-create-20261009.webp" width={350} alt="モバイル版の新規口座フォームに証券会社とISAの別名を入力した例"/>

口座を作成しただけでは、保有資産の評価額は増えません。
その口座で実際に保有している銘柄を登録すると、保有情報が表示されます。

<Toggle title="同じ証券会社に複数の口座を作れますか？">
別名を変えて区別できます。
同じ証券会社にISAと海外株式口座があれば、それぞれ登録します。

<br/>

証券会社と別名が同じ組み合わせを入力しても、別の口座は追加されません。
実際に別々の口座なら、分かりやすい別名で区別してください。
口座情報を編集するときも、既存の口座と証券会社・別名の組み合わせが重複しないか確認します。
</Toggle>

## 3. 口座情報を編集する

編集する口座を選び、口座情報の編集（`계좌 정보 수정`）を開きます。
証券会社または別名を変更し、口座情報を保存（`계좌 정보 저장`）を押します。
元の値に戻すには、入力を取り消す（`입력 취소`）を押します。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide10-desktop-rename-20261009.webp" width={800} alt="PCで口座情報の編集を開いた画面と、保存・入力取り消しボタン"/>

例えば、テスト口座（`테스트 계좌`）を海外株式（`해외주식`）に変えると、その口座の名前を一度に更新できます。
銘柄ごとに口座名を変更する必要はありません。

<Ybox>
証券会社や口座名の変更は、選択した口座の全保有銘柄に反映されます。
一つの銘柄だけを別口座に移す場合は、その銘柄の口座移動を使います。
</Ybox>

入力を編集したまま別の口座に移るときは、先に保存するか、入力を取り消します。
保存ボタンの近くには、この口座のN銘柄に適用（`이 계좌의 N개 종목에 적용`）と、変更が及ぶ範囲が表示されます。
画面下部の未保存の案内では、新規口座の入力、口座情報の変更、銘柄の入力、移動の確認が区別されます。
変更内容を確認して、該当する保存ボタンを押してください。

## 4. 株式・ETFを直接登録する

まず銘柄を入れる口座を選びます。
保有銘柄（`보유 종목`）の横の銘柄を直接追加（`종목 직접 추가`）を押すと、入力欄が開きます。

### 4.1. 市場を選び、銘柄を検索する

市場（`시장`）で、韓国株式・ETF（`국내 주식·ETF`）か米国株式・ETF（`미국 주식·ETF`）を選びます。
銘柄名またはコード（`종목명 또는 코드`）に名前かコードを入力し、検索（`검색`）を押します。
入力欄でEnterを押しても検索できます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide10-desktop-search-20261009.webp" width={800} alt="PC版で韓国株式・ETFから005930を検索したときのサムスン電子の結果"/>

検索結果で銘柄名、コード、取引所を確認し、目的の結果を押します。
入力欄に文字を入力しただけでは、銘柄の選択は完了しません。
**検索結果を選んでから**数量と単価を入力します。

<br/>

サムスン電子を登録する例では、韓国市場で `005930` を検索します。
Appleを登録する例では、米国市場で `AAPL` を検索します。
名前が似ているETFは、特にコードと取引所も併せて確認してください。

<Toggle title="検索結果が表示されないか、追加ボタンが無効です">
まず選択した市場と、銘柄名やコードを確認します。
韓国の銘柄を米国市場で検索していないか確かめてください。
検索結果が出たら、目的の銘柄を実際に選択したかも確認します。

<br/>

現在価格は保存後に取得します。
検索結果は銘柄を特定するための情報です。検索だけで保有資産の保存や最新価格の確定は行われません。
</Toggle>

### 4.2. 数量と取得単価

例えばサムスン電子を10株保有し、1株あたりの平均取得単価が70,000ウォンなら、次のように入力します。

- 現在の総保有数量・株（`현재 총보유 수량 · 주`）には `10` を入力します。
- 1株あたりの平均取得単価・ウォン（`주당 평균 매입단가 · 원`）には `70000` を入力します。
- 口座と銘柄を確認し、この口座に追加（`이 계좌에 추가`）を押します。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide10-desktop-add-20261009.webp" width={800} alt="PC版でサムスン電子の保有数量10株と、1株あたりの平均取得単価7万ウォンを入力した保存前の例"/>

この場合の取得総額は10株 × 70,000ウォン＝700,000ウォンです。
入力欄の下にある取得総額の検算（`총매입금액 검산`）に、この掛け算の結果が表示されます。
保存前に、取得総額を1株あたりの単価欄に入れていないか確認します。
単価欄に700,000ウォンを入れると、1株あたりの単価として扱われ、結果が変わります。

<br/>

米国株式では入力欄に `USD` と表示されます。
1株あたり平均180ドルで10株を保有しているなら、数量は `10`、単価は `180` です。
ドル建ての取得単価をウォンに換算したり、取得総額の1,800ドルを入力したりしないようにします。

<Bbox>
単価が分からない場合は、入力欄の案内に従って空欄にできます。
ただし、その資産の取得単価をもとにした損益は正確に計算できません。後で実際の平均単価を確認して修正してください。
不明な金額は0で埋めず、空欄にしておきます。
</Bbox>

数量は正の値で、小数点以下6桁まで入力できます。
例えば0.5株を保有していれば、`0.5` と入力します。
保存後に銘柄と数量が一覧に表示されるか確かめ、価格の取得結果はダッシュボードや詳細画面で確認します。

## 5. 登録済みの保有銘柄を編集する

追加購入した場合や、数量と単価の入力を間違えた場合は、その口座の銘柄カードで編集（`수정`）を押します。
保有銘柄の編集（`보유 종목 수정`）で数量と平均単価を変更し、銘柄の変更を保存（`종목 수정 저장`）を押します。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide10-desktop-edit-20261009.webp" width={800} alt="PC版で登録済みのApple株10株と、1株あたりの平均取得単価180ドルを編集する画面"/>

この画面では、登録済みの銘柄の数量と単価を変更します。
別の銘柄に変更するための検索欄は表示されません。
新しい銘柄を取得した場合は、その銘柄を別に追加します。

### 5.1. 追加購入後の総数量

保有していた10株に2株を買い増したら、現在の総保有数量・株（`현재 총보유 수량 · 주`）を `12` に変更します。
今回購入した2株だけを入力すると、保有数量全体が2株になります。
編集欄には、取引した数量ではなく**現在の総保有数量**を入力します。

<br/>

平均単価にも、今回の取引価格だけを入力しないようにします。
可能なら、証券会社が表示する現在の保有分の平均取得単価を確認して入力します。

<Toggle title="平均取得単価はどう計算しますか？">
1株180ドルで10株を保有し、1株200ドルで2株を追加購入したとします。
手数料などを除いた単純な例では、取得総額は1,800ドル＋400ドル＝2,200ドルです。
12株で割った平均は約183.3333ドルです。

<br/>

実際の口座の単価には、証券会社の計算方法が反映される場合があります。
この画面では取引履歴から平均単価を自動計算しないため、証券会社に表示された平均単価を確認するとよいでしょう。
</Toggle>

### 5.2. モバイルで銘柄を編集する

モバイルでも、口座を選び、銘柄の編集（`수정`）を押します。
入力欄に表示された銘柄、単位、現在の総数量を確認します。
下の銘柄の変更を保存（`종목 수정 저장`）を押すと、変更が反映されます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide10-mobile-edit-20261009.webp" width={350} alt="モバイル版のApple株の保有数量、ドル建て平均取得単価、銘柄の変更を保存するボタン"/>

同じ口座にある銘柄を銘柄の直接追加（`종목 직접 추가`）で再登録しようとすると、既存の銘柄の数量を編集するよう案内されます。
重複した項目に分けず、実際の総数量を確認して修正します。
別口座にも同じ銘柄を保有している場合は、その口座を選んで別々に登録できます。

## 6. 保有銘柄を別の口座に移す

銘柄カードの口座移動（`계좌 이동`）の一覧から、別の口座を選べます。
まず移動する銘柄名と現在の口座を確認します。

<br/>

**口座を選んだだけでは、変更は保存されません。**
選択すると、銘柄名、現在の総数量、移動元と移動先の口座を表示する確認欄が開きます。
内容が正しければ確認して移動（`확인 후 이동`）を、選び間違えた場合はキャンセル（`취소`）を押します。
未保存の入力があれば、先に保存するか取り消します。

<Ybox>
口座移動は、アプリに登録した銘柄の保有口座を変更する機能です。
証券会社間の実際の株式移管や売買は行いません。
実際の残高がどこにあるか確認し、アプリの登録情報を合わせるために使ってください。
</Ybox>

### 6.1. 移動する範囲

移動の対象は、その銘柄カードに登録した保有項目全体です。
10株のうち2株だけを移すような、数量指定はできません。
実際に一部の株を移した場合は、両方の口座の実残高をもとに、それぞれの保有情報を更新します。

<br/>

移動先の口座に同じ銘柄があると、自動では合算されません。
数量を確認し、それぞれ編集するよう案内されます。
平均単価も自動では統合されません。
2026年10月10日、QAアカウントでApple株10株を別の登録口座に移し、元の口座に戻しました。
10株という数量と、1株あたり180ドルの平均取得単価は維持されました。

<Toggle title="口座を移すとポートの割り当ても変わりますか？">
口座移動は、資産をどこに保管しているかを変更する操作です。
どの投資ポートに入れるかは、別の資産割り当て画面で確認します。
現在の口座移動では、保有項目の数量、単価、ポートの割り当てを維持したまま、口座情報を変更します。

<br/>

同じ銘柄を複数の口座で持っている場合は、口座ごとの直接割り当ても確認してください。
口座移動の後は、銘柄詳細と資産割り当て画面で、意図した状態になっているか確認するとよいでしょう。
</Toggle>

## 7. 口座とポートの違い

口座は、どこに保管している資産かを区別します。
ポートは、その資産をどんな投資上の役割と目標比率で管理するかを区別します。
それぞれ分類する基準が異なります。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide10-account-port-20261009.webp" width={800} alt="証券会社と口座は保管場所を区別し、米国株指数や韓国株指数のポートは投資上の役割を区別することを示す比較図"/>

| 区分 | 確認する問い | 設定画面 |
| --- | --- | --- |
| ログインアカウント | 誰の資産ですか？ | アカウント |
| 証券口座 | どこに保管していますか？ | 口座管理 |
| 投資ポート | どんな役割と比率で管理しますか？ | 目標設計・資産割り当て |

例えば同じISAの中で、韓国株指数ETFと、異なる役割を持つ資産を保有できます。
一方、異なる証券口座の資産を同じ投資ポートに入れることもできます。
口座を追加しただけでは、目標比率は設定されません。

<br/>

口座ごとの数量を照合できたら、[第4回 資産割り当て](https://www.promleeblog.com/blog/post/439-portrhythm-asset-assignment-guide)に進み、各資産のポートを確認します。
[第6回 現在と目標の構成比を比較](https://www.promleeblog.com/blog/post/441-portrhythm-current-target-allocation-guide)では全体の構成比を確認できます。

## 8. ほかの画面とのつながり

口座管理（`계좌 관리`）は、口座ごとの株式とETFを直接管理する画面です。
資産の種類や操作に応じて、ほかの画面も使います。

| 必要な操作 | 使用する画面 |
| --- | --- |
| 口座の追加、別名の編集、口座ごとの株式・ETFの登録 | 口座管理 |
| 残高の画像から銘柄を認識 | スクリーンショットの取り込み |
| 暗号資産・現金・その他の資産の管理 | 資産の編集 |
| 銘柄の評価額・損益・口座別の詳細を確認 | ダッシュボード・保有資産・銘柄詳細 |
| 資産の投資ポートを指定 | 資産割り当て |
| 目標比率との差を確認 | ポート構成比 |
| 外部からの入出金と評価額の推移を確認 | 資産記録 |

銘柄名を押すと、該当する資産の詳細画面に移動します。
口座管理には、株式・ETFの口座評価額の合計と、銘柄ごとの数量・平均単価が表示されます。
銘柄ごとの評価額と損益は、詳細画面で確認します。
[第3回 資産登録](https://www.promleeblog.com/blog/post/438-portrhythm-asset-registration-guide)で紹介した、スクリーンショットから登録する方法も引き続き使えます。

### 8.1. 実際の残高と照合する

口座ごとに次の点を確認します。

- 証券会社と口座の別名が、実際の管理区分に合っているか確認します。
- 銘柄名に加え、市場とコードを照合します。
- 数量には現在の総保有数量を入力します。
- 平均単価の通貨を確認します。
- 保存後に、該当口座の一覧と銘柄詳細を確認します。
- 現金とポートの割り当ては、対応する画面で併せて確認します。

<br/>

10株を売って現金が増えた場合でも、価格を取得しただけで数量と現金が自動同期されるわけではありません。
新しい口座管理画面でも、証券会社の実残高と照合し、保有情報を手動で合わせます。
口座名にISAや年金貯蓄と入力しただけでは、税金、拠出上限、口座ごとの取引可否は計算されません。

## まとめ

口座管理が加わり、口座を先に整理してから銘柄を検索・登録できるようになりました。
スクリーンショットを使わずに登録したり、保有済みの銘柄の数量と単価を口座別に修正したりするときに使えます。

<br/>

最初に口座を選びます。
新規銘柄は検索して追加し、既存銘柄は現在の総数量に更新します。
口座移動は、アプリ内の登録情報を実際の保有口座に合わせるために使います。

<br/>

機能の追加に合わせ、ガイドも更新していきます。
第10回では、これまでの利用手順に口座ごとの管理方法を加えました。
[口座管理画面](https://pf.promleeblog.com/?view=accounts)で、保有する株式やETFがどの口座にあるか確認してみてください。
