## はじめに

> この記事はFlutter 3.24を前提にしています。

FlutterプロジェクトとFirebaseプロジェクトは連携済みとします。Firebaseプロジェクトがなければ、次の記事を参考に作成してください。
[FirebaseにFlutterアプリを登録する](/blog/post/134-flutter-firebase-apps)

### FCMとは？

<Img src="https://firebase.google.com/static/docs/cloud-messaging/images/diagram-FCM.png?hl=ko" width={500} alt="FCMのアーキテクチャ概要（出典） https://firebase.google.com/docs/cloud-messaging/fcm-architecture"/>

Firebase Cloud Messaging（FCM）は、無料でメッセージを安定して送信できるクロスプラットフォームのメッセージングサービスです。
FCMでメッセージを送受信するには、主に次の2つが必要です。

1. Cloud Functions for Firebaseやアプリサーバーなど、メッセージの作成、宛先の指定、送信ができる信頼できる環境
2. プラットフォームごとの配信サービスからメッセージを受け取るApple、Android、Web（JavaScript）のクライアントアプリ

通常、1つ目はバックエンド、2つ目はFlutterアプリです。今回は主に2つ目を扱い、FlutterでFCMトークンを取得してプッシュ通知を受け取る方法を見ていきます。

## 1. iOSの設定

> Apple Developerアカウントが必要です。持っていなければ[Apple Developer](https://developer.apple.com/)に登録するか、ここを飛ばしてAndroidの設定だけ行ってください。

### 1.1. APNs認証キーを作成する

[Apple DeveloperポータルのAuth Keys](https://developer.apple.com/account/resources/authkeys/list)にアクセスしてログインし、Keysの右にある「＋」を押して新しい認証キーを作ります。

1. 任意の名前を入力し、APNsを選びます。
2. Configureを押し、用途に合う項目を選んで設定を完了します。
3. Continue、Registerの順に押すと、キーが作られます。

   完了すると、次のようにキーが発行されます。

[Apple DeveloperポータルのIdentifiers](https://developer.apple.com/account/resources/identifiers/list)にアクセスしてログインし、Identifiersの右にある「＋」を押して新しい識別子を作ります。

1. App IDsを選び、次の画面でAppを選択してContinueを押します。
   <Img src="/posts/250228-112135.png" width={500} alt=""/>

```xml title="/android/app/src/main/AndroidManifest.xml"
	<uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>

	</application>

```

## 3. Flutterでプッシュ通知を受信するコードを書く

### 3.1. firebase_messagingパッケージをインストールする

```bash
flutter pub add firebase_messaging
```

### 3.2. 通知を受信する許可を得る

通知の許可を求める箇所に、次のコードを追加します。

```dart
import 'package:firebase_messaging/firebase_messaging.dart';

// 적절한 위치에 선언
FirebaseMessaging messaging = FirebaseMessaging.instance;
NotificationSettings settings = await messaging.requestPermission(
  alert: true,
  announcement: false,
  badge: true,
  carPlay: false,
  criticalAlert: false,
  provisional: false,
  sound: true,
);
print('User granted permission: ${settings.authorizationStatus}');
```

### 3.3. プッシュ通知の受信コードを書く（バックグラウンド）

エントリーポイントのmain.dartに、次のコードを追加します。

> バックグラウンドのメッセージハンドラーについて、いくつか注意点があります。

1. 匿名関数は使えません。
2. トップレベルの関数である必要があります。初期化が必要なクラスメソッドなどは使えません。
3. Flutter 3.3.0以降では、関数宣言の直前に @pragma('vm:entry-point') を付ける必要があります。付けないと、リリースモードのツリーシェイキングで削除される場合があります。

```dart title="/lib/main.dart"
import 'package:firebase_messaging/firebase_messaging.dart';

@pragma('vm:entry-point')
Future<void> _firebaseMessagingBackgroundHandler(RemoteMessage message) async {
  await Firebase.initializeApp();
}

void main() {
  FirebaseMessaging.onBackgroundMessage(_firebaseMessagingBackgroundHandler);
  runApp(MyApp());
}
```

### 3.4. プッシュ通知の受信コードを書く（フォアグラウンド）

エントリーポイントのファイルに、次のリスナーを追加します。

```dart title="/lib/main.dart"
import 'package:firebase_messaging/firebase_messaging.dart';

void main(){
	// ...
	FirebaseMessaging.onMessage.listen((RemoteMessage message) {
		print('Got a message whilst in the foreground!');
		print('Message data: ${message.data}');

		if (message.notification != null) {
			print('Message also contained a notification: ${message.notification}');
		}
	});
  runApp(MyApp());
}
```

## 4. FCMトークンを取得する
### 4.1. FCMトークンとは？
FCMトークンは、FlutterアプリがFCMサーバーと通信するための固有の識別子です。Flutterアプリでトークンを取得すると、プッシュ通知を受信できます。

### 4.2. FCMトークンを取得する

```dart
import 'package:firebase_messaging/firebase_messaging.dart';

// 적절한 위치에 선언
final req = await FirebaseMessaging.instance.requestPermission(
	alert: true,
	badge: true,
	sound: true,
);
final fcmToken = await FirebaseMessaging.instance.getToken();
if (req.authorizationStatus == AuthorizationStatus.authorized && fcmToken != null) {
	print('FCM Token: $fcmToken');
} else {
	print('FCM Token: null');
}
```

## 問題と対処方法

### iOSでFCMトークンの取得に失敗する

> apns token has not been set yet. please ensure the apns token is available by calling getapnstoken()

基本設定が正しくてもこのエラーが出る場合、FlutterがAPNsトークンを自動取得できていない可能性があります。その場合は手動でAPNsトークンを取得します。

```dart title="/lib/main.dart" {16}
import 'package:firebase_messaging/firebase_messaging.dart';
import 'package:flutter/material.dart';

void main() async {
	WidgetsFlutterBinding.ensureInitialized();
	FirebaseMessaging messaging = FirebaseMessaging.instance;
	await messaging.requestPermission(
		alert: true,
		announcement: false,
		badge: true,
		carPlay: false,
		criticalAlert: false,
		provisional: false,
		sound: true,
	);
	messaging.getAPNSToken(); // 이 코드 추가
	await messaging.getToken();
	runApp(MyApp());
}
```

iOSの実機にアプリをインストールして実行すると、上のエラーが出ることがあります。iOSでFCMトークンを取得するには、APNsトークンが必要なためです。アプリを起動し、APNsトークンを取得してからFCMトークンを取得するよう、上記の手順でコードを修正します。
