## はじめに

株式は投資資金全体の60%にすると決めたのに、ある日確認すると66%になっていました。
株式が値上がりしたのかもしれませんし、ほかの資産を売ったり、株式だけを買い増したりした結果かもしれません。
数値を見てすぐに売却ボタンを押す前に、最初に決めた基準と、自分の資金事情を確認します。
**比率が変わったら点検を始めます。すぐに売る必要があるとは限りません。**
<br/>
比率を決めた配分に戻すことを**リバランス**と呼びます。
ここでは「投資用のグループに入っている量を調整する」と考えましょう。
今回は、いつ点検するか、どれだけずれたら検討するか、どの資金で戻すかを、1枚の表にまとめます。

<Rbox>
本文の計算は理解のための例であり、投資の推奨ではありません。
PortRhythmの画面はテスト用アカウントのデータで、本文の金額と異なる場合があります。
</Rbox>

## 目標は自分の予定から決める

目標比率を決める前に、お金をいつ使うかを書きます。
近く使う資金と長く置ける資金を同じ方針で運用すると、市場が下がったときに急いで売る必要が生じるかもしれません。
目標配分は、投資期間や損失を負担できる事情によって変わります。
[Investor.govの資産配分の説明](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)
<br/>
目標は株式60%、債券20%、金5%、現金15%です。
この目標と、現在の残高を比べます。

| グループ | 現在の金額 | 現在比率 | 目標 |
| --- | ---: | ---: | ---: |
| 株式 | 660万ウォン | 66% | 60% |
| 債券 | 160万ウォン | 16% | 20% |
| 金 | 50万ウォン | 5% | 5% |
| 現金 | 130万ウォン | 13% | 15% |
| 合計 | **1,000万ウォン** | **100%** | **100%** |

資産は株式、債券、金、現金に分けました。
株式は目標より多く、債券と現金は少なくなっています。
「何を売るか」に加えて、別の問いがあります。
**新たに入れられる余裕資金があるなら、不足しているグループに入れて比率を戻せるでしょうか。**

## 60%と66%の差

2つの比率を引くと `66 − 60 = 6` です。
差は**6パーセントポイント**で、`6%p` と書きます。
気温が20度から26度になったとき、差を6度と呼ぶように、比率同士の差に使う単位です。
<br/>
別の表し方もあります。
目標の60より6大きいため、`6 ÷ 60 = 10%` です。
アプリの「各ポートの目標額を基準にする」差に対応します。今回のように全体の金額を固定すると、株式の目標額600万ウォンより60万ウォン、つまり10%多い状態です。

| 表し方 | 数値の意味 |
| --- | --- |
| 全体に占める比率の差 | 60%から66%へ、+6%p |
| 目標に対してどれだけ多いか | 目標額600万ウォンより60万ウォン多い、+10% |

同じ残高を説明していても、**数値の単位が違えば許容基準も変わります。**
「5を超えたら確認する」だけでなく、`5%p` か `목표 대비 5%`（目標比5%）かを書きます。
詳しい画面の読み方は[現在比率と目標比率のガイド](https://www.promleeblog.com/blog/post/441-portrhythm-current-target-allocation-guide)を参照してください。

## 新しい資金100万ウォンで合わせる

株式660万ウォンはそのままで、余裕資金100万ウォンを追加すると仮定します。
全体が1,100万ウォンになり、`660 ÷ 1,100 = 60%` です。
**株式を1株も売らなくても、株式比率は66%から60%に下がります。**
株式の金額が減ったのではなく、分母の総額が増えたためです。

| グループ | 追加前 | 新しい資金の使い道 | 追加後 |
| --- | ---: | ---: | ---: |
| 株式 | 660万ウォン | 0ウォン | 660万ウォン・60% |
| 債券 | 160万ウォン | +60万ウォン | 220万ウォン・20% |
| 金 | 50万ウォン | +5万ウォン | 55万ウォン・5% |
| 現金 | 130万ウォン | +35万ウォン | 165万ウォン・15% |
| 合計 | **1,000万ウォン** | **+100万ウォン** | **1,100万ウォン・100%** |

計算では、費用、税、価格変化、取引単位の制限を除いています。
追加した100万ウォンのうち、65万ウォンで資産を買い、35万ウォンを現金で残します。
もともとの現金130万ウォンを新しい入金に足し直すことはしません。

<Img src="/portfolio-reading-06-rebalancing-20261017.webp" width={750} height={500} alt="株式を売らずに100万ウォンの新しい資金を配分し、株式比率を66%から60%に戻す手順"/>

新しい資金が50万ウォンなら、総額は1,050万ウォン、株式比率は約62.9%です。
その資金だけでは目標の60%にぴったり合わせられません。
100万ウォンを無理に用意する前に、今の差を許容するか、費用を考慮して別の調整をするかを検討します。

## 毎日の売買に代わる点検ルール

価格が動くたびに比率も変わります。
小さな変化のたびに売買すると、投資計画よりも取引ボタンを見る回数が増えかねません。
いつ見直すか、どの程度の差を許容するかを決めておくと、毎回一から考えずに済みます。
定期的な点検や、所定の乖離を基準に調整する方法はInvestor.govでも紹介されています。
[Investor.govのリバランスの説明](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)
<br/>
例えば「毎月確認し、株式の目標から5%pを超えてずれたら理由を調べる」と書けます。
今回は66%で、目標の60%との差は6%pなので、確認の対象です。
生活の予定が変わっていないか、残高に誤りがないか、取引に費用がかかるかを確認してから、実行を決めます。

<Bbox>
最初はカレンダーに「購入日」ではなく「点検日」を書いてみてください。
確認して何も売買しない判断も、ルールに沿った結果です。
</Bbox>

## PortRhythmで確認する3つの画面

PortRhythmでは、**目標設計 → ポート比率 → リバランス**の順に確認できます。
目標設計でグループと許容誤差の単位を確認し、ポート比率で現在と目標を比べます。
計算範囲の読み方は、[目標設定ガイド](https://www.promleeblog.com/blog/post/437-portrhythm-portfolio-setup-guide)と[リバランスガイド](https://www.promleeblog.com/blog/post/442-portrhythm-rebalancing-guide)をご覧ください。

<Img src="/portrhythm-guide6-desktop-current-20261009.webp" width={750} height={422} alt="現在比率、目標比率、差を並べて確認するポート比率の画面"/>

見るのは、**現在、目標、差の列**です。
ポート名と資産クラスが異なるか、現金が別のポートに混ざっているなら、比較の範囲をそろえます。
許容誤差には、全体比率を基準にする `%p` と、各ポートの目標額を基準にする `%` があるので、単位を確認します。
<br/>
リバランス画面の計算と実際の注文は区別します。
整数単位での取引、手数料と税、口座ごとに使えるお金、取引可能な時点を別に確認します。
画面で合計された現金を、1つの口座ですぐに全額使えるとは限りません。

## 自分のリバランスルール表

複雑な式を使う前に、次の6行を書きます。

| 項目 | 記録する内容 |
| --- | --- |
| 目標 | 株式60%、債券20%、金5%、現金15% |
| 点検頻度 | 月1回。予定が変わったら追加で確認 |
| 検討基準 | 株式の目標から5%pを超えてずれたら理由を確認 |
| 最初に検討する方法 | 無理のない新規資金で不足分を補う |
| 実行前に確認すること | 費用、取引単位、口座ごとの資金、近い支出 |
| 今回の判断 | 何をするか、理由、次の点検日 |

ルールは、自分の投資期間と資金事情に合わせます。
**今の残高に合わせて目標を動かす前に、目標を変える理由が生じたかを書きます。**

## おわりに

株式比率が増えたとき、売却のほかにも選択肢があります。
今回は、株式660万ウォンを維持し、総額を1,100万ウォンに増やして目標比率に合わせました。
今日の成果は、**点検時期、許容範囲、調整方法、実行時の例外を記録したルール表**です。
<br/>
[PortRhythmのポート比率](https://pf.promleeblog.com/?view=composition)で目標との差が最も大きいグループを1つ選び、理由を書いてみてください。
次回は、調整に使う現金と分配金をどう分けるかを見ます。
現金にも用途を付けておくと、「余ったお金」と「使う予定のお金」を混同しにくくなります。
