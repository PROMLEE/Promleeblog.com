> https://www.acmicpc.net/problem/10026
## アルゴリズムの分類
グラフ理論、グラフ探索、幅優先探索、深さ優先探索

## 問題の説明
> この問題では、赤と緑を区別できない場合を赤緑色覚特性として扱います。

N×Nの絵が与えられ、各マスはR、G、Bのいずれかで塗られています。
赤緑色覚特性がある場合はRとGを区別できないため、同じ色として扱います。
```
RRRBB
GGBBB
BBBRR
BBRRR
RRRRR
```
上の絵では、赤と緑を区別できる人は4つの領域を識別できます。
赤と緑を区別できない人は、3つの領域を識別できます。
それぞれの見え方で区別できる領域の数を出力してください。

### 入力
最初の行にNが与えられます（1 ≤ N ≤ 100）。
2行目からN行にわたって絵が与えられます。
```
5
RRRBB
GGBBB
BBBRR
BBRRR
RRRRR
```

### 出力
赤と緑を区別できる場合の領域数と、区別できない場合の領域数を、空白で区切って出力します。
```
4 3
```

## 解き方
1. BFS（幅優先探索）で各領域を探索します。
2. 赤と緑を区別できない場合は、RとGを同じ色として探索します。
3. BFSで領域を探索し、訪れたマスはvisited配列に記録します。
4. BFSをキューで実装し、上下左右につながる同じ色のマスを探索します。
5. 領域を1つ探索するたびにカウントを増やします。
6. 最後に、赤と緑を区別できる場合と、区別できない場合の領域数を出力します。

## コード - Python
```python
import sys
from collections import deque

sys.setrecursionlimit(10000)  # 재귀 제한 해제 (DFS 쓸 경우 대비)
N = int(sys.stdin.readline())

 # 색상 격자 입력 받기
grid = [list(sys.stdin.readline().strip()) for _ in range(N)]

 # 상하좌우 방향 정의
dx = [0, 0, 1, -1]
dy = [1, -1, 0, 0]

 # BFS로 한 구역 탐색하는 함수
def bfs(x, y, visited, board, is_amblyopia):
    queue = deque()
    queue.append((x, y))
    visited[x][y] = True  # 현재 위치 방문 처리
    current_color = board[x][y]

    while queue:
        cx, cy = queue.popleft()
        for i in range(4):
            nx, ny = cx + dx[i], cy + dy[i]

            # 범위를 벗어나거나 이미 방문한 경우 무시
            if 0 <= nx < N and 0 <= ny < N and not visited[nx][ny]:
                next_color = board[nx][ny]

                if is_amblyopia:
                    # 적록색약인 경우: R과 G는 같은 색으로 간주
                    if (current_color in "RG" and next_color in "RG") or current_color == next_color:
                        visited[nx][ny] = True
                        queue.append((nx, ny))
                else:
                    # 일반인: 정확히 같은 색만 같은 구역
                    if next_color == current_color:
                        visited[nx][ny] = True
                        queue.append((nx, ny))

 # 전체 격자를 순회하면서 BFS 시작 지점을 찾아 구역 수 세기
def count_areas(is_amblyopia):
    visited = [[False]*N for _ in range(N)]
    count = 0
    for i in range(N):
        for j in range(N):
            if not visited[i][j]:
                bfs(i, j, visited, grid, is_amblyopia)
                count += 1  # BFS 한 번 돌면 하나의 구역
    return count

 # 결과 계산 및 출력
normal = count_areas(False)       # 일반인의 시각
color_blind = count_areas(True)   # 적록색약인의 시각
print(normal, color_blind)
```

## ポイント
### BFSによる探索
- BFSで1つの領域を探索し、訪れたマスはvisited配列に記録します。
- キューを使い、上下左右につながる同じ色のマスを探索します。

### 時間計算量
$O(N^2)$ です。各マスを訪れるのは最大1回です。
N ≤ 100なので十分に効率的です。
