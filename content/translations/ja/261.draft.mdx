## アルゴリズムの分類
数学、文字列、貪欲法、構文解析

## 問題の説明
正の整数と`+`、`-`からなる式が与えられます。
適切な位置に括弧を付け、式の値を最小にするプログラムを書きます。

### 入力
最初の行に式が与えられます。
式は`1`以上`1000000`以下の正の整数と`+`、`-`で構成され、少なくとも一つの演算子を含みます。
式の長さは最大`50`です。
```txt
50-50+40-30+20-10
```
### 出力
得られる結果のうち、最小値を出力します。
50-(50+40)-(30+20)-10 = 50 - 50 - 40 - 30 - 20 - 10 = -100
```txt
-100
```

<Img src="/250506-185802.webp" width={300} alt="括弧の付け方と式の値の関係"/>

## 解き方
1. 式を`-`で分割して、それぞれの塊に分けます。
2. 最初の塊は、そのまま加算します。
3. それ以降の塊は括弧で囲まれると考え、それぞれを+で分割して足し合わせ、その合計を引きます。
4. すべての塊を計算した結果を出力します。

<Ads1 />

## コード — Python
```python
expression = input().strip()

  # 1. '-'를 기준으로 먼저 나눈다.
parts = expression.split('-')

  # 2. 첫 번째 덩어리는 무조건 더한다.
total = sum(map(int, parts[0].split('+')))

  # 3. 그 이후 덩어리는 모두 괄호로 묶인다고 생각하고 각각 +로 쪼개서 합산한 뒤 빼기
for part in parts[1:]:
    total -= sum(map(int, part.split('+')))

print(total)
```
### 力業の例
<Rbox>まねしないでください。このようなコードは書かないようにしましょう。</Rbox>
```python
line = input().strip().split("-")
answer = sum(list(map(int, line[0].split("+"))))
print(answer if len(line) <= 1 else answer - sum([list(map(int, s.split("-")))[0] for s in "+".join(line[1:]).split("+")]))

```
## 要点
記号のあとに続く数を、括弧でまとめて一度に引くと最小値になります。
- +は括弧の中でだけ影響し、
- -は括弧の始点になるため、
- 最初の-以降は、すべて()の中に入ると考えます。

### 時間計算量
- split('-') → O(N)
- 各塊に対するsplit('+') → 全体でO(N)
- 各数のint()変換 → O(N)
- 合計の計算 → O(N)

最終的な時間計算量：O(N)
