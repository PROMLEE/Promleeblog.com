## はじめに
今回は、実務で必要になる`fetch`の*ヘッダー追加*、*Cookie送信*、*キャッシュ無効化とカスタマイズ*を扱います。
続いて、Route HandlerでAPIサーバーのように動作させる方法を確認します。

## fetchのカスタマイズ：ヘッダーとCookie
`fetch`はブラウザーとほぼ同じように使えますが、Server Componentsではサーバー環境の特徴を活用できます。
たとえば、*ヘッダーを追加*したり、*Cookieを含めたり*できます。
### ヘッダーを追加する例

```tsx
const res = await fetch('https://api.example.com/data', {
  headers: {
    'Authorization': 'Bearer my-token',
  },
});
```
認証トークンやユーザー情報など、必要なヘッダーを送れます。

## cookies() APIでCookieを渡す
Server Componentsでは、組み込みの`cookies()`でクライアントのCookieへアクセスできます。
ログイン情報をCookieから読み、要求に含める場合などに使います。

```tsx
import { cookies } from 'next/headers';

const cookieStore = cookies();
const token = cookieStore.get('token');
const res = await fetch('https://api.example.com/user', {
  headers: {
    Authorization: `Bearer ${token?.value}`,
  },
});
```
認証情報をサーバー側で安全に処理するのに役立ちます。

## タグを使ったキャッシュ無効化
Next.jsは`fetch`に*タグ*を付け、そのタグのデータを簡単に*無効化*する機能を提供します。
### タグの追加例

```tsx
await fetch('https://api.example.com/data', {
  next: {
    tags: ['data'],
  },
});
```
後で`revalidateTag('data')`を呼び、そのキャッシュを無効にできます。

### Server Actionで無効化する例

```tsx
'use server';
import { revalidateTag } from 'next/cache';
export async function updateSomething() {
  // 데이터 수정 로직
  await revalidateTag('data'); // 'data' 태그에 해당하는 fetch 캐시 무효화
}
```
ユーザーがデータを変更したとき、それに関連する要求だけを正確に再取得させられます。

## Route HandlerでAPIを作る
`app/api/`に*Route Handler*を定義すると、Next.jsを独自APIサーバーとして使えます。
ユーザー情報を取得する例は、次のとおりです。

```tsx
// app/api/user/route.ts
import { NextResponse } from 'next/server';
export async function GET() {
  const res = await fetch('https://jsonplaceholder.typicode.com/users/1');
  const user = await res.json();
    return NextResponse.json(user);
}
```
これで`/api/user`への要求に、JSONを返すAPIが動作します。
`GET`、`POST`、`PUT`、`DELETE`などを、それぞれ関数として実装できます。
Server Actionsとの組み合わせも便利です。
