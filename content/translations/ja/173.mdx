## はじめに
React NativeとExpoを使ってアプリを開発していたところ、Xcodeを16.3に更新した直後から、予期しないビルドエラーが出始めました。コンソールには `std::char_traits<unsigned char>` に関するテンプレートエラーが繰り返し出て、一部のPodでコンパイルが止まりました。
早く作業を再開するため、Xcodeを16.2へ*ダウングレード*することにしました。この記事では、私が遭遇した状況と、Xcodeを安全にダウングレードする手順を紹介します。

### Xcode 16.3への更新後に起きたエラー
Xcodeを16.3に更新すると、次のエラーが出てビルドが中断しました。
```
static_assert(is_same<_CharT, typename traits_type::char_type>::value,
              ^ implicit instantiation of undefined template 'std::char_traits<unsigned char>'
```
このエラーは `string_view` に関わるC++標準ライブラリ内部で発生しました。React Nativeの `RCT-Folly` や `React-perflogger` など、内部Podコンポーネントとの互換性の問題に見えました。

簡単に言えば、*新しいXcodeと既存の一部のC++ネイティブコードがかみ合っていない*状態です。Expo環境ではC++コードを直接扱わないので、安定して動いていた以前のバージョンへ戻すのが、根本的な対策を施すより早い方法でした。

## Xcodeをダウングレードする手順（16.3 → 16.2）
手順は大きく4段階です。
### 1. 既存のXcode 16.3を削除するか名前を変える
Macでは同じ場所に `Xcode.app` という名前で複数のアプリを置けないため、既存のアプリを削除するか、名前を変えます。
**削除する場合**
```
sudo rm -rf /Applications/Xcode.app
```
**名前を変更して残す場合**
```
sudo mv /Applications/Xcode.app /Applications/Xcode-16.3.app
```
あとで16.3を再び使いたい場合は、名前を変えて残すとバックアップになります。

### 2. Xcode 16.2をダウンロードする
次のリンクからXcode 16.2をダウンロードできます。
🔗 [Apple Developer Downloads](https://developer.apple.com/download/all/)
- Apple IDでログインします。
- 「Xcode 16.2」で検索し、`.xip` ファイルをダウンロードします。
<Img src="/posts/250402-101948.webp" width={500} alt=""/>

### 3. Xcode 16.2をインストールする
ダウンロードした `.xip` ファイルをダブルクリックして展開し、`/Applications` フォルダに移動します。
ドラッグ＆ドロップで移動してもかまいません。
```
sudo mv ~/Downloads/Xcode.app /Applications/
```
<Img src="/posts/250402-102241.webp" width={300} alt="アプリケーションフォルダを確認する"/>

### 4. Xcode 16.2を有効にする
最後に `xcode-select` コマンドで、システムが使うXcodeを指定します。
```
sudo xcode-select -s /Applications/Xcode.app
```
適用されたバージョンを次のコマンドで確認します。
```
xcodebuild -version
```
想定される出力です。
```
Xcode 16.2
Build version 16Cxxx
```
プロジェクトをもう一度ビルドすると、エラーが出ず、正常に動くことを確認できます。
## おわりに
今回の経験で、*最新版が常に安定しているとは限らない*と改めて感じました。React Nativeのようにネイティブコンポーネントと連携するフレームワークでは、XcodeやAndroid Studioのバージョン互換性に気を配る必要があります。
今後は、メジャーバージョンを更新する前に、GitHubのIssueやExpoのリリースノートを確認してから判断しようと思います。
