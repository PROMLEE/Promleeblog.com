> 「株式は証券会社のアプリ、暗号資産は取引所、現金は銀行口座にあります。どうやって全部まとめればいいのでしょうか？」

初めて資産を登録するときは、入力欄を見ただけで迷うことがあります。
銘柄コードとは何か、取得単価にはいくら書くのか、ドルの現金はウォンに換算すべきか。
今回は、**保有する資産をPortRhythmに登録する手順**を画面ごとにたどります。
株式とETFは残高画面のスクリーンショットまたは手入力、暗号資産は銘柄検索、現金は金額入力で登録します。
PCとモバイルの画面を見ながら、一つずつ試してください。

<br/>

<Bbox>
今回の目標は、保有資産の登録を完了することです。数量、取得単価、通貨を確認して保存し、実際の残高と照合します。登録した資産を投資のかごに割り当てる手順は、第4回で詳しく扱います。
</Bbox>

[PortRhythmを開く →](https://pf.promleeblog.com)

目標ポートフォリオをまだ作っていなければ、先に[第2回 目標ポートフォリオと投資比率を設定する](https://www.promleeblog.com/blog/post/437-portrhythm-portfolio-setup-guide)を進めてください。
かごを用意してから資産を登録すると、その後の割り当ても進めやすくなります。

<br/>

## 始める前に

資産の種類によって、最初に開くメニューが異なります。

| 登録する資産 | 開くメニュー | 入力方法 | 保存方法 |
| --- | --- | --- | --- |
| 韓国株・ETF | 口座管理またはスクリーンショットの取り込み | 口座別に銘柄を検索して直接登録、または残高画像を取り込む | この口座に追加／確認して保存 |
| 米国株・ETF | 口座管理またはスクリーンショットの取り込み | 口座別に銘柄を検索して直接登録、または残高画像を取り込む | この口座に追加／確認して保存 |
| 暗号資産 | 資産編集 | Bithumbのウォン建て市場で検索し、数量と取得単価を入力 | 追加 → 暗号資産・現金の変更を保存 |
| ウォン・ドルの現金、金額を別途管理するその他の資産 | 資産編集 | 名前、金額、通貨を入力 | 追加 → 暗号資産・現金の変更を保存 |

**株式とETFには保有数量を、現金には保有金額を入力します。**
例えば株式を10株持っている場合、株式の数量欄に総評価額200万ウォンを入れないでください。
現金を200万ウォン持っている場合は、現金の入力欄にその金額を入れます。

<br/>

#### 手元に用意しておく情報

- **株式・ETF**
  証券会社と口座の区分、韓国・米国の市場区分、銘柄名とコード、現在の保有数量、1株あたりの平均取得単価を用意します。
- **暗号資産**
  正確な銘柄名、現在の保有数量、1単位あたりの平均取得単価を用意します。
- **現金**
  管理する残高、ウォンかドルか、どのかごに入れるかを確認します。

この記事の画面はローカルのテストアカウントで撮影しました。
Apple株10株、イーサリアム0.05単位、米ドルの現金1,000ドルなどは、**入力方法を説明するための例**です。
画面の価格は撮影時の表示値です。入力値は現在の市場価格や投資の推奨を示すものではありません。

<br/>

## 1. スクリーンショットを取り込む

#### 1.1 PC

左のメニューで**ツール → スクリーンショットの取り込み**を押します。
「スクリーンショットから資産を取り込む」という見出しの下に、三つの領域が表示されます。

- **01 画面の選択**
  資産を保有している証券会社、口座、市場を指定します。
- **02 スクリーンショットのアップロード**
  残高画像から銘柄と数値を読み取ります。
- **03 内容の確認**
  読み取った内容を修正するか、直接追加して保存します。

<Img src="/portrhythm-assets-desktop-import-20261008.webp" width={800} alt="PC版のスクリーンショット取り込み画面にある画面選択、画像のアップロード、内容確認の各領域"/>

<br/>

#### 1.2 モバイル

下部の**すべて → スクリーンショットの取り込み**を押します。
PCで横に並んでいた領域が、モバイルでは縦に並びます。
先に画面の選択欄を入力し、下にスクロールして、ファイルの選択と内容の確認に進んでください。

<Img src="/portrhythm-assets-mobile-import-20261008.webp" width={350} alt="モバイル版のスクリーンショット取り込みで証券会社、口座区分、韓国株・海外株の残高画面を選ぶ例"/>

モバイルでは入力欄が多く、画面が縦に長くなります。
キーボードが下の項目を隠している場合は、閉じてからスクロールしてください。

<br/>

## 2. 証券会社と口座の区分

#### 2.1 証券会社は資産の保管先です

「証券会社」に、その残高を保有している証券会社の名前を入力します。
初期値をそのまま使わず、実際の残高と合うか確認してください。
「口座区分」は、同じ証券会社の複数口座を区別する名前です。
実際の口座番号を入れる必要はありません。
**一般口座、ISA、年金貯蓄**など、自分で分かる名前を付けます。

| 入力欄 | 説明用の例 | 確認すること |
| --- | --- | --- |
| 証券会社 | メリッツ | 実残高の証券会社と一致するか |
| 口座区分 | 一般口座 | ほかの口座と区別できるか |
| 残高画面 | 韓国株式または海外株式 | 登録する銘柄の市場と一致するか |

<br/>

#### 2.2 韓国株式と海外株式を選ぶ

韓国株式と韓国上場ETFは、**韓国株式**を選びます。通貨はウォンです。
米国株式と米国上場ETFは、**海外株式**を選びます。通貨はドルです。
この画面の海外株式登録は米国銘柄を対象にしています。
韓国上場の米国株指数ETFは、名前に「米国」があっても**韓国株式**です。
投資先に加え、まず**どの市場に上場しているか**を確認します。

<Ybox>
市場は銘柄を追加する前に確認してください。追加済みの行がある状態で上の残高画面を変更しても、その行の市場は自動では変わりません。誤って追加した場合は、該当行を外し、正しい市場で追加し直します。
</Ybox>

<br/>

#### 2.3 次に登録するときも同じ口座名を使う

今回「一般口座」と入力したら、次に同じ残高を更新するときも「一般口座」を使ってください。
「基本口座」や「総合口座」に変えると、アプリが別口座として扱う場合があります。
**同じ口座には一貫して同じ名前を使うこと**が、二重計上を防ぐ簡単な方法です。
実際に別の口座なら、名前を分けて登録します。

<br/>

## 3. 残高のスクリーンショット

#### 3.1 数字を読み取れる画像を用意する

証券会社のアプリで、保有銘柄と数量が表示された残高画面を撮影します。
できれば銘柄名、保有数量、価格、取得情報が一度に見える画面を用意してください。
文字が小さすぎたり、画面を大きく切り取ったりした画像では、数値を読み取りにくくなります。
長い残高一覧を複数の画像に分けた場合は、次の画像に同じ銘柄が重なっていないか確認します。

<br/>

「スクリーンショットのアップロード」で**ファイルを選択**を押します。
PCでは保存した画像ファイルを、モバイルでは写真ライブラリやファイル内の画像を選びます。
PNGやJPGなどの画像ファイルを使います。
画像を選ぶと、ブラウザーで文字を読み取ります。
初回は、文字認識に必要なデータの読み込みに時間がかかることがあります。
認識が終わったら、下の**内容の確認**に進みます。

<Bbox>
スクリーンショットはブラウザーで解析します。画像そのものをサーバーにアップロードして保管する方式ではありません。「確認して保存」を押すと、確認した銘柄、数量、取得情報がログイン中のアカウントに保存されます。
</Bbox>

<br/>

#### 3.3 認識結果を確認する

形の似た文字や、小さな数字を読み違える場合があります。
特に、ETFの名前が途中で切れていないか、小数点の位置が違わないか、別の数値を価格と認識していないかを確認してください。
**ファイルを選んだ後、下で内容を確認し、保存して登録が完了します。**

<br/>

## 4. 銘柄名とコードを確認する

PCでは、一つの銘柄の行に複数の入力欄が横に並びます。
モバイルでは、同じ入力欄が縦に並びます。
以下はOCRの結果ではなく、**「直接追加」で作成した入力例**です。
画像から読み取った銘柄も、同じ内容確認欄で確認します。

<Img src="/portrhythm-assets-desktop-review-20261008.webp" width={800} alt="PC版の内容確認欄にApple、コードAAPL、数量10、画像の価格180、取得単価170を直接入力した例"/>
<Img src="/portrhythm-assets-mobile-review-20261008.webp" width={350} alt="モバイル版の内容確認欄にある銘柄名、銘柄コード、数量、画像の価格、取得単価と確認して保存するボタン"/>

<br/>

#### 4.1 銘柄名だけ合っていればよいか

銘柄名は人が読む名前です。
**銘柄コード**は、価格を取得する銘柄を識別するための値です。

| 区分 | コードの例 | 意味 |
| --- | --- | --- |
| 韓国の銘柄 | 005930 | 韓国の銘柄を識別するコード |
| 米国の銘柄 | AAPL | 米国銘柄のティッカー |
| 米国銘柄の取引所 | NAS・NYS・AMSなど | 価格取得に必要な取引所の区分 |

名前の似たETFや、異なる市場の商品を名前だけで選ばないでください。
保有商品と**コード、市場、取引所**が一致するか確認します。
韓国のコードは先頭が0の場合があり、一部の新しいコードには英字が含まれます。
金額の数値のように扱って、先頭の0を省略しないでください。

<br/>

#### 4.2 KISでコードを探す手順

- **銘柄名か、分かっているコードを入力します。**
  画像で名前が途中で切れていたら、先に正確な名前に修正します。
- **KISでコードを探すボタンを押します。**
  価格取得に使う銘柄の候補を検索します。
- **候補が複数あれば、該当銘柄を選びます。**
  名前と併せて、コードと取引所も確認します。候補を一つに特定できた場合は、そのまま反映されることがあります。
- **反映されたコードを再確認します。**
  証券会社の残高にある銘柄と一致することを確認し、数値の入力に進みます。

米国銘柄ではティッカーの確認が必須です。
韓国銘柄も、価格を取得できるようにコードを確認しておくとよいでしょう。

<Ybox>
銘柄名やコードを修正したら、再検索してください。名前を変えると既存のコードと取引所の確認が解除され、コードを変えると取引所の確認が解除されます。最終入力の状態で、KISのコード検索をもう一度行います。
</Ybox>

## 5. 数量と価格を入力する

ここでは、**総額と1単位あたりの価格**を区別します。

| 入力欄 | 入力する内容 | 入力しない内容 |
| --- | --- | --- |
| 数量 | 現在保有している株数 | 評価額、今回買った株数だけ |
| 画像の価格 | スクリーンショット撮影時の1株の価格 | 銘柄全体の評価額 |
| 取得単価 | 1株あたりの平均取得価格 | 取得総額、現在価格 |

**韓国銘柄の価格はウォン、米国銘柄の価格はドル**で入力します。
米国銘柄を登録するときに、取得単価をウォンに換算して入力しないでください。

<br/>

#### 5.1 Apple株10株を入力する例

説明用に、Apple株10株を保有し、1株あたりの平均取得価格が170ドルだとします。
撮影時点の価格は180ドルと仮定します。

| 入力項目 | 入力例 |
| --- | ---: |
| 銘柄名 | Apple |
| 銘柄コード | AAPL |
| 数量 | 10 |
| 画像の価格 | 180 |
| 取得単価 | 170 |

取得総額は10株 × 170ドル＝1,700ドルです。
**取得単価の欄には170を入力します。** 1,700は総額です。
画像の価格だけで計算すると、評価額は1,800ドルです。
保存後に新しい市場価格を取得すると、評価額はその価格に基づいて変わる場合があります。

<Gbox>
単価には1単位あたりの価格、数量には保有する単位数を入れます。二つを正しく入力すれば、アプリが掛け算で金額を計算します。
</Gbox>

<br/>

#### 5.2 取得単価が分からない場合

証券会社の残高画面で平均取得単価を確認して入力するのが最も正確です。
分からなければ、空欄にできます。
価格と数量があれば評価額は計算できますが、取得情報がなければ取得価格に基づく損益は計算できません。
**分からない単価を0で埋めたり、現在価格で代用したりしないでください。**
未入力と、実際の取得価格が入力済みの状態は区別します。

<Toggle title="端株を保有している場合">
数量には小数を入力できます。
現在の株式数量の編集では、小数点以下6桁までを基準とします。
証券会社に表示された数量を確認して入力してください。
小数点の位置がずれると評価額も大きく変わります。
保存前に、0.5株を5株と入力していないか確認します。
</Toggle>

## 6. スクリーンショットなしで直接追加する

株式・ETFを直接登録するときは、**口座管理**からも始められます。
PCの左メニュー、またはモバイルの「すべて → 資産管理 → 口座管理」（`전체 → 자산 관리 → 계좌 관리`）を開きます。
証券会社と口座の別名を作り、銘柄の直接追加（`종목 직접 추가`）で韓国・米国の市場を選んで検索します。
検索結果を選び、現在の総保有数量と1株あたりの平均取得単価を入力します。
保存前に、取得総額の検算（`총매입금액 검산`）で数量と単価を確認し、この口座に追加（`이 계좌에 추가`）を押します。
口座別の追加、編集、移動の確認は[第10回 口座管理](https://www.promleeblog.com/blog/post/445-portrhythm-brokerage-account-guide)で詳しく説明します。

<br/>

以下は、従来の**スクリーンショット取り込み画面の直接追加**の手順です。
口座管理の直接追加とは保存ボタンが異なるので、現在の画面を確認してください。

対応していない証券会社を使っている場合や、登録する銘柄が少ない場合は、手入力が便利です。
画像ファイルがなくても登録できます。

- **先に画面の選択欄を入力します。**
  証券会社、口座区分、韓国株式か海外株式かを決めます。
- **内容の確認にある直接追加を押します。**
  新しい銘柄の行が表示されます。
- **銘柄名とコードを確認します。**
  KISのコード検索で、該当銘柄を確認します。
- **数量と価格を入力します。**
  保有数量、分かっている画像の価格と取得単価を入力します。
- **ほかの銘柄も必要なら、直接追加をもう一度押します。**
  同じ証券会社、口座、市場に属する銘柄を追加します。

不要な行は右の**x**で外します。
この操作は、保存前の入力一覧から行を除外するものです。
証券会社や口座が異なる残高は、いったん保存してから画面選択を変え、別々に登録してください。

<br/>

## 7. 確認して保存する

最後に、三つの点を照合します。

- **保有先**
  証券会社、口座区分、韓国または米国の市場は正しいか？
- **銘柄**
  名前、コード、取引所は実際の保有商品と一致するか？
- **数値**
  数量、1株の価格、1株あたりの平均取得単価、通貨は正しいか？

正しければ**確認して保存**を押します。
保存に成功すると、保有資産画面へ移動します。
登録した銘柄が表示され、数量が実残高と一致することを確認してください。

<br/>

#### 7.1 同じ残高を再登録するとどうなるか

同じ証券会社、口座、市場に同じ銘柄コードで登録すると、既存銘柄の残高が更新されます。
取引所情報も一致しているか確認します。
例えば、最初に10株を登録してから2株買い増したとします。
新しい残高を登録するときは、**現在の総保有数量である12株**を入力します。
登録後も12株と表示されます。

| 状況 | 入力する数量 | 登録後の保有数量 |
| --- | ---: | ---: |
| 最初に10株を登録 | 10 | 10 |
| 2株を買い増した後、同じ口座の残高を更新 | 12 | 12 |
| その後5株を売却し、同じ口座の残高を更新 | 7 | 7 |

<Ybox>
口座名を変えて登録すると、別の残高になる場合があります。同じ残高の名前だけを変えて再登録しないでください。銘柄コードのない項目も、名前だけで自動統合されるとは限りません。
</Ybox>

スクリーンショットでは口座全体を自動同期しません。
新しい画像にない銘柄が、既存の保有一覧から自動で削除されることもありません。
全株を売却した銘柄は保有一覧で別途整理し、実際の残高と照合してください。

<Ads2/>

## 8. 暗号資産を検索する

株式の登録が済んだら、暗号資産を登録します。
PCでは左の**資産編集**を押します。
モバイルでは**すべて → 資産編集**に進みます。
下にある**暗号資産・現金の編集**を探します。
株式一覧が先に表示されるので、スクロールが必要な場合があります。
欄が閉じていたら、見出しを押して開きます。

<br/>

#### 8.1 似た名前から正しい銘柄を選ぶ

「暗号資産・Bithumbのウォン建て価格」の検索欄に、名前またはコードを入力します。
例えば**イーサリアム**または**KRW-ETH**を入力し、検索を押します。
結果から、実際に保有する銘柄を選びます。
イーサリアム、イーサリアムクラシック、イーサリアムネームサービスは別の銘柄です。
名前が似ていても、**市場コード**まで確認してください。
選択後は、入力欄に「イーサリアム・KRW-ETH」のように名前とコードが表示されます。
表示を確認してから数量を入力します。

<Img src="/portrhythm-assets-desktop-crypto-20261008.webp" width={800} alt="PC版の資産編集でイーサリアムKRW-ETHを選び、数量0.05、1単位あたりの取得価格3000000を入力した例"/>
<Img src="/portrhythm-assets-mobile-crypto-20261008.webp" width={350} alt="モバイル版の暗号資産入力欄にあるイーサリアムの検索、保有数量、取得単価、ポート選択、追加ボタン"/>

<br/>

#### 8.2 Bithumbのウォン建て価格

この入力では、**Bithumbのウォン建て市場の価格で評価額を計算します。**
取引所のアカウントを接続し、自分の残高を自動取得する機能ではありません。
保有数量は自分で確認して入力します。
ほかの場所に保有する銘柄でも、Bithumbに同じ銘柄のウォン建て市場があれば、その価格で管理できます。
ただし、実際に保有する取引所の価格とは異なる場合があります。
検索に出ない市場を、似た別の銘柄で代用しないでください。

<br/>

## 9. 暗号資産の数量と取得単価を入力する

#### 9.1 少量でも保有数量をそのまま入力する

イーサリアムを0.05単位持っているなら、数量に**0.05**を入力します。
購入に使ったウォンの金額や現在の評価額を、数量欄に入れないでください。
数量は正の数で、小数点以下12桁まで入力できます。
「1単位あたりの取得価格（ウォン）」には、**1単位あたりの平均取得価格**を入力します。
全保有分に使った金額は、別の値です。

| 項目 | 入力例 | 意味 |
| --- | ---: | --- |
| 銘柄 | イーサリアム・KRW-ETH | 評価に使う市場 |
| 数量 | 0.05 | 保有するイーサリアムの数量 |
| 1単位あたりの取得価格 | 3,000,000 | イーサリアム1単位あたりの平均取得価格、ウォン |
| 取得総額 | 150,000ウォン | 0.05 × 3,000,000で計算した額 |

取得総額の15万ウォンを取得単価欄に入力すると、計算結果が変わります。
**この例で入力するのは3,000,000です。** 150,000は総額です。

<br/>

ビットコインも同じ手順です。
0.01 BTCを保有し、1 BTCの平均取得価格が8,000万ウォンなら、数量は0.01、取得単価は80,000,000です。
取得総額は80万ウォンになります。
取得単価が分からなければ、空欄にできます。
この場合に評価額と取得価格に基づく損益で、計算できる範囲が異なるのは、株式と同じです。

<br/>

#### 9.2 ポートを選んでから追加する

数量と取得単価の横のポート選択で、この資産を入れるかごを選びます。
初期設定のポートが自分の計画に合っているか確認してください。
画像ではテストアカウントの「ビットコイン」が選ばれていますが、イーサリアムを必ずそのポートに入れる必要はありません。
入力内容を確認し、**追加**を押します。
下の一覧に該当銘柄が表示されたか確認します。

<Bbox>
暗号資産の「追加」は、保存前の一覧に項目を入れる操作です。下の「暗号資産・現金の変更を保存」まで押すと、アカウントに反映されます。モバイルでは下部の「変更を保存」も使えます。
</Bbox>

<br/>

#### 9.3 登録済みの銘柄を買い増した場合

同じ市場の銘柄は一度だけ登録できます。
ビットコインがすでにあれば、新しい項目を追加せず、**既存のビットコインの保有数量と取得単価**を修正します。
複数の取引所やウォレットで保有する同じ銘柄をまとめて管理する場合は、その市場の総保有数量を入力します。
株式のような証券会社・口座別の登録欄はありません。

<Toggle title="複数回買った暗号資産の平均取得価格はどう計算しますか？">
二つの価格を足して2で割る単純平均と、数量で重み付けする平均は異なります。
例えば0.01 BTCを1 BTCあたり8,000万ウォンで、0.02 BTCを1 BTCあたり9,000万ウォンで買ったとします。
総数量は0.03 BTC、取得総額は80万ウォン＋180万ウォン＝260万ウォンです。
1 BTCあたりの平均取得価格は**260万ウォン ÷ 0.03**で、約8,666万6,667ウォンです。
取引所が平均取得価格を表示する場合は、手数料を含める基準などを確認してその値を使ってください。
</Toggle>

<br/>

## 10. 現金を登録する（ウォン・ドル・その他の手入力）

同じ資産編集画面の下にスクロールします。
**その他の手入力資産**が表示されます。
ここでは株式のように数量と市場価格を組み合わせず、管理する金額を直接入力します。
現金や、評価額を別途管理する資産に使います。

<Img src="/portrhythm-assets-desktop-cash-20261008.webp" width={800} alt="PC版のその他の手入力資産で、ドル現金の名前、金額1000、ドル通貨とポートを選ぶ例"/>
<Img src="/portrhythm-assets-mobile-cash-20261008.webp" width={350} alt="モバイル版のその他の手入力資産にある名前、金額、ウォン・ドルの選択、ポート選択、追加ボタン"/>

<br/>

#### 10.1 ウォンの現金50万ウォンを入力する

- **名前**
  「生活費口座の現金」「投資待ちの現金」など、見分けられる名前を入力します。
- **通貨**
  ウォンを選びます。
- **金額**
  50万ウォンなら**500000**を入力します。
- **ポート**
  管理するかごを選び、まだ決めていなければ未分類にします。
- **追加**
  下の一覧に名前と金額が表示されたか確認します。

名前だけを入力し、金額を空欄にしないでください。
目的の残高が入っているか確認してから追加します。

<br/>

#### 10.2 ドルの現金1,000ドルを入力する

通貨で**ドル**を選びます。
金額に**1000**を入力します。
ウォン換算後の数字は入れません。

| 保有する現金 | 選ぶ通貨 | 入力する金額 |
| --- | --- | ---: |
| 50万ウォン | ウォン | 500000 |
| 1,000ドル | ドル | 1000 |

説明用に1ドル＝1,350ウォンとすると、1,000ドルのウォン換算評価額は135万ウォンです。
この評価には、アプリの為替レート設定が反映されます。

<Ybox>
ドルを選んで1,350,000を入力すると、135万ドルとして計算されます。ドル資産にはドルの残高を入力し、換算はアプリに任せます。
</Ybox>

撮影した画面では、その時点のテストアカウントの為替レートで換算した額を表示しています。
自分の画面で換算額が違う場合は、まず[第2回の為替レート設定](https://www.promleeblog.com/blog/post/437-portrhythm-portfolio-setup-guide)を確認してください。

<br/>

#### 10.3 どこまで現金を含めるか

アプリで比較する投資資産の範囲を先に決めてください。
投資に使う現金と生活費口座の両方を入れると、総額と構成比が変わります。
「投資待ちの現金」という**ポート**を作ることと、実際の現金額を**資産**として登録することは別です。
ポート名を作成しただけでは、現金の評価額は計上されません。
手入力資産では、残高を自動取得しません。
入出金や金額の変化があったら、金額を修正して保存してください。
ドル資産は、入力したドル額を維持し、設定したレートでウォン換算評価額を計算します。

<Toggle title="同じ資産を株式や暗号資産と手入力の両方に入れてもよいですか？">
株式10株を登録した後、その評価額を手入力資産にも入れると、同じ資産が二重計上されます。
暗号資産も、数量で登録したら、同じ銘柄の評価額を別途登録しないでください。
手入力は、別途管理する金額を入れるために使います。
手入力資産は名前が同じでも自動で一つにまとめないため、同じ残高が一覧に二度入っていないかも確認します。
</Toggle>

## 11. 暗号資産と現金の変更を保存する

暗号資産と現金を一覧に追加したら、最後に保存します。
PCでは欄の下の**暗号資産・現金の変更を保存**を押します。
モバイルでは同じボタンか、画面下部の**変更を保存**を押します。

<Img src="/portrhythm-assets-mobile-save-20261008.webp" width={350} alt="ドル現金を一時一覧に追加し、モバイルで暗号資産・現金の変更保存と下部の保存ボタンを確認する画面"/>

*画像は保存ボタンの位置を示す例です。撮影用の入力は実際には保存していません。*

完了したら、**保存済み**の表示を確認します。
保有資産に移動し、登録した暗号資産と現金があるか確認してください。
暗号資産は、市場価格を取得してから数量に応じて評価額を計算します。

<br/>

株式の行を修正する個別の「保存」と、暗号資産・現金の変更保存は、手順が異なります。
株式1銘柄を保存しても、下にある未保存の現金の入力は保存されません。
変更した欄ごとに保存の完了を確認してください。

<Gbox>
株式は「確認して保存」、暗号資産と現金は「追加してから変更を保存」です。この二つを覚えると、入力した内容が消える場面を減らせます。
</Gbox>

<br/>

## 12. 登録後に保有資産を確認する

実際の残高とPortRhythmを並べて確認します。
総額を先に合わせようとせず、**資産ごとの数量と通貨**から確認してください。

| 確認項目 | 正しい状態 |
| --- | --- |
| 株式口座の区分 | 同じ口座を別の名前で重複登録していない |
| 株式の取得単価 | 取得総額ではなく1株あたりの平均取得価格 |
| 暗号資産 | 正確な市場コードと総保有数量 |
| 暗号資産の取得価格 | 1単位あたりのウォン建て平均取得価格 |
| 現金 | 名前、残高、ウォンかドルかが一致 |
| 手入力の一覧 | 同じ残高や登録済み銘柄が重複していない |
| 保存 | 一時的な追加で止まらず、保存が完了している |

<br/>

#### 12.1 証券会社のアプリと評価額が少し異なる場合

数量が同じでも、**価格を取得した時点と為替レート**で評価額は変わります。
株式は取得した価格があればその価格を使い、取得できない場合は入力済みの画像の価格を使うことがあります。
画面の価格の出典と取得時刻も確認してください。
暗号資産はBithumbのウォン建て価格を使うため、ほかの取引所の評価額と異なる場合があります。
ドル資産のウォン換算には、PortRhythmの為替レート設定を使います。
先に数量、単価、通貨の入力ミスを確認し、その後で価格と為替レートの基準を比べてください。

<br/>

## よくある質問

<Toggle title="スクリーンショットを選んでも銘柄が表示されません">
対応する証券会社と残高形式かを確認します。
銘柄と数量が鮮明な画像かも確認してください。
うまく読み取れなければ、「直接追加」で入力できます。
画像認識が成功しなくても登録できます。
</Toggle>

<Toggle title="保存時に銘柄コードや数量を確認するよう表示されます">
米国銘柄にはティッカーが必要です。
銘柄名と市場を確認し、KISでコードを検索してください。
保有数量は0より大きい必要があります。
価格や取得単価を入力した場合は、有効な正の値か確認し、不明な値を0で埋めないでください。
証券会社と口座区分が空欄でないかも確認します。
</Toggle>

<Toggle title="登録した株式の価格が表示されないか、想定と異なります">
銘柄コード、市場、取引所が実際の商品に合っているか確認します。
誤ったコードなら、資産編集で該当銘柄のコードの確認・変更機能を使います。
現在価格を取得できず、画像の価格もない場合は、評価額を計算するための価格が不足している可能性があります。
名前が似た別の銘柄に変えず、実際の銘柄情報を確認してください。
</Toggle>

<Toggle title="暗号資産を検索しましたが、追加できません">
検索結果で銘柄を実際に選んだか確認します。
検索語を入力した状態と、市場を選択した状態は別です。
数量は正の値が必要です。取得価格も入力する場合は正の値を使います。
同じ市場の項目がすでにあれば、既存の数量と取得価格を修正してください。
結果がなければ、対応するBithumbのウォン建て市場にその銘柄があるか確認します。
</Toggle>

<Toggle title="現金を追加しましたが、再読み込みすると消えました">
「追加」は、保存前の一覧に入れる操作です。
暗号資産・現金の変更保存、またはモバイルの変更保存まで押したか確認してください。
保存完了を確認してから、別の画面に移動します。
最初に登録したときと同じログイン方法とアカウントでアクセスしているかも確認します。
</Toggle>

<Toggle title="金額が想定の数百倍、または数千倍になりました">
まず単位を確認します。
米国株の取得単価にウォン換算額を入れたり、ドルの現金にウォンの金額を入れたりすると、結果が大きく変わります。
株式や暗号資産の単価欄には、1株または1単位あたりの価格を入力します。
数量欄には保有数量、ドルの金額欄には実際のドル残高を入力します。
重複登録も確認してください。
</Toggle>
