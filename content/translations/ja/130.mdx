## はじめに
> この記事はMac環境で書かれています。

一つのプロジェクトフォルダーで、複数のリモートリポジトリを管理したい場合があります。
例えば、同じプロジェクトを別々のクライアントへ提供する場合です。
このようなときに、一つのフォルダーから複数のリモートリポジトリを管理する方法を紹介します。

## 1. 一つ目のremote repositoryを追加する
まず、空のプロジェクトフォルダーを作ります。
```bash
mkdir project-folder
```
GitHubで事前に作成したリポジトリの、リモートURLをコピーします。
<Img src="/posts/240606-154630.png" alt="240606-154630" width="800"/>
コピーしたURLを使い、一つ目のリモートリポジトリを追加します。
```bash
git remote add origin https://github.com/user/first-repo.git
```

<Ads1 />
## 2. 二つ目のremote repositoryを追加する
GitHubで追加のリポジトリを作り、そのリモートURLを使います。
二つ目を追加するときは、origin以外の名前を使うことをおすすめします。
originという名前を使うと、すべての操作が二つのリモートリポジトリへ同時に適用されてしまいます。
私は、二つ目のリモート名をsecond-remoteにしました。
```bash
git remote add second-remote https://github.com/user/second-repo.git
```
## 3. 設定を確認する
ターミナルでプロジェクトフォルダーへ移動し、次のコマンドを実行します。
```bash
git remote -v
```

例えば、次のように表示されます。
```bash
origin  https://github.com/user/first-repo.git (fetch)
origin  https://github.com/user/first-repo.git (push)
second-remote  https://github.com/user/second-repo.git (fetch)
second-remote  https://github.com/user/second-repo.git (push)
```

<Ads2 />
## 4. ブランチの切り替えとpush・pull
二つのリモートが接続されているため、ブランチを切り替える際は、リモート名を指定します。
```bash
git checkout second-remote/main
```

ブランチを切り替えたら、作業を進めます。
```bash
git add .
git commit -m "commit message"
git push second-remote main
```
もちろん、両方のリモートのブランチへ続けてpushすることもできます。
```bash
git push origin main
git push second-remote main
```

pullする場合も、リモート名を正しく指定する必要があります。
```bash
git pull origin main
git pull second-remote main
```

## 5. remote repositoryを削除する
リモートリポジトリの設定を削除する場合は、次のコマンドを実行します。
```bash
git remote remove origin
git remote remove second-remote
```

## おわりに
一つのプロジェクトフォルダーで、複数のリモートリポジトリを管理する方法を紹介しました。
この方法を使えば、複数のリモートを扱いやすくなります。
