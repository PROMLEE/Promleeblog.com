## はじめに

フルーツセットを2箱買い、好きなリンゴも別に買いました。
箱は3つありますが、開けると1つ目のセットにも2つ目にもリンゴが入っています。
ETFと個別株を買うときも、似たことが起こります。
**買った商品の数より、その中に何がどれだけ入っているかを見ます。**
<br/>
[第1回](https://www.promleeblog.com/blog/post/458-portfolio-reading-consolidated-holdings)では、1,000万ウォンのうち株式が600万ウォンであることを確認しました。
今回はETFの中身も開いて、「企業Xに連動するお金はいくらあるか」を計算します。
作るのは、**直接買った株とETFの中の持ち分を合計した、企業別のチェックリスト**です。

<Rbox>
本文の計算は理解のための例であり、投資の推奨ではありません。
PortRhythmの画面はテスト用アカウントのデータで、本文の金額と異なる場合があります。
</Rbox>

## 2つのETFにも同じ企業が入る

ETFを、複数の資産を詰め合わせた商品と考えます。
名前が異なる2つのETFにも、同じ企業の株式が入ることがあります。
Xの株を直接買っていれば、Xは3つの経路で投資資金につながります。
<br/>
FINRAも、ファンド同士や、直接保有する株式との重複がないか、構成銘柄を確認するよう案内しています。
運用会社が違っても、組み入れる企業まで違うとは限りません。
[FINRAの集中リスクの説明](https://www.finra.org/investors/insights/concentration-risk)
<br/>
重複が見つかっても、買い方を誤ったとは限りません。
好きな企業の比率を意図的に増やしていることもあります。
まず、**思ったより多く持っているか**を確認し、その比率を維持する理由があるかを書きます。

## 自分の保有分とETFの中の持ち分

計算に使う保有資産は、第1回の表から3行だけ取り出します。
比率の分母は、残りの資産も含めた1,000万ウォンです。

| 資産 | 保有額 | 全体に占める割合 |
| --- | ---: | ---: |
| 米国株ETF A | 300万ウォン | 30% |
| 米国成長株ETF B | 150万ウォン | 15% |
| 個別株X | 50万ウォン | 5% |

ETF A内のXの比率は6%、ETF B内では10%です。
ほかの保有項目にはX株が入っていないとします。
<br/>
30%と6%は、違う問いに答える数字です。
30%は「自分のお金のうちETF Aに入った割合」、6%は「ETF Aの中でXが占める割合」です。
買い物代全体でフルーツセットが占める割合と、セットの中でリンゴが占める割合を別々に見るようなものです。

## 300万ウォンの中の6%を求める

大きな式を使う前に、金額を計算します。
ETF Aの300万ウォンの6%は `300만 × 0.06 = 18만 원`（18万ウォン）です。
ETF Bの150万ウォンの10%は `150만 × 0.10 = 15만 원`（15万ウォン）です。
ここに、直接買ったXの50万ウォンを足します。
<br/>
`18만 + 15만 + 50만 = 83만 원`（83万ウォン）です。
総額1,000万ウォンで割ると、`83만 ÷ 1,000만 × 100 = 8.3%` です。
**一覧上で直接保有するXは5%でしたが、ETFの中身を合わせると8.3%になります。**

<Img src="/portfolio-reading-02-etf-overlap-20261017.webp" width={750} height={500} alt="ETF AのXが18万ウォン、ETF BのXが15万ウォン、直接保有するXが50万ウォンで、合計83万ウォン・8.3%"/>

| Xを含む場所 | 計算 | Xに相当する金額 | 全体に占める割合 |
| --- | --- | ---: | ---: |
| ETF Aの中 | 300万ウォンの6% | 18万ウォン | 1.8% |
| ETF Bの中 | 150万ウォンの10% | 15万ウォン | 1.5% |
| 直接買ったX | 全額がX | 50万ウォン | 5.0% |
| 合計 | | **83万ウォン** | **8.3%** |

このように、ある企業の株価に連動する投資資金の割合を、企業別のエクスポージャーと呼びます。
用語を覚えるより、**自分のお金のうちXと一緒に動く分**と考えれば十分です。
8.3%と5%の差は3.3パーセントポイント、略して `3.3%p` です。
<br/>
比率同士で計算するなら、`30% × 6% = 1.8%` です。
電卓では `0.30 × 0.06 = 0.018` を求めてから100を掛けます。
混乱したら、上の表のようにウォン建ての金額を先に求め、総額で割ります。

## 83万ウォンを新しいお金として足さない

ETFの中身を見ても、お金が新たに生まれたわけではありません。
83万ウォンのうち33万ウォンは、ETF AとBの残高にすでに含まれています。
ETFの評価額を足し、その中のXも足すと、同じお金を二重に数えます。
**表の読み方が変わっただけで、総額は1,000万ウォンのままです。**
<br/>
企業別に説明し直すと、次のようになります。
今回はXだけを計算し、ほかの株式の中身までは確認していません。

| 区分 | 金額 | 全体比率 | 確認状況 |
| --- | ---: | ---: | --- |
| X株の合計 | 83万ウォン | 8.3% | 計算済み |
| その他の株式 | 517万ウォン | 51.7% | 企業別の内訳は未確認 |
| 債券・金・現金 | 400万ウォン | 40% | 今回のX株の計算対象外 |
| 合計 | **1,000万ウォン** | **100%** | |

「その他の株式」517万ウォンは1社の名前ではなく、まだ詳しく見ていない部分です。
未確認だからといって、安全または均等に分散されているとは扱いません。
異なる企業を組み入れていても、同じ業種に集中していれば一緒に値動きする可能性があります。
ETFが狭い業種に集中していれば、十分な分散にはならない場合があります。
[Investor.govの分散投資の説明](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)

## 実際のETFは構成表を確認する

自分のETFに当てはめるときは、運用会社の公式サイトで**実際の保有銘柄と組入比率**を探します。
連動対象指数の構成表と、ETFが実際に保有する資産の表が同じ資料かを確かめます。
銘柄コードと構成表の基準日も記録します。
資料と自分の残高の日付が異なれば、「別の日の構成で推定」とメモします。
<br/>
上位10社しか掲載されていなければ、残りの部分にXが入っているかはわかりません。
同じ会社の株式が別の名称や種類で表示されている場合は、同じ会社にまとめる基準も確認します。
最初は関心のある企業1社から調べてもかまいません。

<Ybox>
この掛け算は、普通株を直接組み入れるETFに使う方法です。
商品名にレバレッジやインバースと付いている場合や、別のファンドやデリバティブを通じて投資する場合は、仕組みが異なることがあります。
その場合は同じ式をすぐに当てはめず、説明書で投資方法を先に確認します。
</Ybox>

## PortRhythmからチェックリストへ

PortRhythmの保有資産で、**どのETFをいくら保有しているか**を確認します。
銘柄コード、口座、数量、評価額を元の残高と照合します。
同じETFを2つの口座で保有するなら、金額を合計して計算します。
画面の見方は[ダッシュボードと保有資産ガイド](https://www.promleeblog.com/blog/post/440-portrhythm-dashboard-holdings-guide)を参照してください。

<Img src="/portrhythm-guide5-desktop-holdings-20261008.webp" width={750} height={422} alt="銘柄、口座、数量、価格、評価額を確認する保有資産画面"/>

見るのは銘柄名、コード、評価額です。
保有一覧に運用会社の構成表を結び付け、**企業別の金額を計算します。**
<br/>
自分のチェックリストには、次の5行を残します。

| 項目 | 記録する内容 |
| --- | --- |
| 確認する企業 | X |
| 直接買った金額 | 50万ウォン |
| ETFの中の持ち分 | Aで18万ウォン、Bで15万ウォン |
| 合計と全体比率 | 83万ウォン、8.3% |
| 資料の日付・未確認事項 | T0、ほかの企業の構成は未分析 |

<Bbox>
最初からすべての企業を計算しようとすると、表を開く前に疲れてしまいます。
直接買った株を1つ選び、自分のETFにもその会社が入っているかを確かめるところから始めてみてください。
</Bbox>

## おわりに

複数の箱に、同じ企業が入っていました。
直接保有するXの50万ウォンに、ETFに含まれる33万ウォンを加えると、**合計83万ウォン、全体の8.3%**です。
「ETFを2つ持っています」に加え、「Xに連動するお金はこのくらいです」と説明できます。
<br/>
[PortRhythmの保有資産](https://pf.promleeblog.com/?view=holdings)で企業を1社選び、チェックリストを埋めてみてください。
次回は、決済通貨と実際の投資対象が違う場合を見ます。
ウォンで買ったのに、なぜ米ドルの為替レートの影響を受けるのかを確認します。
