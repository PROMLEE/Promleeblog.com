## はじめに

オンラインで商品を選ぶとき、本体の価格だけを見て一番安い店を選びました。
ところが、決済画面で送料を加えると、順位が変わりました。
ETFも、紹介画面の報酬欄だけでは見落とす費用があります。
**総報酬は大切な価格表示ですが、費用の明細すべてを示してはいません。**
<br/>
今回は、TIGER、ACE、SOLの米国S&P500 ETFの公式費用表を読みます。
目的は、**どの費用がどこに反映されるかを説明できるようになること**です。
同じ費用を二重に足したり、控除済みの報酬をリターンから再び引いたりしないように確認します。

<Rbox>
商品数値は2026年10月20日に確認した公式資料に基づきます。
計算例は費用の仕組みを示すためのものです。過去の費用率は、将来の実際の費用や商品の順位を保証しません。
</Rbox>

## 費用が発生する2つの場所

まず「ファンドの中」と「自分の取引」を分けます。
ファンドが株式を保管、売買するための費用と、自分がETFを売買するときに負担する費用は異なります。

<Img src="/etf-selection-03-costs-20261020.webp" width={750} height={500} alt="ファンド内の総報酬・その他の費用・売買費用と、投資家の手数料・気配値の差・両替費用を分けた図"/>

| 発生する場所 | 確認する項目 | 参照資料 |
| --- | --- | --- |
| ファンドの中 | 総報酬、その他の費用、内部の売買費用 | 投資説明書、運用報告書 |
| 自分の取引 | 証券会社の手数料、売買気配値の差、両替費用 | 口座の手数料条件、取引時の気配値 |

ファンドの運営費は資産から支出され、残った資産の価値に影響します。
個別の決済通知が来なくても、費用は発生します。
一方、証券会社の取引手数料などは、ファンドの費用表だけではすべてわかりません。
[Investor.govのファンドとETFの費用の説明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/mutual-fund-and-etf-fees-and-expenses-investor-bulletin)

## 総報酬の隣の欄も読む

総報酬は、運用、信託、事務管理など、所定の報酬項目をまとめた比率です。
隣に、保管、指数の使用、会計監査などの**その他の費用**が別に表示されることがあります。
さらに隣の**総報酬・費用**に何が含まれるかは、脚注で確認します。
すでに合算された値に、前の項目をもう一度足さないようにします。
<br/>
3商品の説明書から該当欄を写します。
以下はすべて年率で、単位は `%` です。

| 項目 | TIGER 360750 | ACE 360200 | SOL 433330 |
| --- | ---: | ---: | ---: |
| 総報酬 | 0.0068 | 0.0047 | 0.0047 |
| その他の費用 | 0.0600 | 0.0660 | 0.0485 |
| 総報酬・費用 | 0.0668 | 0.0707 | 0.0532 |

TIGERは作成基準日が `2026-10-01` の説明書32ページ、ACEは効力発生日が `2026-02-13` の説明書の報酬・手数料欄、SOLは作成基準日が `2026-05-22` の説明書32ページを確認しました。
その他の費用は、文書で定められた過去の会計期間の実績に基づきます。総報酬は、その文書で示された報酬率です。
**確認日が同じでも、すべての数値が同じ日に実測した費用というわけではありません。**
[TIGERの投資説明書](https://investments.miraeasset.com/tigeretf/upload/etf/20261008090949000003.pdf) · [ACEの文書一覧](https://papi.aceetf.co.kr/api/funds/K55101D78195/documents) · [SOLの公式文書](https://www.soletf.com/ko/fund/etf/210930)
<br/>
例えばTIGERの表では `0.0068 + 0.0600 = 0.0668%` です。
0.0668%に総報酬0.0068%を足すと、総報酬が二重計上されます。
比率を足す前に、項目名と脚注を合わせて読みます。

## 「合成総報酬費用」の「合成」が指すもの

SOLの説明書には、もう1つ欄があります。
総報酬・費用は0.0532%ですが、**合成総報酬費用は0.0674%**です。
説明書には、投資先の集団投資スキームの報酬を含むと書かれています。
ほかのファンドを経由して投資する場合、そのファンド内の報酬も確認する欄です。
<br/>
差は `0.0674 − 0.0532 = 0.0142%p` です。
同じ説明書の、投資先ファンドの予想総報酬0.01420%に対応します。
**費用表の見出しに「合成」とあるだけでは、合成ETFとは判断できません。**
商品名の「合成」は投資の仕組みを示し、この表の「合成」は費用を合算したことを示します。
[SOLの説明書の報酬・手数料欄](https://www.soletf.com/ko/fund/etf/210930)
<br/>
SOLの0.0532%を、投資先ファンドを含む他商品の比率と比べると、対象範囲が異なる場合があります。
文書ごとに含まれる項目を確認し、そろえてから比べます。

## ファンドの売買費用も別に見る

ファンドが株式を売買する際の証券取引費用は、その他の費用とは別に表示される場合があります。
ACEは年率0.0303%、SOLは0.0359%を別の欄に記載しています。
両文書で、この過去費用の会計期間は `2025-01-01 → 2025-12-31` です。
TIGERの説明書は、直前の会計期間の証券取引費用を別表で金額として示しています。
[ACEの費用の脚注](https://papi.aceetf.co.kr/api/funds/K55101D78195/documents) · [SOLの費用の脚注](https://www.soletf.com/ko/fund/etf/210930) · [TIGERの費用の脚注](https://investments.miraeasset.com/tigeretf/upload/etf/20261008090949000003.pdf)
<br/>
パーセントとウォン建ての金額を同じ欄に置いて、そのまま足すことはできません。
金額を比率に変えるには、該当期間の平均純資産など、適切な基準が必要です。
資料にない費用を0で埋めず、**単位と対象範囲を先にそろえます。**

## 小さな比率を金額に直す

比率の大きさをつかむには、投資額に掛けてみます。
投資額が1年を通じて1,000万ウォンで一定とし、年率の費用だけを変えます。

| 年間費用率 | 1年分の単純換算 |
| --- | ---: |
| 0.10% | 1万ウォン |
| 0.20% | 2万ウォン |
| 差0.10%p | 1万ウォン |

月ごとの残高変動、追加投資、複利、税を除いた概算です。
ファンドの実際の費用が年末に一度、この金額で請求されるという意味ではありません。
<br/>
表示された総報酬だけを同じ方法で換算すると、1,000万ウォンの0.0068%は680ウォン、0.0047%は470ウォンです。
差は年間210ウォンです。
この差だけでは、費用全体の順位を決めにくいとわかります。
その他の費用と取引条件まで確認する理由です。

## 自分の取引で発生する費用

証券会社の手数料は、自分の口座に適用される条件を確認します。
韓国上場ETFをウォンで買うなら、原資産が米国株というだけで、自分の口座の両替手数料を加えることはしません。
米ドルで直接取引する場合など、実際に両替が必要な場合とは区別します。
<br/>
気配値も費用に影響します。
今すぐ買う価格が10,010ウォン、売る価格が9,990ウォンなら、中間値10,000ウォンとの差はそれぞれ10ウォンです。
売りと買いの気配値の差を示す**スプレッド**は `20 ÷ 10,000 = 0.20%` です。
価格が変わらず、表示数量で約定できるなら、100口を買ってすぐ売ると2,000ウォンの差が生じます。
<br/>
これはある時点の気配値の比較で、固定の年会費ではありません。
注文数量、市場の状況、約定価格で変わります。
この価格差を取引損益に反映しているなら、同じスプレッドを費用としてもう一度引きません。
[Investor.govのETF取引費用の説明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/mutual-fund-and-etf-fees-and-expenses-investor-bulletin)

## 費用比較表の最終確認

数値とともに、**単位、期間、含まれる項目**を表に記録します。

- 総報酬と総報酬・費用を区別したか。
- 投資先ファンドの報酬を含むか。
- 証券取引費用は比率か、金額か。
- 過去費用の会計期間と、現在の報酬率を区別したか。
- 自分の口座の手数料と、実際の気配値を確認したか。

<Bbox>
公式のNAVリターンには、ファンドがすでに支払った費用が反映されています。
そこから開示報酬をもう一度引くと、同じ費用が二重に反映される場合があります。
費用表は、成績の差が生じた理由を読み取るためにも使えます。投資家の取引手数料など、まだ反映されていない項目だけを分けて確認します。
</Bbox>

PortRhythmの評価額は、費用の規模をつかむための出発点として使えます。
報酬、その他の費用、気配値は公式文書や取引画面で確認し、費用表に書きます。
保有期間が長ければ繰り返し発生する費用を、売買が多ければその都度かかる費用も確認します。

## おわりに

ETFの費用は、表示された報酬だけではわかりません。
ファンド内の費用と自分の取引費用を分け、合算済みの値を重複して足さない方法を確認しました。
今日の成果は、**どの費用がどこに含まれているかを説明できる比較表**です。
<br/>
次回は、費用と運用方式が実際の指数連動成績にどう表れるかを見ます。
指数を下回ったことと、指数との間隔が揺れたことの違いを確認します。
