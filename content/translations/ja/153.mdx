## はじめに
> この記事では、基本的なExpoプロジェクトが作成済みであることを前提にします。作成方法は[Windows版Expoプロジェクト作成](/blog/post/117-expo-proj-init)、[Mac版](/blog/post/143-expo-init-mac)を参照してください。
> 基本的なReact Native CLI環境でも、追加設定を行えば利用できます。

### スマートフォンの生体認証
スマートフォンの生体認証は、端末のセキュリティ強化に役立ちます。指紋、顔、虹彩などを使って本人確認を行う方式です。端末を便利に使いながら認証できます。
expo-local-authenticationを使うと、Androidの生体認証プロンプトやiOSのFace ID・Touch IDを通じて、指紋または顔でユーザーを認証できます。
## expo-local-authenticationのインストール
```bash
expo install expo-local-authentication
```
## 追加設定
### Expo環境
Expo環境では、ルートディレクトリの`app.json`に次の設定を追加します。
```json
{
  "expo": {
    "plugins": [
      [
        "expo-local-authentication",
        {
          "faceIDPermission": "Allow $(PRODUCT_NAME) to use Face ID."
        }
      ]
    ]
  }
}
```
### React Native CLI環境
追加設定は[react-native-local-authenticationの説明](https://github.com/expo/expo/tree/main/packages/expo-local-authentication#installation-in-bare-react-native-projects)を参照してください。
Androidでは`android/app/src/main/AndroidManifest.xml`に次の設定を追加します。
```xml
<uses-permission android:name="android.permission.USE_BIOMETRIC" />
<uses-permission android:name="android.permission.USE_FINGERPRINT" />
```
iOSではターミナルで次のコマンドを実行して設定を追加します。
```bash
npx pod-install
```
さらに`ios/Info.plist`にも次の設定を追加します。
```xml
<key>NSFaceIDUsageDescription</key>
<string>Allow $(PRODUCT_NAME) to use FaceID</string>
```

## 使い方
```tsx
import * as LocalAuthentication from 'expo-local-authentication';
import React from 'react';
import { Button, Text, View } from 'react-native';

export default function App() {
	const handleAuthentication = async () => {
		const hasHardware = await LocalAuthentication.hasHardwareAsync();
		if (!hasHardware) {
			alert('생체 인증을 사용할 수 없는 기기입니다.');
			return;
		}
		const isEnrolled = await LocalAuthentication.isEnrolledAsync();
		if (!isEnrolled) {
			alert('생체 인증이 등록되어 있지 않습니다.');
			return;
		}
		const result = await LocalAuthentication.authenticateAsync({
			promptMessage: '생체 인증을 사용하여 로그인하세요.',
		});
		if (result.success) {
			alert('로그인 성공!');
		} else {
			alert('로그인 실패!');
		}
	};

	return (
		<View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
			<Text>생체 인증을 사용하여 로그인하세요.</Text>
			<Button title="로그인" onPress={handleAuthentication} />
		</View>
	);
}
```

途中の指紋認証画面は、セキュリティ上の理由からキャプチャできません。
各関数の役割は次のとおりです。

### LocalAuthentication.hasHardwareAsync
端末で顔認証または指紋スキャナーを利用できるかを判定します。戻り値は`Promise<boolean>`です。

### LocalAuthentication.isEnrolledAsync
端末に指紋または顔が登録されているかを判定します。戻り値は`Promise<boolean>`です。
### LocalAuthentication.authenticateAsync
指紋やTouch ID（端末で利用できる場合はFace ID）による認証を試みます。引数として`LocalAuthenticationOptions`を受け取ります。
LocalAuthenticationOptionsでよく使うパラメーターをいくつか紹介します。
- promptMessage: string
Touch IDまたはFace IDの認証画面に表示するメッセージです。認証を求める理由がユーザーに伝わるよう設定することをおすすめします。
- cancelLabel: string
Touch IDまたはFace IDの画面に表示するキャンセルボタンのラベルです。デフォルト値は'Cancel'です。
- biometricsSecurityLevel: 'strong' | 'weak'
許可する生体認証のセキュリティレベルを設定します。
`strong`はAndroidのクラス3生体認証だけを許可します。指紋や3D顔認証が例です。
`weak`ではAndroidのクラス3とクラス2の両方を許可します。クラス2はクラス3より安全性が低く、カメラによる顔認証などが該当します。
- disableDeviceFallback: boolean
認証に複数回失敗すると、システムは端末のパスコードへフォールバックします。この設定を有効にするとシステムのフォールバックを無効にし、アプリ側で処理できます。独自の認証フローで必要になる場合があります。

全体の流れは次のとおりです。
1. `hasHardwareAsync`で生体認証が利用可能か確認します。
2. `isEnrolledAsync`で生体情報が登録済みか確認します。
3. `authenticateAsync`で生体認証を実行します。

## まとめ
Expo local authenticationを使ったReact Nativeの生体認証は、安全で便利な本人確認手段です。生体認証をアプリに簡単に組み込むことで、セキュリティとユーザー体験を向上できます。パスワードを入力せずに本人確認できるため、情報漏えいのリスク軽減にも役立ちます。Expo local authenticationは、安全なモバイルアプリを構築するための有用なツールです。
