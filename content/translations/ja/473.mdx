## はじめに

ノートパソコンを選ぶために比較表を作りました。
重さ、画面、バッテリー、価格まで書いたのに、かえって選べなくなりました。
考えてみると、「毎日持ち歩くか」という問いが抜けていました。
ETFも数字をたくさん集めるだけでは選べません。
<br/>
**比較表の一番上には、商品名より先に、自分が任せたい役割を書きます。**
最終回では、これまでの7回の問いを1枚にまとめ、選んだ理由や保留した理由を記録します。

<Rbox>
商品費用表は2026年10月20日に確認した説明書に基づき、この記事は2026年10月21日にまとめました。
未確認の項目はそのまま残しています。選択の記録は特定商品の購入推奨や将来の成績順位ではありません。
</Rbox>

## 役割を一文で書く

「リターンが良いETF」より、もう少し具体的にします。
例えば「長期投資資金で米国大型株を保有する役割」と書けます。
資金を使う時期、通貨、許容する値動きも添えます。
<br/>
債券なら、近い将来の支出に備えるのか、長期ポートフォリオに金利感応度を持たせるのかを分けます。
分配型の商品なら、今使う現金が必要か、受け取ったお金を再投資するかを記録します。
こうした問いに答えると、同じ列で比較する候補を決めやすくなります。
<br/>
株式、債券、カバードコールを「最近の上昇率が高い順」で並べると、役割が違う商品を成績だけで比較することになります。
**役割の同じ候補を、同じ尺度で比べます。**

## 最初に確認する必須条件

比較の第一段階では、加点より先に満たすべき条件を決めます。
米国大型株の役割を担う候補なら、次の順で確認します。

| 必須の問い | 確認すること |
| --- | --- |
| どの指数か | 正確な指数名とPR・TR・NTR |
| 為替の扱いは | 取引通貨と為替ヘッジ方針 |
| 別の戦略を組み込んでいるか | レバレッジ、インバース、コール売りなどの構造 |
| 自分の口座で取引できるか | 取引可能な商品、市場、口座の条件 |
| 比較できる資料はあるか | 期間、通貨、分配金の扱いをそろえた成果 |

口座で取引できるかと、自分に適しているかは別の問いです。
条件が見つからなければ、満たすと推測せず、確認先を書きます。
商品名とコードは[第1回](https://www.promleeblog.com/blog/post/466-etf-selection-reading-names)、比較条件は[第2回](https://www.promleeblog.com/blog/post/467-etf-selection-comparing-same-index)をご覧ください。

## 3商品の比較表

TIGER、ACE、SOLの米国S&P500 ETFで確認した内容をまとめました。
報酬と費用の比率は、すべて年率の `%` です。

| 項目 | TIGER 360750 | ACE 360200 | SOL 433330 |
| --- | --- | --- | --- |
| 主な役割 | 米国大型株 | 米国大型株 | 米国大型株 |
| 公式の指数表記 | S&P500 ウォン換算 | S&P500 PR ウォン換算 | S&P500 PR ウォン換算 |
| 為替ヘッジ方針 | 実施しない | 実施しない予定 | 実施しない予定 |
| 総報酬 | 0.0068 | 0.0047 | 0.0047 |
| その他の費用 | 0.0600 | 0.0660 | 0.0485 |
| 総報酬・費用 | 0.0668 | 0.0707 | 0.0532 |
| 投資先ファンドを含む費用 | 合成総報酬費用 0.0668 | 定義を追加確認 | 合成総報酬費用 0.0674 |

TIGERの説明書の作成基準日は `2026-10-01`、ACEの効力発生日は `2026-02-13`、SOLの作成基準日は `2026-05-22` です。
その他の費用には、文書が定める過去の会計期間が反映されます。同じ日に実測した費用の総額を示すものではありません。
証券取引費用、自分の口座の手数料、売買気配値の差も、表の合計とは別に読み取ります。
費用に何が含まれるか、ウォン換算の方法は[第3回](https://www.promleeblog.com/blog/post/468-etf-selection-total-costs)で確認できます。
[TIGERの説明書](https://investments.miraeasset.com/tigeretf/upload/etf/20261008090949000003.pdf) · [ACEの文書一覧](https://papi.aceetf.co.kr/api/funds/K55101D78195/documents) · [SOLの商品情報と文書](https://www.soletf.com/ko/fund/etf/210930)

## 空欄も判断の材料にする

表の次の行には、連動成績と取引条件を記録します。
以下は3商品に共通する確認状況です。

| 項目 | 現在の記録 | 次にすること |
| --- | --- | --- |
| 指数の定義 | TIGERのPR・TRを詳しく照合する必要あり | 公式の指数定義を確認 |
| 連動成績 | 共通期間の日次トータルリターン資料が未取得 | NAVと指数の配当、通貨、日付がそろうか確認 |
| 開示上のトラッキング・エラー | 同じ定義・期間での照合前 | 開示の計算式と観測期間を記録 |
| 取引条件 | 注文時点の気配値と数量は未観測 | 同時点の価値基準と気配値を記録 |
| 口座の条件 | 読者の口座によって異なる | 取引可否と手数料を確認 |

この比較では、**候補は3つ、選択は追加確認まで保留**とします。
資料がないことは、商品が劣ることや、値が0であることを意味しません。
空欄を、次に確認する問いへ変えたことが、今回の成果です。
<br/>
特にSOLの総報酬・費用0.0532%だけで、他商品より全体の費用が低いとは判断しません。
投資先ファンドの報酬を含むかによって、比較の範囲が変わります。
単位や期間がそろわない費用ランキングや、任意の重みを付けた総合点は、選ぶ理由を曖昧にしかねません。

## 債券とインカムには問いを追加する

共通の表をコピーし、役割に合う行を足します。
株式ETFの表に分配率を足しただけで、すべての商品を比較しません。

| 役割 | 追加項目 |
| --- | --- |
| 債券 | デュレーションの種類と基準日、信用、通貨、満期・終了条件 |
| 配当株 | 選定ルール、集中度、分配方針、トータルリターン |
| カバードコール | 原資産、コールの比率・権利行使価格・契約期間、分配の内訳、上昇への参加度 |

債券ではデュレーションが長いほど、金利変動に対して価格が大きく動く可能性があります。
カバードコールでプレミアムを受け取るのは、その代わりに権利を渡す契約と結びついています。
総合点に加える前に、自分が求める役割に合うかを読み取ります。
[iSharesの債券の仕組み](https://www.ishares.com/us/strategies/bond-etfs/build-better-bond-ladders) · [OICのカバードコール](https://www.optionseducation.org/strategies/all-strategies/covered-call-buy-write)

## 選択の記録を5行で残す

選ぶときは、表の下に次の5行を書きます。
保留した理由も、同じ形式で残せます。

| 問い | 今回の記録 |
| --- | --- |
| 任せる役割は | 長期投資資金の米国大型株 |
| 必須条件は | 正確な指数、ヘッジ、口座条件、成果の定義を確認 |
| 何を比較したか | 3商品の公式な構造と費用項目 |
| 今の判断は | 指数の定義、共通の時系列、気配値を追加確認してから選ぶ |
| いつ見直すか | 必要な資料がそろったとき。その後は方針、費用、資金の目的が変わったとき |

「ほかの人がよく買っているから」という理由より、あとで見直しやすくなります。
すべて確認して小さな差だけが残った場合は、自分の投資額や期間でその差がどれほど重要かを書きます。
1,000万ウォンに対し、表示報酬0.0068%と0.0047%の差は単純な年換算で210ウォンです。[第3回の計算](https://www.promleeblog.com/blog/post/468-etf-selection-total-costs)をこうした判断に使えます。
この金額は費用全体の差ではありません。

## PortRhythmでの位置づけ

3候補を検討しても、すべてを保有残高に登録する必要はありません。
実際に保有する商品が決まったら、コードと数量を確認し、担う資産の役割に割り当てます。
そのあと現在比率と目標比率を見ます。
<br/>
商品AからBに入れ替えることと、米国株の比率を増やすことは別の判断です。
似た商品を追加した結果、株式全体の比率が想定以上に高くなっていないかも確認します。
[PortRhythmでの資産割り当て](https://www.promleeblog.com/blog/post/439-portrhythm-asset-assignment-guide) · [現在比率と目標比率の確認](https://www.promleeblog.com/blog/post/441-portrhythm-current-target-allocation-guide)

<Bbox>
選択の理由を一文にして月次チェックリストに添えます。
翌月は順位の変化より、その理由が資金の目的にまだ合っているかを先に確認します。
商品条件が変わったら、該当項目をあらためて比較します。
</Bbox>

## おわりに

ETFの名前を出発点に、指数、費用、連動成績、取引条件を読みました。
債券とインカム戦略では、仕組みに合う問いを加えました。
完成した比較表は、**自分の選択理由と残った問いを説明する記録**です。
<br/>
保有するETFを1つ選び、役割、必須条件、確認した資料、判断、見直し条件を記録してみてください。
[月次ポートフォリオレポート](https://www.promleeblog.com/blog/post/465-portfolio-reading-monthly-review)にその記録をつなげると、商品選びと資産全体の点検を一緒に行えます。
