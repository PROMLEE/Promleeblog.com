## はじめに

> 「PCでは資産が見えるのに、スマートフォンでは何も表示されません。保存できていないのでしょうか？」

別の端末で初めてログインし、空の画面が出ると戸惑います。
夜に画面を開いて明るければ、まずダークモードを探したくなります。
こうしたときに最初に確認するのが、アカウント（`계정`）画面です。

<br/>

[第8回 資産記録](https://www.promleeblog.com/blog/post/443-portrhythm-asset-history-guide)では、評価額と入出金を記録しました。
今回は、その記録をどのアカウントで確認できるか、表示設定がどこに保存されるかを見ていきます。
資産を入力し直す前に、この違いを確かめます。

<br/>

**資産データと画面設定は、別々の場所に保存されます。**
保存した資産とポート設定はログインアカウントにひも付きます。
ライト・ダークモードは、現在のブラウザーに保存されます。
そのため、同じアカウントでアクセスしても、スマートフォンとPCで画面の色が異なる場合があります。

<Bbox>
別の端末で資産が表示されなければ、再登録する前に、普段使っているログイン方法とアカウントを確認してください。
この記事の画面はローカルのQAアカウントです。
実際のアカウントでは、ログインサービスから渡された名前とメールアドレスが表示される場合があります。
</Bbox>

## 1. アカウント画面を開く

PCでは、左のメニューでアカウント（`계정`）を押します。
サイドバー下部のプロフィール欄からも開けます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-desktop-account-20261009.webp" width={800} alt="PC版のマイアカウント画面に表示されたログインアカウント、画面モード、投資設定、利用案内"/>

マイアカウント（`내 계정`）には、次の項目がまとまっています。

- ログイン中のアカウント
現在どのアカウントの資産を見ているか確認します。
- 画面設定
ライト・ダークモードを選びます。
- 投資設定
目標比率とリバランス基準を設定する画面に移動します。
- 利用案内
利用ガイドとデータ管理の案内を確認します。
- ログアウトとサービス情報
ログインを終了するか、サービス紹介やGitHubのリンクを開きます。

### 1.1. モバイルのメニュー

モバイルでは、上部のプロフィールボタンを押すか、下部のすべて（`전체`）メニューを開きます。
すべて（`전체`）では、下にスクロールし、記録とアカウント（`기록과 계정`）のアカウント（`계정`）を選びます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-menu-20261009.webp" width={350} alt="モバイル版のすべてのメニューで、記録とアカウント欄にあるアカウントメニュー"/>

アカウント画面は上から順に確認できます。
ログイン中のアカウントと画面設定が上に、利用案内とログアウトが下にあります。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-account-20261009.webp" width={350} alt="モバイル版のマイアカウント画面にあるログインアカウントとライト・ダークモードの選択"/>

## 2. ログインアカウントを確認する

上部のログイン中のアカウント（`로그인한 계정`）で名前を確認します。
メールアドレスが提供されていれば、一緒に表示されます。
ここには現在のログイン情報が表示されます。名前やメールアドレスを編集する欄ではありません。

<br/>

普段Kakaoを使っていた人が、今回はNaverでログインしたとします。
同じ人がアクセスしても、現在のサービスでは、**ログインサービスごとのアカウントは自動で統合されません。**
普段使うログインサービスと、そこで選択したアカウントを確認します。

<br/>

PCでKakaoのアカウントAに保存したなら、スマートフォンでも同じKakaoのアカウントAでログインします。
ブラウザーですでに別のソーシャルアカウントにログインしていると、意図と異なるアカウントが選ばれることがあります。表示名も確認してください。

<Toggle title="表示名が同じなら、同じアカウントですか？">
表示名だけで同じアカウントとは判断できません。
KakaoとNaverで表示名が同じでも、ログインサービスは異なります。
普段使うログインサービスと、実際のソーシャルアカウントの両方を確認します。

<br/>

QA画面にメールアドレスは表示されていません。
メールアドレスは常に表示されるわけではないため、表示されないことだけで保存エラーとは判断しません。
</Toggle>

### 2.1. 資産が表示されない場合

次の順番で確認すると、重複登録を減らせます。

- 現在ログイン中のアカウントを確認します。
普段のKakaoまたはNaverのアカウントと同じかを見ます。
- 前回の入力を保存したか確認します。
入力値が画面に出ていたことと、保存が完了したことは区別します。
- 接続状況と読み込みの案内を確認します。
まだ読み込み中なのか、接続エラーの案内が出ているのかを確認します。
- 元のアカウントで確認し直します。
切り替える場合は、未保存の変更を処理してからログアウトし、ログインし直します。

<br/>

*別のアカウントにログインしている場合*と、*データがまだ読み込まれていない場合*は区別します。
確認前に同じ資産を再登録すると、元のアカウントに戻った際に混乱しやすくなります。

## 3. ライト・ダークモード

画面設定（`화면 설정`）の画面モード（`화면 모드`）で、ライト（`라이트`）またはダーク（`다크`）を選びます。
上部にある太陽・月のボタンでも切り替えられます。
アカウント画面と上部のボタンは、同じ画面モードを変更します。

<br/>

選択はすぐに反映されます。
資産の入力と異なり、別の保存ボタンは不要です。
画面に表示されるとおり、**現在のブラウザーに保存されます**。
別の端末やブラウザーで同じアカウントにログインしても、画面モードは自動ではそろいません。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-storage-boundaries-20261009.webp" width={800} alt="保存した資産とポート設定はログインアカウント、画面モードは現在のブラウザー、現在の画面と選択資産はページURLに残ることを示す図"/>

### 3.1. 保存先の違い

| 項目 | 保存・参照先 | 別の端末で確認すること |
| --- | --- | --- |
| 保存した資産とポート設定 | ログインアカウント | 同じアカウントでログインする |
| ライト・ダークモード | 現在のブラウザー | そのブラウザーで選ぶ |
| 現在の画面・選択した資産 | ページのURL | 同じ画面のURLを開く |
| 未保存の入力 | 保存前の状態 | 先に保存が完了したか確認する |

ダークモードを切り替えても、保有数量や目標比率は変わりません。
ブラウザーの設定を消しても、アカウントに保存した資産は一緒に削除されません。
どのブラウザーデータを削除したかによって、画面設定やログイン状態は変わる場合があります。

<Toggle title="新しいブラウザーで画面が明るくなりました">
画面モードはブラウザーごとに保存します。
新しいブラウザーや別のブラウザープロフィールには、以前の選択が保存されていない場合があります。
そのブラウザーで好みのモードを選び直せば使えます。
表示色が戻っただけで、資産の保存に問題があると判断する必要はありません。
</Toggle>

## 4. 目標設定と利用ガイド

アカウント画面の投資設定（`투자 설정`）には、目標比率とリバランス基準（`목표 비중과 리밸런싱 기준`）があります。
押すと目標設計（`목표 설계`）に移動します。
比率を入力するのは移動先の画面です。

<br/>

目標比率や許容誤差を変える場合は、この経路を使います。
詳しい入力方法は[第2回 目標ポートフォリオと投資比率の設定](https://www.promleeblog.com/blog/post/437-portrhythm-portfolio-setup-guide)で扱います。

### 4.1. 利用ガイド

利用案内（`이용 안내`）の利用ガイド（`사용 가이드`）を押します。
最初に行う手順、取引後の資産の編集、リバランス、よくある質問を確認できます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-desktop-guide-20261009.webp" width={800} alt="PC版の利用ガイドの紹介と、開始手順、資産編集、リバランス、よくある質問の目次"/>

ガイドの目標設計（`목표 설계`）、株式登録（`주식 등록`）、資産割り当て（`자산 배정`）、ポート構成比（`포트 비중`）、リバランス（`리밸런싱`）のボタンから、関連画面へ移動できます。
最初はガイドの順番どおりに進み、慣れたら必要な機能のボタンだけ使えます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-guide-20261009.webp" width={350} alt="モバイル版の利用ガイドの紹介と開始手順の目次"/>

<br/>

モバイルでは、目次を押すか下にスクロールして、目的の説明を探します。
ガイドに記載された比率は説明用の例です。自分の目標は別に設定します。
自分のポート構成と目標比率は、目標設計で確認します。

## 5. データ管理の案内

データの管理方法（`내 데이터는 어떻게 관리되나요?`）を押すと、三つの案内が開きます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-desktop-data-20261009.webp" width={800} alt="PC版のアカウント画面で開いた資産の保存、残高スクリーンショットの処理、保有数量の管理の案内"/>

### 5.1. アカウントに保存した資産

登録した資産とポート設定は、ログインアカウントに保存されます。
同じアカウントでログインし直せば、保存した内容を確認できます。
端末間で引き継がれるのは**保存した内容**です。
未保存の入力は引き継がれません。

### 5.2. 残高のスクリーンショットの処理

残高のスクリーンショットはブラウザーで解析し、元画像をアプリのサーバーにアップロードしたり保存したりしません。
認識結果を確認して保存した銘柄情報は、アカウントに保管されます。
*元画像の保管*と、*登録した資産情報の保管*は別の処理です。

<br/>

保存前に銘柄コード、数量、取得単価を確認する方法は[第3回 資産登録](https://www.promleeblog.com/blog/post/438-portrhythm-asset-registration-guide)で説明しています。
誤認識があっても元画像が自動で再解析され、値が直るわけではありません。保存する値を自分で確認します。

### 5.3. 保有数量を自分で管理する

価格の取得と証券口座残高の同期は異なります。
価格が更新されても、実際の取引後の保有数量と取得単価は手動で修正します。
現金も実際の残高に合わせます。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-data-20261009.webp" width={350} alt="モバイルで開いたアカウントへの保存、スクリーンショット原本を保管しないこと、数量の手動管理の案内"/>

<Bbox>
例えば10株のうち2株を売ったら、保有数量を実残高の8株に合わせます。
価格を更新しただけでは、数量は8株になりません。
売却後の現金も実残高を確認し、変更を保存してください。
</Bbox>

## 6. 画面の移動と再読み込み

画面を移動すると、現在の画面がページのURLに反映されます。
アカウント画面を再読み込みすると同じ画面に戻り、ブラウザーの「戻る」「進む」で画面を行き来できます。
資産の詳細画面では、選択した資産の情報もURLに反映されます。

<br/>

**画面の位置を記憶することと、入力内容を保存することは別です。**
目標や資産情報を編集した場合は、保存が完了したことを確認してから、再読み込みしたり別の端末に移ったりします。

<Ybox>
接続がおかしくて再読み込みする場合は、未保存の変更がないか先に確認してください。
再読み込み後に同じ画面に戻っても、保存していない入力は復元されません。
</Ybox>

<Toggle title="URLを他の人に送ると、自分の資産も見えますか？">
画面のURLを送っても、アカウントに保存した資産やログイン権限は共有されません。
ログインアカウントのデータと画面のURLは区別します。

<br/>

共有する必要がある場合は、先に何を見せるかを整理します。
詳細画面のURLに含まれる資産の識別情報や、スクリーンショットに含まれる口座情報まで不用意に送らないよう、確認してください。
</Toggle>

## 7. ログアウトと再ログイン

アカウント画面の下にログアウト（`로그아웃`）があります。
押すと、現在のブラウザーのログインセッションを終了し、最初の画面に戻ります。

<Img src="https://cdn.promleeblog.com/posts/portrhythm-guide9-mobile-service-20261009.webp" width={350} alt="モバイルのアカウント画面下部のログアウトボタンとサービス紹介、GitHubリポジトリ、不具合報告へのリンク"/>

ログアウトしても、**アカウントに保存した資産は残ります。**
もう一度確認するには、普段使うログインサービスとアカウントを選びます。
別のブラウザーや端末のログインまで一斉に終了すると考えないようにします。

<br/>

利用を終える前に、入力が保存済みか確認します。
特に複数人が使うブラウザーでは、自分の資産画面を開いたままにしないようにします。
この画面には、退会や全資産の削除を行うボタンはありません。

<Toggle title="スマートフォンに戻ったら接続エラーが表示されます">
再確認の案内が表示されたら、接続を確認してから画面の案内に従います。
一時的な通信障害と、ログインの終了は区別します。

<br/>

再ログインが必要な画面なら、元のアカウントでログインします。
ログインサービスを切り替えたり、資産を再登録したりせず、接続状態を確認します。
</Toggle>

## 8. サービス情報と問い合わせ

ログアウトの下にサービス情報（`서비스 정보`）があります。
三つのリンクは用途が異なります。

| リンク | 用途 |
| --- | --- |
| サービス紹介 | PortRhythmの目的と主な機能を確認 |
| GitHubリポジトリ | プロジェクトのコードと文書を確認 |
| 不具合報告・機能の提案 | 公開Issuesに問題や提案を投稿 |

サービス紹介（`서비스 소개`）は、ログインせずに閲覧できる紹介ページを開きます。
GitHubのリンクは新しいタブで開きます。
Issuesに投稿するにはGitHubへのログインが必要です。

### 8.1. 問題を説明する

「動きません」だけでなく、どの画面で何をしたときに問題が起きたかを書くと、確認しやすくなります。

- 利用環境
PCかモバイルかと、ブラウザー名を書きます。
- 画面と操作
例えば、アカウントから利用ガイドへ移動した、というように押した順番を書きます。
- 期待した結果と実際の結果
どの画面が開くと期待したか、実際に何が表示されたかを書きます。
- 案内メッセージ
エラーメッセージがあれば、必要な部分だけを書きます。

<Ybox>
GitHub Issuesへの投稿は公開されます。
口座番号、メールアドレス、保有金額など、公開する必要のない情報はスクリーンショットと本文で伏せます。
パスワードやAPIキーを問題の説明に含めないでください。
アプリ内の残高スクリーンショット処理は、GitHubに直接アップロードした画像には適用されません。
</Ybox>

<br/>

例えば、次の程度の記述から始められます。

> モバイルのSafariで、すべて → アカウント → 利用ガイドの順に押しました。
> ガイドが開くはずでしたが、前の画面が残りました。
> アクセスし直しても、同じ手順で起こります。

これは問い合わせの書き方の例で、実際に確認した不具合ではありません。

## まとめ

ここまで、PortRhythmの紹介と主な機能の使い方を見てきました。
新しく追加された口座管理機能は、[第10回 口座管理](https://www.promleeblog.com/blog/post/445-portrhythm-brokerage-account-guide)で扱います。
シリーズは、分散した資産を一か所にまとめる話から始まりました。
目標を決め、資産を登録し、現在の構成比を確認し、変化を記録する順に進めてきました。

<br/>

アカウント画面では、同じアカウントで保存した資産を確認し、各ブラウザーで見やすい画面モードを選びます。
再読み込みやログアウトの前には、入力が保存されているか確認します。
この基本設定が済んだら、自分の投資基準に合わせてPortRhythmを使い始められます。
