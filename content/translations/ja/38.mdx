共同プロジェクトでは、Organizationを作成し、その中のRepositoryで作業を進めることがよくあります。
プロジェクトが終わったあと、そのRepositoryを丸ごと自分の所有するものとして持っておきたい場合があります。
Forkする方法もありますが、元のRepositoryを引き続き管理する必要があるという欠点があります。
そこで、`--mirror`オプションを使って、自分のGitHubへRepositoryをコピーする方法を紹介します。

## 新しいRepositoryを作成する
既存のRepositoryをコピーするための、新しいRepositoryを作成します。
1. GitHubにログインし、https://github.com/new を開きます。
2. コピー先のRepository名を入力します。
3. PublicまたはPrivateを選択します。
4. Create repositoryボタンをクリックします。
   <Img src="/posts/240606-152842.png" alt="240606-152842" width="600"/>

<Ads1 />
## ローカルへRepositoryをコピーしてpushする
5. 既存の*コピー対象Repositoryのアドレス*をコピーします。
   <Img src="/posts/240606-154630.png" alt="240606-154630" width="800"/>
6. 次のコマンドで、自分のコンピューターの適切な場所へcloneします。韓国語のプレースホルダーは、手順5でコピーしたアドレスを表しています。
   `git clone {5번에서 복사한 Repository 주소}{:bash}`
   <Img src="/posts/240606-154920.png" alt="240606-154920" width="600"/>
7. cloneしたRepositoryへ移動します。ここでは`cd Old_repo{:bash}`です。次のプレースホルダーはRepository名を表します。
   `cd {Repository 이름}{:bash}`
8. `--mirror`オプションを使い、元のRepositoryを新しいRepositoryへpushします。プレースホルダーは新しいRepositoryのアドレスです。
   `git remote set-url --push origin {새로운 Repository 주소}{:bash}`
   `git push --mirror{:bash}`
   <Img src="/posts/240606-155454.png" alt="240606-155454" width="900" />

## 結果を確認する
新しく作成したRepositoryを開き、正常にpushされたことを確認します。
コミット履歴も正しくコピーされているか確認します。
