## アルゴリズムの分類
再帰、二分木

## 問題の説明
0または正の整数が与えられます。
この数を二進数に変換して二分木に当てはめたとき、木として正しく成り立つかを確認する問題です。
例えば9を二進数にすると1001です。木に当てはめると次のようになります。
```
 1
  \
   0
  / \
 0   1

1 0 0 1
```
これは*正しく成り立たない木*です。
この問題では、値が0のノードを、存在しないノードとして扱います。
次は、7を二進数に変換し、二分木に当てはめた例です。
```
  1
 / \
1   1

1 1 1
```
この木には、空のノードの下に実在する子ノードがないため、*正しく成り立つ木*です。
このように成り立つ場合は1、そうでなければ0を、リストとして返します。

## 解き方
1. 与えられた数を二進数に変換します。
2. 二進数の長さを求め、配置先の二分木の高さを決めます。2のn乗が二進数の長さ以上になるまで、nを増やします。
3. 二進数の長さが2のn乗になるように0で埋めます。
4. 二分木が正しく成り立つかを確認する関数を書きます。
5. 確認する関数の処理は、次のとおりです。
   1. リストの長さが0ならTrueを返します。
   2. リストの中央の値が0で空のノードなのに、子ノードに1が含まれている場合はFalseを返します。
   3. それ以外は、リストの前半と後半を再帰的に確認します。左の子と右の子を調べる処理です。
6. 与えられた各数について確認した結果をリストへ格納して返します。

## コード — Python
```python
def solution(numbers):
    answer = []
    for s in numbers:
        binnum, height = bin(s)[2:], 0  # 주어진 수를 이진수로 변환
        while 2 ** height <= len(binnum):  # 이진수의 길이가 2의 n승이 되도록 높이를 구함
            height += 1
        binnum = binnum.zfill(2 ** height - 1) # 이진수의 길이가 2의 n승이 되도록 0을 채움
        answer.append(1 if check(binnum) else 0 )
    return answer

def check(lst): # 이진 트리가 온전한 지 확인하는 함수
    n = len(lst) // 2
    if n == 0:  # 리스트의 길이가 1이면 True
        return True
    elif lst[n] == "0" and ("1" in lst): # 빈 노드이지만 자식 노드에 1이 있는 경우 False 
        return False
    else: 
        return check(lst[:n]) and check(lst[n + 1:]) # 재귀적으로 확인
```

## 要点
- 二分木の高さの求め方。
- 二分木が正しく成り立つかの確認方法。子ノードを再帰的に調べます。
