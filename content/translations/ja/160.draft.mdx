> https://www.acmicpc.net/problem/1927
## アルゴリズムの分類
データ構造、優先度付きキュー

## 解き方
1. Pythonの標準モジュールheapqを使って解けます。ヒープを自分で実装する方法でも解けます。
2. 入力が0でない場合：heapq.heappush(リスト, データ)で追加します。
3. 入力が0の場合：リストが空かどうかを確認し、空でなければheapq.heappop(リスト)で取り出して出力します。

## コード — Python
```python
import heapq
import sys

H = []
n = int(sys.stdin.readline())
for i in range(n):
    k = int(sys.stdin.readline())
    if k == 0:
        if len(H) == 0:
            print(0)
            continue
        else:
            print(heapq.heappop(H))
    else:
        heapq.heappush(H, k)
```

## 発生した問題と対処
1. 5行目と7行目でinput()を使ってデータを読み込むと、実行時間制限を超えました。
   - Pythonでは、この入力処理にinput()を使う代わりに、sysモジュールのreadlineを利用します。

## 要点
- heapqモジュールで最小ヒープを実装できます。
- heapq.heappush(リスト, データ)で追加します。
- heapq.heappop(リスト)で取り出します。
- 空のリストから取り出そうとするとIndexErrorになるため、空の場合の処理が必要です。
- 計算量：O(NlogN)
