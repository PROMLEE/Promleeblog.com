## はじめに

> 「資産は登録しましたが、この損益の数字は何を基準に計算したのでしょうか？」

[第4回 資産割り当て](https://www.promleeblog.com/blog/post/439-portrhythm-asset-assignment-guide)まで終えていれば、資産ごとに管理するポートが決まっています。
次はダッシュボードで、資産の金額と損益を確認します。

<br/>

大きな数字から見ると分かりやすくなります。
まず「いくら保有しているか」を見て、「何を基準に増減したか」を確かめ、気になる銘柄を押してみます。

<br/>

<Bbox>

今回の目標は、資産の評価額と損益を読み、必要な保有情報を修正できるようになることです。
アプリを開いて銘柄を一つ選び、手順をたどると、画面と数字を結び付けやすくなります。

</Bbox>

[PortRhythmを開く](https://pf.promleeblog.com)
画面はテストアカウントの資産例です。
価格は取得時点によって変わるため、以下の計算例はスクリーンショットの金額とは別に説明します。

<br/>

## 1. ダッシュボード

ダッシュボードは、分散した資産をまとめて確認する最初の画面です。
PCでは左のダッシュボード（`대시보드`）、モバイルでは下部の資産（`자산`）を押します。

<Img src="/portrhythm-guide5-desktop-dashboard-20261008.webp" width={800} alt="PC版のダッシュボードに表示された総評価額、全体損益、銘柄一覧"/>

次の三段階で読みます。

- **総評価額**
  登録済みの資産を、現在適用される価格と為替レートで計算した金額です。
- **全体損益／日次損益**
  取得単価と比べるか、前日終値と比べるかを選びます。
- **保有資産一覧**
  銘柄ごとの金額と損益を確認し、名前を押して詳細を開きます。

PCの右側には、ポート別の構成比も表示されます。
現在と目標の構成比を比較する方法は、次の第6回で扱います。

<br/>

### 1.1 モバイル画面

モバイルでは、評価額と銘柄一覧が先に表示されます。
上部の数値の下で全体損益／日次損益（`전체 수익 / 일간 수익`）を押すと、概要と投資銘柄の損益が一緒に切り替わります。

<Img src="/portrhythm-guide5-mobile-dashboard-20261008.webp" width={350} alt="モバイル版のダッシュボードの日次損益と資産一覧"/>

スクロールすると、損益の集計基準（`손익 집계 기준`）と直近の価格確認時刻があります。
損益額に加え、何のデータで計算したかも確認できます。

<br/>

## 2. 総評価額

**総評価額は、現在登録されている資産のウォン換算額の合計です。**
株式、ETF、暗号資産、手入力した現金とその他の資産を合算します。

| 資産 | 評価方法 |
| --- | --- |
| 韓国株・ETF | 現在価格 × 保有数量 |
| 米国株・ETF | ドル建ての現在価格 × 保有数量 × 適用為替レート |
| 暗号資産 | Bithumbのウォン建て現在価格 × 保有数量 |
| ウォンの現金・その他 | 手入力したウォンの金額 |
| ドルの現金・その他 | 手入力したドルの金額 × 適用為替レート |

例えば株式12万ウォンと現金8万ウォンを登録したら、総評価額は20万ウォンです。
投資に使った金額や、入金の合計とは異なります。

<br/>

### 2.1 現金と為替レート

現金も資産なので、総評価額に含めます。
ただし、手入力の現金やその他の資産について、取得単価に基づく投資損益は計算しません。

<br/>

米国株とドルの現金は、目標設計で指定した自動取得または手入力の為替レートでウォンに換算します。
ドル建ての価格が同じでも、適用為替レートが変わると、ウォン換算評価額は変わる場合があります。

<Ybox>

現金を含む総評価額は、全体収益率の分母には使いません。
収益率は、損益を計算できる株式や暗号資産の取得額を基準に計算します。

</Ybox>

<br/>

## 3. 全体損益と日次損益

**二つのボタンで、比較の基準を切り替えます。**
全体損益は平均取得単価、日次損益は各市場の前日終値と比較します。

### 3.1 全体損益

全体損益は、現在保有する株式や暗号資産が、取得単価と比べてどれだけ増減したかを示します。

- 全体損益 ＝（現在価格 − 平均取得単価）× 保有数量
- 全体収益率 ＝ 全体損益 ÷ 取得額 × 100

平均取得単価は、株式1株や暗号資産1単位を購入するのにかかった平均価格です。
アプリに取得単価がなければ、その資産の損益を確認できません。

<br/>

複数の資産を集計するときも、収益率を単純平均しません。
損益を確認できる資産について、損益合計を取得額の合計で割ります。

<br/>

### 3.2 日次損益

日次損益は、各市場の前日終値から現在価格までの変動を、現在の保有数量に適用した金額です。

- 日次損益 ＝（現在価格 − 前日終値）× 保有数量
- 日次収益率 ＝ 日次損益 ÷ 前日終値を基準とした保有額 × 100

現在価格と前日終値の両方を確認できる資産だけを計算します。
前日終値を確認済みの銘柄が2件中2件（`전일 종가 확인 2/2개`）のような表示で、集計範囲を確認できます。

<Img src="/portrhythm-guide5-desktop-daily-20261008.webp" width={800} alt="日次損益を選ぶと一緒に切り替わる概要と銘柄別損益"/>

*日次損益は、韓国時間の午前0時以降に口座で実際に生じた損益と異なる場合があります。*
前日終値の時点は市場ごとに異なり、取引時間中の売買や入出金も口座の損益として反映していないためです。

<br/>

### 3.3 同じ10株で比べる

ある銘柄を10株保有しているとします。
平均取得単価は10,000ウォン、前日終値は11,500ウォン、現在価格は12,000ウォンです。

| 確認する値 | 計算 | 結果 |
| --- | --- | --- |
| 評価額 | 12,000ウォン × 10株 | 120,000ウォン |
| 全体損益 | (12,000ウォン − 10,000ウォン) × 10株 | +20,000ウォン |
| 全体収益率 | 20,000ウォン ÷ 100,000ウォン | +20% |
| 日次損益 | (12,000ウォン − 11,500ウォン) × 10株 | +5,000ウォン |
| 日次収益率 | 5,000ウォン ÷ 115,000ウォン | 約+4.35% |

全体損益は買値からどれだけ上がったか、日次損益は前日終値からどれだけ動いたかを示します。
ボタンを切り替えても、評価額の12万ウォンは同じです。

<br/>

ここに現金8万ウォンを加えると、総評価額は20万ウォンになります。
現金を足しても、この例の全体損益は+2万ウォン、全体収益率は+20%です。

<br/>

<Toggle title="証券会社の損益と異なる理由">

PortRhythmの全体損益は、現在保有している分の評価損益です。
売却済み資産の実現損益、配当、手数料、税金を含めた口座の累積損益とは異なります。

米国株では、ドル建ての現在価格と取得単価の差に、現在の適用為替レートを掛けます。
購入時と現在の為替レートの差による為替損益は含みません。
日次損益も価格変動が基準で、為替変動と現金は除外します。

数値が異なる場合は、保有数量、平均取得単価、価格の時点、損益の集計範囲をそろえて比べます。

</Toggle>

## 4. 銘柄一覧と並べ替え

ダッシュボードの一覧は、投資（`투자`）と現金・その他（`현금·기타`）に分かれます。
投資には株式、ETF、暗号資産が、現金・その他には手入力した資産が表示されます。

<br/>

銘柄ごとに、名前、コード、保有数量、評価額を確認します。
投資銘柄の損益は、上で選んだ全体または日次の基準に従います。

<br/>

### 4.1 並べ替えの基準

一覧の上にある並べ替え欄で、表示順を選びます。

- 評価額の高い順／低い順（`평가액 높은순 / 낮은순`）
  評価額の大きい資産か小さい資産から見ます。
- 損益の高い順／低い順（`손익 높은순 / 낮은순`）
  選択した期間の利益や損失の金額を基準に見ます。
- 収益率の高い順／低い順（`수익률 높은순 / 낮은순`）
  選択した期間の比率を基準に見ます。
- 名前順（`이름순`）
  銘柄名の順で探します。

損益額は全体の結果にどれだけ寄与したかを、収益率は取得額や前日の基準額に対してどれだけ動いたかを見るのに使えます。
収益率が高くても、保有額が小さければ、全体の損益への影響は小さい場合があります。

<br/>

損益を確認できない項目は後ろに並びます。
損益のない現金・その他の一覧で損益や収益率による並べ替えを選ぶと、評価額が高い順に表示します。

<br/>

全体・日次の選択と並べ替えは、現在のブラウザーにアカウントごとに保存されます。
画面を移動したり再読み込みしたりしても維持されるため、見慣れない数値が出たら、選択中の基準を確認します。

<br/>

### 4.2 同じ銘柄の合算

ダッシュボードでは、市場、取引所、銘柄コードが同じ株式をまとめます。
例えば同じApple株をA口座に3株、B口座に7株登録していれば、一覧には合計10株と表示されます。

<br/>

詳細を開くと、口座別の保有明細を確認できます。
取引所やコードが異なる項目は、名前だけで合算しません。

<Toggle title="複数の口座を合算した平均取得単価">

数量で重み付けした平均です。
A口座に1株100ドルで3株、B口座に1株200ドルで7株あれば、取得総額は1,700ドルです。
合計10株で割ると、平均取得単価は170ドルになります。

二つの単価を単純平均した150ドルとは異なります。
一部の口座の取得単価がなければ、合算した銘柄の損益をすべて計算できないため、その口座の単価を確認します。

</Toggle>

<br/>

## 5. 保有資産を検索する

株式を口座別に詳しく見るには、保有資産（`보유 자산`）を開きます。
PCでは左のメニュー、モバイルでは下部のすべて（`전체`）から保有資産（`보유 자산`）を選びます。

<Img src="/portrhythm-guide5-desktop-holdings-20261008.webp" width={800} alt="PC版の保有資産画面の市場フィルター、検索欄、口座別の株式一覧"/>

この画面には、口座別の株式・ETFの保有明細が表示されます。
暗号資産と現金は、ダッシュボードで確認します。

### 5.1 市場フィルターと検索

- すべて／韓国／米国（`전체 / 국내 / 미국`）を選びます。
  表示したい市場の株式に絞ります。
- 検索欄に銘柄名、銘柄コード、証券会社を入力します。
  例えばApple、AAPL、登録した証券会社名で探します。
- 目的の銘柄名を押します。
  該当口座の保有項目の詳細が開きます。

モバイルでは、横長の表に代わって銘柄ごとのカードが表示されます。
カードの数量、価格、評価額、損益を上から順に確認します。

<Img src="/portrhythm-guide5-mobile-holdings-20261008.webp" width={350} alt="モバイル版の保有資産画面の検索欄と株式カード"/>

<br/>

### 5.2 金額の通貨

ダッシュボードではウォンに換算して集計しますが、保有資産画面の米国株はドルで表示します。
同じ銘柄の金額が異なって見えたら、先にウォンとドルを区別します。

| 画面 | 表示対象 | 金額の基準 |
| --- | --- | --- |
| ダッシュボード | 株式、暗号資産、現金、その他 | ウォン換算 |
| 保有資産 | 口座ごとの株式・ETF | 韓国はウォン、米国はドル |
| 資産詳細 | 選択した資産または合算銘柄 | 評価額はウォン、現在価格と取得単価は資産の通貨 |

保有資産の評価損益は、取得単価に基づく全体損益です。
ダッシュボードで日次損益を選んでも、この画面の損益は切り替わりません。

<br/>

並べ替えの選択はダッシュボードと共有します。
ただし、全市場を金額で並べる場合は、ウォンとドルをそのまま比較しないよう、韓国と米国の市場ごとに並べ替えます。

<br/>

## 6. 資産詳細

ダッシュボードの資産や、保有資産画面の銘柄名を押すと詳細が開きます。
金額が想定と違うときに、入力内容と価格を照合できる画面です。

<Img src="/portrhythm-guide5-desktop-detail-20261008.webp" width={800} alt="株式詳細に表示された評価額、数量、現在価格、口座別の保有明細"/>

### 6.1 詳細の項目

- 評価額（`평가 금액`）
  現在価格で計算したウォンの金額です。
- 保有数量（`보유 수량`）
  株式は株、暗号資産は通貨の数量です。
- 現在価格（`현재가`）
  株式1株、または暗号資産1単位の価格です。
- 平均取得単価（`평균 매입단가`）
  株式1株、または暗号資産1単位の平均取得価格です。
- 評価損益（`평가손익`）
  現在の保有分を平均取得単価と比較した損益です。

**詳細の評価損益は、取得単価を基準に計算します。**
ダッシュボードで日次損益を選んでいても、詳細では保有分全体の評価損益を確認します。

<br/>

米国株の現在価格と取得単価はドルで表示されます。
暗号資産の取得単価は、1単位あたりのウォン価格です。
現金やその他の資産では、入力した金額と評価基準を確認します。

<br/>

### 6.2 口座別の保有明細

株式詳細の口座別保有（`계좌별 보유`）で、証券会社、口座名、数量、取得単価を確認します。
ダッシュボードから合算銘柄を開いた場合は、この一覧で口座別に確認できます。

<br/>

保有資産画面から特定の口座の項目を開いた場合は、選んだ口座の詳細が表示されます。
同じ銘柄でも、開いた画面によって集計範囲が異なります。

<Img src="/portrhythm-guide5-mobile-detail-20261008.webp" width={350} alt="モバイル版の株式詳細に表示された取得単価と、口座別の編集ボタン"/>

一覧に戻るには、前の画面（`← 이전 화면`）を押します。
数量を修正するときは、銘柄名と対象の口座名を確認します。

## 7. 保有情報を修正する

買い増しや一部売却を行ったら、実残高に合わせて数量と平均取得単価を修正します。
価格を更新しただけでは、保有数量は変わりません。

### 7.1 株式を修正する

株式詳細の口座別保有（`계좌별 보유`）で、目的の口座の編集（`수정`）を押します。
同じ画面の下に入力欄が開きます。

<Img src="/portrhythm-guide5-desktop-edit-20261008.webp" width={800} alt="株式詳細の下に開いた保有数量と平均取得単価の編集欄"/>

- 保有数量（`보유 수량`）に、現在の残高の総数量を入力します。
  10株を保有していて2株買い増したなら、入力するのは合計12株です。
- 平均取得単価（`평균 매입단가`）に、証券会社の残高画面に表示された1株あたりの平均価格を入力します。
  米国株はドル、韓国株はウォンです。
- 入力を確認し、保存（`저장`）を押します。
  該当する保有項目を保存し、同じ画面の金額と損益が更新されます。

編集を取りやめる場合は、キャンセル（`취소`）を押します。
モバイルでも、詳細画面で口座別の編集（`수정`）を押し、下の入力欄まで移動すると同じように修正できます。

<br/>

### 7.2 暗号資産と現金

暗号資産や現金・その他の資産は、詳細画面の資産を編集（`자산 수정`）を押します。
資産の種類に応じて変更できる項目が異なります。

| 資産 | 修正する値 | 入力の基準 |
| --- | --- | --- |
| 暗号資産 | 保有数量、平均取得単価 | 暗号資産の数量と、1単位あたりのウォン建て取得価格 |
| ウォンの現金・その他 | 資産名、ウォンの金額 | 現在のウォン残高 |
| ドルの現金・その他 | 資産名、ドルの金額 | ウォン換算前のドルの金額 |

例えば0.01 BTCの取得総額が100万ウォンなら、1 BTCあたりの取得単価は1億ウォンです。
数量には0.01、平均取得単価には100,000,000を入力します。

<br/>

現金は現在残っている金額に修正します。
現金500ドルをウォンに換算し、その数値をドルの欄に入れると通貨が混ざります。先に入力欄の通貨を確認します。

<br/>

<Bbox>

取得単価が分からなければ、推測したり0を入れたりせず、空欄にして確認します。
評価額は確認できる価格と数量で計算します。取得単価のない資産の損益は、未確認として扱えます。

</Bbox>

### 7.3 ほかの情報を修正する

数量と単価以外の情報は、次の経路を使います。

- 銘柄コード・取引所
  資産を編集（`자산 수정`）→ この銘柄を編集（`이 종목 수정`）→ 銘柄コードを確認・変更（`종목코드 확인·변경`）の順に開きます。
- 資産の所属ポート
  資産割り当て（`자산 배정`）で変更し、保存します。
  詳しい方法は[第4回 資産割り当て](https://www.promleeblog.com/blog/post/439-portrhythm-asset-assignment-guide)で説明しました。

詳細の編集欄で保存（`저장`）を押すと、その項目がすぐに保存されます。
目標設計や資産割り当て画面で、改めて保存する必要はありません。

<br/>

## 8. 価格の出典と更新

数量と取得単価が正しいのに金額が違う場合は、価格の出典と時刻を確認します。
保有資産画面では現在価格の下に、韓国投資証券の価格か、スクリーンショットに基づく価格かが表示されます。

<br/>

ダッシュボード下部の「価格・為替の基準を見る」（`가격·환율 기준 보기`）で、価格と為替レートの集計基準を確認できます。
モバイルでは、銘柄一覧の下にある損益の集計基準（`손익 집계 기준`）と直近の価格確認時刻も併せて見ます。

<Img src="/portrhythm-guide5-desktop-price-20261008.webp" width={800} alt="ダッシュボード下部の価格・為替の基準と直近の確認時刻"/>

### 8.1 価格を確認する順序

- 価格を更新（`가격 갱신`）します。
  モバイルのダッシュボードでは、総評価額の横の更新アイコンを押します。
- 現在価格と直近の確認時刻を見ます。
  取得中なら、結果が出てから再度確認します。
- スクリーンショットに基づく価格が続く場合は、銘柄コードと取引所を確認します。
  登録した銘柄が実際の保有銘柄と同じか照合します。
- 日次損益が空欄なら、前日終値を確認できているか調べます。
  評価額を計算する価格があっても、日次損益に必要な情報がすべてそろっているとは限りません。

APIから新しい価格を取得できない場合は、以前に確認した価格や、スクリーンショットに記載された価格を使う場合があります。
数字が表示されたら、取得した時刻も確認します。

<br/>

### 8.2 更新の範囲

画面が開いていてアクティブな間は、株式は約5分、Bithumbの暗号資産は約1分間隔で自動更新を試みます。
取得時刻と取引所での実際の約定時刻は異なる場合があります。

<br/>

**価格更新は、市場価格を取得する機能です。**
証券会社で新たに買った数量、売った数量、現金残高は、自分で登録・修正します。

<br/>

## 9. よくある質問

<Toggle title="全体損益がプラスで、日次損益がマイナスです">

取得価格より高く、前日終値より低い場合に起こります。
例えば10,000ウォンで買った銘柄の前日終値が12,000ウォンで、現在価格が11,800ウォンなら、全体損益はプラス、日次損益はマイナスです。
二つの値は異なる基準で計算しています。

</Toggle>

<Toggle title="資産は表示されますが、損益がありません">

全体損益には平均取得単価と価格が、日次損益にはAPIで取得した現在価格と前日終値が必要です。
それぞれに必要なデータを確認します。

取得中（`조회 중`）はデータを待っている状態、情報なし（`정보 없음`）は計算に必要な情報を確認できなかった状態です。
損益が空欄でも、利益や損失が0ウォンという意味ではありません。
手入力した現金やその他の資産は、投資損益を計算しません。

</Toggle>

<Toggle title="ダッシュボードと保有資産画面で数量が違います">

ダッシュボードでは同じ株式を合算し、保有資産画面では口座別に表示します。
まず各口座の数量を足し、ダッシュボードの数量と比べます。

合計も異なる場合は、同じ口座で同じ銘柄を重複登録していないか、銘柄コードや取引所が異なる状態で登録していないかを確認します。

</Toggle>

## まとめ

最初からすべての数字を解釈する必要はありません。
総評価額で資産の規模を見て、全体・日次から比較基準を選び、一つの銘柄を開いて数量と取得単価を確認します。

数字が異なるときは、**通貨 → 集計範囲 → 数量と単価 → 価格の時点**の順に確認すると、理由を見つけやすくなります。

金額と保有情報を整理したら、どのかごが目標より多く、どのかごが不足しているかを見ます。
次の第6回では、現在比率と目標比率を比べる方法を扱います。
