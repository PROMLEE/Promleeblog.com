## はじめに
ブログ開発のための基本設定を行います。
この記事で設定する内容は次のとおりです。

- Next.jsプロジェクトの作成
- Tailwind CSS（Shadcn/ui）の設定

<Bbox>Node.js 18以降とnpmがインストールされている必要があります。</Bbox>

## Next.jsプロジェクトの作成と実行
### プロジェクトの作成
Next.jsプロジェクトを作るには、次のコマンドを実行します。

```bash
npx create-next-app@latest
```
<Img src="/posts/240709-131008.png" width={500} alt="すべて既定の設定で進めました。"/>
1. **プロジェクト名**を入力します。
2. **TypeScript**を使うか選びます。
	- JavaScriptを使う場合は**No**を選びます。
3. **ESLint**を使うか選びます。
4. **Tailwind CSS**を使うか選びます。
5. **'src/'**ディレクトリを作るか選びます。
6. **App Router**を使うか選びます。Next.js 13以降で利用できます。
	- Pages Routerを使う場合は**No**を選びます。
7. **絶対パスの設定**を変更するか選びます。
	- 既定では**'src/'**ディレクトリです。

### プロジェクトの実行
プロジェクトを作成したら、次のコマンドで追加パッケージを最新版にインストール、または更新します。

```bash
cd {프로젝트 이름}
npm install next@latest react@latest react-dom@latest
```
プロジェクトを実行するには、次のコマンドを使います。

```bash
npm run dev
```
正常に起動した後、ブラウザーでhttp://localhost:3000 にアクセスすると、次の画面が表示されます。

## Tailwind CSSの設定
### Shadcn/uiのインストール（任意）
Shadcn/uiはTailwind CSSを使うUIライブラリです。
[Shadcn/ui](https://ui.shadcn.com)
次のコマンドでShadcn/uiをインストールします。
tailwind-mergeはShadcn/uiが使うプラグインです。

```bash
npx shadcn-ui@latest init
npm i tailwind-merge
```
<Img src="/posts/240709-135300.png" width={500} alt="既定の設定で進めました。"/>

### tailwindcss/typographyのインストール（任意）
Next.jsプロジェクトを作成した時点で、Tailwind CSSの基本設定は完了しています。
ただし、Tailwind CSSにはHTMLタグのスタイルをリセットする性質があるため、後でMarkdownを描画してもスタイルが適用されません。
これを解決するのが`prose`です。
`prose`は`tailwindcss/typography`プラグインを使い、Markdownの描画にスタイルを適用します。
次のコマンドで`tailwindcss/typography`をインストールします。

```bash
npm i @tailwindcss/typography
```
tailwind.config.tsを開き、次のようにプラグインを追加します。

```js title="tailwind.config.ts"
module.exports = {
	// ...
	plugins: [
		require('@tailwindcss/typography'),
		// ...
	],
	// ...
}
```
