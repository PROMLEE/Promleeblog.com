## はじめに
> この記事はfirebase_auth ^5.5.0を前提にしています。

> [Firebaseコンソール](https://console.firebase.google.com/)にプロジェクトを作成し、アプリを登録済みとします。まだであれば[アプリを登録する](/blog/post/134-flutter-firebase-apps)を参照してください。

NAVER Cloud Console、Kakao Alimtalk、NICE認証など、携帯電話による認証を提供するサービスはいくつもあります。ここでは、Flutterで手軽に実装できる*Firebase Auth*を使います。

## 1. Firebase Authを設定する
Firebaseコンソールの「構築」→「Authentication」に進み、「始める」を押します。
<Img src="/posts/250225-115958.png" width={500} alt="Authenticationの設定を始める"/>
ログイン方法の設定画面で「電話番号」を有効にします。エミュレーターを使う場合は、テスト用の電話番号と確認コードを追加します。
筆者は `+1 1234567812` と `123654` を追加しました。
<Img src="/posts/250225-130250.png" width={500} alt="電話番号認証を有効にする"/>
<Img src="/posts/250225-130653.png" width={500} alt="電話番号認証を有効にした状態"/>

## 2. SHAフィンガープリントを追加する（Android）
### 2.1. 証明書のフィンガープリントを取得する
AndroidアプリでFirebase認証を使うため、SHAフィンガープリントを追加します。次のコマンドで確認できます。
パスワードを求められたら、既定の `android` を入力します。
```bash title="MAC/Linux"
keytool -list -v \
-alias androiddebugkey -keystore ~/.android/debug.keystore
```
```bash title="Windows"
keytool -list -v \
-alias androiddebugkey -keystore %USERPROFILE%\.android\debug.keystore
```
成功すると、次のように表示されます。
<Img src="/posts/250225-132418.png" width={500} alt="SHAフィンガープリントを確認する"/>

### 2.2. SHAフィンガープリントを追加する
Firebaseコンソールで、登録したAndroidアプリの設定を開きます。
<Img src="/posts/250225-151601.png" width={300} alt="Androidアプリの設定"/>
全般タブの「マイアプリ」で「フィンガープリントを追加」を押します。
<Img src="/posts/250225-151739.png" width={400} alt="フィンガープリントを追加する"/>
証明書のSHA1とSHA256を、それぞれ追加します。

## 3. Flutterのコードを書く
筆者のフォルダー構成は次のとおりです。main.dartからpage_onboarding.dartを呼び出します。
```
📦lib
┣ 📜main.dart
┣ 📜page_onboarding.dart
```
### 3.1. Firebase Authプラグインを追加する
プロジェクトのルートで次のコマンドを実行し、プラグインを追加します。
```bash
flutter pub add firebase_auth
```

### 3.2. page_onboarding.dartを書く
page_onboarding.dartに次のコードを追加します。電話番号は[上の手順](#1-firebase-auth-설정)で追加したテスト番号を使います。
```dart title="/lib/page_onboarding.dart" {17}
import 'package:firebase_auth/firebase_auth.dart';
import 'package:flutter/material.dart';

class PageOnboarding extends StatelessWidget {
  const PageOnboarding({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            TextButton(
                onPressed: () async {
                  await FirebaseAuth.instance.verifyPhoneNumber(
                    phoneNumber: '+1 1234567812', // 테스트 번호
                    verificationCompleted: (PhoneAuthCredential credential) {
                      print("credential: $credential");
                    },
                    verificationFailed: (FirebaseAuthException e) {
                      print("verificationFailed: $e");
                    },
                    codeSent: (String verificationId, int? resendToken) {
                      print("codeSent: $verificationId");
                      print("codeSent: $resendToken");
                    },
                    codeAutoRetrievalTimeout: (String verificationId) {
                      print("codeAutoRetrievalTimeout: $verificationId");
                    },
                  );
                },
                child: const Text("Phone Number Verification"))
          ],
        ),
      ),
    );
  }
}
```
テキストを押してCAPTCHA認証を行い、認証完了のログが出るか確認します。
次のようなエラーが出た場合は、[認証リクエストでエラーが出る](#인증-요청-시-오류-발생)を参照してください。
```bash
Fatal error: Please register custom URL scheme app-1-****** in the app's Info.plist file.
```

## 4. verifyPhoneNumberのコールバック
### 4.1. verificationCompleted
Android端末でのみ動作する、SMSコードを自動処理するコールバックです。
```dart
verificationCompleted: (PhoneAuthCredential credential) {
  print("credential: $credential");
	await auth.signInWithCredential(credential); // 자동 인증 과정 진행
},
```

### 4.2. verificationFailed
電話番号の誤りやSMS送信枠の超過など、認証の失敗を処理します。
```dart
verificationFailed: (FirebaseAuthException e) {
	if (e.code == 'invalid-phone-number') {
		print('The provided phone number is not valid.');
	} else {
		print("verificationFailed: $e");
	}
},
```

### 4.3. codeSent
Firebaseから端末にコードが送信された場合に呼ばれ、ユーザーに入力を促すために使います。

```dart
codeSent: (String verificationId, int? resendToken) {
  print("codeSent: $verificationId");
  print("codeSent: $resendToken");
},
```
### 4.4. codeAutoRetrievalTimeout
SMSコードを自動取得できなかった場合のタイムアウトを処理します。
```dart
codeAutoRetrievalTimeout: (String verificationId) {
  print("codeAutoRetrievalTimeout: $verificationId");
},
```

## 5. 認証完了時の処理
電話番号認証のコードを入力したら、次のコードで認証を完了できます。
verificationIdには[4.3. codeSent](#43-codeSent)で受け取った値を使います。コード全体も参照してください。
```dart title="/lib/page_onboarding.dart"
TextButton(
	onPressed: () async {
		PhoneAuthCredential credential =
				PhoneAuthProvider.credential(
						verificationId: verificationId,
						smsCode: "123654",
						);
		await FirebaseAuth.instance
				.signInWithCredential(credential)
				.then((value) {
				print("signInWithCredential: $value");
		}).catchError((error) {
			print("signInWithCredential: $error");
		});
	},
	child: const Text("Sign In"),
),
```

### ビルド時のエラー - Firebaseのバージョン競合
Podfile.lockでFirebase/CoreOnlyが11.6.0に固定されている一方で、firebase_coreが11.8.0を要求するため、バージョンの競合が発生しました。
```bash
!] CocoaPods could not find compatible versions for pod "Firebase/CoreOnly":
  In snapshot (Podfile.lock):
    Firebase/CoreOnly (= 11.6.0)

  In Podfile:
    firebase_core (from .symlinks/plugins/firebase_core/ios) was resolved to 3.12.0, which depends on
      Firebase/CoreOnly (= 11.8.0)

You have either:
 * changed the constraints of dependency Firebase/CoreOnly inside your development pod firebase_core.
   You should run pod update Firebase/CoreOnly to apply changes you've made.
```
#### 対処方法
Podfile.lockを削除し、再インストールします。
```bash
rm ios/Podfile.lock
pod install --repo-update
```

### 認証リクエストでエラーが出る
iOSでreCAPTCHAのためにブラウザを開いてアプリに戻るとき、URLスキームを登録していないと、次のエラーが出ることがあります。
```bash
Fatal error: Please register custom URL scheme app-1-****** in the app's Info.plist file.
```
#### 対処方法
Info.plistに次のようにURLスキームを追加します。
```xml title="/ios/Runner/Info.plist"
<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleURLSchemes</key>
        <array>
            <string>app-1-******</string>
        </array>
    </dict>
</array>
```

```dart title="/lib/page_onboarding.dart"
import 'package:firebase_auth/firebase_auth.dart';
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

class PageOnboarding extends StatefulWidget {
  const PageOnboarding({super.key});

  @override
  State<PageOnboarding> createState() => _PageOnboardingState();
}

class _PageOnboardingState extends State<PageOnboarding> {
  String verificationId = '';

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            TextButton(
              onPressed: () async {
                await FirebaseAuth.instance.verifyPhoneNumber(
                  phoneNumber: '+1 1234567812', // 테스트 번호
                  timeout: const Duration(seconds: 60),
                  verificationCompleted: (PhoneAuthCredential credential) {
										print("verificationCompleted: $credential");
                  },
                  verificationFailed: (FirebaseAuthException e) {
										print("verificationFailed: $e");
                  },
                  codeSent: (String verificationId, int? resendToken) {
                    this.verificationId = verificationId;
										print("codeSent: $verificationId");
										print("codeSent: $resendToken");
                  },
                  codeAutoRetrievalTimeout: (String verificationId) {
										print("codeAutoRetrievalTimeout: $verificationId");
                  },
                );
              },
              child: const Text("Phone Number Verification"),
            ),
            const SizedBox(height: 20),
            SizedBox(
              width: 200,
              child: TextField( 	// 인증 코드 입력 (123654)
                onChanged: (value) {
                  setState(() {
                    smsCode = value;
                  });
                },
              ),
            ),
            TextButton(
              onPressed: () async {
                PhoneAuthCredential credential = PhoneAuthProvider.credential(
                    verificationId: verificationId, smsCode: smsCode);
                await FirebaseAuth.instance
                    .signInWithCredential(credential)
											.then((value) {
										print("signInWithCredential: $value");
                }).catchError((error) {
										print("signInWithCredential: $error");
                });
              },
              child: const Text("Sign In"),
            ),
          ],
        ),
      ),
    );
  }
}
```
