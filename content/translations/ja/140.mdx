## はじめに
> この記事はExpo環境で作成していますが、すべてのReact Native環境で利用できます。
また、基本的な設定が済んだプロジェクトを前提にしています。

### 画面更新を実装する理由
アプリには通常、画面間を移動しやすくするボトムタブメニューがあります。しかし、別のタブでデータを変更して戻っても、最初に読み込んだデータが表示されたままで、変更が反映されないことがあります。このような場合は画面更新機能を実装します。

## 1. ScrollViewコンポーネントを作る
まず、画面更新を行う画面を作成します。ここで使うrefreshControlコンポーネントはScrollViewの中に配置します。サンプルデータを一覧表示する画面を作ってみましょう。

```tsx title="/app/index.tsx"
import React, { useState } from 'react';
import { Text, ScrollView } from 'react-native';

const List = () => {
  const [refreshTime, setRefreshTime] = useState(0);

  return (
    <ScrollView style={{ flex: 1, backgroundColor: 'white', padding: 20 }}>
      {Array.from({ length: 100 }).map((_, index) => (
        <Text key={index} style={{ textAlign: 'center', justifyContent: 'center', fontSize: 30 }}>
          {`새로고침 ${refreshTime}회`}
        </Text>
      ))}
    </ScrollView>
  );
};

export default List;
```

## 2. 画面更新を実装する
次に、ScrollViewの内部プロパティであるrefreshControlを使って更新機能を実装します。
RefreshControlは、ScrollViewやリストにプル・トゥ・リフレッシュを追加するコンポーネントです。スクロール位置がscrollY: 0のときに下へスワイプすると、onRefreshイベントが発生します。refreshingは更新中かどうかを示し、onRefreshには更新処理を実装します。動作を確認しやすいよう、ここでは1秒の遅延を入れています。

```tsx title="/app/index.tsx"
import React, { useState } from 'react';
import { Text, ScrollView, RefreshControl } from 'react-native';

const List = () => {
  const [refreshing, setRefreshing] = useState(false); // 새로고침 상태를 나타내는 상태 변수
  const [refreshTime, setRefreshTime] = useState(0);

  const handleRefresh = () => { // 새로고침 기능을 구현하는 함수
    setRefreshing(true);
    setTimeout(() => { // 1초의 딜레이
      setRefreshTime(refreshTime + 1); // 새로고침시 실행되는 함수
      setRefreshing(false);
    }, 1000);
  };

  return (
    <ScrollView
      style={{ flex: 1, backgroundColor: 'white', padding: 20 }}
      refreshControl={<RefreshControl refreshing={refreshing} onRefresh={handleRefresh} />}
    >
      {Array.from({ length: 100 }).map((_, index) => (
        <Text key={index} style={{ textAlign: 'center', justifyContent: 'center', fontSize: 30 }}>
          {`새로고침 ${refreshTime}회`}
        </Text>
      ))}
    </ScrollView>
  );
};

export default List;
```

## 3. その他のProps
RefreshControlのPropsは、基本的にViewコンポーネントのPropsを継承します。それに加えて、次のプロパティを利用できます。

### 3.1. colors / tintColor
colorsはAndroid専用、tintColorはiOS専用のプロパティです。どちらも更新アイコンの色を設定します。colorsには色の配列を指定し、Indicatorが表示されている間に色が順番に切り替わります。
[colorsプロパティの例](https://reactnative.dev/docs/colors)

```tsx title="/app/index.tsx"
// ... 
	<RefreshControl refreshing={refreshing} onRefresh={handleRefresh} colors={['blue', 'red', 'green']} /> // Android
	<RefreshControl refreshing={refreshing} onRefresh={handleRefresh} tintColor="blue" /> // iOS
// ...
```

### 3.2. enabled（Android）
更新機能を有効または無効にします。デフォルトはtrueです。

```tsx title="/app/index.tsx"
// ... 
	<RefreshControl refreshing={refreshing} onRefresh={handleRefresh} enabled={false} /> 
	// 새로고침 기능 비활성화 (Android)
// ...
```

### 3.3. progressBackgroundColor（Android）
更新アイコンの背景色を設定します。複数の色を指定するcolorsとは異なり、色は1つだけ指定できます。
```tsx title="/app/index.tsx"
// ... 
	<RefreshControl refreshing={refreshing} onRefresh={handleRefresh} progressBackgroundColor="blue" />
	// 새로고침 아이콘의 배경색 설정 (Android)
// ...
```

### 3.4. size（Android）
更新アイコンのサイズを設定します。デフォルトは`'default'`で、`'large'`にすると大きく表示されます。
```tsx title="/app/index.tsx"
// ... 
	<RefreshControl refreshing={refreshing} onRefresh={handleRefresh} size="large" />
	// 새로고침 아이콘의 사이즈 설정 (Android)
// ...
```

### 3.5. title、titleColor（iOS）
更新アイコンの下にタイトルを表示します。titleColorプロパティでタイトルの色を設定できます。
```tsx title="/app/index.tsx"
// ... 
	<RefreshControl refreshing={refreshing} onRefresh={handleRefresh} title="새로고침" titleColor="blue" />
	// 새로고침 아이콘 아래에 제목 표시 (Ios)
// ...
```

## まとめ
サーバーからデータを自動取得するだけでは不十分な場合、ユーザー自身が画面を更新できるようにしましょう。必要な画面にこの機能を適用すると、ユーザー体験を改善できます。
