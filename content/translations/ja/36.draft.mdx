## ハッシュ関数とは？ (What is a Hash Function)
> 任意のサイズのデータを入力し、固定サイズの出力を返す関数です。

- 例：ビットごとのXOR

| | Bit 1 | Bit 2 | ... | Bit n |
| --- | --- | --- | --- | --- |
| Block 1 | $x_{11}$ | $x_{12}$ | ... | $x_{1n}$ |
| Block 2 | $x_{21}$ | $x_{22}$ | ... | $x_{2n}$ |
| ... | ... | ... | ... | ... |
| Block m | $x_{m1}$ | $x_{m2}$ | ... | $x_{mn}$ |
| Hash Output | $y_1$ | $y_2$ | ... | $y_n$ |

例えば、二つのブロック$x_{11}, x_{12}, \ldots, x_{1n}$と$x_{21}, x_{22}, \ldots, x_{2n}$のXORを取り、$y_1, y_2, \ldots, y_n$を返します。

## 暗号学的ハッシュ関数 (Cryptographic Hash Function)
> 任意長のメッセージを入力し、*固定長のメッセージダイジェスト*を出力する関数$h$です。
暗号学的ハッシュ関数は、次の条件を満たす必要があります。
1. **計算効率** (Computational Efficiency)
   - 入力$m$が与えられたら、$h(m)$を効率よく計算できる必要があります。
2. **一方向性**、または**原像計算困難性** (One-way or Pre-image Resistance)
   - $y$が与えられたとき、$h(m')=y$を満たす$m'$を見つけることが、計算量的に不可能である必要があります。
3. **第二原像計算困難性**、または**弱衝突困難性** (Second Pre-image Resistance or Weak Collision Resistance)
   - $m$が与えられたとき、$h(m')=h(m)$を満たす$m'$を見つけることが、計算量的に不可能である必要があります。
4. **衝突困難性** (Collision Resistance)
   - $m, m'$について、$h(m)=h(m')$を満たす$m, m'$を見つけることが、計算量的に不可能である必要があります。

例：MD5、HAVAL-128、SHA-1、*SHA-2*、SHA-3。

### SHA-1とSHA-2のラウンド関数 (Round Function of SHA-1 and SHA-2)
<Img src="/posts/240613-144200.png" width={400}/>

1. 初期値
   - $A, B, C, D, E$
2. ラウンド関数
   - $f_t(B, C, D)$は、ラウンド番号$t$に応じて異なる論理演算を行います。
3. ビットの循環シフト
   - $A$と$B$を、それぞれ5ビット、30ビット循環シフトします。
   - ビットを左へ回転させ、最も左のビットは最も右へ移します。
4. 演算と更新
   - 各ラウンドで、$A, B, C, D, E$を、それぞれ$f_t$やほかの演算によって更新します。
   - $A = f_t(B, C, D) + K_t + W_t + E$のような式で更新します。

例：最初のラウンドでは、次の演算を行います。
- $A = ((A << 5) + f_t(B, C, D) + E + K_t + W_t)$
- $B = A$：元の$A$の値を$B$へ保存します。
- $C = B << 30$
- $D = C$
- $E = D$
