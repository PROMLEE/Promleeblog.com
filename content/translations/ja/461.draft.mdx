## はじめに

かばんを持って体重計に乗っても、増えた重さがすべて自分の体重とは考えないでしょう。
投資口座も同じです。
自分で200万ウォンを追加したなら、増えた残高から、そのお金を先に切り分けます。
**残高が増えたことと、投資でお金を得たことは別です。**
<br/>
今回は3口座をまとめた投資資金全体を見ます。
まず「いくら得たか」に答え、次に「いつ入れたお金か」を確認します。
作るのは、**開始額、終了額、入出金、投資結果を記録する成績表**です。
リターンの英語名はあとで出てきます。初めて読む場合は、いくら追加していくら残ったかから追ってください。

<Rbox>
本文の計算は理解のための例であり、投資の推奨ではありません。
PortRhythmの画面はテスト用アカウントのデータで、本文の金額と異なる場合があります。
</Rbox>

## 残高は320万ウォン増え、投資で得たのは120万ウォン

最初は1,000万ウォンありました。
途中で自分のお金を200万ウォン追加し、最終残高は1,320万ウォンです。
増えた320万ウォンから追加した200万ウォンを引くと、投資で増えたのは120万ウォンです。

> 1,320万 − 1,000万 − 200万 = 120万ウォン

入金から出金を引いた金額を「純入金」と呼びます。
200万ウォンを入れて50万ウォンを引き出したなら、純入金は150万ウォンです。
**最終残高 − 開始残高 − 純入金**で、投資損益を照合できます。
ただし、資産、取引、費用に抜けがなく、同じ範囲の残高を比較する必要があります。
<br/>
120万ウォンは利益の金額です。
当初の1,000万ウォンで割ると12%、追加分を含む1,200万ウォンで割ると10%です。
どちらかをそのまま「自分のリターン」と書く前に、もう1つ問いがあります。
**追加した200万ウォンも、最初から投資されていたのでしょうか。**
1日だけ投資したお金と、1年間投資したお金は、同じ値動きを経験していません。

## 口座間の振替は新規入金か

A口座からB口座へ50万ウォンを移したとします。
2つの口座をまとめて管理していれば、家の中で部屋を移っただけです。
投資資金全体に、新しいお金は入っていません。
こうした移動を「内部振替」、決めた投資範囲の外とのやり取りを「外部入出金」と区別します。

| 起きたこと | 3口座全体での扱い |
| --- | --- |
| 給与口座から投資口座へ200万ウォン入れる | 外部入金 +200万ウォン |
| 投資口座Aから投資口座Bへ移す | 内部移動、新規入金0ウォン |
| 分配金を口座内に残す | 投資で生じた現金。新しい元本の入金ではない |
| 生活費として10万ウォン引き出す | 外部出金 −10万ウォン |
| 売買手数料を払う | 投資費用。元本の引き出しとは区別 |

A口座だけで計算するなら、Bへ送ったお金はAの外への出金です。
だからこそ、**どこまでをひとまとまりとするかを先に決めます。**
一方の口座から引き、もう一方にまだ入れていない場合は、残高を確認する時点もそろえます。

## 同じ200万ウォンでも、投資を始める日が違う

追加投資の時点が異なる2人を比べます。
どちらも最初は1,000万ウォンを持ち、200万ウォンを一度追加します。
1人は最初に、もう1人は途中で入れます。
<br/>
期間は `2025-01-01` から `2026-01-01` までの365日です。
同じ投資対象の価値が**100 → 120 → 110**と動いたと仮定します。
最初から最後までは+10%ですが、途中の120で入ると、110に下がる区間だけを経験します。
どちらも追加資金をすぐ同じ対象に投資し、同じ価格推移をたどります。
分配金、手数料、税、為替変動は0とします。
<br/>
当初の1,000万ウォンは、どちらも1,100万ウォンになります。
**違いは、追加した200万ウォンがどの区間に投資されたか**から生じます。

- **最初に入れた200万ウォン**
  100から始まり110になったので、220万ウォンになります。
  最終合計は `1,100만 + 220만 = 1,320만 원`（1,320万ウォン）です。
- **途中で入れた200万ウォン**
  120で投資を始め110になったため、`200만 × 110 ÷ 120` で、約183万3,333ウォンになります。
  最終合計は約1,283万3,333ウォンです。

2人の記録を並べます。
表は韓国時間、ウォン建てです。開始日と中間日には09:00に評価し、09:01に入金します。その1分間に価格は変わらないとします。

| 時点・出来事 | 最初に追加した人 | 途中で追加した人 |
| --- | ---: | ---: |
| 2025-01-01の開始残高 | 1,000万ウォン | 1,000万ウォン |
| 同日に200万ウォンを追加したあと | 1,200万ウォン | 1,000万ウォン |
| 2025-07-02の追加前 | 1,440万ウォン | 1,200万ウォン |
| 同日の中間入金後 | 1,440万ウォン | 1,400万ウォン |
| 2026-01-01の最終残高 | 1,320万ウォン | 約1,283万3,333ウォン |

計算は丸める前の値で行い、表示は1ウォン単位に丸めています。
今回の値動きでは、最初の追加資金が上昇区間にも投資されていたので、結果が良くなりました。
今後も必ず早く入れるほうが有利というルールではありません。

## リターンで答える2つの問い

ここで、異なる名前のリターンが必要な理由を見ます。
最初は、次の2つの問いを区別できれば十分です。

| 知りたいこと | 指標 | 結果 |
| --- | --- | --- |
| 入金した時点の影響を除くと、投資対象はどれだけ動いたか | 時間加重収益率（TWR） | どちらも10% |
| 自分が入れた金額と日付を考慮するとどうなるか | 金額加重収益率。ここではXIRRで計算 | 最初は年率10%、途中は年率約7.59% |

時間加重収益率は、入出金のたびに区間を分け、それぞれの区間のリターンをつなげます。
今回のように投資の値動きが同じなら、入金日が違っても10%です。
金額加重収益率は、**いくら、いつ入れたかまで反映した、自分の資金の成果**です。
この2つの視点は、CFA Instituteの成績評価資料でも区別されています。
[CFA Instituteの成績評価](https://rpc.cfainstitute.org/sites/default/files/-/media/documents/book/rf-publication/2017/rf-v2017-n3-1.pdf)
<br/>
`XIRR` は、日付が不規則な入出金から金額加重収益率を計算するExcel関数です。
結果は年率換算で表示されます。
今回は期間自体が365日ですが、1か月の記録から求めた年率を、その月に実際に得たリターンとして読まないようにします。
[MicrosoftのXIRR関数](https://support.microsoft.com/ko-kr/excel/functions/xirr-function)

## 成績表の基本4行

リターンの名前を付ける前に、損益を照合します。

| 記録する内容 | 最初に追加 | 途中で追加 |
| --- | ---: | ---: |
| 開始額 | 1,000万ウォン | 1,000万ウォン |
| 終了額 | 1,320万ウォン | 約1,283万3,333ウォン |
| 外部からの純入金 | 200万ウォン | 200万ウォン |
| 投資で増えた額 | **120万ウォン** | **約83万3,333ウォン** |

隣に計算の目的とリターンの名前を書きます。
この例ではTWRはどちらも10%、XIRRはそれぞれ年率10%と年率約7.59%です。
120万ウォンを当初の1,000万ウォンで割った12%は単純な比較値で、入金日を考慮したリターンではありません。
<br/>
証券会社の「平均取得単価に対する収益」も、違う問いに答えている場合があります。
現在残る株式だけか、売却済みの利益や引き出した分配金も含むかを確認します。
**金額、期間、含めたお金が同じかを確認してから数値を比べます。**

<Bbox>
今日は、開始額、終了額、外部からの純入金、損益の4行を照合するだけでも十分です。
リターン計算に必要な中間残高がなければ、無理にパーセントを付けず、「追加資料が必要」と記録します。
下の計算は、自分の数値で再現したいときに読み進めてください。
</Bbox>

## 自分で計算する

### 区間をつなぐTWR

途中で追加した人は、入金前に1,000万ウォンが1,200万ウォンになりました。
第1区間のリターンは+20%です。
入金直後の1,400万ウォンから、最後の約1,283万3,333ウォンまでは約−8.33%です。
つなげると `1.20 × (110 ÷ 120) − 1 = 10%` です。
最初に追加した人も、入金直後の1,200万ウォンを出発点にすれば、同じ2区間になります。
<br/>
この計算には、**入出金の前後の残高**が必要です。
開始と終了の残高だけでは、途中の入金と価格変化を正確に分けにくくなります。
キャッシュフロー時点の評価と区間のつなぎ方は、GIPSの計算ガイドを参照できます。
[GIPSのリターン計算方法](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/)
実際には入金によって現金の保有状況や取引費用が変わるため、今回と同じ値動きとみなせるかも確認します。

### 日付と金額を入力するXIRR

XIRRは、口座ではなく**自分の財布から**見て入力するとわかりやすくなります。
投資に出したお金はマイナス、投資から受け取るお金や最後に残る価値はプラスです。
入金をプラスとした先ほどの残高表とは逆の視点です。

| 日付 | 最初に追加した人 | 途中で追加した人 |
| --- | ---: | ---: |
| 2025-01-01 | −12,000,000 | −10,000,000 |
| 2025-07-02 | 0 | −2,000,000 |
| 2026-01-01 | +13,200,000 | +12,833,333.333333 |

表の単位はウォンです。
開始残高は、その日に新たに入れたお金でなくても、計算開始日に投じた価値として書きます。
最終残高は、まだ売っていなくても、残存価値として1回だけ入力します。
売却代金を入力済みなら、同じ価値を足し直しません。
<br/>
Excelで、日付をA2:A4、最初に追加した人の金額をB2:B4、途中で追加した人の金額をC2:C4に書きます。
日付はExcelが日付として認識する値を入力し、結果のセルをパーセント表示にします。

```excel title="날짜와 금액으로 수익률 계산"
=XIRR(B2:B4,A2:A4)
=XIRR(C2:C4,A2:A4)
```

結果は、**最初は年率10.00%、途中は年率約7.59%**です。
途中の例で、丸める前の計算値は約7.586475%です。
XIRRは365日を基準に計算し、時刻の時と分は計算しません。
[MicrosoftのXIRR入力の基準](https://support.microsoft.com/ko-kr/excel/functions/xirr-function)

<Ybox>
XIRRには、資金を出すマイナスと、受け取るプラスの両方が必要です。
入出金が複雑に繰り返されると、答えが出なかったり、複数の答えがあり得たりします。
エラーが出たら、数値を勝手に変えず、まず日付、符号、記録の抜けを確認します。
</Ybox>

## 分配金と費用は一度ずつ反映する

口座に残した配当や分配金は、追加した元本ではありません。
口座内の現金として残高に含め、外へ引き出したなら出金も記録します。
分配金の詳しい例は[第7回](https://www.promleeblog.com/blog/post/464-portfolio-reading-distributions-cash)で確認できます。
分配前の100万ウォンが資産90万ウォンと現金10万ウォンに分かれたなら、合計は100万ウォンのままです。
<br/>
再投資を含むリターンに現金分配金を追加したり、残高から控除済みの手数料を再び引いたりしません。
ウォン建てで成績を見るなら、残高と入出金をウォン建てにそろえ、外貨の入出金で使ったレートも記録します。
自分の成績表に、費用、分配金、為替をどう反映したかも書きます。

## PortRhythmで記録を照合する

PortRhythmの資産履歴で、**評価額の変化 → 同じ期間の純入金 → 純入金を除いた増減**を確認します。
資産の追加や数量修正で値が増えたなら、投資利益と混ざっていないかを見ます。
入力方法は[資産履歴ガイド](https://www.promleeblog.com/blog/post/443-portrhythm-asset-history-guide)を参照してください。

<Img src="/portrhythm-guide8-desktop-overview-20261009.webp" width={750} height={422} alt="評価額の変化、純入金、純入金を除いた増減を比較する資産履歴画面"/>

アプリも、**純入金を除いた増減は投資収益率ではない**と案内しています。
TWRとXIRRは、日付ごとの入出金と、その時点の残高を使って計算します。
<br/>
入金が期間の境界日にあれば、時刻も確認します。
2026年10月17日に確認した仕様では、開始残高の測定時刻より後から、最終残高の測定時刻までを集計します。
開始時刻とまったく同じ入出金は除き、終了時刻と同じものは含めます。
当日の入出金時刻が不明なら、アプリが確認を求めたり、増減の計算を保留したりする場合があります。

## おわりに

残高が320万ウォン増えても、新たに入れた200万ウォンを引くと、投資で得たのは120万ウォンでした。
同じ額を追加しても、いつ入れたかで結果が変わることも確認しました。
**まず利益の金額を照合し、そのあと知りたい問いに合うリターンを記録します。**
<br/>
[PortRhythmの資産履歴](https://pf.promleeblog.com/?view=history)で開始と終了の残高、外部入出金を並べて書いてみてください。
次回は最終リターンが同じでも、途中の下落が異なることを見ます。
いくら得たかに加え、どこまで下がっても計画を守れるかを書いてみます。
