# 다국어 포스팅

한국어 URL은 유지합니다. 영어 `/en`, 일본어 `/ja`, 중국어 간체 `/zh`에서
언어별 메뉴와 글을 제공합니다. URL로 언어를 결정하므로 브라우저 설정에 따라
검색엔진이나 독자에게 다른 본문을 제공하지 않습니다.

번역은 Codex가 작성한 MDX 파일입니다. 별도 번역 API나 DB 스키마 변경은 필요 없습니다.
한국어는 기존 DB를 사용하며, 번역 파일의 공개에는 코드 배포가 필요합니다.

## 작성과 공개

웹 프로젝트 디렉터리에서 실행합니다.

```sh
npm run translation -- prepare 109 en
npm run translation -- prepare 109 ja
npm run translation -- prepare 109 zh
```

`content/translations/언어/109.source.json`을 참고해 `109.draft.mdx`의
`title`, `description`, 본문을 번역합니다. `post_id`, `locale`, `source_hash`는 유지합니다.
코드 블록, URL, MDX 컴포넌트와 속성은 보존하고 제목·본문·이미지 설명을 번역합니다.
기존 초안은 자동으로 덮어쓰지 않습니다.
샘플로 109번 글의 세 언어 초안을 이미 작성해 두었으므로 해당 파일은 바로 수정할 수 있습니다.

검증한 번역을 공개 파일로 승격합니다. `--reviewed`는 검증 완료를 나타냅니다.
사람이 직접 검토할지 Codex가 검증 후 공개할지는 사용자가 결정합니다.

```sh
npm run translation -- publish 109 en --reviewed
```

공개 파일 `109.mdx`를 커밋·배포하면 노출됩니다. 초안과 원문 스냅샷은
공개 로더와 사이트맵에서 제외합니다. API 키나 비밀 토큰을 번역 파일에 넣지 않습니다.
공개 파일이 없으면 원문 링크와 번역 준비 중 안내를 표시하고 검색 색인을 막습니다.

## 원문 변경

원문 제목·설명·본문의 해시가 달라지면 기존 공개 번역에 원문 변경 안내를 표시합니다.
게시된 번역은 새 초안과 독립적이므로 수정 중에도 유지됩니다.
공개 명령은 원문 해시가 달라졌거나 잠긴 글이면 실패합니다.
기존 캐시 갱신 API는 세 언어 페이지도 무효화하지만 새 번역 파일의 배포를 대신하지 않습니다.

`TRANSLATION_SOURCE_URL`로 원문 조회 서버를 변경할 수 있습니다.
기본값은 `https://www.promleeblog.com`입니다. 신규 글은 원문 서버에 저장하여
실제 Post ID를 얻은 후 번역을 연결합니다.

카테고리·주제는 기존 데이터의 URL 식별자를 읽기 쉬운 표기로 사용합니다.
소개 페이지는 각 언어의 짧은 소개와 한국어 상세 원문 링크를 제공합니다.

## 검증

`npm run test:i18n`은 언어별 URL, 초안 비공개, 원문 변경 감지, 공개 명령의
실패 시 기존 번역 보존을 검증합니다. 테스트는 임시 디렉터리와 로컬 모의 원문 API를
사용하며 운영 DB나 번역 파일을 변경하지 않습니다.

## 운영 배포 전 전체 번역 검사

```sh
npm run translation:check -- --require-complete
```

현재 공개 글 목록과 세 언어 공개 파일을 비교하고, 원문 해시·필수 메타데이터·MDX
컴파일을 검사합니다. 누락이나 잘못된 파일이 있으면 실패합니다.
누락 ID와 검사 결과는 Git에서 제외한 `.translation-work/coverage.json`에 저장합니다.
전체 번역을 운영 배포할 때는 이 검사를 통과한 후 진행합니다.
언어 선택은 footer에 있으며, 한국어 메뉴 문구와 기존 메인·글 화면을 유지합니다.
통합 사이트맵 외에 `/en/sitemap.xml`, `/ja/sitemap.xml`, `/zh/sitemap.xml`도 제공합니다.
각 공개 번역과 원문에는 동일한 상호 hreflang 목록과 언어별 canonical을 제공합니다.
